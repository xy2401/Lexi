# 多模型独立练习规范

## 数据与文件边界

单元、目标词和文件名只来自 `public/data/duolingo-zs-en.json`，不得修改原始数据。练习可参考同模型本课讲解，保持辅助词和难度一致；不得参考原版或其他模型正文。

讲解使用普通 Markdown；练习写入同目录的 `<原始文件名去掉 .md>.test.md`。首课样例为 `public/data/duolingo-zs-en.gpt-6.1/001-喜好.test.md`。各版本可以缺课，不自动补用其他版本。

## Markdown 格式 2

新练习使用可直接阅读的 Markdown，少量标签负责划分题目和提供稳定标识。不要把题干、答案或讲解包在 JSON 代码块里。一级标题为 `# <单元名>练习`，所有内容放在唯一的 `<practice unit="单元编号" format="2">` 与 `</practice>` 之间。

文件开头写 `标题：…`、可选的 `辅助词：a, am, are`，随后是 `## 学习目标`。每个目标使用 `- ID | 名称 | 说明`，例如 `- possession | 分清我的、你的 | 用 my / your 说明所属关系。`。ID 使用小写字母、数字与连字符；不要使用 `recommended`、`review`、`listening`、`expression`。

题目示例：

```markdown
<exercise id="u001-possession-01" type="input" activity="write" goal="possession" stage="recall">

目标词：my, mother

### 题目
用英文写出“我的母亲”。

### 答案
- my mother

### 提示
- 先说明是谁的，再写人物称呼。

### 讲解
my 表示我的；my mother 是我的母亲。

</exercise>
```

`id` 不得重复或重新分配给不同题目；`goal` 引用本课目标；`stage` 使用 `recognize`、`build` 或 `recall`。`目标词：` 使用逗号分隔，全部来自原始词表。可添加 `### 场景`；`### 提示` 必须是由弱到强的非空列表。每题都需要题目与讲解。

## 题型与专用小节

| activity | type | 专用内容 |
| --- | --- | --- |
| `word-choice` 词义选择 | `choice` | 看词选义、句意理解或看中文选英文。 |
| `cloze` 补全句子 | `choice` | 用空缺句作题干，选出合适的词。 |
| `compose` 连词成句 | `compose` | `### 词块` 用 `I \| like \| English` 分隔；`### 答案` 列出所有合理句子。每个词块是单个词。 |
| `write` 英文填写 | `input` | `### 答案` 列表包含合理的单词、词组或句子变体。 |
| `matching` 词义配对 | `matching` | `### 配对` 使用 `- [book] book \| 书`，每组 2–6 对，英文、中文和 ID 分别唯一。 |
| `audio-choice` 听音选义 | `choice` | 增加 `### 听力`，其内容为英文朗读文本。 |
| `audio-spell` 听音拼写 | `input` | `### 听力` 放单词；`### 答案` 放可接受的拼写。 |
| `dictation` 句子听写 | `input` | `### 听力` 放句子；`### 答案` 放可接受的完整句子。 |

选择题使用 `### 选项`，每项为 `- [ID] 内容`；`### 答案` 只写正确选项 ID。`### 选项反馈` 用相同 ID 列表逐一解释选项。需要 2–5 个不同选项，干扰项针对真实误区。听力题的题干、场景和提示不得直接透露答案。

答案归一化大小写、连续空格、撇号和句末标点，不做模糊语义评分。配对必须完整且正确才算答对，提交前允许修改。所有作者内容作为文字展示，不执行 HTML 或脚本。旧格式 1 仅保留读取兼容性，新文件写格式 2。

## 教学与体验

按本课目标编写题库，不强制凑齐题型或固定题量。首页明确标明本单元、题型与实际题数；按题型的入口只筛选本单元题目。综合轮最多 8 题，覆盖学习目标并包含组句、回忆及可用的配对、听力题。设备不能朗读时保留听力入口和原因说明，综合轮跳过听力。

反馈停留到点击继续；错题不追加无限队列。提示、查看听力原文和答案影响独立作答记录。结果提供目标反馈和逐题回顾；巩固轮最多 4 题，优先使用相关变式题。

初次独立答对安排次日复习；跨天独立回忆使用 3、7、14 天间隔，同日纠正不提高间隔。答错、提示作答或查看答案立即进入待巩固。间隔是产品规则，不表示精确记忆概率。

## 发布与进度

`npm run build:course` 更新 `practiceUnitIds`，`npm run validate:course` 校验内容和清单。讲义校验拒绝练习标签与代码块；`.test.md` 不被识别为讲义。

`practiceItems`、`practiceSessions` 按模型、单元和稳定题目 ID 隔离。判题内容变化使旧题记录和未完成轮失效；解释、提示、题型展示名称和文件格式的调整不改变判题指纹。暂停或刷新保留草稿、配对和提示状态。清除学习进度同时清除新旧记录，保留版本偏好。

发布前检查解析错误、实际题量、配对判分、听力降级、保存重试、刷新恢复、版本隔离及桌面与手机操作。
