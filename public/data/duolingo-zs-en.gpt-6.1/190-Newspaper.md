# Newspaper

> Newspaper: Report on recent events

## 这一课要学会什么

读懂虚构新闻中的变化与事件，用 there has / have been 表示截至现在发生了什么。所有报道句子都是语言例子，不是实际新闻。

## 从“发生了什么”开始

**A:** Has there been any damage? 有没有发生损坏？  
**B:** There has been some damage, but no one was hurt. 有一些损坏，不过没有人受伤。

**damage** 作损坏这个名词通常不可数，所以搭配 **there has been**。若后面是复数，如 changes（变化），使用 **there have been**：There have been some changes. 已经有一些变化。

## 六种形式，按后面的数量选择

| 用法 | 单数或不可数 | 复数 |
| --- | --- | --- |
| 肯定 | there has been | there have been |
| 否定 | there hasn't been | there haven't been |
| 疑问 | has there been | have there been |

**There hasn't been a flood.** 没有发生洪水。**There haven't been any changes.** 没有发生变化。hasn't / haven't 是 has / have not 的缩写。

**Has there been an improvement?** 有没有改善？**Have there been any changes?** 有没有发生变化？问句把 has / have 放到 there 前，不写 There has been...? 来学习标准疑问句型。

been 是 be 的过去分词。选择 has 或 have，主要看后面所说事物的单复数与可数性，不看 there。

## 变化的方向，别读反

**increase** 是增加；**decrease** 是减少，两者都可作动词或名词。虚构例子：The number increased from ten to twelve. 数量从十增加到十二。

**improvement** 是改善；**unemployment** 是失业这一概念，通常不可数。an increase in unemployment 是失业增加；an improvement 不必然指每个指标都增加。读懂方向之后再看具体对象。

**recent** 是最近的：recent events，最近的事件。**most of the reports** 是这些报道中的大多数；**most of + 限定的群体** 不等于全部。也可以说 most reports，一般性地说大多数报道，不在这时多加 of。

## 常见事件词

**happen** 是发生：What happened? 发生了什么？**crash** 是碰撞、撞车，也可表示系统崩溃；**flood** 是洪水或淹没；**explode** 是爆炸；**warning** 是警告。它们不提供处理事件的步骤。

**involve** 是涉及、使参与：The report involves two towns. 报道涉及两个镇。**protest** 是抗议；**against** 表示反对、与……相对：a protest against the plan，反对这个计划的抗议。

**murder** 是谋杀；**shoot** 可以表示射击，也可在影像语境中表示拍摄。**shot** 是 shoot 的过去式和过去分词，也可作名词。例如 She shot a video. 她拍了一段视频，video 使这里的含义清楚。不把这个词每次都理解成枪击。

## 准确报道，也要保留未知

问 Has there been any damage? 不等于已经确认损坏。most of 不等于 every。用 recent、increase、decrease 等词时，要读清它们修饰什么；没有确认的信息不凭单个关键词补成结论。

## 常见错误

- damage、unemployment 通常不可数，搭配 has been。
- changes 是复数，搭配 have been。
- 疑问句是 Has / Have there been...?
- shot 可以谈拍摄，必须结合它的对象和语境。
