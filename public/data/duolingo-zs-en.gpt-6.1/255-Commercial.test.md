# Commercial练习

<practice unit="255" format="2">

标题：产品介绍：并列、否定与强调倒装
辅助词：it, they, the, a, is, are, bright, quiet, box, bag, blue, sell, lamps, books, ad, me, but, also, information, light

## 学习目标

- description | 理解产品描述与说法 | 区分产品性质、效果说法和价格表达。
- parallel | 并列两项与表达否定 | 使用 both、neither、nor 和 no。
- emphasis | 组织强调与条件结果 | 理解 not only 的位置、倒装与 otherwise。

<exercise id="u255-description-01" type="matching" activity="matching" goal="description" stage="recognize">

目标词：functional, artificial, boost, confidence, energy, impress

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] functional | 实用的、有相应功能的
- [p2] artificial | 人工的、人造的
- [p3] boost | 提高、增强
- [p4] confidence | 信心
- [p5] energy | 精力、能量
- [p6] impress | 给人留下深刻印象

### 提示

- 先分出性质、动作与名词。
- artificial 说来源，functional 说功能。

### 讲解

描述属性与报告效果说法是不同的任务。

</exercise>

<exercise id="u255-description-02" type="choice" activity="word-choice" goal="description" stage="recognize">

目标词：artificial, functional

### 题目

artificial light 一定是无法正常发挥作用的光吗？

### 选项

- [a] 不一定；artificial 主要说明它是人造的
- [b] 一定；artificial 与 defective 完全同义
- [c] 一定是自然产生的光

### 答案

a

### 选项反馈

- [a] 来源与是否有功能不同。
- [b] 有缺陷是 defective，不是 artificial 自带的含义。
- [c] 这与人造义项相反。

### 提示

- 区分来源与质量。
- 不要把人造直接等同于故障。

### 讲解

artificial light 是人造光，不自动说明品质。

</exercise>

<exercise id="u255-parallel-05" type="choice" activity="word-choice" goal="parallel" stage="recognize">

目标词：both, neither, nor

### 题目

Neither the box nor the bag is blue. 表示什么？

### 选项

- [a] 箱子和袋子都不是蓝色
- [b] 箱子和袋子都是蓝色
- [c] 只有箱子一定是蓝色

### 答案

a

### 选项反馈

- [a] neither…nor… 同时否定两项。
- [b] 那需要 both…and… 的肯定方向。
- [c] 这与 neither 对箱子的否定相冲突。

### 提示

- 把 neither 与 nor 一起看。
- 它们对应两项的否定。

### 讲解

neither A nor B 表示两者都不。

</exercise>

<exercise id="u255-emphasis-06" type="choice" activity="cloze" goal="emphasis" stage="build">

目标词：not only is

### 题目

补全：Not only ___ bright, but it is also quiet.

### 选项

- [a] is it
- [b] it is
- [c] do it

### 答案

a

### 选项反馈

- [a] 句首 not only 触发此处的 is 与主语倒装。
- [b] 这适合一般陈述语序，但本题句首强调结构使用倒装。
- [c] bright 前需要 be，不能用 do 直接连接形容词。

### 提示

- 看 not only 的位置在句首。
- bright 是形容词，需要 be。

### 讲解

Not only is it bright… 将 is 放在 it 前面。

</exercise>

<exercise id="u255-emphasis-09" type="choice" activity="word-choice" goal="emphasis" stage="recognize">

目标词：not only, not only is

### 题目

It is not only bright but also quiet. 这里要把 is 放到 it 前吗？

### 选项

- [a] 不用；not only 在这个句中并列两个形容词
- [b] 必须；任何 not only 都要求整句倒装
- [c] 必须删掉 is

### 答案

a

### 选项反馈

- [a] 句中结构保持 It is 的普通语序。
- [b] 位置和结构不同，不能一律倒装。
- [c] 形容词前仍需要 be 作谓语。

### 提示

- 注意 not only 并不在句首。
- 它连接 bright 与 quiet。

### 讲解

句中的 not only 可并列成分，普通语序不变。

</exercise>

<exercise id="u255-emphasis-10" type="choice" activity="word-choice" goal="emphasis" stage="recognize">

目标词：not only do, did

### 题目

Not only do they sell lamps… 为什么 sell 不加 s？

### 选项

- [a] 前面已有 do，后面的实义动词用原形
- [b] 因为 sell 在这里是名词
- [c] 因为这句必须是过去时

### 答案

a

### 选项反馈

- [a] do 后使用 sell 原形。
- [b] sell 是卖这个动作。
- [c] do 在这里不是过去式；过去时助动词是 did。

### 提示

- 找到前面的助动词。
- 助动词后面的动词形式要匹配。

### 讲解

Not only do they sell… 中 do 提前，sell 仍用原形。

</exercise>

<exercise id="u255-emphasis-14" type="choice" activity="audio-choice" goal="emphasis" stage="recognize">

目标词：otherwise

### 题目

听一句话，选择 otherwise 的作用。

### 听力

Write down the name. Otherwise, you might forget it.

### 选项

- [a] 说明不写下名字可能发生的结果
- [b] 证明名字已经忘记了
- [c] 说明写下名字和忘记完全没有关系

### 答案

a

### 选项反馈

- [a] otherwise 在这里是否则。
- [b] might forget 是可能结果，不是已完成事实。
- [c] 句子明确用否则连接两种情况。

### 提示

- 先听前一句要求的动作。
- 后一句提出没有做时的可能结果。

### 讲解

Write down the name. Otherwise, you might forget it. 用 otherwise 连接否则的结果。

</exercise>
