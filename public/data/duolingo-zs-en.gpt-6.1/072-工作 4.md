# 工作 4

> 在工作场合向人求助

## 这一课要学会什么

在工作场合明确提出求助，说明设备或任务的问题。区分 ask for、help with，认识 everyone 类人物词的单数搭配，并用 could、might、must 表达请求、可能和要求。

## 向同事求助

**A:** Could you help me with this machine? 你能帮我处理这台机器的问题吗？  
**B:** What's wrong? 怎么了？  
**A:** Unfortunately, it's broken. 很遗憾，它坏了。  
**B:** Let's ask for help. 我们求助吧。

you、me、this、what's、wrong、it's、let's 是前课或辅助词。**machine** 是机器，**broken** 在这里是坏了的状态；**unfortunately** 表示很遗憾、不幸的是。

## ask for 与 help with

**ask for** 是请求得到某物：**Ask for help.** 寻求帮助。**help** 可作名词帮助，也可作动词帮忙。

**help with** 后接需要帮忙的对象：**Could you help with the email?** 你能帮忙处理这封邮件吗？the 是辅助词，**email** 是邮件。

ask the customer 是询问那位顾客，ask for help 是索取帮助。**customer** 是顾客，不把问一个人和请求得到什么混成同一个结构。

## could、might、must 的不同作用

**could** 在本课是礼貌请求：Could you help? **might** 是可能：**Somebody might know.** 可能有人知道，know 是辅助词。它不保证一定有人知道。

**must** 是必须：**I must complete the report by Friday.** 我必须在星期五前完成报告。I、report、Friday 是辅助词，**complete** 是完成，**by** 在这里给最迟时间。

could / might / must 后都用动作原形，不写 must completes。要求强度与发生可能性不同，不能只因为三个词都在动作前，就当作同义词。

## anybody、somebody、everybody

**anybody** 是任何人、有人，常用在问句或否定；**somebody** 是某人；**everybody** 是每个人。**Can anybody help?** 有人能帮忙吗？can 是辅助词。

**Everybody is busy.** 每个人都很忙，is、busy 是辅助词。虽然指许多人，这类 everybody 主语在本课按单数配动词，不写 Everybody are busy。

**several** 是几个，后接复数：several customers，几位顾客；customers 是辅助复数。它与 somebody 的不确定单个人物不同。

## 讨论、会议室与日程

**discuss** 是讨论，直接接内容：**Discuss the problem.** 讨论这个问题，problem 是辅助词。不在本句写 discuss about the problem。

**discussion** 是讨论这个名词，**a discussion about the problem**，关于问题的讨论；a、about 是辅助词。动词与名词搭配不同。

**meeting room** 是会议室，**daily / weekly / regular** 是每天的／每周的／定期、常规的：a weekly meeting，每周的会议；meeting 是辅助词。regular 只给规律性，不一定等于每天。

## 尝试、工作与回应

**try** 是尝试：**Try to complete the task.** 尝试完成任务。task 是辅助词，**to** 连接尝试做的动作。

**work** 作动词是工作，也可表示设备运行：**The machine doesn't work.** 机器不运转，doesn't 是辅助词。**thing** 是东西、事情；business（业务、生意）给出更具体的活动范围。

**how** 在 **How does the machine work?** 中问方式、原理：“这台机器如何运转？”does 是问句中的辅助词，后面保留 work 原形。how 问如何，不等于问谁能来帮忙。

**hurry** 是赶紧、匆忙：**Don't hurry.** 别急，don't 是辅助词。**Good job!** 做得好！是对工作的肯定，**good job** 不等于一份工作职位。**sir** 是先生、对男性的礼貌称呼，可用于有这个称呼习惯的服务场景。

求助先讲对象和问题，再说需要何种帮助。期限、可能性与请求用不同词表达，礼貌称呼和肯定也不替代具体任务信息。
