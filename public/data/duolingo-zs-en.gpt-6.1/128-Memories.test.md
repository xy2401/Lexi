# Memories练习

<practice unit="128" format="2">

标题：童年习惯、一次经历与现在的变化
辅助词：be used to, I, be, did, friends, yes, we, play, cards, the, eat, catch, kick, a, ball, in, my, teacher, was, what, you, grow, tell

## 学习目标

- habits | 比较过去习惯与现在 | 使用 used to / never used to、now 和 shy / strict。
- events | 叙述童年经历与对象 | 使用 caught / kicked、动物、部位和邻里词汇。
- home | 介绍拜访、器具和活动 | 使用 come over、card / trumpet、食品与 joke。

<exercise id="u128-habits-01" type="matching" activity="matching" goal="habits" stage="recognize">

目标词：childhood, used to, never used to, now, shy, strict

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] childhood | 童年
- [p2] used to | 过去常常／过去是
- [p3] never used to | 过去从不
- [p4] now | 现在
- [p5] shy | 害羞的
- [p6] strict | 严格的

### 提示

- 时间、习惯与性质不同。

### 讲解

never 不能遗漏。

</exercise>

<exercise id="u128-habits-02" type="choice" activity="cloze" goal="habits" stage="build">

目标词：used to, trumpet

### 题目

I used to ____ the trumpet.

### 选项

- [a] play
- [b] played
- [c] playing

### 答案

a

### 选项反馈

- [a] used to 后接动作原形。
- [b] 不用过去式 played。
- [c] 不是 used to + -ing 的本课结构。

### 提示

- 过去习惯已经由 used to 表达。

### 讲解

I used to play the trumpet.

</exercise>

<exercise id="u128-events-10" type="choice" activity="word-choice" goal="events" stage="recognize">

目标词：caught, used to

### 题目

I caught a frog. 本句是否直接说明我以前经常抓青蛙？

### 选项

- [a] 没有，只报告过去抓到过。
- [b] 是，caught 永远表示天天抓。
- [c] 是，而且我现在仍每天抓。

### 答案

a

### 选项反馈

- [a] 没有习惯频率表达。
- [b] 过去形式不自动给频率。
- [c] 没有现在或每天信息。

### 提示

- 区别一次过去动作与过去习惯。

### 讲解

习惯需要 used to 或其他频率语境。

</exercise>
