# Internet练习

<practice unit="204" format="2">

标题：比较技术习惯，说明正在适应
辅助词：I, am, are, you, this, one, use, using, it, file, account, day, week, changes, at

## 学习目标

- habits | 区分过去与适应 | 使用 used to do、get used to doing 与频率表达。
- terms | 分清设备与角色 | 识别 browser、server、user 和设备名词。
- actions | 读懂常用动作 | 使用 press、locate、log out of 和 take a look。

<exercise id="u204-habits-01" type="choice" activity="word-choice" goal="habits" stage="recognize">

目标词：used to, get used to

### 题目

I used to use it. / I am getting used to using it. 依次表示什么？

### 选项

- [a] 过去常用／正在适应用
- [b] 正在安装／已经删除

### 答案

a

### 选项反馈

- [a] 一个说过去习惯，一个说当前适应。
- [b] 这些句子没有安装或删除的意思。

### 提示

- 观察 use 与 using 的位置。

### 讲解

两个 used to 结构不能直接互换。

</exercise>
