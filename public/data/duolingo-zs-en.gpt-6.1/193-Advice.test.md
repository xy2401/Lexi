# Advice练习

<practice unit="193" format="2">

标题：想象负责时，会怎样安排
辅助词：I, he, she, we, they, would, in, charge, change, ask, first, different, choose, jacket, need, enter, audience

## 学习目标

- hypothesis | 表达假设与结果 | 使用 if ... were 与 would + 原形。
- decisions | 说明许可与安排 | 区分 permission / permit、课程、角色与路线。
- meaning | 判断状态与语境 | 识别态度副词、多义词与提醒表达。

<exercise id="u193-hypothesis-01" type="choice" activity="word-choice" goal="hypothesis" stage="recognize">

目标词：if you were

### 题目

If you were in charge, what would you change? 本课中在做什么？

### 选项

- [a] 想象由你负责的情况
- [b] 已确认你昨天负责过

### 答案

a

### 选项反馈

- [a] 不是单凭 were 在回忆过去。
- [b] 句子没有确认这个事实。

### 提示

- 注意 would 和假设场景。

### 讲解

if ... were 可表达与当前不同的想象。

</exercise>

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] if he were | 如果他处在某种假设情况
- [p2] if she were | 如果她处在某种假设情况
- [p3] if they were | 如果他们处在某种假设情况

<exercise id="u193-decisions-08" type="choice" activity="word-choice" goal="decisions" stage="recognize">

目标词：permission, permit

### 题目

哪一组都自然？

### 选项

- [a] We need permission. We need a permit.
- [b] We need a permission. We need permit.

### 答案

a

### 选项反馈

- [a] 一般许可不可数；一份许可证可数。
- [b] 两个冠词与名词用法都不合本题语境。

### 提示

- 区分许可概念与一份文件。

### 讲解

permission 通常不直接加 a。
