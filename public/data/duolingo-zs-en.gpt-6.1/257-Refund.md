# Refund

> Refund: Explain a product issue

## 把产品问题说具体

这一课使用虚构的客服对话，学习说明问题、询问要求和辨别回答。退款、保证和政策等词用于英语表达，不代表某家店的实际规则。

## 一个虚构的问答

A: I think the item is defective. May I ask about a refund?  
B: Could you state the problem?  
A: It does not work. Must I provide proof of purchase?  
B: In this example, yes. We can explain the process.

甲：我觉得这个物品有缺陷。我可以问一下退款吗？乙：能说明问题吗？甲：它不能工作。我必须提供购买凭证吗？乙：在这个例子里，是的。我们可以说明处理流程。

item 是物品，provide 是提供，explain 是解释；does not work 表示不能正常工作。对话中的回答属于虚构场景，不推广为其他商家的规定。

## 缺陷、不可用与没有问题

**defective** 是有缺陷的、有故障的；**unavailable** 是不可获得的、暂时无法提供的；**useless** 是没用的。一个物品 unavailable，不一定 defective；可能只是暂时没有。

**no good** 是不好、没有用，常见于 be no good：This old device is no good. 这个旧设备不好用。device 是设备；no good 是口语评价，比具体指出问题更笼统。

**nothing wrong with** 常见于 There is nothing wrong with…，表示……没有问题：There is nothing wrong with the box. 箱子没有问题。wrong 在这里是有问题的，with 后接检查对象。

**waterproof** 表示防水的。water-resistant 通常表示有一定抗水性，不能直接把两种名称当作完全相同的承诺；具体产品能力还要看它的描述。本课只学习形容词。

## 凭证、退款和承诺

**proof of purchase** 是购买凭证；**sticker** 是贴纸、标签贴；**refund** 可作名词表示退款，也可作动词表示退还款项。**full refund** 是全额退款，full 说明退款金额的完整程度，不说明一切附加费用或条件。

**guarantee** 可作名词表示保证、承诺，也可作动词表示保证：The label mentions a guarantee. 标签提到了一项保证。label 是标签；要知道保证什么，仍需有具体内容。

**satisfaction** 是满意、满足：customer satisfaction 是顾客满意度。customer 是顾客；满意度与是否有缺陷是不同的概念。

## 人、服务和处理流程

**service** 是服务；**supervisor** 是主管、监督者。The supervisor explains the service. 主管解释了这项服务。

**policy** 是政策、规则、方针；**process** 可作名词表示过程、流程，也可作动词表示处理：explain the process 是说明流程；process a request 是处理一个请求。request 是请求。

**state** 可作动词表示陈述、说明，也可作名词表示状态或州。Please state the problem clearly. 请清楚地说明问题。clearly 是清楚地；这里 state 是动作，不是地名。

**carefully** 是仔细地、谨慎地：Read the message carefully. 仔细读这条消息。message 是消息；carefully 修饰 read 的方式。

**speak politely to** 是礼貌地对某人说话：speak politely to the supervisor 是礼貌地和主管说话。politely 修饰说话方式，to 连接交谈对象。

**in need of** 表示需要……：The device is in need of repair. 设备需要维修。repair 是维修；in need of 后接名词类内容。

## Must I 与 Must we：必须吗？

**must I** 常见于 Must I…? 我必须……吗？**must we** 是 Must we…? 我们必须……吗？情态动词移到主语前，后面用原形：Must we wait? 我们必须等待吗？

若肯定回答，可说 Yes, you must. 若表示不必，可说 No, you don't have to. 对比 You must not… 是不允许……、禁止……。不必做与不准做不是同一件事。

## everybody 与 their 并不冲突

**everybody** 是每个人，作主语通常按单数处理；**their** 可表示他们的，也可在不指定性别时回指 everybody 等不定代词：Everybody has their own questions. 每个人都有自己的问题。has 配合 everybody，their 回指每个人；own 是自己的。

## 易错点

- defective 是有缺陷，unavailable 是暂不可得，不要把缺货直接当故障。
- nothing wrong with 后接对象；in need of 后接所需内容。
- state the problem 中 state 是说明；process a request 中 process 是处理。
- Must I / Must we 后接原形；don't have to 表示不必，must not 表示不准。
- everybody has 用单数谓语；their 可回指不指定性别的每个人。
