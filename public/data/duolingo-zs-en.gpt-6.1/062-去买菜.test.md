# 去买菜练习

<practice unit="62" format="2">

标题：市场购物、有无、数量与计量
辅助词：on, the, to, carrots, yes, we, need, a, some, of, grapes, onions, one, thousand, grams, bag, is, dinner, was, at, isn't, look for

## 学习目标

- availability | 按对象数量询问有无 | 区分 is there / are there / is there any 与 there is no。
- quantity | 选择合适数量与单位 | 使用 a few、too many / much、piece、gram / kilogram。
- shopping | 认识食品并核对清单 | 使用 make / add、食品词、场所、fresh / heavy / price 和 look。

<exercise id="u062-availability-03" type="matching" activity="matching" goal="availability" stage="recognize">

目标词：is there, are there, is there any, there is, there is no, no

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] is there | 询问单数／不可数对象是否有
- [p2] are there | 询问复数对象是否有
- [p3] is there any | 询问是否有某不可数对象（本题）
- [p4] there is | 有一个／不可数对象
- [p5] there is no | 没有某单数／不可数对象
- [p6] no | 没有／不

### 提示

- 对象的数决定 be，不按中文猜。

### 讲解

tofu 在本课按不可数处理；carrots 是复数。

</exercise>

<exercise id="u062-availability-04" type="choice" activity="word-choice" goal="availability" stage="recognize">

目标词：is there any, tofu, are there

### 题目

询问“有豆腐吗？”哪句符合本课形式？

### 选项

- [a] Is there any tofu?
- [b] Are there any tofu?
- [c] Is there no any tofu?

### 答案

a

### 选项反馈

- [a] tofu 不可数，配 is。
- [b] 不能把本句 tofu 当作普通复数。
- [c] no 与 any 不这样叠加表达这个普通询问。

### 提示

- 先识别名词的数量用法。

### 讲解

Is there any tofu?。

</exercise>
