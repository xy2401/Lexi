# 时间

> 表达星期和时间

## 这一课要学会什么

问现在几点、活动几点开始，说明星期与上下午。区分 What time is it? 和 What time does…?，把主语与动词形式一起检查。

## 准备看比赛

**A:** What time is it? 现在几点？  
**B:** It's seven o'clock. 七点整。  
**A:** What time does the game start? 比赛几点开始？  
**B:** It starts at eleven. 十一点开始。

the、game、it、does 是前课或辅助词。**what time is it** 问当前时间；**what time does** 帮助询问一个第三人称单数主语的动作时间。后一问句不是继续问此刻钟上几点。

## 报钟点：it is 与 it's

**it is** 可缩写为 **it's**。**It is twelve o'clock.** 十二点整。**o'clock** 表示整点；**seven / eleven / twelve** 是七／十一／十二。

不需要整点标记时可说 **It's eleven.** 十一点。明确安排则用 **at**：**at seven** 在七点，**at twelve o'clock** 在十二点整。

**minute** 是分钟，辅助复数 minutes 表示多分钟：**five minutes** 五分钟。five 是前课数字。o'clock 是整点表达，minute 是时长单位，不是两个可随意替换的同义词。

## 活动问句：do / does 后回到原形

**start** 开始，**starts** 是第三人称单数形式：**The game starts at eleven.** 比赛十一点开始。

问句：**What time does the game start?** does 已承担第三人称变化，后面的 start 不再加 -s。不要写 What time does the game starts?。

**what time do** 用于 I / you / we / they 这类主语：**What time do you go to work?** 你几点去上班？you、we、they、I 是辅助代词。**go to** 是去某地的动作结构，**work** 在 go to work 中表示工作场所／上班，不需要再加 the。

**what time is** 则出现在 be 结构中：**What time is the game?** 比赛几点？这是询问比赛的时间安排，句中没有 start 这个普通动作。

## 星期、下午与钟点使用不同介词

**Thursday / Friday** 是星期四／星期五。**on Friday** 在星期五；on 是辅助词。

**afternoon** 是下午，**in the afternoon** 在下午。**The game starts at seven on Friday.** 比赛星期五七点开始。先把 at 配钟点、on 配星期、in 配下午各自记清。

**this** 是这个，**this afternoon** 是今天下午；这类时间词组前不再加 in：**The game starts this afternoon.** 比赛今天下午开始。

## late for：说迟到的对象

**late for** 是某事迟到：**I'm late for work.** 我上班迟到了。I'm 是辅助缩写。**The boy is late for the game.** 那个男孩参加比赛迟到了。**boy** 是男孩，is 是辅助词。

late for 不表示活动本身几点开始；要知道开始时间，还要问 What time does…start?。

## 几个补充词，不套进钟点句框

**right** 在答复信息时可以表示正确：**That's right.** 对了／那是对的。that's 是前课缩写。right 也有右边的意义，按语境区分。

**hot** 是热的；**wine** 是葡萄酒；**feet** 是 foot（脚）的复数，也可在测量场景表示多英尺，本课先复习身体部位意义。**much** 是很多的量，常见前课搭配 how much 询价，不能把询价用的 much 加进 What time is it? 来问时间。

问钟点先选句框，再检查有没有普通动作：有 start 就用 do / does 帮助提问；直接问时间则用 be。
