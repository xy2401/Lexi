# 运动练习

<practice unit="35" format="2">

标题：运动活动、建议与等待
辅助词：I'm, tennis, me, please, he, is, they, are, I, like, this, go, get, get up, early, here, it's, rain, snow, swim, sit, learn, to, you, the, looking for

## 学习目标

- movement | 描述正在进行的运动 | 认识 run / running、swimming、sitting 与速度表达。
- suggestion | 提出活动建议 | 使用 let’s、go outside / stay 及天气进行时。
- waiting | 说清等待与寻找 | 区分 wait for、waiting for、find 和 can’t find。

<exercise id="u035-movement-01" type="matching" activity="matching" goal="movement" stage="recognize">

目标词：run, running, swimming, sitting, shopping, learning

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] run | 跑（原形）
- [p2] running | 跑（-ing 形式）
- [p3] swimming | 游泳（-ing 形式）
- [p4] sitting | 坐（-ing 形式）
- [p5] shopping | 购物（-ing 形式）
- [p6] learning | 学习（-ing 形式）

### 提示

- 有些动词要双写最后一个辅音。

### 讲解

run / swim / sit / shop 在这些形式中双写末尾辅音。

</exercise>

<exercise id="u035-movement-02" type="choice" activity="word-choice" goal="movement" stage="recognize">

目标词：run, running

### 题目

run 的本课 -ing 形式是哪项？

### 选项

- [a] running
- [b] runing
- [c] runsing

### 答案

a

### 选项反馈

- [a] 先双写 n，再加 -ing。
- [b] 漏掉第二个 n。
- [c] 先不加第三人称 -s，再构成 -ing。

### 提示

- 这类形式不是原形直接只加三个字母。

### 讲解

run → running，不是 runing。

</exercise>

<exercise id="u035-movement-05" type="choice" activity="word-choice" goal="movement" stage="recognize">

目标词：learning, swimming

### 题目

表达“我正在学游泳”，哪句符合本课结构？

### 选项

- [a] I'm learning to swim.
- [b] I'm learning to swimming.
- [c] I learning to swim.

### 答案

a

### 选项反馈

- [a] learning 描述学习过程，to 后 swim 用原形。
- [b] to 后不使用 swimming。
- [c] 进行时缺少 am。

### 提示

- 只有描述当前过程的主要动作使用 be + -ing。

### 讲解

I’m learning to swim. 不把所有动词一起改成 -ing。

</exercise>

<exercise id="u035-waiting-13" type="matching" activity="matching" goal="waiting" stage="recognize">

目标词：wait, wait for, waiting, waiting for, find, can't find

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] wait | 等（原形）
- [p2] wait for | 等待某人或某事
- [p3] waiting | 等（-ing 形式）
- [p4] waiting for | 等待某对象（-ing 结构）
- [p5] find | 找到
- [p6] can't find | 找不到

### 提示

- 找到是结果，等待与寻找是过程。

### 讲解

</exercise>

<exercise id="u035-waiting-14" type="choice" activity="cloze" goal="waiting" stage="build">

目标词：waiting for

### 题目

I’m waiting ____ you.

### 选项

- [a] for
- [b] to
- [c] about

### 答案

a

### 选项反馈

- [a] 等待对象由 for 引出。
- [b] 本课 wait 的对象不这样用 to 引出。
- [c] about 常说话题，不是等待对象。

### 提示

- 动作变成 -ing 不改变本课的对象介词。

### 讲解

I’m waiting for you. 我在等你。

</exercise>
