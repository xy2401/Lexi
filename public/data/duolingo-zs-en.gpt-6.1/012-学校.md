# 学校

> 谈论学校

## 这一课要学会什么

谈学校、课程和考试，用 easy / difficult 说明难度，用 have / has 说明谁有什么。顺带认识 these 指多个东西，避免把单复数只当作词尾变化。

## 考前与同学聊天

**A:** We have an exam today. 我们今天有一场考试。  
**B:** Is the exam difficult? 考试难吗？  
**A:** We have many questions. The exam is important. 我们有很多问题。这场考试很重要。

we、is、the 沿用前课。**today** 是今天；**exam** 是考试；**questions** 是多个问题。这里的 questions 可以是想向老师提的问题，不能仅凭一句话判断一定是试卷上的题目。

## 学校、课、书与考试

| 词 | 含义 | 数量形式 |
| --- | --- | --- |
| school | 学校 | a school，一所学校 |
| class | 课；班级 | a class，一节课或一个班 |
| book | 书 | a book，一本书 |
| exam / exams | 考试／多场考试 | an exam / two exams |
| question / questions | 问题、题目／多个 | a question / many questions |

**an** 与 a 都表示“一个”。选 a 还是 an 看后面紧跟的发音：exam 以元音音素开头，使用 **an exam**。不是只看字母名称，也不是看到所有名词都加 an。

## have 与 has：根据谁拥有来选

**have** 表示有：**We have a book.** 我们有一本书。  
**has** 用于 he、she 等第三人称单数：**She has a book.** 她有一本书。

she 是前课的人物词。**They have an exam today.** 他们今天有一场考试。主语 **they** 是他们，搭配 have；不要因为后面的 exam 是单数，就改用 has。数量与动词变化分别由不同信息决定。

**many** 修饰可数复数：many books、many questions、many exams。这里的 books 是 book 的复数辅助词形。many question 少了名词复数标记。

## 判断难度、重要性与评价

- **easy**：容易的。The exam is easy. 考试容易。
- **difficult**：困难的。The exam is difficult. 考试难。
- **important**：重要的。This question is important. 这个问题很重要。
- **cool**：酷的、不错的；也可以说凉爽。谈课程评价时可说 This class is cool. 这门课挺酷。

this 沿用前课。important 说重要程度，不等于 difficult；一场容易的考试仍然可能重要。

**pass** 在考试语境中是通过：**I pass the exam.** 我通过考试。这里是一般表达，I 是辅助主语；实际讲一次已经发生的考试经历，英语通常要使用过去式 passed，后续课程会系统学习。

## that is 与 these

**that is** 是“那是”，通常介绍单个、较远或刚提到的东西：**That is a book.** 那是一本书。

**these** 是“这些”，指多个、较近的东西：**These are books.** 这些是书。are 沿用前课。不要写 These is a book：these、is、a book 的数量彼此冲突。

## 少量能力与两个补充词

**speak** 是说、讲，**a little** 是一点。**I speak a little English.** 我会说一点英语。English 沿用前课；这与 many questions 的结构不同，语言量不靠给 English 加复数表示。

**exact** 是准确的、精确的。补充名词 answer 表示答案：**the exact answer** 是准确的答案。exact 说精确，不说轻松或酷。

**glass** 可以是玻璃或一个玻璃杯；本课先认识可数的 **a glass**（一个玻璃杯），与前课 a cup 的容器概念并列。玻璃材料这个意义通常不可数，不把所有 glass 都机械加 -s。

从主语到数量逐项检查：they 决定 have，many 决定 questions，these 决定 are。
