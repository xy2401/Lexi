# Store

> Store: Request help with returns

## 这一课要学会什么

说清物品问题，询问退货、换货或替换。例句中的商店与处理结果都是虚构的，不表示实际退货权利或商家政策。

## 先描述问题，再问能否处理

**A:** The shirt is damaged. Could I return it? 衬衫损坏了。我可以退回吗？  
**B:** Would you like an exchange? 你想换货吗？

**damaged** 是损坏的；**return** 在商店语境中是退回、退货。把物品退回不自动等于一定获得退款。

**exchange** 是交换、换货；**replace** 是替换、用另一个代替：Could you replace this shirt? 你能替换这件衬衫吗？exchange 可说换款、换尺码等；replace 强调替代原物品。具体结果还要看对话。

## 退款与店内额度不是一回事

**money back** 是退款、把钱退回：I'd like my money back. 我希望退款。**store credit** 是店内额度，通常用于以后在该店消费，不直接等同于现金退款。

这两个词帮助理解对方提出什么；它们不说明任何实际商店必须接受哪种处理。

**would** 可用于礼貌愿望：I would like an exchange. 我想换货。**wouldn't** 是 would not，也可表示过去不肯：The clerk wouldn't replace the shirt. 店员当时不肯替换这件衬衫。clerk 是店员。结合语境区分愿望、假设与过去拒绝。

## 物品哪里有问题

**button** 是纽扣；**collar** 是衣领；**label** 是标签。**stain** 是污渍，也可作动词表示弄脏：There is a stain on the collar. 衣领上有污渍。

**off** 可表示脱离、掉下：The button came off. 纽扣掉了；在其他语境也可表示折扣或关闭。**still** 是仍然：The shirt is still damaged. 衬衫仍然有损坏，不因为 still 就表示静止不动。

## 样式、材质与商品名称

**pattern** 是图案、式样；**stripe** 是条纹，多个条纹可用 stripes。a striped shirt 是有条纹的衬衫；striped 是辅助形容词。

**silk** 是丝、丝绸，通常按不可数材料使用；**thick** 是厚的。材质与厚度是两种不同属性：a thick coat，一件厚外套；a silk shirt，一件丝绸衬衫。

**bra** 是胸罩；**diamond** 是钻石。这些是商品名词，不根据购买物品推断一个人的身份或经济情况。

## 组织一个简短请求

描述：There is a stain on the collar. 衣领有污渍。

询问：Could I return it? 我可以退回吗？

偏好：I'd like my money back. 我希望退款。

先说明想要的处理，再听对方答复。return、exchange、replace、money back、store credit 分别表达不同动作或结果。

## 常见误区

- I would like... 后可直接接名词；would like to 后接动作原形。
- damaged 描述状态；replace 描述替换动作。
- label 是标签，collar 是衣领，button 是纽扣。
- store credit 不直接等于 money back；return 不保证结果。
