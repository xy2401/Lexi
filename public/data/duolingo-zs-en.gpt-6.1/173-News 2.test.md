# News 2练习

<practice unit="173" format="2">

标题：询问属实与间接问句语序
辅助词：report, made, town, votes, school, decision, speech, lost, kitten

## 学习目标

- verify | 询问是否属实 | 使用 true、wonder if 和过去表达。
- society | 社会与评价 | 辨认社会、环境、人物和主观评价。
- reports | 报道词与范围 | 理解时间、数量、进展和事件词。

<exercise id="u173-verify-01" type="choice" activity="word-choice" goal="verify" stage="recognize">

目标词：wonder if, true

### 题目

哪个句子表示“我想知道报道是否属实”？

### 选项

- [a] I wonder if the report is true.
- [b] I wonder if is the report true.
- [c] I wonder the report true is if.

### 答案

a

### 选项反馈

- [a] if 后使用主语在前的陈述语序。
- [b] 间接问句不倒装。
- [c] 词序不成立。

### 提示

- if 后先放主语。

### 讲解

I wonder if + 主语 + 动词。

</exercise>

### 题目

### 选项

### 答案

a

- [a] 与 book 结合说书展。
- [b] 这里 fair 是可数名词，不是评价形容词。
- [c] battle 才是战斗。

### 提示

- 看 a book fair 这个名词结构。

### 讲解

fair 有集市、展会的名词义。

<exercise id="u173-society-10" type="choice" activity="word-choice" goal="society" stage="recognize">

目标词：powerful, true

### 题目

A powerful speech. 这个评价能直接证明什么？

### 选项

- [a] 演讲有力量或感染力
- [b] 每句内容都属实
- [c] 演讲者一定是市长

### 答案

a

### 选项反馈

- [a] powerful 是强度或影响评价。
- [b] 感染力不证明真实性。
- [c] 没有身份信息。

### 提示

- 不要把评价扩大为事实证明。

### 讲解

powerful 与 true 描述不同性质。
