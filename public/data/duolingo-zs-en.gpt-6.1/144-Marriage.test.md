# Marriage练习

<practice unit="144" format="2">

标题：询问准备情况、关系与联系频率
辅助词：date, arrive, arrived, yesterday, view, warm, before, meet

## 学习目标

- status | 准备情况 | 选择完成表达和过去问句。
- events | 活动与关系 | 辨认庆祝活动及状态词。
- contact | 近况与频率 | 表达最近、很少和更经常。

<exercise id="u144-status-01" type="choice" activity="word-choice" goal="status" stage="recognize">

目标词：have, has

### 题目

询问“她定好日期了吗？”哪句正确？

### 选项

- [a] Have she set a date?
- [b] Has she set a date?
- [c] Has she sets a date?

### 答案

b

### 选项反馈

- [a] she 用 has。
- [b] has 后接 set 的过去分词。
- [c] has 后不用第三人称 sets。

### 提示

- 主语是 she。

### 讲解

Has she set a date?

</exercise>

<exercise id="u144-status-05" type="choice" activity="word-choice" goal="status" stage="recognize">

目标词：did, have

### 题目

明确询问“昨天定日期了吗？”本课选哪句？

### 选项

- [a] Did you set a date yesterday?
- [b] Have you set a date yesterday?
- [c] Did you has set a date yesterday?

### 答案

a

### 选项反馈

- [a] yesterday 对应过去一次动作。
- [b] 完成表达不与这个明确结束的过去时间这样搭配。
- [c] did 后直接用原形 set，不加 has。

### 提示

- 过去问句用 did。

### 讲解

Did you set…yesterday?

</exercise>

<exercise id="u144-events-09" type="choice" activity="word-choice" goal="events" stage="recognize">

目标词：nice and, peaceful

### 题目

a nice and peaceful place 最自然地表达什么？

### 选项

- [a] 一个很宁静、很舒适的地方
- [b] 一个吵闹的地方
- [c] 一个必定举行婚礼的地方

### 答案

a

### 选项反馈

- [a] nice and 在这里加强 peaceful 的舒适感。
- [b] 这与 peaceful 相反。
- [c] 句子没规定活动用途。

### 提示

- 注意 peaceful 的状态。

### 讲解

nice and + 形容词是口语中的舒适程度表达。

<exercise id="u144-contact-15" type="choice" activity="cloze" goal="contact" stage="build">

- [c] rare

### 答案

### 讲解

Have you seen them lately? 询问近况。
