# Game Day

> Game Day: Suggest where to sit

## 比赛日：座位、现场和不同意见

本课用原创的虚构比赛日对话学习现场词汇、座位安排和口语反应。分节、犯规和赛制只作词义理解，不规定真实赛事的规则或时间表。

## 一段原创对话

A: The idea was that we would sit in the bleachers.  
B: By now, those seats may be full.  
A: The point is, we need seats together.  
B: Come on, let's ask before we decide.

甲：原本的想法是我们坐看台。乙：到现在，那些座位可能已满了。甲：重点是我们需要坐在一起。乙：来吧，我们先问一下再决定。

seats 是座位，full 是满的，together 是一起，decide 是决定；would sit 说明原本设想的安排，不等于已经坐下。

## 先认识比赛现场

**bleachers** 是通常一排排升高的看台座位；**parking spot** 是停车位；**cooler** 在聚会用品语境中是保冷箱，也可作 cool 的比较级，表示更凉。

**jersey** 是运动衫、球衣；**mascot** 是吉祥物。The mascot wears a jersey. 吉祥物穿着球衣。wears 是穿着。

**tailgating** 在美式比赛日语境里可指在停车区域、车辆尾部附近举行的赛前聚会；在驾驶语境还可表示紧跟前车。这里用聚会义，不介绍驾驶行为或赛事场地规定。

## 场上与比赛阶段

**referee** 是裁判；**whistle** 可作名词表示哨子，也可作动词表示吹哨、吹口哨。**foul** 在运动语境里是犯规，也可有肮脏、恶劣等其他义项。

**call** 可表示裁判的判定：I disagree with the call. 我不同意那个判定。disagree with 是不同意；这里不是打电话。**quarter** 可以表示四分之一，也可指某些比赛中的一节；**halftime** 是中场休息；**playoff** 是季后赛、淘汰赛阶段的比赛。具体项目怎样分段，不能从这些单词直接推断。

## 不同意，不必逐字说“我不购买它”

**I don't buy it** 表示我不相信、我不接受这个说法。A: He says all the seats are gone. 他说座位全没了。B: I don't buy it. 我不太相信。gone 是没了、不在了；这里 buy 不是实际买东西。

**nonsense** 是胡说、无意义的话；**not exactly** 是不完全、算不上，也可以委婉纠正：A: Is it quiet here? 这里安静吗？B: Not exactly. 不太算是。quiet 是安静的。

**there's no way** 可表示不可能、没办法：There's no way we can sit there. 我们不可能坐在那里。也可接 to do：There is no way to know. 没办法知道。它不一定指一条实体道路不存在。

**come on** 可表示来吧、快点，也可表示加油或不相信的反应：Come on, let's ask. 来吧，我们问问。Come on! 在看球时也可能是加油。必须根据前后话语理解。

## 先说计划，再说重点

**the idea was that** 是原本的想法是……，that 后接完整小句：The idea was that we would sit together. 原本的想法是我们坐在一起。它报告计划，不自动说明计划已经实现。

**the point is** 是重点是……：The point is that we need seats together. 重点是我们需要坐在一起。that 在口语中可以省略。

**the same** 是相同的、同一个：We have the same idea. 我们有同样的想法。same 在此通常前面有 the。

**by now** 是到现在、现在应该已经：By now, the game may have started. 到现在，比赛可能已经开始。game 是比赛；may have started 是对到现在之前的可能结果的判断。

## it 需要上下文

**it** 可以回指前文的事物：The cooler is heavy. It is blue. 保冷箱很重，它是蓝色的。heavy 是重的，blue 是蓝色的。也可出现在天气句 It is cold. 天冷了；cold 是冷的。前者有明确所指，后者不必寻找某个物品。

## 易错点

- call 在裁判语境是判定；cooler 在用品语境是保冷箱。
- I don't buy it 是不相信，there's no way 可表示不可能。
- not exactly 缓和纠正，不等于完全同意。
- The idea was that 报告原本计划；The point is 说明当前重点。
- the same 通常保留 the；by now 是到现在，不是将来某天。
