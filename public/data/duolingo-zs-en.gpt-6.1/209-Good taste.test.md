# Good taste练习

<practice unit="209" format="2">

标题：说口味，回想一次观影选择
辅助词：I, you, she, watch, watching, film, films, scene, style, asked, suggested, seen, about, music

## 学习目标

- taste | 说明个人口味 | 使用 generally、dislike、decide 与作品形式词。
- describe | 分清评价与事实 | 区分 real / realistic、rare、trend 和展示词。
- past-option | 回想过去的另一选择 | 使用 if you had、缩写和 would have 的结果。

<exercise id="u209-taste-01" type="choice" activity="word-choice" goal="taste" stage="recognize">

目标词：dislike

### 题目

I dislike watching very long films. 表达什么？

### 选项

- [a] 我个人不喜欢看很长的电影
- [b] 所有长电影都已被证明不好

### 答案

a

### 选项反馈

- [a] 是说话人的偏好。
- [b] 句子没有给所有作品作事实结论。

### 提示

- 注意主语 I。

### 讲解

偏好不等于公共排名。

</exercise>

<exercise id="u209-past-option-12" type="choice" activity="word-choice" goal="past-option" stage="recognize">

目标词：if, if you had, if you'd

### 题目

If you'd asked... 在本课过去假设中 'd 是什么？

### 选项

- [a] had
- [b] would

### 答案

a

### 选项反馈

- [a] asked 在此是过去分词。
- [b] 这里的条件从句使用 had asked。

### 提示

- 先看 if 与后面的词形。

### 讲解

if you'd asked = if you had asked。

</exercise>

<exercise id="u209-past-option-13" type="compose" activity="compose" goal="past-option" stage="build">

目标词：if you had, would have

### 题目

组句：“如果你当时问过，我本会推荐那部剧情作品。”

### 词块

asked, | had | you | If | drama | the | suggested | have | would | I

### 答案

- If you had asked, I would have suggested the drama.

### 提示

- 条件使用 had，结果使用 would have。

### 讲解

asked 与 suggested 都是过去分词。

</exercise>

<exercise id="u209-past-option-14" type="input" activity="write" goal="past-option" stage="recall">

目标词：if you'd, would've

### 题目

将“If you had asked, I would have suggested the drama.” 两处都改成缩写。

### 答案

- If you'd asked, I would've suggested the drama.

### 提示

- 前一处缩 you had，后一处缩 would have。

### 讲解

两处缩写代表的内容不同。

</exercise>

<exercise id="u209-past-option-15" type="input" activity="write" goal="past-option" stage="recall">
