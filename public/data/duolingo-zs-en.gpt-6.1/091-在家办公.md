# 在家办公

> 描述你的工作安排

## 这一课要学会什么

说明在家办公的安排，礼貌提出请求，并报告文档、设备和时间上的问题。区分 print / printer、dead / slow 与 shouldn't / can't / won't。

## 开会前处理文档

**A:** Is it all right if I print this document? 我可以打印这份文档吗？  
**B:** Yes, but the printer is slow. 可以，但打印机很慢。  
**A:** My battery is dead. I can't join online right now. 我的电池没电了。我现在无法在线参加。  
**B:** Take a moment. I'll send the invitation again. 稍等一会儿。我再发一次邀请。

I、this、yes、but、the、is、my、join、right now、take、a、I'll、send、again 是辅助词。**document** 是文档，**print** 是打印，**printer** 是打印机，**battery** 是电池，**dead** 在电池场景是没电的，**online** 是在线。

## is it all right if 与 bother

**is it all right if** 在句首写 Is it all right if，询问是否可以做某事，if 后接完整句 I print this document。

**bother** 是打扰：**Sorry to bother you.** 抱歉打扰你，sorry、to、you 是辅助词。请求先说明具体动作和对象，不只说一个 please 让对方猜需要什么，please 是辅助词。

**make sure** 是确认、确保：**Make sure the printer is on.** 确认打印机开着，on 是辅助状态词。它后面可以接完整需要核对的情况。

## can't、won't 与 shouldn't

**can't** 是 cannot，**won't** 是 will not，**shouldn't** 是 should not 的缩写，cannot、will not、should not 是辅助完整形式。

**I can't print now.** 我现在不能打印，now 是辅助词，说明当下能力或条件受限。**I won't print it.** 我不会打印它，it 是辅助代词，说明将来不做或意愿。**I shouldn't bother her.** 我不应该打扰她，her 是辅助词，说明建议或行为是否合适。

三个否定都不在后面的 print / bother 原形上再加 -s。根据要表达的限制、意愿或建议选择。

## home office、screen 与 quiet

**home office** 是居家办公空间，**screen** 是屏幕，**quiet** 是安静的，**slow** 是慢的：**My home office is quiet.** 我的居家办公空间很安静。

**well** 在 work well 中是运转良好、工作做得好，work 是辅助词；**unhappy** 是不开心的。设备 slow 不自动说明使用者 unhappy，两类信息分开表达。

## 时段：early、these days、weekday

**early** 是早的、提早地：**I start early.** 我很早开始，start 是辅助词。**these days** 是最近、这些日子，**weekday** 是工作日，weekdays 是辅助复数。

**all the time** 是总是、一直，**all** 是所有、全部。these days 描述最近一段时期，不等于任何时候都如此。**moment** 是一会儿、时刻；**forty** 是四十。

**break** 是休息：**a forty-minute break**，一次四十分钟的休息，minute 是辅助词。作为复合形容词 minute 保持单数；普通时长说 forty minutes，minutes 是辅助复数。

## receive、invitation 与 the rest

**receive** 是收到，**invitation** 是邀请、邀请信息：**I received the invitation.** 我收到了邀请，received 是辅助过去式。

**the rest** 是剩余部分：**Print the rest.** 打印剩下的部分。它与 take a rest（休息，辅助对照搭配）的 rest 意思不同。

## put on、tie、pajama 与 herself

**put on** 是穿上、戴上，**tie** 是领带：**Put on a tie.** 戴上领带。**pajama** 是词表中的单数形式，常见于 pajama top（睡衣上衣）；整套睡衣常说 pajamas，top、pajamas 是辅助词。

**herself** 是她自己：**She printed it herself.** 她自己打印了它，she、printed 是辅助词。说明时间安排、设备状态和请求时分别说完整，需要强调亲自完成时再补 herself。
