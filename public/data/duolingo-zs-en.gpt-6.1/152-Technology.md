# Technology

> Technology: Look up information online

## 学习目标

描述查资料和设备操作，用 look up、back up、set up 等完整词组；区分物品名称与操作；认识 update、upgrade 和 sort of 在语境中的意思。

## 帮朋友整理一份文档

**A:** Can you look up this word? 你能查查这个词吗？  
**B:** Sure. Did you back up the file? 可以。你备份文件了吗？  
**A:** Yes. I accidentally pressed the wrong button. 备份了。我不小心按错按钮了。

file 是文件，pressed 是 press 的过去式“按”。此处练习通用语言，不指定软件版本或产品操作步骤。

## 小词决定了动作

**look** 是看；**look up** 在资料场景是查阅：look up a word（查一个词）。另一个语境也可表示抬头看，需看对象和场景。

**back** 可以表示回去、回来；**back up** 在文件场景是备份。back up the file / back the file up 都可；用代词说 back it up，不写 back up it。

**set** 可以是设置、放置，过去形式仍是 set；**set up** 是设立、设置好：set up an account（创建账户），account 是账户。**sign** 是签名或标志；**sign up** 是报名、注册，sign up for a class（报名一门课）。不是每个含 sign 的动作都是注册。

**plug** 是插头，也可作插入的动词；**plug in** 是接通、插入电源接口：plug in the charger（接上充电器）。charger 是充电器。这里只辨认词组，不提供维修或接线指导。

## 文件与连接

**attach** 是附上、附加：attach a file（附上文件）。**connect** 是连接：connect to a network（连接网络），network 是网络。**follow** 是跟随，也可表示关注账号；follow the instructions 是按照说明操作，instructions 是说明。

**notice** 是注意到：I noticed a message.（我注意到一条消息。）它说发现信息，不是创建账号。**accidentally** 是意外地、不小心地，修饰动作：accidentally pressed the button。

## 屏幕与声音词

**smartphone** 是智能手机，**button** 是按钮，**username** 是用户名，**voicemail** 是语音留言或语音信箱，**volume** 在这里是音量：turn down the volume（调低音量）。

**dot com** 是把 .com 读出来时的表达，例如把虚构地址念作 example dot com。dot 是点，不是斜杠；本课不要求打开网站或输入真实登录信息。

## 更新、升级与模糊程度

**update** 是更新，例如更新资料或软件；**upgrade** 是升级，强调提升版本、等级或能力。实际产品里两者可能有关联，本课先区分动作含义：update a document（更新文档），upgrade a device（升级设备），device 是设备。

**cost** 可作花费的动词或费用名词：What does it cost?（它要多少钱？）这里不提供价格，也不比较具体产品。

**sort of** 在口语中可表示有点、某种程度上：It's sort of slow.（它有点慢。）不是“整理”的命令；要说对文件排序，会用 sort the files。

## 回顾

look up 查阅，back up 备份，set up 设置好，sign up 注册，plug in 接通。先把词组作为整体理解，再检查宾语：back it up 的 it 在中间。update / upgrade 与 attach / connect 各自描述不同操作。
