# Halloween

> Halloween: Ask about someone's preferences

## 学习目标

询问服装偏好时，用 do / does / did 区分现在与过去；说清合身、松紧与搭配；认识 tear 的不规则词形和 tie 的 -ing 形式。

## 挑一件节日服装

**A:** Do you like this costume? 你喜欢这套装扮吗？  
**B:** Yes, but it doesn't fit. 喜欢，但它不合身。  
**A:** Did you try the loose one? 你试过那件宽松的吗？

costume 是节日或表演装扮；try 是试。**Halloween** 是万圣节；这里讨论虚构服装选择，不要求读者参加某种活动。

## 先确定时间，再选助动词

现在问 I / you / we / they 的一般动作，用 **do**：Do you like it?（你喜欢它吗？）问 he / she / it，用 **does**：Does she like it?（她喜欢它吗？）does 已承担第三人称形式，后面用 like，不用 likes。

现在否定分别用 **don't**（do not）和 **doesn't**（does not）：I don't like it.；She doesn't like it.。过去的一般动作问句用 **did**，否定用 **didn't**：Did she like it?；She didn't like it.。did / didn't 后也用动词原形。

这些助动词用于这里的 like、fit 等一般动词；She is happy. 这种 be 句子不再加 do。先辨认主干，再决定问法。

## 合身、松紧、搭配各说一件事

**fit** 作动词表示尺寸合适：This costume fits.（这套装扮合身。）Does it fit?（它合身吗？）**tight** 是紧的，**loose** 是宽松的；tight / loose 说明松紧，不直接说明你喜欢不喜欢。

**match** 是相配：The tie matches the shirt.（领带与衬衫相配。）tie 是领带，shirt 是衬衫。fit 主要说尺寸，match 主要说搭配。**fashionable** 是时髦的，也不等于一定合身。

**shop** 可作商店，也可作逛店购物的动词：a costume shop（一家装扮用品店），shop for a costume（选购装扮）。

## 系好与撕破

**tie** 作动词是系：tie a ribbon（系一条丝带）。现在进行表达：She is **tying** a ribbon.（她正在系丝带。）tie 变 -ing 时不是 tieing，而是 tying。

**tear** 在“撕破”的意思中有三种形式：tear → **tore** → **torn**。I tore the costume yesterday.（我昨天撕破了装扮。）The costume is torn.（装扮破了。）I have torn it.（我把它撕破了。）tear 也有“眼泪”的名词含义，读音与撕破不同；本课先练撕破这一组。

## 装扮元素与目的

**bat** 是蝙蝠，**witch** 是女巫。a bat costume 是蝙蝠装扮，a witch costume 是女巫装扮。这里 bat 取动物义，不是球棒。

**so that** 可以引出目的：I chose a loose costume so that I could move easily.（我选了宽松的装扮，以便能轻松活动。）chose 是 choose 的过去式，could 是 can 的过去形式，move easily 是轻松活动。不要把 so that 当作两件毫无关系的事之间的装饰词。

## 易错点

- Does she like…? 和 Did she like…? 都用 like 原形。
- fit 是尺寸合适，match 是搭配相称。
- tying 不写 tieing；tore 是过去式，torn 是过去分词。
