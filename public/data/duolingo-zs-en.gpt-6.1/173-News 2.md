# News 2

> News: Check if information is true

## 学习目标

谈虚构消息时，区分信息、感受和是否属实；用 wonder if 提出不确定的问题；辨认社会、环境与冲突词，不把主观评价当成证据。

## 看一张虚构新闻卡片

**A:** The charity has made progress recently. 那家慈善组织最近有进展。  
**B:** Is that true? 那是真的吗？  
**A:** I wonder if the report is true. 我想知道这篇报道是否属实。

report 是报道，made 是 make 的过去分词。卡片内容和人物均为虚构，初读一句陈述不等于已经核实。

## 直接问与间接问，语序不同

**wonder** 是想知道、疑惑；**wonder if** 是想知道是否。直接问 Is the report **true**?，放进 I wonder if 后，使用陈述语序：I wonder if the report is true.。

不要写 I wonder if is the report true。if 后有主语 the report，再有动词 is。过去说自己当时想知道，用 **wondered**：I wondered if it was true.（我当时想知道它是否属实。）

## 时间、数量与进展

**recently** 是最近，可与完成表达搭配，也可在适当语境配过去时：They have made **progress** recently.（他们最近有进展。）progress 是进展，通常不可数，make progress 不写 make a progress。

**mainly** 是主要地：The report is mainly about the town.（报道主要讲这个城镇。）town 是城镇。

**majority** 是多数、过半的部分：the majority of the votes（多数选票），votes 是选票。mainly 是副词，majority 是名词，不能因意思相近而交换位置。

## 社会与环境词

**society** 是社会，**poverty** 是贫困，**pollution** 是污染。**charity** 可指慈善事业或慈善组织：a charity；**support** 是支持、支援：support a school（支持一所学校）。

**mayor** 是市长，**political** 是政治的，**law** 是法律。**fair** 可以是公平的，也可以作集市的名词：a fair decision（公平决定），a book fair（书展）。decision 是决定，book 是书。

**powerful** 是有力量的、影响大的：a powerful speech（有感染力的演讲）。这样的评价不说明演讲里的每句话都真实。

## 冲突、灾难与救援

**army** 是军队，**battle** 是战斗，**defeat** 是击败，也可作失败的名词；**peace** 是和平。The fictional army lost a battle.（虚构军队输了一场战斗。）lost 是 lose 的过去式。

**disaster** 是灾难，**rescue** 是救援、救出：They rescued a kitten.（他们救出一只小猫。）kitten 是小猫。本课辨认报道词义，不描述真实军事、法律或救援程序。

## 从消息里保留什么

先说明听到或读到的内容，再问 Is it true? / I wonder if…。recently 说明时间，mainly 说明重点，majority 说明数量比例；fair、powerful 是评价。不要把不同种类的信息混成同一个“已证实”的结论。
