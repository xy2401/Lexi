# 一日三餐

> 讲述你想要的食物和饮料

## 这一课要学会什么

谈午饭、晚饭和想要的食物；用 would like 区分“想要某物”和“想做某事”。食材、份量与感谢表达各有位置，不必一次点出全部词表。

## 和家人商量午饭

**A:** What would you like for lunch? 午饭你想吃什么？  
**B:** I would like chicken and some fruit. 我想吃鸡肉和一些水果。  
**A:** Would you like to have hot pot for dinner? 晚饭你想吃火锅吗？

I、and、some 是辅助词；**lunch / dinner** 是午饭／晚饭。前课 breakfast 是早饭。**for** 在这里说明是哪一餐：for lunch、for dinner，不说明食物数量。

## 食物与食材

| 词 | 本课意义 | 提醒 |
| --- | --- | --- |
| food | 食物 | 泛说食物时通常不可数 |
| meat | 肉 | 不等于所有食物 |
| beef / pork | 牛肉／猪肉 | 本课按不可数食材理解 |
| chicken / fish | 鸡肉／鱼肉 | 餐桌语境；也可在其他场景指动物 |
| cheese | 奶酪 | 通常按食物或食材泛称 |
| cake | 蛋糕 | a cake 是一个完整蛋糕；some cake 是一些蛋糕 |
| fruit | 水果 | 泛说水果时通常不可数 |
| hot pot | 火锅 | 两个词，作为一道餐饮方式来理解 |

**have** 在用餐表达里可表示吃、喝：**We have fish for dinner.** 我们晚饭吃鱼。we 是辅助词；have 不只有“拥有”一种意思，具体看所接对象与场景。

## 要某物：would like + 名词

**I would like cheese.** 我想要奶酪。**Would you like beer?** 你想要啤酒吗？**would you like** 可以用来礼貌提供选择；**what would you like** 则让对方说出想要的东西。

**beer / wine** 是啤酒／葡萄酒。这里学习餐饮词义和句型，不把所有场景都设定为需要点酒。

**I would like fish, not beef.** 我想要鱼肉，不要牛肉。**not** 在这个简短对比中排除后面的牛肉。句子里有 like 才完整，不写 I would fish。

## 要做某事：would like to + 动词原形

**would like to** 后接动作：**I would like to make dinner.** 我想做晚饭。**Would you like to have lunch?** 你想吃午饭吗？**would you like to** 是询问是否想做某事的结构。

**make** 做、制作，第三人称单数是 **makes**：**My dad makes lunch.** 我爸爸做午饭。my、dad 是辅助词。但在 **He would like to make lunch.** 中，to 后用 make 原形；he 是辅助词，不把 makes 放到这里。

区分两句：I would like dinner（我想要晚饭）与 I would like to make dinner（我想做晚饭）。to 后需要动作，不能只放一个食物名。

## 份量与种类

**glasses of** 是多玻璃杯……：**two glasses of water** 两杯水。two、water 是辅助词；glasses 是容器的复数，后面的水不加 -s。

**kind of** 表示一种类别：**a kind of fruit** 一种水果。a 是辅助冠词。它没有说明吃了多少克或多少份，也不是某个水果的专有名称。

## 用餐后的感谢与补充词

**thank you for** 后接感谢的事情：**Thank you for dinner.** 谢谢你准备／招待晚饭。只要场景明确，中文可自然理解为感谢这顿饭。

**line** 在这里先认识排队的一队人，**in line** 是在排队。**race** 是比赛、赛跑，不能因为拼写相近就与 rice（米饭）混淆；rice 是前课词。line 与 race 属于补充词，不硬塞到食物点单里。

点餐先想清楚要的是食物还是一个动作，再选择 would like 或 would like to。
