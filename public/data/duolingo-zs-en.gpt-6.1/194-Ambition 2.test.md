# Ambition 2练习

<practice unit="194" format="2">

标题：谈求职与当前尚未实现的设想
辅助词：I, we, would, time, more, learn, bake, rush, experience, call, talked, a, in, want

## 学习目标

- jobs | 说工作与优势 | 识别职业、岗位、就业与能力词。
- meeting | 说明求职交流 | 使用 interview、face to face 与 hourly wage。
- if-time | 表达条件与改变 | 用 If I had... 与 would / wouldn't 说当前设想。

<exercise id="u194-if-time-11" type="choice" activity="word-choice" goal="if-time" stage="recognize">

目标词：if, if I, had

### 题目

已说明我现在时间不够：If I had more time, I would learn to bake. 是哪种含义？

### 选项

- [a] 想象当前有更多时间的情况
- [b] 确认我昨天已完成烘焙课

### 答案

a

### 选项反馈

- [a] had 在这里用于假设。
- [b] 句子没有确认过去学习成果。

### 提示

- 先看设定，再看 would。

### 讲解

过去形式不总在叙述过去。

</exercise>

<exercise id="u194-if-time-12" type="choice" activity="cloze" goal="if-time" stage="build">

目标词：had

### 题目

“如果我有更多时间，我会学烘焙”：If I ___ more time, I would learn to bake.

### 选项

- [a] had
- [b] would have

### 答案

a

### 选项反馈

- [a] 用于本课的当前假设。
- [b] 这个条件句不把 would 放在这里。

### 提示

- 条件句和结果句的形式不同。

### 讲解

If I had...，I would...。

</exercise>

<exercise id="u194-if-time-15" type="choice" activity="word-choice" goal="if-time" stage="recognize">

目标词：if, had

### 题目

哪句表达可能实现的未来条件：“如果我有时间，我会打电话”？

### 选项

- [a] If I have time, I'll call.
- [b] If I had time, I'll call.

### 答案

a

### 选项反馈

- [a] have 与 will call 搭配未来可能条件。
- [b] 本课不把这种假设过去形式与该将来结果这样混用。

### 提示

- 区分真实可能条件与当前假设。

### 讲解

If I had time, I would call 则常用于当前假设。

</exercise>
