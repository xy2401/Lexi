标题：表达旅行偏好、票种与条件计划
辅助词：tickets, tomorrow, ticket, room, route, left, rains, prefer, exploring

## 学习目标

- travel | 交通与住宿 | 辨认行程、票种和预订动作。
- choices | 旅行偏好 | 区分活动、服务和地点选择。
- plans | 条件与沟通 | 使用 if、will、won’t 并请求重复。

<exercise id="u166-choices-09" type="choice" activity="word-choice" goal="choices" stage="recognize">

- [c] 没有这个限定。

### 提示

### 讲解

wherever we go 是完整地点从句。

<exercise id="u166-plans-12" type="choice" activity="word-choice" goal="plans" stage="recognize">

目标词：if, will, get

### 题目

哪句符合本课的未来条件表达？

### 选项

- [a] If we get tickets, we'll go.
- [b] If we will get tickets, we'll go.
- [c] If we gets tickets, we go will.

### 答案

a

### 选项反馈

- [a] if 从句用现在时，主句用 will。
- [b] 这个普通未来条件不用在 if 从句里重复 will。
- [c] we 后不能用 gets，主句次序也错误。

### 提示

- 条件与结果使用不同时间形式。

### 讲解

If we get…we will…。

</exercise>
