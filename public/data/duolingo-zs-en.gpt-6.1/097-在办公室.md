# 在办公室

> 与人谈论工作

## 这一课要学会什么

交流办公室任务，说明文件操作、打印方式和花费时间。区分 job / work、file / folder 与单面双面，回顾 asked、told、wanted 的过去表达。

## 同事解释打印任务

**A:** What do I need to do? 我需要做什么？  
**B:** Download the file and save it in this folder. 下载文件，保存在这个文件夹里。  
**A:** Single-sided or double-sided? 单面还是双面？  
**B:** Double-sided. By the way, how long will it take? 双面。顺便问一下，会花多久？

do、I、to、the、and、it、in、this、or、will 是辅助词。**need** 是需要，**download** 是下载，**file** 是文件，**save** 是保存，**folder** 是文件夹。这里是虚构任务说明，不操作任何实际文件。

## file / folder 与软件器具

**software** 是软件，通常不可数，不直接写 three softwares。**keyboard** 是键盘，**mouse** 在电脑场景是鼠标。

**click** 是点击，**right-click** 是右键点击：**Right-click the file.** 右键点击文件。**copy / paste** 是复制／粘贴，**move** 是移动：**Move the file to this folder.** 把文件移到这个文件夹。

copy 创建副本，move 说移动位置，save 说保存内容；并不是所有动作都等于下载。

## 打印：single-sided / double-sided

**single-sided** 是单面的，**double-sided** 是双面的，**page** 是一页、页面：**Print this page double-sided.** 双面打印这个页面，print 是辅助词。实际任务还可说明页数和文档范围，page 本身不表示整个文件。

**directions** 在任务场景是操作说明、指示：**Follow these directions.** 按照这些说明做，follow、these 是辅助词；不是只用于道路方向。

## job、work、sales 与 salesperson

**job** 是一份工作、一个任务，可数：two jobs，两份工作，two、jobs 是辅助词。**work** 是工作、工作内容，通常不可数：a lot of work，很多工作，a lot of 是辅助词组。

**sales** 是销售、销售业务，**salesperson** 是销售人员：**She is a salesperson.** 她是销售人员，she、is、a 是辅助词。人和业务不同。

## how long 与 take

**how long** 问多久，**take** 在 How long will it take? 中是花费时间。**It will take ten minutes.** 会花十分钟，ten、minutes 是辅助词。

**what** 在 What do I need to do? 中问所需动作。先问清做什么，再问多久；不要只听到 take 就一律理解成拿东西。

## asked、told 与 wanted

**asked** 来自 ask（询问、请求，辅助原形）：**She asked me to copy the file.** 她请我复制文件，me 是辅助词，to 后保留 copy 原形。

**told** 来自 tell（告诉，辅助原形）：**She told me to save the file.** 她告诉我保存文件。told 不是 asked 的另一种拼写，给指示与提出请求语气不同。

**wanted** 来自 want（想要，辅助原形）：**I wanted to work in sales.** 我曾想做销售。句子说过去的愿望，不证明职位已经得到。

## as usual、beginning 与日常安排

**as usual** 是像往常一样：**I arrived early as usual.** 我像往常一样早到，arrived、early 是辅助词。**beginning** 是开始部分：**at the beginning of the page**，在页面开头，at、of 是辅助词。

**alarm clock** 是闹钟，**traffic** 是交通、车流。**I suppose** 是我想、我估计：**I suppose the traffic is busy.** 我想路上很忙，busy 是辅助词。它是说话者的推测，不是已经确认的路况。

**by the way** 是顺便说一下，**ok** 在正常用语中可写 OK（好、可以）。任务沟通按动作、对象、位置和时长组织；别把文件、文件夹与整个软件混成一个对象。
