# 新工作

> 描述求职经历

## 这一课要学会什么

描述找工作和工作经历，礼貌地询问是否可以做某事，并区分多久、从何时开始和刚刚完成。重点是 look for、how long / since 与 have / has written。

## 到公司参加面谈

**A:** Pleased to meet you. 很高兴认识你。  
**B:** Please fill in this form. 请填写这张表。  
**A:** Is it OK if I use my résumé? 我可以用我的简历吗？  
**B:** Certainly. The manager will be with you in a minute. 当然。经理一会儿就来见你。

please、in、this、I、use、my、the、will、you 是辅助词。**pleased to meet you** 是初次见面招呼，**form** 是表格，**fill** 是填；fill in 是填写的完整搭配。**résumé** 是简历，注意这个原词表中的重音符号。

## 请求许可：is it ok if / is it ok to

原词表的 **is it ok if / is it ok to** 在句首写 Is it OK if / Is it OK to。**Is it OK if I call?** 我可以打电话吗？**call** 是打电话，if 后保留完整句 I call。

**Is it OK to call now?** 现在可以打电话吗？now 是辅助词，to 后使用动作原形，没有另加 I。**certainly** 是当然、可以，回应请求。

## 职位、部门与找工作

**look for** 是寻找：**I'm looking for a job.** 我在找工作，I'm、looking、a、job 是辅助词。looking 是 look 的 -ing 形式，look 是辅助原形。

**engineer** 是工程师，**manager** 是经理，**receptionist** 是前台接待员，**secretary** 是秘书，**department** 是部门。receptionist 指人，不是前台地点。

**program** 是程序，也可指项目；**improve** 是改善、提高：**I want to improve this program.** 我想改进这个程序，want、to 是辅助词。

## have / has 与 written

**have / has** 可表示有，也可作完成时助动词：**I have written my résumé.** 我写好了简历；**She has written a résumé.** 她写好了一份简历，she 是辅助词。

**written** 是 write（写，辅助原形）的过去分词，放在 have / has 后，不写 I have wrote。**just** 在 **I have just written my résumé.** 中是刚刚；它强调刚完成的动作。

**it has** 是 it 后接 has 的组合，it 是辅助代词：**It has been a busy day.** 今天是忙碌的一天，been、busy、day 是辅助词。has 后的词形取决于后续结构，不是任何动词都直接加 -s。

## how long、since、before 与 last

**how long** 问多久：**How long have you worked here?** 你在这里工作多久了？worked、here 是辅助词。**since** 给起点：**I have worked here since May.** 我从五月起在这里工作，May 是辅助词。

**before** 是在…之前：before the interview，面试之前，interview 是辅助词。**last** 可指上一个，也可作持续：**How long does the interview last?** 面试持续多久？does 是辅助词。last 的角色由句子决定。

**more than** 是超过：more than a year，超过一年，year 是辅助词。**a minute** 是一分钟，也可在口语中表示一小会儿。经理 be with you in a minute，是一会儿来接待你，不是说永远陪着你。

## 共事、休息与建议

**be with** 是与某人在一起、来接待；**with** 引出共事对象。**get along** 是相处融洽：**I get along with my manager.** 我与经理相处融洽。

**break** 在工作场景是休息：a break，一次休息。**advice** 是建议，通常不可数：some advice，一些建议，some 是辅助词；不写 an advice。**Good luck!** 祝你好运！**good luck** 是祝福，不保证求职结果。先讲经历，再提出清楚的许可问题，时间与建议另行补充。
