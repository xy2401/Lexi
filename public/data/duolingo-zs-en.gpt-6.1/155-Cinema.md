# Cinema

> Cinema: Describe animated movies

## 学习目标

介绍动画电影时，说清角色、情节与背景；根据名词数量选择 there is / there are、much / many；让 everyone、someone 等代词与单数动词一致。

## 准备看一部虚构动画

**A:** There are many characters in this animated film. 这部动画电影里有很多角色。  
**B:** What is the plot? 情节是什么？  
**A:** It is set in a village. Everyone has a secret. 故事发生在一个村庄。每个人都有一个秘密。

village 是村庄，secret 是秘密。这里的电影是原创虚构场景，不指某部真实作品。

## 作品、角色、观众与情节

**film** 是电影，**animated** 是动画的：an animated film。**character** 是作品中的角色；**audience** 是观众，观看作品的人。角色不等于饰演角色的演员，也不等于观众。

**plot** 是情节、故事发展；**set** 在 be set in 中描述背景：The film is set in a village.。这里 **be** 的形式是 is；set 不变，不是在说有人现在设置播放器。

**talented** 是有才华的。**independent** 是独立的，an independent film 是独立电影。**documentary** 是纪录片，**horror** 是恐怖作品或恐怖类型，**thriller** 是惊悚片／惊悚作品，**romantic** 是浪漫的。horror 与 thriller 可以有重叠，不要求每部作品只属于一个类型。

## 有一个，有多个；有多少

**there is** 接单数或不可数名词：There is a character.；There is some **popcorn**.（有一些爆米花。）**there are** 接复数：There are many characters.。

**many** 接可数复数：many films，many characters。**much** 接不可数：much popcorn。popcorn 通常不可数；一份可说 a bag of popcorn（一袋爆米花）。不要写 many popcorns 表示一袋里很多粒。

## 看似很多人，动词却用单数

**everyone** 是每个人；**someone** 是某个人；**anyone** 是任何人或问题中的有人；**no one** 是没有人。这些普通主语用单数动词：Everyone **has** a ticket.（每个人都有票。）Someone is here.（有人在这里。）No one is here.（这里没有人。）ticket 是票。

原形 **have** 表示有，第三人称单数是 has。不要因为 everyone 涉及很多人就写 Everyone have…。问“有人来了吗？”可用 Is anyone here?。

no one 已经表示没有人，不再加 isn't 来表达相同意思。用 be 时也跟单数：No one is，不写 No one are。

## 表达自己的喜好

**can't stand** 是受不了：I can't stand horror films.（我受不了恐怖片。）这是个人喜好，不是作品好坏的客观结论。I like romantic films.（我喜欢浪漫电影。）可以用简单句先说明类型，再补原因。

## 回顾

用 animated 描述电影形式，用 character / plot / be set in 介绍内容。人物多个用 there are、many；爆米花用 there is、much。everyone 指每个人，但句法上跟 has / is 这样的单数形式。
