# 旅行

> 介绍地点

## 这一课要学会什么

问交通地点在哪里，说明需要去哪里，并辨认票务和证件信息。问路时先表达目的，再确认位置，句子短也能把信息说清楚。

## 在车站找售票处

**A:** Excuse me. Where is the ticket office? 不好意思，售票处在哪里？  
**B:** It's over there. 它在那边。  
**A:** I need to go to the station. 我需要去车站。

excuse me、I、it's 是辅助词或前课表达；it's = it is。**where is** 问单个地点或物品的位置，**ticket office** 是售票处。**the** 指双方知道、正在寻找的那个地方，不代表“一个”。

## 地点与交通工具分开认识

| 地点 | 意义 | 对应交通工具 |
| --- | --- | --- |
| airport | 机场 | plane，飞机 |
| station | 车站 | train，火车；也可有 bus station 等具体类型 |
| port | 港口 | 本课先认识港口这个地点名 |
| hotel | 酒店 | 住宿地点，不是交通工具 |
| bathroom | 洗手间／浴室 | 问路场景通常指洗手间 |

**bus** 公交车／巴士，**subway** 地铁，**taxi** 出租车。station 单独出现不保证一定是火车站；需要精确时，可以补充 train 或 bus。

## go to 与 need to：两个 to 不重复

**go** 去，**to** 常把目的地接在 go 后：**go to the hotel** 去那家酒店。**need to** 后接动作原形：**I need to go.** 我需要走／去。

合起来是 **I need to go to the airport.** 我需要去机场。第一个 to 属于 need to go 的动作结构，第二个 to 引出地点。不能因为看见两个 to 就删除后一个。

**in** 表示在里面或某区域内：**My passport is in the bag.** 我的护照在包里。my、is、bag 是前课词；in 说现有位置，to 说前往方向。

## 这里、那边与“就在”

**here** 是这里，**over there** 是在那边。**right here** 是就在这里，right 强调位置准确。**right** 也可表示右边或正确，但 right here 不是“右边的这里”。

**Where is the bathroom?** 洗手间在哪里？**It's right here.** 就在这里。**What is this?** 这是什么？**what is** 问身份、内容；where is 问位置，两个问词不互换。

**over** 在不同结构里意思不同：over there 是那边；**The game is over.** 游戏结束了。game 是前课的游戏。先按完整搭配理解，不把 over 一律翻成“上方”。

## 买票、证件与时间状态

**ticket** 是票，**passport** 是护照。**pass** 在本课补充“递给”的动作：**Pass the ticket, please.** 请递一下票。please 是辅助礼貌词。passport 不是 pass 加上 port 就能按“递港口”猜出的意义。

**closed** 是关闭的：**The ticket office is closed.** 售票处关门了。closed 描述状态，不能直接省掉 is。**late** 是迟到的／晚的：**I'm late.** 我迟到了。I'm 是辅助缩写。

## first name 与 last name

**first name** 是名，**last name** 是姓。**last** 可表示最后的；在 last name 中形成“姓”的固定搭配。英文姓名 Anna Smith 中，Anna 是 first name，Smith 是 last name。

中文姓名通常先姓后名，但表格里的 first name 仍填名字部分，last name 填姓氏部分，不是机械按中文书写顺序把第一个字填到 first name。

问路和填表先确认在问“哪里”“什么”还是“姓名的一部分”，就能避免答非所问。
