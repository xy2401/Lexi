# Old Times练习

<practice unit="134" format="2">

标题：过去习惯的疑问、否定与回忆
辅助词：you, play, yes, I, knew, a, kite, know, used to, stay, assignments, my, played, sister, stayed, the, floor, of, book, tennis

## 学习目标

- habits | 形成过去习惯的疑问和否定 | 区分 did + use to、didn’t use to 与 never used to。
- memories | 说明能力、数量与打扫 | 使用 know how to、fly、fewer 与 sweep / swept。
- background | 介绍回忆的景象和背景 | 认识自然、物品、工作等名称，使用 however 对照。

<exercise id="u134-habits-01" type="matching" activity="matching" goal="habits" stage="recognize">

目标词：did, use to, didn't use to, never used to, indoors, outdoors

### 题目

把英文与对应的中文含义逐一配对。

### 配对

- [p1] did | 过去疑问／否定的助动词
- [p2] use to | 在 did 之后的过去习惯结构
- [p3] didn't use to | 过去不常／过去并不是
- [p4] never used to | 过去从不
- [p5] indoors | 在室内
- [p6] outdoors | 在户外

### 提示

- 助动词、习惯否定和地点不同。

### 讲解

不能把 use to 单独用在本课肯定句。

</exercise>

<exercise id="u134-habits-02" type="choice" activity="cloze" goal="habits" stage="build">

目标词：did, use to

### 题目

Did you ____ play outdoors?

### 选项

- [a] use to
- [b] used to
- [c] using to

### 答案

a

### 选项反馈

- [a] did 后用 use，不加 d。
- [b] 过去标记已经由 did 承担。
- [c] 本句不使用这个形式。

### 提示

- 先看句子是否已有 did。

### 讲解

Did you use to play outdoors?

</exercise>

<exercise id="u134-habits-06" type="choice" activity="word-choice" goal="habits" stage="recognize">

目标词：use to

### 题目

哪一种是本课过去习惯的规范肯定形式？

### 选项

- [a] I used to play outdoors.
- [b] I use to play outdoors.
- [c] I did used to play outdoors.

### 答案

a

### 选项反馈

- [a] 没有 did 的肯定形式用 used to。
- [b] 不能将 did 后形式独立作本题肯定。
- [c] did 后不保留 used 的 d。

### 提示

- 区分肯定与带 did 的结构。

### 讲解

三个结构的过去标记位置不同。

</exercise>

<exercise id="u134-background-16" type="choice" activity="word-choice" goal="background" stage="recognize">

目标词：however

### 题目

however 在补充童年经历时，主要可以表达什么？

### 选项

- [a] 不过、然而，引出对照。
- [b] 保证每个人经历完全相同。
- [c] 规定税务结果已经确定。

### 答案

a

### 选项反馈

- [a] 补充另一种情况。
- [b] 对照不表示全部相同。
- [c] 它不提供任何具体结果。

### 提示

- 看它连接的是哪种信息关系。

### 讲解

例如我在户外，姐姐／妹妹在室内。

</exercise>

<exercise id="u134-habits-17" type="choice" activity="audio-choice" goal="habits" stage="recognize">

目标词：didn't use to, outdoors

### 题目

听过去习惯的否定，选择意思。

### 听力

I didn't use to play outdoors.

### 选项

- [a] 我以前不常在户外玩。
- [b] 我现在一定每天在户外玩。
- [c] 我已经扫完全部屋子。

### 答案

a

### 选项反馈

- [a] 听力保留过去习惯的否定。
- [b] 没有现在或每天信息。
- [c] 没有清扫结果。

### 提示

- 听习惯是否为否定及活动地点。

### 讲解

I didn’t use to play outdoors.
