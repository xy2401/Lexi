# Internet

> Internet: Compare old and new technology

## 这一课要学会什么

比较以前与现在使用设备的习惯，区分 used to do 和 get used to doing；读懂常用技术动作词。本课不要求安装软件或更改任何账户设置。

## 曾经这样，现在正在适应

**A:** I used to use a giant device. 我以前用过一台很大的设备。  
**B:** Are you getting used to this one? 你正在适应这一台吗？

**used to + 原形** 说过去常做、过去处于某状态，通常暗示现在不同了。I used to use this device. 我过去常用这台设备。不要把 used to 当成一定曾经用过一次。

**get used to + 名词或 -ing** 是逐渐习惯：I am getting used to using it. 我正在习惯使用它。这里 to 是介词，所以用 using，不用 use。

**be used to + 名词或 -ing** 则说已经习惯：I am used to using it. 我习惯用它。这两个 to 与普通的 want to use 不同。

## 设备、人员与程序

**device** 是设备；**giant** 是巨大的，也可作名词表示巨人。**user** 是用户；**browser** 是浏览器；**server** 是服务器。它们是不同角色，不把浏览器、用户与提供服务的系统混为一谈。

**graphics** 是图形、图像呈现，常用复数形式。**microphone** 是麦克风；**webcam** 是网络摄像头；**robot** 是机器人。认识词语不表示某款设备具体具备哪些功能。

## 常见动作，要说清对象

**press** 是按：press a key，按一个键；**key** 也可表示钥匙、关键，键盘语境才是按键。**switch** 可表示切换，也可表示开关：switch devices，切换设备。

**restart** 是重新启动；**install** 是安装；**locate** 是找到位置、定位：locate the file，找到文件。file 是文件这个辅助词。

**log out of + 账户或系统** 是退出登录：log out of the account。它不等于删除账户，也不只是关掉当前窗口。account 是账户。

## 频率与“看一眼”

**once a day** 是每天一次；**once a week** 是每周一次。词表中的 **once a** 是频率表达的开头，后面补时间单位，不是完整独立句子。

**frequent** 是频繁的形容词：frequent changes，频繁变化。副词 frequently 是频繁地：It changes frequently. 它经常变化。不要把频繁直接等同于每天恰好一次。

**take a look** 是看一眼：Could you take a look? 你能看一下吗？**take a look at + 对象** 指明看什么：take a look at the file，看一下文件。

## 用三种时间角度比较

过去习惯：I used to use this browser. 我过去常用这个浏览器。

逐渐适应：I'm getting used to using it. 我正在习惯用它。

已习惯：I'm used to using it. 我习惯用它。

先决定自己在说哪个角度，再选 used to do 或 used to doing。看起来相近的词组，语法与意思不同。

## 常见误区

- used to use 说过去习惯；getting used to using 说适应过程。
- log out of 保留 of；不是删除账户。
- once a 后补 day / week 等单位；frequent 本身不提供确切次数。
- key 在 press a key 中是按键，不是每次都译为钥匙。
