# 在办公室练习

<practice unit="97" format="2">

标题：办公室任务、文件操作与工作交流
辅助词：do, I, to, the, and, it, in, this, or, will, print, follow, these, two, jobs, a lot of, she, is, a, ten, minutes, ask, me, tell, want, arrived, early, at, of, busy

## 学习目标

- files | 说明文件和打印任务 | 区分 file / folder，使用下载、保存、复制、粘贴与打印方式。
- communication | 询问任务并回顾指示 | 使用 what / how long、take、asked / told / wanted 与 I suppose。
- workplace | 交流岗位和日常安排 | 区分 job / work、sales / salesperson，认识日常与话题转换词。

<exercise id="u097-files-08" type="choice" activity="word-choice" goal="files" stage="recognize">

目标词：copy, move

### 题目

copy the file 与 move the file 在本课是同一个动作吗？

### 选项

- [a] 不是，复制与移动位置不同。
- [b] 是，都只是改成双面打印。
- [c] 是，都说明闹钟响了。

### 答案

a

### 选项反馈

- [a] copy 创建副本，move 说位置变化。
- [b] 打印方式不是这两个操作。
- [c] 与 alarm clock 无关。

### 提示

- 区分操作对文件的作用。

### 讲解

copy / move 不应机械互换。

</exercise>
