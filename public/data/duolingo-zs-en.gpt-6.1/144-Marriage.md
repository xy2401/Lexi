# Marriage

> Marriage: Ask about wedding details

## 学习目标

询问婚礼与近况时，区分 have / has 的完成表达和 did 的过去问句；用频率词说联系次数；辨认庆祝活动、关系状态与程度表达。

## 向朋友询问活动准备

**A:** Have you set a date? 你们定好日期了吗？  
**B:** Yes. The event will be nice and peaceful. 定好了。活动会很舒适、很宁静。  
**A:** Has your friend arrived? 你的朋友到了吗？

arrived 是 arrive（到达）的过去分词。这里是虚构聚会对话，不规定婚礼或关系必须采用什么形式。

## 已经做过：have / has 后接过去分词

I / you / we / they 用 **have**；he / she / it 用 **has**。Have you set a date?；Has she set a date?。**set** 可以是设置、确定，三个形式 set → set → set 没有改变。

否定是 **haven't**（have not）与 **hasn't**（has not）：We haven't set a date.（我们还没定日期。）She hasn't arrived.（她还没到。）不要根据 set 的外形判断是否完成，要看 have / has。

有明确过去时间的一次动作，问 **did**：Did you set a date yesterday?（你们昨天定日期了吗？）did 后用原形。Have you…? 关注到现在的结果；Did you…yesterday? 询问昨天那次动作。本课不把两种形式当成随意替换的装饰。

## 活动与关系：含义先分开

**event** 是活动、事件；**anniversary** 是周年纪念日；**honeymoon** 是蜜月。婚礼是一场 event，anniversary 与 wedding day 的时间关系不同。**in a relationship** 是处于恋爱关系中，不表示已经结婚。

**tradition** 是传统，**typical** 是典型的、常见的。A typical event 不代表每次活动都必须如此。**incredible** 是难以置信的、令人赞叹的：The view was incredible.（景色令人赞叹。）view 是景色。

**peaceful** 是宁静的、平和的。**nice and** 可在口语中加强后面的形容词：nice and peaceful（很宁静、舒适），nice and warm（暖暖的、很舒服）。nice and 在这种结构里不是把两个完全独立的评价生硬连起来。

## 联系频率与最近的情况

**lately** 是最近、近来，常用于完成表达：Have you seen them lately?（你最近见过他们吗？）**rarely** 是很少：We rarely meet.（我们很少见面。）rarely 本身有低频率意思，不再加 don't 来表示同一个意思。

**more often** 是更经常，比较时可用 **than**：We meet more often than before.（我们比以前更常见面。）before 是以前。than 连接比较对象，不是表示“然后”的 then。

## 到达现场的小动作

**van** 是厢式货车或面包车，视具体车辆而定；本课不规定运输规则。**wave** 作动词是挥手，作名词也能是波浪：They waved to us.（他们向我们挥手。）waved 是过去式。不要把 wave 与婚礼传统绑成固定行为。

## 回顾

问已完成的结果：Have you set…? / Has she arrived…?。问昨天：Did you…yesterday?。说频率：rarely、more often than before；说最近：lately。动作发生的时间与频率清楚了，近况就容易说明。
