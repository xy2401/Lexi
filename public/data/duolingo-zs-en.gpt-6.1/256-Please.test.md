# Please练习

<practice unit="256" format="2">

标题：请求帮忙：内容、替代方案与语气
辅助词：I, you, me, the, a, could, help, helping, work, delay, door, meeting, schedule, to, stay, was, if, be, able, busy, here, have, tried

## 学习目标

- favor | 说明帮助与困难 | 区分帮忙、回报、弥补和不方便。
- request | 提出清楚的礼貌请求 | 使用 consider、might 与 wondering 的后续形式。
- action | 说明动作与替代方案 | 表达重新安排、弄清、等待与其他选择。

<exercise id="u256-favor-01" type="choice" activity="word-choice" goal="favor" stage="recognize">

目标词：favor, return the favor, make up for

### 题目

return the favor 最接近什么？

### 选项

- [a] 回报别人给过的帮助
- [b] 弥补一次耽搁
- [c] 取消从未提出的请求

### 答案

a

### 选项反馈

- [a] return the favor 是回报帮助。
- [b] 那是 make up for the delay。
- [c] return the favor 没有这个含义。

### 提示

- 看 favor 指哪一种事情。
- 区分回报帮助和弥补问题。

### 讲解

return the favor 是回报这份帮助。

</exercise>

<exercise id="u256-request-06" type="choice" activity="word-choice" goal="request" stage="recognize">

目标词：wondering, really

### 题目

I was wondering if you could help. 一定表示现在已经不想问了吗？

### 选项

- [a] 不一定；这是常见的当前礼貌请求
- [b] 一定；was 使任何当前请求都无效
- [c] 一定表示对方已经帮忙了

### 答案

a

### 选项反馈

- [a] 过去形式可缓和语气，不必限定为请求已经失效。
- [b] 不能机械只按时间解释这种礼貌用法。
- [c] 请求并未报告对方已经行动。

### 提示

- 结合礼貌请求的交谈功能。
- 语法过去形式也可以拉开语气距离。

### 讲解

I was wondering if… 常用于缓和当前请求。

</exercise>

<exercise id="u256-action-11" type="choice" activity="word-choice" goal="action" stage="recognize">

目标词：alternatively

### 题目

Alternatively, we could wait. alternatively 引出了什么？

### 选项

- [a] 另一种可考虑的选择
- [b] 已经确定必须等待的命令
- [c] 对前一件事已发生的确认

### 答案

a

### 选项反馈

- [a] alternatively 引出替代方案。
- [b] could 与替代开场并没有这种确定命令。
- [c] 句子提出选择，不是确认完成。

### 提示

- 注意这是方案之间的关系。
- 它不是结果保证。

### 讲解

alternatively 是作为另一种选择、或者。

</exercise>
