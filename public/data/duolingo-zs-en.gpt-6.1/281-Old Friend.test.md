# Old Friend练习

<practice unit="281" format="2">

标题：老友重逢与最新近况
辅助词：news, work, job, city, visit, son, years, call, message, working, tired, compliment

## 学习目标

- greetings | 自然问候与更新近况 | 掌握重逢、时间间隔与简短回应。
- changes | 介绍变化和体验 | 说明年龄、成长、海外生活与适应。
- summary | 总结与后续联系 | 表达截至目前、总体评价和承诺。

<exercise id="u281-greetings-02" type="choice" activity="word-choice" goal="greetings" stage="recognize">

目标词：how long has it been, it's been

### 题目

重逢时问 How long has it been?，回答 It's been three years.，主要谈什么？

### 选项

- [a] 距离上次见面过了多久。
- [b] 现在正好三点钟。
- [c] 未来必须一起住三年。

### 答案

a

### 选项反馈

- [a] 正确，语境补足时间起点。
- [b] years 是时间长度，不是几点。
- [c] 句子没有未来义务。

### 提示

- 关注 has been 与时间长度。
- 重逢提供上次见面的参照。

### 讲解

It's been 是 It has been，用来说明经过的时间。

</exercise>

<exercise id="u281-changes-03" type="choice" activity="word-choice" goal="changes" stage="recognize">

目标词：expecting

### 题目

We're expecting a visit. 中 expecting 表示什么？

### 选项

- [a] 期待一次来访。
- [b] 无论宾语是什么都必然表示怀孕。
- [c] 已经取消所有来访。

### 答案

a

### 选项反馈

- [a] 正确，宾语 visit 明确期待内容。
- [b] expecting 需结合宾语和语境。
- [c] 句子没有取消或否定。

### 提示

- 先看 expecting 后接了什么。
- 这里是一次来访。

### 讲解

expecting 不总是要有宝宝了；本句是期待来访。

</exercise>

<exercise id="u281-changes-04" type="choice" activity="word-choice" goal="changes" stage="recognize">

目标词：liking, loving

### 题目

How are you liking the city? 与 I'm loving my job. 在口语里怎样理解？

### 选项

- [a] 强调最近的体验与热情。
- [b] 两句在任何语境都绝对错误。
- [c] 以后所有 like 和 love 都必须用进行式。

### 答案

a

### 选项反馈

- [a] 正确，是可见的口语进行式用法。
- [b] 不能把通常不用进行式的规则扩大成绝对禁令。
- [c] 稳定喜好仍常用一般现在时。

### 提示

- 注意最近的生活体验。
- 不要将一种口语用法变成全部情况的规则。

### 讲解

liking、loving 的进行式在口语中可以突出当下体验。

</exercise>

<exercise id="u281-summary-05" type="choice" activity="word-choice" goal="summary" stage="recognize">

目标词：so far

### 题目

So far, things have gone well. 能直接说明什么？

### 选项

- [a] 到目前为止进展顺利。
- [b] 未来永远不会遇到困难。
- [c] 所有事情还没开始。

### 答案

a

### 选项反馈

- [a] 正确，限制在当前为止。
- [b] so far 不保证未来。
- [c] have gone well 已涉及过去到现在的进展。

### 提示

- 保留时间范围。
- so far 只谈截至目前。

### 讲解

so far 表示到目前为止。

</exercise>

<exercise id="u281-changes-06" type="choice" activity="cloze" goal="changes" stage="build">

目标词：get used to

### 题目

补全“我在习惯这里的工作”：I'm getting used to ___ here.

### 选项

- [a] working
- [b] work
- [c] worked

### 答案

a

### 选项反馈

- [a] 正确，介词 to 后接 -ing。
- [b] 这是误套 used to work 的过去习惯结构。
- [c] 这里不能接过去式。

### 提示

- get used to 中的 to 是介词。
- 动作使用 -ing 形式。

### 讲解

get used to working here 是习惯在这里工作。

</exercise>
