# Store

买衣服和饰品最扫兴的事，莫过于兴冲冲拎回家拆开包装，却发现真丝领口有一块污渍，或者袖口的扣子已经松脱掉了下来。走到商场的客服柜台沟通售后时，怎样不卑不亢地指明瑕疵、说清自己是想原路退钱还是换一件新品？这一单元围绕 **Store（商场退换货服务）**，帮你把衣物细节、破损描述与礼貌协商句式一次配齐。

## 你将在本课学会

- 精准区分退换货核心动词 **return**、**exchange**、**replace**，以及两种补偿方式 **money back** 与 **store credit**
- 说清服装配件与材质花纹：**collar**、**button**、**label**、**bra**、**silk**、**thick**、**pattern**、**stripe** 与 **diamond**
- 用 **damaged**、**stain**、**off**、**still** 有理有据地向店员展示商品状况
- 借助情态动词 **would** 与 **wouldn't** 让售后诉求和偏好表达既委婉又得体

## 退货、换码还是退代金券？先把诉求讲明白

站在柜台前，店员首先想知道你想怎么处理手里的商品。这组高频词分工非常清晰：

| 售后关键词 | 核心含义 | 柜台常见搭配与场景提示 |
| :--- | :--- | :--- |
| **return** | 退货（退回商品） | *I'd like to **return** this coat.*（我想退掉这件外套。） |
| **exchange** | 换货（调换尺码/款式） | 常搭配介词 *for*：**exchange** *it for a medium*（把它换成中号） |
| **replace** | 更换；替补新品 | 侧重用完好品顶替残次品：*Can you **replace** the broken zipper?* |
| **money back** | 退钱；原路退款 | 口语最常用 *get my **money back***（拿回退款） |
| **store credit** | 店内抵用额度/代金券 | 没有收据或特价商品退货时，商店常退 **store credit** 供下次店内消费 |

在沟通方案时，硬邦邦地说 *I want...* 容易显得生硬，换成 **would** 和 **wouldn't** 气氛立刻柔和下来：

- 店员礼貌询问偏好：***Would** you prefer your **money back** or **store credit**?*（您倾向于退钱还是退店内消费额度？）
- 顾客委婉说明顾虑：*I **wouldn't** wear such a **thick** scarf in spring, so **would** it be possible to **exchange** it?*（春天我不会戴这么厚的围巾，请问能换一件吗？）

## 细节放大镜：部位、材质与花纹

向店员解释退换原因时，越能点准具体部位和面料，沟通效率越高：

- **贴身衣物与小部件**：**bra** 指“文胸、胸罩”；衬衫最显眼的是 **collar**（衣领）和一排 **button**（纽扣）；而退换货最关键的凭证除了小票，就是衣服上的 **label**（标签、吊牌或洗水标）。
- **面料质感**：**silk**（丝绸、真丝）轻盈娇贵，护理不当极易钩丝；**thick**（厚的、厚实的）则常形容冬装毛衣、呢大衣的扎实手感。
- **图案与几何美感**：花色统称 **pattern**（图案、花纹）；经典的条纹叫 **stripe**（条纹衫常说 *a shirt with blue stripes*）。至于 **diamond**，在珠宝柜台它是璀璨的“钻石”，到了针织衫或丝巾上，它还常指经典的“菱形格纹”（*a **diamond** **pattern***）。

## 指认瑕疵的四个关键词

当商品并非你不喜欢，而是本身有质量问题时，下面四个词能帮你把情况说得一清二楚：

1. **damaged（受损的、有破损的）**：概括一切刮痕、开线或运输损坏，如 *The gift box arrived **damaged**.*
2. **stain（污渍、染色斑点）**：试穿化妆品蹭到的痕迹、油点都算，常搭介词 *on*——*There is a dark **stain** on the **collar**.*（衣领上有一块深色污渍。）
3. **off（脱落、掉下；减价）**：在售后场景里最常描述配件脱落，比如 *One **button** came **off***（掉了一颗扣子）；同时别忘了它也能表示“撕下吊牌”（*take the **label** **off***）或促销折扣（*20% **off***）。
4. **still（仍然、还）**：证明商品全新未穿过的定心丸——*The original **label** is **still** attached.*（原装吊牌还在上面呢。）

## 柜台实战例句

1. **I'd like to return this silk blouse because there is an oil stain right on the collar.**
   我想退掉这件真丝衬衫，因为衣领上正好有一块油渍。
   *点拨：`return` 说明诉求，`silk` 与 `collar` 点明衣物特征，`stain on...` 精准指出瑕疵位置。*

2. **The price label is still on the bra, so could I exchange it for a different size?**
   这件文胸上的价格吊牌还在，请问我能换个别的尺码吗？
   *点拨：贴身衣物能否退换往往取决于 `label` 是否 `still on`，换尺码用 `exchange ... for ...`。*

3. **Two buttons came off my new jacket—would the store replace it or give me my money back?**
   我新夹克掉了两颗扣子——店里会给我换件新的，还是把钱退给我？
   *点拨：`come off` 自然表达纽扣脱落；`would` 引出礼貌询问，并列对比 `replace` 与 `money back`。*

4. **Since you lost the receipt, we wouldn't be able to give cash, but we can offer store credit.**
   由于您弄丢了收据，我们无法退现金，但可以为您提供店内消费额度。
   *点拨：`wouldn't be able to` 比生硬的 *can't* 更具客服礼貌度，同时引出常见替代方案 `store credit`。*

5. **Does this thick wool sweater come in a blue stripe, or only in this diamond pattern?**
   这件厚羊毛衫有蓝色条纹款吗，还是只有这种菱形花纹？
   *点拨：`come in + 颜色/花纹` 是商场询问“有没有某款式”的地道句型，巧妙对比 `stripe` 与 `diamond pattern`。*

6. **The diamond ring wasn't damaged at all, and they even gave me ten percent off!**
   那枚钻戒一点儿也没受损，而且他们甚至还给了我九折优惠！
   *点拨：此处 `diamond` 回归“钻石”本义，`ten percent off` 表示减免百分之十（即中文说的九折）。*

## 退换货表达避坑指南

- **别把 `return` 当成“退钱”**：*return* 的宾语永远是**商品**（*return the dress* 退裙子），不能说 *return my money* 来表达退款；想要回钱，地道说法是 **get my money back**（或名词 *a refund*）。
- **中英文折扣方向刚好相反**：中文说“打八折”是指付原价的 80%，而英文用 **off** 说的是**减掉多少**——减掉 20% 叫 **20% off**（相当于八折），千万别把 *80% off* 理解成八折，那是惊人的“两折清仓”！
- **分清 `exchange` 与 `replace` 的视角**：顾客拿小号去换大号，通常说 *I want to **exchange** this shirt*；如果是零件坏了请商家拿个好的补上，常用 *Could you **replace** the missing **button**?*
