# Suggestion练习

<practice unit="181" format="2">

标题：Suggestion练习
辅助词：excuse, dinner, healthy, gladly, drive, shuttle, bus, either, way, enjoy, view, start, fresh, tomorrow, roast, smells, amazing, sister, eat, meat, sit, salad, bar, drink, stayed, quiet, small, home, grandma, highly, made, great, pasta, tried, stay, longer

## 学习目标

- food-travel | 餐饮与旅行推荐词 | 掌握 recommend、lamb、vegetarian、option、resort、waterfall、souvenir 的用法。
- polite-modals | 用 would 与 could 温和提议 | 熟练运用 would you、we would、we'd、you'd、could、take、say 软化语气。
- persuade-manners | 沟通礼仪与说服讨论 | 区分 politely 与 rude，准确运用 convince、doubt that、point 与不可数名词 progress。
- connectors-space | 转折顺承与方位介词 | 用 but、so、by 自然衔接饮食偏好、位置说明与备选建议。

### 题目
把点餐与旅行购物中的高频词汇和中文释义配成对。

### 配对
- [recommend] recommend | 推荐
- [lamb] lamb | 羊肉；小羊羔
- [vegetarian] vegetarian | 素食的；素食主义者
- [option] option | 选择；选项

### 提示
- lamb 词尾的 b 不发音，在菜单上指“羊肉”。

### 讲解

<exercise id="u181-modals-01" type="choice" activity="cloze" goal="polite-modals" stage="build">

目标词：would you, we'd, vegetarian, option

### 题目
补全餐厅里向服务员征求推荐的对话：
Excuse me, what ___ recommend for dinner? ___ love a healthy ___ ___ if you have one.

### 选项
- [opt-a] would you / We'd / vegetarian / option
- [opt-b] you'd / Could / lamb / progress
- [opt-c] we would / Rude / resort / point

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！疑问句倒装用 what would you recommend?，答句用 We'd love...（= We would love）礼貌表达需求，a healthy vegetarian option 指健康的素食选择。
- [opt-b] 特殊疑问句中情态动词要放在主语 you 前面（would you 而非 you'd），且 progress 不可数也不指菜品。
- [opt-c] 疑问句语序错误，且 Rude、resort、point 均不符合点餐语境。

### 提示
- 第一空是疑问句语序“您会……吗？”；第二空是 We would 的缩略形式。
- 后两空构成“素食选择”。

### 讲解
What would you recommend? 比直接问 What do you recommend? 更显温文尔雅；We'd love... 是点餐时替代生硬 I want 的高分句型。

</exercise>

<exercise id="u181-modals-02" type="choice" activity="cloze" goal="polite-modals" stage="build">

目标词：we would, could, take, you'd

### 题目
补全朋友间的出行提议：
___ gladly drive you there, or you ___ ___ the shuttle bus—either way, ___ really enjoy the mountain view!

### 选项
- [opt-a] Would you / say / convince / we'd
- [opt-b] We would / could / take / you'd
- [opt-c] Doubt that / but / by / option

### 答案
opt-b

### 选项反馈
- [opt-a] 陈述句开头不能用疑问倒装 Would you，且 say convince 不通顺。
- [opt-b] 正确！We would gladly drive...（我们很乐意开车送你）、you could take the shuttle bus（你也可以乘班车）、you'd really enjoy...（你一定会很喜欢）三处情态结构自然流畅。
- [opt-c] 各空词性与交通提议语境均不匹配。

### 提示
- 第一空是陈述语序“我们很乐意……”；第二、三空表示“可以乘坐”班车。
- 最后一空向对方热情安利风景：“你一定会……”。

### 讲解
could 在现在语境中表无压力的可行提议（“可以……”），take the bus 表乘车，you'd (= you would) 常用来预测对方一定会喜欢某项体验。

</exercise>

<exercise id="u181-manners-02" type="choice" activity="cloze" goal="persuade-manners" stage="build">

目标词：point, doubt that, progress, say

### 题目
补全小组讨论旅游攻略时的对话：
That's a good ___! I ___ we can make much ___ tonight, so what do you ___ we start fresh tomorrow?

### 选项
- [opt-a] point / doubt that / progress / say
- [opt-b] option / convince / souvenir / take
- [opt-c] resort / recommend / lamb / could

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！That's a good point!（说得有道理）、doubt that...（觉得未必……）、make much progress（取得多少进展）、what do you say we...（你说咱们……怎么样）全是地道口语搭配。
- [opt-b] convince 后接人而非无引导词的从句，much 后面也不能修饰可数单数 souvenir。
- [opt-c] 各词含义与商讨计划进度的语境完全不符。

### 提示
- 赞同别人说的在理用 That's a good ___!
- 第三空受 much 修饰，填不可数名词“进展”；第四空构成 What do you ___ we...?

### 讲解
记住两个高频固定搭配：make progress（取得进展，progress 不可数，用 much/great 修饰）和 What do you say we + 动词原形...?（咱们……怎么样？）。

</exercise>

<exercise id="u181-connect-01" type="choice" activity="cloze" goal="connectors-space" stage="build">

目标词：lamb, but, so, by

### 题目
选出恰当的词把点餐协商串联起来：
The roast ___ smells amazing, ___ my sister doesn't eat meat, ___ could we sit ___ the salad bar instead?

### 选项
- [opt-a] lamb / but / so / by
- [opt-b] waterfall / so / but / politely
- [opt-c] souvenir / by / so / rude

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！roast lamb（烤羊肉）闻起来很香，用 but 转折说明妹妹不吃肉，再用 so 顺承提出请求：坐在沙拉吧旁边（by the salad bar）。
- [opt-b] 瀑布不能搭配 roast（烘烤），且因果和转折连词位置颠倒。
- [opt-c] 烤纪念品不合常理，介词与形容词位置也错误。

### 提示
- 先夸烤羊肉香，再用转折连词引出不吃肉的情况，接着用结果连词引出换座位的提议。
- 最后一空表示“在沙拉台旁边”。

### 讲解
委婉调整别人提议的经典公式是“先肯定 + but 说明实际情况 + so 提出替代方案”；介词 by 在座位场景中常表示“在……旁边”（如 by the window / by the salad bar）。

</exercise>

<exercise id="u181-manners-03" type="choice" activity="word-choice" goal="persuade-manners" stage="recognize">

目标词：politely, convince, rude

### 题目
下面哪句话中 `politely`、`convince` 和 `rude` 的词性与语法搭配完全正确？

### 选项
- [opt-a] Let's ask politely; trying to convince him to drink it would be rude.
- [opt-b] Let's ask rude; trying to convince him drink it would be politely.
- [opt-c] Let's politely to ask; trying to rude him would be convince.

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！副词 politely 修饰动词 ask；convince sb. to do sth. 搭配不定式 to drink；系动词 be 后接形容词 rude 作表语。
- [opt-b] ask 后应用副词而非形容词 rude；convince sb. 后漏了 to；would be 后应用形容词而非副词 politely。
- [opt-c] Let's 后直接接动词原形 ask，rude 是形容词不能作动词，convince 也不能作形容词表语。

### 提示
- 修饰动词 ask 要用 -ly 结尾的副词；放在 would be 后面作表语要用形容词。
- “说服某人做某事”的结构是 convince sb. to do sth.。

### 讲解
注意区分词性：politely 是副词（修饰动作 ask / say / refuse），rude 是形容词（作表语或定语）；convince 后接“人 + to do”。

</exercise>

<exercise id="u181-food-03" type="input" activity="write" goal="food-travel" stage="recall">

目标词：recommend, lamb

### 题目
用英文写出：“我强烈推荐这道烤羊肉。”（主语 `I`，“强烈”用副词 `highly`，“这道烤羊肉”用 `the roast ...`）

### 答案
- I highly recommend the roast lamb.

### 提示
- “强烈推荐”是固定高频搭配 highly + 推荐动词。
- “羊肉”是不可数名词，末尾有一个不发音的字母 b。

### 讲解
highly recommend 是推荐美食、书籍或餐厅时的黄金搭配；the roast lamb 指烤羊肉，注意 recommend 中间是一个 c、两个 m，lamb 末尾有 b。

</exercise>

<exercise id="u181-manners-04" type="input" activity="write" goal="persuade-manners" stage="recall">

目标词：progress

### 题目
用英文写出：“我们今天取得了很大进展。”（主语 `We`，动词用过去式 `made`，修饰词用 `great`，句末写 `today`）

### 答案
- We made great progress today.

### 提示
- “进展”是不可数名词，great 前面千万不要加冠词 a！
- 单词以 pro- 开头，后半部分是 gress。

### 讲解
make great progress 是极重要的地道搭配；由于 progress 是不可数名词，无论进展多大都不能写成 a great progress。

</exercise>

### 听力
I think you'd really like their new vegetarian pasta option.

### 题目
听录音，说话人在向朋友推荐什么？

### 选项
- [opt-a] 店里新推出的素食意面选择。
- [opt-b] 瀑布旁边一家度假村的招牌烤羊肉。
- [opt-c] 纪念品商店里手工制作的茶杯。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！you'd really like 热情预测“你一定会很喜欢”，their new vegetarian pasta option 指他们新出的素食意面选项。

- [opt-c] 录音中没有提到纪念品店或茶杯。

### 提示
- 注意听 I think 后面的缩略情态结构，以及 pasta 前面表示“素食的”形容词。

### 讲解
I think you'd really like... 是朋友间分享美食、电影或好去处时最自然亲切的安利句式。
