# 购物 4

逛街淘到心仪又划算的好物，回到家总忍不住跟朋友好好炫耀一番：“那家店所有东西都在打折！我试穿了一件泳衣尺码刚刚好，买满一百块还免费送了一条围巾！”这一课我们就来学习如何眉飞色舞地用英语分享一次完整的购物经历。

## 本课学习目标

- 谈论促销折扣、赠品与账单总价（**on sale / for free / total cost / sixty / hundred**）
- 熟练运用购物高频动词及其不规则过去式（**sell → sold / paid / got / shop / return**）
- 描述服饰配饰、尺码试穿与排队结账（**scarf / earrings / swimsuit / size / small / large / try / try on / wait in line**）
- 用地道的感叹与口语词表达惊喜体验（**yeah / amazing / perfect / star / everything / how can ...?**）

## 划算到想尖叫：打折、免费送与算总账

跟朋友聊起“买得值不值”，最核心的就是下面这组价格与优惠表达：

- **on sale**：正在打折促销（注意 **on** 强调“处于特卖活动中”，比如 **Everything here is on sale!** 这里所有东西都在打折！**everything** 虽指全部商品，作主语时动词用单数 **is / was**）。
- **for free**：免费地，常放在句末，如 **I got a bag for free**（我免费拿到了一个包）。
- **total cost**：总费用、总价。结账算总账时常搭配百位与十位数字：**one hundred and sixty dollars**（一百六十美元，百位 **hundred** 与十位 **sixty** 之间可用 **and** 连接，美式口语也可省略）。
- **How can ...?**：表示惊讶感叹“怎么能 / 怎么会……呢？”，比如看到骨折价时脱口而出：**How can everything be so cheap?**（怎么所有东西都能这么便宜？）

## 讲述购物过程：三组必背过去式与售后退换

分享已经结束的逛街经历，动词自然要切到过去时。这三组词在购物故事里出镜率极高：

| 词汇对比 | 词性与含义 | 实用搭配与拼写提醒 |
| --- | --- | --- |
| **sell** → **sold** | 卖（原形 → 过去式） | **Does this shop sell hats?** / **They sold the last one.**（**shop** 作名词是“商店”，也可作动词“购物”） |
| **pay** → **paid** | 付款（过去式） | 注意拼写是 **p-a-i-d**（不是 *payed*），常说 **paid sixty dollars for it** |
| **get** → **got** | 买到、得到（过去式） | 口语里常用 **got** 代替 bought，显得轻松自然 |
| **return** | 退货、归还 | 在旅行中是“返回”，在商场里则是超实用的“**退货**”（**return the shirt**） |

## 试衣间与收银台：单品、尺码与排队

走进服装配饰店，我们先看单品，再挑尺码、试穿，最后排队买单：

1. **三件人气单品**：**scarf**（围巾）、**earrings**（耳环，因为两只耳朵成对佩戴，日常多用复数）、**swimsuit**（连体泳衣，由 **swim** + **suit** 合成）。
2. **尺码大小**：**size**（尺码）常搭配 **small**（小号的，衣服吊牌上的 **S** 码）和 **large**（大号的，吊牌上的 **L** 码）。想要某个尺码常用介词 **in**，比如 **Do you have this in a large size?**（这件有大码吗？）
3. **try 与 try on**：单用 **try** 表示“尝试”（如 **try a small size** 试试小码）；加上介词副词 **on** 组成 **try on**，专门指“把衣服、鞋子、配饰穿戴在身上试效果”。
4. **排队结账**：打折季收银台前常排起长队，美式英语地道说法是 **wait in line**（排队等候，字面是“站在一条队列里等”）。

## 情绪价值拉满：像母语者一样夸赞

朋友给你看她新买的耳环或围巾时，别只会说 good，换上这几个词立刻鲜活起来：

- **Yeah!**（是啊！/ 没错！比 Yes 更随性亲切的口语回应）
- **amazing**（太棒了、令人惊艳的）
- **perfect**（完美的、严丝合缝的，夸尺码合身最常用：**The size is perfect!**）
- **star**（原意“星星”，也指“明星”，夸朋友戴上配饰像电影明星：**You look like a movie star!**，或者夸一家“五星好店” **a five-star shop**）

## 原创购物分享例句精选

1. **— Did you buy that scarf? — Yeah! Everything in the shop was on sale.**
   ——你买那条围巾了吗？——买啦！店里所有东西都在打折。
   *点拨：that 指代双方都知道的那件单品，Everything 配单数 was。*
2. **I waited in line for half an hour to try on this swimsuit, and the size is perfect!**
   为了试穿这件泳衣我排了半小时队，而且尺码完美合身！
   *点拨：wait in line 与 try on 还原真实试衣间场景。*
3. **She paid one hundred dollars for the coat and got a pair of earrings for free.**
   她花一百美元买了那件外套，还免费得了一副耳环。
   *点拨：paid ... for ... 与 got ... for free 对照鲜明。*
4. **This small size is too tight; do they sell a large size here, or did they already sell out?**
   这个小码太紧了；他们这儿卖大码吗，还是已经卖光了？
   *点拨：助动词 do / did 后面动词保持原形 sell。*
5. **They sold two hundred tickets in ten minutes — how can that star be so popular?**
   他们十分钟就卖出了两百张票——那位明星怎么能这么受欢迎？
   *点拨：具体数字 two hundred 后不加 s；how can 表达惊叹。*
6. **The total cost was only sixty dollars, and you can return anything within thirty days.**
   总费用才六十美元，而且三十天内任何商品都可以退货。
   *点拨：total cost 指账单总金额，return 表示售后退还。*

## 常见易错点提醒

- **try on 遇到代词必须放中间**：试穿一条围巾可以说 **try on the scarf**，但如果用 **it** 代替围巾、用 **them** 代替耳环（**earrings**），就必须说 **try it on** / **try them on**，不能说 *try on it*。
- **牢记 paid 的不规则拼写**：虽然 **play** 的过去式是规则的 played，但 **pay**（付钱）和 **say**（说）一样，过去式要把 **y** 变成 **i** 加 **d**：**paid**。
- **百位具体数字后 hundred 不加 s**：“一百”是 **one hundred**（或 **a hundred**），不能写成 *one hundreds*。
