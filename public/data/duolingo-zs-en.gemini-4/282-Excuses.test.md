## 学习目标
- follow-up-work | 推进职场后续沟通 | 用跟进、群发资料、准则与事务相关词汇处理工作衔接。

- past-logic | 严谨推理与过去完成复盘 | 运用 given that、the case that 及 had been 系列结构分析前因后果。

<exercise id="u282-work-01" type="matching" activity="matching" goal="follow-up-work" stage="recognize">

目标词：follow up, send out, guidelines, background information, corporation

### 题目
把会后跟进与企业沟通中的高频表达与中文意思配成对。

### 配对
- [follow-up] follow up | 跟进后续进展
- [send-out] send out | 发出；分发
- [guidelines] guidelines | 指导方针；操作准则
- [bg-info] background information | 背景资料
- [corporation] corporation | 大公司；企业

### 提示
- 会议结束后继续追踪落实某事叫 `follow up`。
- 把通知或文件统一群发出去叫 `send out`。

### 讲解
在大型 `corporation` 工作时，会后及时 `follow up` 并向团队 `send out` 完整的 `background information` 与 `guidelines` 是基本职业素养。

</exercise>

<exercise id="u282-duty-01" type="matching" activity="matching" goal="duty-priority" stage="recognize">

目标词：efficient, practical, technical, obligation, observation

### 题目
把职场分析问题与明确职责常用的五个词和中文释义配对。

### 配对
- [efficient] efficient | 高效率的
- [practical] practical | 切实可行的；务实的
- [technical] technical | 技术上的
- [obligation] obligation | 义务；职责
- [observation] observation | 观察；观察所得的评论

### 提示
- 注意区分拼写相近的 `obligation`（必须履行的义务）与 `observation`（敏锐观察）。
- 不空谈理论、能落地的方案是 `practical`。

### 讲解
遇到 `technical`（技术上的）故障时，履行岗位 `obligation`（职责）、提出敏锐的 `observation`（观察），才能拿出既 `practical` 又 `efficient` 的对策。

</exercise>

<exercise id="u282-duty-02" type="choice" activity="word-choice" goal="duty-priority" stage="recognize">

目标词：making excuses, failure to, credit

### 场景
项目延期后，组长在复盘会上提醒大家要正视漏检问题，同时表扬了连夜修复系统的工程师。

### 题目
下面哪句话准确表达了“别再为未能按时测试找借口了，我们应该把修复系统的功劳归于林工”？

### 选项
- [opt-credit] Stop making excuses for our failure to test on time, and let's give Engineer Lin credit for fixing the system.
- [opt-prior] Stop sending out for our priority to test on time, and let's give Engineer Lin matter for fixing the system.
- [opt-corp] Stop following up for our corporation to test on time, and let's give Engineer Lin obligation for fixing the system.

### 答案
opt-credit

### 选项反馈
- [opt-credit] 正确！`stop making excuses` 是停止找借口，`failure to + 动词原形` 是未能做某事，`give sb. credit` 是把功劳归于某人。
- [opt-prior] `priority` 和 `matter` 填入句中语义不通。
- [opt-corp] 跟进进度是好事，不应说 `stop following up`，且 `give obligation` 并非表扬功劳。

### 提示
- “停止找借口”在 `Stop` 后接动名词短语。
- “把功劳归于某人”用固定搭配 `give sb. ____`。

### 讲解
成熟团队复盘有两大原则：诚实面对 `failure to ...`（未能做到某事）而不 `making excuses`，同时大方给出力的人记功（`give credit`）。

</exercise>

<exercise id="u282-work-02" type="choice" activity="word-choice" goal="follow-up-work" stage="recognize">

目标词：matter, potential, target

### 题目
哪句话表达了“在这件紧迫事务恶化之前解决它，我们依然能达成年度销售目标并释放增长潜力”？

### 选项
- [opt-target] If we resolve this urgent matter soon, we can still hit our sales target and unlock growth potential.
- [opt-had] If we send out this technical guideline soon, we can still hit our excuse and unlock observation.
- [opt-case] If we follow up this corporation soon, we can still hit our obligation and unlock prior.

### 答案
opt-target

### 选项反馈
- [opt-target] 正确！`urgent matter` 指紧迫事务，`hit our sales target` 指达成销售目标，`growth potential` 指增长潜力。
- [opt-had] `hit our excuse` 搭配荒谬。
- [opt-case] `prior` 是形容词不能直接作 `unlock` 的宾语。

### 提示
- 表示需要处理的“事情、事务”用名词 `matter`。
- 与动词 `hit` 或 `reach` 搭配表示“业绩目标”的是 `target`。

### 讲解
在商务语境中，`an urgent/sensitive matter` 比泛泛的 `thing` 正式得多；`hit a target` 与 `unlock potential` 则是汇报业绩的高频搭配。

</exercise>

<exercise id="u282-duty-03" type="choice" activity="cloze" goal="duty-priority" stage="build">

目标词：prior, prior to, priority

### 题目
用 `prior` 词族的正确形式补全通知：
"Without ____ approval, no code may be updated ____ Monday's launch, as system stability is our top ____."

### 选项
- [opt-a] prior / prior to / priority
- [opt-b] prior to / prior / priority
- [opt-c] priority / prior to / prior

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！第一空修饰名词 `approval` 用形容词 `prior`（事先的）；第二空接名词短语表“在……之前”用介词短语 `prior to`；第三空在 `top` 后作名词表“当务之急”用 `priority`。
- [opt-b] 前两空用反了：`Without prior to approval` 介词重叠错误，`updated prior Monday's launch` 漏了介词 `to`。
- [opt-c] `top` 后面需要名词 `priority`，不能以形容词 `prior` 收尾。

### 提示
- 第一空前已有介词 `Without`，只需填形容词修饰 `approval`。
- 第二空相当于正式版的 `before`，后面接 `Monday's launch`。

### 讲解
牢记三者分工：`prior + 名词`（先前的……）、`prior to + 时间/事件`（在……之前）、`top priority`（头等优先事项）。

</exercise>

<exercise id="u282-logic-01" type="choice" activity="cloze" goal="past-logic" stage="build">

目标词：had been, hadn't it, hadn't been

### 题目
补全项目复盘对话：
"The backup server ____ tested last week, ____?"
"Yes! If it ____ ready, we would have lost all client data."

### 选项
- [opt-a] had been / hadn't it / hadn't been
- [opt-b] hadn't been / had been / hadn't it
- [opt-c] had it been / hadn't it / had been

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！前肯后否的反意疑问句用 `had been ..., hadn't it?`；后一句虚拟条件句表示“要是当时没准备好”用 `If it hadn't been ready`。
- [opt-b] 反意疑问句尾不能填陈述形式 `had been`。
- [opt-c] 第一句是带反意疑问句尾的陈述句，开头不能用倒装语序 `had it been`。

### 提示
- 第一句遵循反意疑问句“前肯定、后否定”原则。
- 第二句主句是 `we would have lost all client data`，说明从句需假设“要是当时没有准备好”。

### 讲解
过去完成时被动 `had been tested` 搭配反意疑问 `hadn't it?` 用来核实既有事实；`If it hadn't been ...` 则用于对过去做反事实假设。

</exercise>

<exercise id="u282-logic-02" type="choice" activity="cloze" goal="past-logic" stage="build">

目标词：given that, the case that, had it been

### 题目
补全分析报告中的严谨论述：
"____ our budget was cut in half, it is often ____ schedules slip; however, ____ flagged earlier, we could have adjusted the scope."

### 选项
- [opt-a] Given that / the case that / had it been
- [opt-b] Prior to / making excuses / hadn't it
- [opt-c] Failure to / given that / had been

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`Given that` 引出已知原因“鉴于预算减半”，`it is often the case that ...` 陈述常见实情，`had it been flagged earlier` 是省略 `if` 的过去虚拟倒装。
- [opt-b] `Prior to` 不能直接接完整从句 `our budget was cut`，句末也不能用 `hadn't it`。
- [opt-c] `Failure to` 后应接动词原形而非从句，第三空缺主语 `it`。

### 提示
- 第一空后接完整句子，表示“鉴于、考虑到”。
- 第三空相当于 `if it had been flagged earlier` 的正式倒装结构。

### 讲解
在正式书面英语中，把 `if it had been ...` 倒装成 `had it been ...` 极其优雅紧凑，常与 `given that` 和 `it is the case that` 搭配使用。

</exercise>

<exercise id="u282-work-04" type="choice" activity="audio-choice" goal="follow-up-work" stage="recognize">

目标词：send out, guidelines, prior to

### 听力
Please send out the safety guidelines prior to the meeting.

### 题目
听录音，说话人要求在会议之前完成什么工作？

### 选项
- [opt-right] 把安全准则分发出去
- [opt-wrong1] 替技术部门寻找延误借口
- [opt-wrong2] 取消跨国企业的年度目标考核

### 答案
opt-right

### 选项反馈
- [opt-right] 正确！录音要求 `prior to the meeting`（在会议之前）`send out the safety guidelines`（把安全准则发出去）。
- [opt-wrong1] 录音没有提到技术部门或找借口。
- [opt-wrong2] 录音没有提到取消考核。

### 提示
- 祈使句开头的动作是“统一发出、群发”。
- 听清宾语 `the safety ...` 以及时间状语 `... the meeting`。

### 讲解
原句为："Please send out the safety guidelines prior to the meeting." 简洁明了地交代了会前准备事项。
