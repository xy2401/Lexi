# 购物 4练习

标题：购物 4练习
辅助词：a, an, be, but, can, cheap, did, do, does, dollars, for, hats, hour, i, is, it, last, like, looked, movie, of, one, only, pair, red, she, so, still, the, these, they, this, too, waited, want, was, we, you

## 学习目标
- deals-prices | 折扣赠品与账单总价 | 用 on sale、for free、total cost、paid 与百十位数字谈论划算交易。
- items-fitting | 服饰尺码与试穿退换 | 谈论围巾、耳环、泳衣的大小尺码，掌握 try on 与 return 用法。
- store-actions | 逛店排队与买卖过去式 | 区分 sell / sold、got，描述逛店与排队结账经历。
- shopping-reactions | 惊喜评价与口语感叹 | 用 amazing、perfect、star、yeah 与 how can 分享购物心情。

<exercise id="u081-items-01" type="matching" activity="matching" goal="items-fitting" stage="recognize">

目标词：scarf, earrings, swimsuit, size, small, large

### 题目
把服饰单品、尺码及大小词汇与中文释义连起来。

### 配对
- [scarf] scarf | 围巾
- [earrings] earrings | 耳环
- [swimsuit] swimsuit | 泳衣
- [size] size | 尺码；大小
- [small] small | 小的；小号的
- [large] large | 大的；大号的

### 提示
- ear（耳朵）加上 rings（环）就是戴在耳朵上的饰品。
- 服装标签上的 S 码和 L 码分别对应最后两个形容词。

### 讲解
scarf（围巾）、earrings（耳环，常用复数）和 swimsuit（泳衣）是常见购物单品；挑衣服时常看 size（尺码），如 small（小号）或 large（大号）。

</exercise>

<exercise id="u081-deals-01" type="matching" activity="matching" goal="deals-prices" stage="recognize">

目标词：on sale, for free, total cost, paid, sixty, hundred

### 题目
把价格优惠与结账表达和对应的中文意思配对。

### 配对
- [on-sale] on sale | 打折促销中
- [for-free] for free | 免费地
- [total-cost] total cost | 总费用；总价
- [paid] paid | 付了款（过去式）
- [sixty] sixty | 六十
- [hundred] hundred | 一百

### 提示
- 注意区分“特价打折”与“完全免费”。
- paid 是动词 pay 的不规则过去式。

### 讲解
on sale 表示商品正在打折，for free 表示免费赠送；total cost 指账单总金额，paid 表示已经付了钱；sixty 是 60，hundred 是 100。

</exercise>

<exercise id="u081-store-01" type="matching" activity="matching" goal="store-actions" stage="recognize">

目标词：shop, sell, sold, try on, return, line

### 题目
把商店购物与售后相关词汇和中文意思连起来。

### 配对
- [shop] shop | 商店；购物
- [sell] sell | 卖（原形）
- [sold] sold | 卖了（过去式）
- [try-on] try on | 试穿；试戴
- [return] return | 退货；归还
- [line] line | 队伍；排

### 提示
- 先把“卖”的原形与过去式区分开。
- wait in line 是商场收银台前常见的“排队等候”。

### 讲解
shop 既可指商店也可指逛街购物；sell 的过去式是 sold；买衣服前常先 try on（试穿），买回家不合适可以 return（退货）；in line 表示在队伍里排队。

</exercise>

<exercise id="u081-react-01" type="choice" activity="word-choice" goal="shopping-reactions" stage="recognize">

目标词：that, shop, yeah, everything, on sale, and, star, in, scarf

### 场景
你刚逛完街回来，室友问你街角那家新店怎么样。

### 题目
“Yeah! Everything in that shop was on sale, and I looked like a movie star in this scarf!” 表达了什么意思？

### 选项
- [opt-a] 太棒啦！那家店里所有东西都在打折，而且我戴上这条围巾看起来像电影明星一样！
- [opt-b] 可惜！那家店所有商品都卖光了，只有一位电影明星买到了这条围巾。
- [opt-c] 是啊！那家店的围巾虽然不打折，但店名叫做“电影之星”。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！Everything ... was on sale 表示全场打折，looked like a movie star in this scarf 形容戴着围巾超有星范儿。
- [opt-b] on sale 是“正在打折促销”，不是“卖光了（sold out）”。
- [opt-c] 原句明确说了 Everything ... was on sale（所有东西都在打折），looked like 是“看起来像”。

### 提示
- on sale 意思是特价促销。
- in + 服饰（in this scarf）在英语里表示“穿戴着某件衣物配饰”。

### 讲解
Yeah! 是热情的口语肯定；Everything 作主语搭配单数 was；in this scarf 表示“戴着这条围巾”，like a movie star 意为“像一位电影明星”。

</exercise>

<exercise id="u081-deals-02" type="choice" activity="cloze" goal="deals-prices" stage="build">

目标词：paid, hundred, and, sixty, got, earrings, for free

### 题目
选择正确的一组词补全超值购物战报：
She _____ one _____ _____ _____ dollars, and she _____ a pair of _____ _____!

### 选项
- [opt-a] paid / hundred / and / sixty / got / earrings / for free
- [opt-b] sold / sixty / in / hundred / try / line / on sale
- [opt-c] return / hundred / and / large / paid / shop / for free

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！“她付了一百六十美元，还免费得到了一副耳环”，过去时态、数字读法与固定短语全部准确。
- [opt-b] sixty in hundred 不是正确的英文数字表达，she try 时态和单复数也不对。
- [opt-c] She return 缺少过去式词尾，a pair of shop 也不成对。

### 提示
- 前半句表达“付了 160 美元”：one hundred and sixty dollars。
- 后半句 a pair of 后面接成双成对的配饰，句末表示“免费地”。

### 讲解
paid 后直接接所付金额；百位与十位用 and 连接为 one hundred and sixty；a pair of earrings 指“一副耳环”，for free 表示免费获赠。

</exercise>

<exercise id="u081-fitting-01" type="choice" activity="cloze" goal="items-fitting" stage="build">

目标词：swimsuit, small, try, large, size, here

### 题目
补全试衣间门口顾客对店员说的话：
This _____ is too _____; can I _____ a _____ _____ _____?

### 选项
- [opt-a] swimsuit / small / try / large / size / here
- [opt-b] line / paid / sell / sixty / star / that
- [opt-c] total cost / large / got / small / shop / in

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！“这件泳衣太小了；我能在这儿试一下大码吗？”非常贴合试衣场景。
- [opt-b] too paid（太付款了）和 sixty star 都不通顺。
- [opt-c] can I 后面必须跟动词原形，不能跟过去式 got。

### 提示
- 前半句说明试穿的单品“太小了（too small）”。
- 后半句礼貌询问能不能在“这里”试一个“大尺码（large size）”。

### 讲解
too small 表示尺码偏小；can I try a large size? 用来向店员索要大一号尺码试穿。

</exercise>

<exercise id="u081-store-02" type="choice" activity="cloze" goal="store-actions" stage="build">

目标词：shop, sell, in, line, sold

### 题目
补全关于抢购热门商品的对话：
Does this _____ still _____ hats? We waited _____ _____ for an hour, but they _____ the last one!

### 选项
- [opt-a] shop / sell / in / line / sold
- [opt-b] size / sold / on / scarf / sell
- [opt-c] star / return / in / earrings / paid

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！助动词 Does 后接动词原形 sell；waited in line 表示排队等候；后半句讲过去结果用过去式 sold（卖掉了最后一个）。
- [opt-b] Does 后面不能接过去式 sold，waited on scarf 也不合逻辑。
- [opt-c] waited in earrings 搭配错误。

### 提示
- 第一句有 Does，谓语动词要用原形“卖”。
- 第二句先说“排队等了一小时”，转折后用过去式说明他们把最后一个“卖掉了”。

### 讲解
Does this shop still sell ...? 询问商店是否仍在出售某物；wait in line 是“排队”；sold 是 sell 的过去式。

</exercise>

<exercise id="u081-react-02" type="compose" activity="compose" goal="shopping-reactions" stage="build">

目标词：how can, everything, here

### 题目
把词块连成一句惊讶感叹：“这里的所有东西怎么会这么便宜？”

### 词块
How | can | everything | here | be | so | cheap

### 答案
- How can everything here be so cheap?

### 提示
- 用 How can 开头表达惊讶疑问。
- 主语是“这里的所有东西”（everything here），后接动词原形 be 和表语 so cheap。

### 讲解
How can + 主语 + 动词原形 ...? 常用来表达难以置信的惊喜或疑问；here 紧跟在 everything 后修饰范围“这里的一切”。

</exercise>

<exercise id="u081-fitting-02" type="compose" activity="compose" goal="items-fitting" stage="build">

目标词：try, on, try on, that, swimsuit

### 题目
把词块连成问句：“她试穿了那件红色的泳衣吗？”

### 词块
Did | she | try | on | that | red | swimsuit

### 答案
- Did she try on that red swimsuit?

### 提示
- 过去时一般疑问句以 Did she 开头，接短语动词原形 try on。
- 宾语按“指示词 + 颜色 + 名词”排列为 that red swimsuit。

### 讲解
try on 表示“试穿”；因为宾语是具体名词词组 that red swimsuit（而不是代词 it），放在 try on 后面非常自然。

</exercise>

<exercise id="u081-deals-03" type="input" activity="write" goal="deals-prices" stage="recall">

目标词：total cost, hundred

### 题目
用英文写出：“总费用是一百美元。”（用现在时 is）

### 答案
- The total cost is one hundred dollars.
- The total cost is a hundred dollars.

### 提示
- 主语“总费用”写作 The total cost，搭配单数系动词 is。
- “一百美元”可以说 one hundred dollars 或 a hundred dollars，注意 hundred 不加 s。

### 讲解
the total cost 指全部开销总计；表达确切的一百美元时，hundred 保持单数，dollars 用复数。

</exercise>

<exercise id="u081-fitting-03" type="input" activity="write" goal="items-fitting" stage="recall">

目标词：return, earrings

### 题目
用英文写出：“我想退掉这副耳环。”（用 want to 与 these）

### 答案
- I want to return these earrings.

### 提示
- “我想要做某事”用 I want to ...，“退货”用动词 return。
- 因为耳环是复数名词，前面的“这”要用复数指示词 these。

### 讲解
return 在购物场景中表示“把买来的商品退回商店”；earrings 是复数形式，因此搭配复数指示代词 these。

</exercise>

<exercise id="u081-listen-01" type="choice" activity="audio-choice" goal="deals-prices" stage="recognize">

目标词：everything, in, that, shop, on sale, got, amazing, scarf, and, paid, sixty

### 听力
Everything in that shop was on sale, so I got an amazing scarf and paid only sixty dollars.

### 题目
听录音中的购物分享，选出与原文一致的一项。

### 选项
- [opt-a] 那家店全场打折，说话人只花了六十美元就买到了一条超棒的围巾。
- [opt-b] 那家店只有围巾不打折，说话人花了一百六十美元才买下来。
- [opt-c] 说话人在店里免费领了一条围巾，一分钱都没付。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！录音清楚提到了 Everything in that shop was on sale 以及 got an amazing scarf and paid only sixty dollars。
- [opt-b] 录音说全场都在打折，价格是 sixty（60）而不是一百六十。
- [opt-c] 录音里付了六十美元（paid only sixty dollars），并不是免费的。

### 提示
- 注意听开头商店的促销范围，以及说话人买到的单品是什么。
- 听清句尾实际支付的十位数金额是多少。

### 讲解
an amazing scarf 指一条极棒的围巾（amazing 以元音音素开头，前接 an）；paid only sixty dollars 强调只花了六十美元，非常划算。

</exercise>
