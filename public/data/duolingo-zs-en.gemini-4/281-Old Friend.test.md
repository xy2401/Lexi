目标词：run into, back in town, catch you up on, so far, can't complain

### 题目
把老友重逢寒暄中最地道的口语表达和中文意思配成对。

### 配对
- [run-into] run into | 偶然撞见；偶遇
- [back-in-town] back in town | 回城里了；回老家了
- [catch-up] catch you up on | 给你聊聊……的最新近况
- [so-far] so far | 到目前为止
- [cant-complain] can't complain | 还不错；没什么好抱怨的

### 提示
- 街角不期而遇用动词短语 `run into`。
- 生活顺遂时，英美人士常低调回答“没什么好抱怨的”。

### 讲解
偶遇刚 `back in town` 的老友（`run into`），坐下来 `catch you up on` 彼此近况，聊聊新生活 `so far` 怎么样，回一句 `Can't complain!` 最自然不过。

</exercise>

目标词：expecting, kindergarten, all grown up, on the whole

### 题目
把聊起家庭变化与总结近况的表达和中文释义配对。

### 配对
- [expecting] expecting | 怀孕；即将迎来宝宝
- [kindergarten] kindergarten | 幼儿园
- [all-grown-up] all grown up | 完全长大成人了

### 讲解

<exercise id="u281-reunion-02" type="choice" activity="word-choice" goal="surprise-reunion" stage="recognize">

目标词：how long has it been, it's been, how's, going

### 场景
你在书店门口偶遇了大学室友，两人激动地拥抱寒暄。

### 题目
下面哪组一问一答最地道地表达了“咱们有多久没见了？工作近来怎么样？”与“都五年了！”？

### 选项
- [opt-been] "How long has it been? How's work going?" — "It's been five years!"
- [opt-long] "How long is it been? How's work get?" — "It's going five years!"
- [opt-run] "How far has it been? Who's work going?" — "It's design five years!"

### 答案
opt-been

### 选项反馈
- [opt-been] 正确！`How long has it been?` 搭配 `It's been ...`（`It has been`）感叹久别重逢，`How's work going?` 询问工作近况。
- [opt-long] 现在完成时助动词应为 `has` 而非 `is`，且询问近况用 `going` 不用 `get`。
- [opt-run] 询问时间跨度用 `How long` 不用 `How far`，`Who's` 也用词错误。

### 提示
- 感叹从上次见面到现在隔了多久，必须使用现在完成时 `has it been`。
- 问候工作进展用 `How's work ____?`。

### 讲解
注意回答里的 `It's been` 是 `It has been` 的缩略形式，与问句 `How long has it been?` 严丝合缝地呼应。

</exercise>

<exercise id="u281-miles-02" type="choice" activity="word-choice" goal="milestones-ties" stage="recognize">

目标词：forties, compliment, things

### 题目
老友夸你步入四十岁后气色反而更好了，你想表达“谢谢夸奖，我四十多岁这几年各方面都很顺心”，哪句英文拼写与用词完全正确？

### 选项
- [opt-forties] Thanks for the compliment—things have been really peaceful in my forties!
- [opt-fourties] Thanks for the complement—things have been really peaceful in my fourties!
- [opt-expect] Thanks for the kindergarten—overseas have been really peaceful in my forties!

### 答案
opt-forties

### 选项反馈
- [opt-forties] 正确！`compliment`（带字母 i）意为夸奖，复数 `things` 泛指生活各方面，四十多岁正确拼写为 `forties`（无 u）。
- [opt-fourties] 两处经典拼写陷阱：把“赞美”误写成了表示“补充”的 `complement`，且 `forties` 多写了字母 `u`。
- [opt-expect] 词义混乱，`overseas` 不能作复数主语。

### 提示
- 注意检查“夸奖”中间是字母 `i` 还是 `e`。
- 检查“四十多岁”的拼写：由 `forty` 变复数，不含字母 `u`！

### 讲解
这道题浓缩了两个高频拼写考点：赞美是 `compliment`，四十多岁是 `in my forties`；而复数 `things` 在口语中常泛指“生活近况、诸事”。

</exercise>

<exercise id="u281-updates-01" type="choice" activity="cloze" goal="life-updates" stage="build">

目标词：liking, design, loving

### 题目
补全两位老同学聊起转行新工作的对话：
"How are you ____ your new career in interior ____?"
"Honestly, I'm ____ every single project!"

### 选项
- [opt-a] liking / design / loving
- [opt-b] expecting / forties / going
- [opt-c] run into / overall / liking

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！口语中常用进行时 `How are you liking ...?` 询问对新工作的感受，并用 `I'm loving ...!` 热情回应；`interior design` 是室内设计。
- [opt-b] 词义与职业话题完全不符。
- [opt-c] `are you` 后面不能接动词原形 `run into`，`in interior overall` 也不通。

### 提示
- 第一空和第三空都在 `be` 动词后使用口语进行时，生动表达对新阶段的喜爱感受。
- 第二空填名词“设计”。

### 讲解
在真实叙旧口语里，`How are you liking ...?` 和 `I'm loving it!` 专门用来表达当下正新鲜、正投入的体验，鲜活又有感染力。

</exercise>

<exercise id="u281-updates-02" type="choice" activity="cloze" goal="life-updates" stage="build">

目标词：overseas, get used to, overall

### 题目
补全外派归来朋友的分享：
"Moving ____ was tough at first because it took months to ____ driving on the left, but ____ it was an unforgettable adventure."

### 选项
- [opt-a] overseas / get used to / overall
- [opt-b] back in town / promise to / any
- [opt-c] overseas / promise to / expecting

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`move overseas` 指搬去海外，`get used to + 动名词 driving` 指逐渐习惯靠左开车，`overall` 总结“总的来说”。
- [opt-b] 后面接动名词 `driving`，不能用接原形的 `promise to`；`any` 也不能作总结副词。
- [opt-c] `promise to driving` 语法错误（`promise to` 后必须接动词原形）。

### 提示
- 第一空表示“去海外”。
- 第二空后面紧跟动名词 `driving`，需选末尾 `to` 为介词的“逐渐习惯于”。

### 讲解
看到空后是 `-ing` 动名词（`driving`），就能锁定 `get used to`（这里的 `to` 是介词）；句末用 `overall` 概括整段海外经历。

</exercise>

<exercise id="u281-miles-03" type="choice" activity="cloze" goal="milestones-ties" stage="build">

目标词：any, promise to, get

### 题目
补全临别前的热情约定：
"If you have ____ free evenings this week, ____ text me so we can ____ together for dinner!"（这周如果你有任何空闲的晚上，答应我一定发消息给我，咱们好聚一聚吃顿晚饭！）

### 选项
- [opt-a] any / promise to / get
- [opt-b] overall / get used to / going
- [opt-c] so far / catch you up on / run into

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！条件句中用 `any` 表示“任何、哪怕一点”，祈使句 `promise to + 动词原形` 表示“答应做某事”，`get together` 表示聚一聚。
- [opt-b] `get used to` 后不接原形 `text`，`can` 后也不接 `going`。
- [opt-c] 语义不通，`can run into together` 矛盾（偶遇不能提前约好）。

### 提示
- 第一空在 `if` 条件句中修饰 `free evenings`，表示“任何”。
- 第二空接动词原形 `text`，表示“答应、保证”；第三空与 `together` 构成固定搭配“相聚”。

### 讲解
老友道别时最暖心的一句就是 `Promise to text/call me so we can get together!`（答应联系我，咱们好好聚一聚！）。

</exercise>

目标词：get used to, overseas

### 题目

### 词块
Did | you | get | used | to | living | overseas

### 答案
- Did you get used to living overseas?

### 提示
- 过去时疑问句以 `Did you` 加原形短语“逐渐习惯于”开头。

目标词：promise to, overseas

Promise to visit us again before you move back overseas.

### 题目
听录音，说话人向老朋友提出了什么请求？

### 选项
