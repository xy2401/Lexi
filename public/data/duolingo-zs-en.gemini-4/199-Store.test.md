<exercise id="u199-returns-01" type="matching" activity="matching" goal="returns-and-refunds" stage="recognize">

目标词：return, exchange, replace, money back, store credit

### 题目
把下列商场售后柜台的高频词汇与中文释义配对。

### 配对
- [return] return | 退货（把商品退回）
- [exchange] exchange | 换货（调换尺码或款式）
- [replace] replace | 替换；更换（残次品）
- [money-back] money back | 退钱；原路退款
- [store-credit] store credit | 店内消费抵用额度

### 提示
- 留意“退钱”和“退店内额度”两种不同补偿方式的英文说法。
- `exchange` 侧重拿一件商品去调换另一件尺码或颜色的商品。

### 讲解
去客服台办理售后时，说清自己是想直接 `return` 拿回 `money back`，还是接受 `store credit`，或是 `exchange` 尺码、请店方 `replace` 坏件，问题就能迅速解决。

</exercise>

<exercise id="u199-details-01" type="matching" activity="matching" goal="garment-details" stage="recognize">

目标词：collar, button, label, silk, stripe

### 题目
把下列衣物部位、材质及花纹词汇与中文意思连起来。

### 配对
- [collar] collar | 衣领
- [button] button | 纽扣
- [label] label | 标签；吊牌
- [silk] silk | 丝绸；真丝
- [stripe] stripe | 条纹

### 提示
- 退换新衣服时，店员通常会先检查衣服上的 `label` 还在不在。
- `silk` 是一种轻薄顺滑的高档面料，`stripe` 则是常见的线条图案。

### 讲解
描述一件衬衫最常提到的细节：领口是 `collar`，门襟和袖口有 `button`，吊牌洗水标叫 `label`，面料可能是 `silk`，花色可能是清爽的 `stripe`。

<exercise id="u199-defects-01" type="choice" activity="word-choice" goal="defects-and-condition" stage="recognize">

目标词：damaged, button, off

### 场景
你刚拆开网购的外套包裹，发现包装破了，而且袖口还掉了一颗扣子。

### 题目
哪一句英文最准确地向客服说明了“外套受损了，而且掉了一颗纽扣”？

### 选项
- [opt-off] The coat arrived damaged, and a button came off.
- [opt-silk] The coat arrived silk, and a button came still.
- [opt-credit] The coat arrived store credit, and a collar came thick.

### 答案
opt-off

### 选项反馈
- [opt-off] 正确！`damaged` 说明商品受损，`a button came off` 地道表达“一颗纽扣脱落了”。
- [opt-silk] `silk` 是名词“丝绸”，`still` 是副词“仍然”，语法和句意都不通。
- [opt-credit] `store credit`（店内额度）不能作 `arrived` 的状态补语。

### 提示
- 描述商品“受损的、有破损的”要用过去分词形式的形容词。
- 扣子从衣服上脱落，动词 `come` 要搭配表示“脱离”的小品词。

### 讲解
`arrived damaged` 是网购售后投诉的标准表达，意为“寄到时就已经破损了”；`come off` 专门描述纽扣、标签或零件松脱掉下。

</exercise>

<exercise id="u199-polite-01" type="choice" activity="cloze" goal="polite-negotiation" stage="build">

目标词：would, money back, store credit

### 题目
补全店员的礼貌提问：____ you prefer your ____, or can we offer you ____ for your next visit?（您是希望原路退钱，还是我们给您退店内消费额度供下次使用？）

### 选项
- [opt-a] Would / money back / store credit
- [opt-b] Off / store credit / collar
- [opt-c] Still / silk / pattern

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`Would you prefer...?` 礼貌询问顾客偏好，并列提供 `money back`（退钱）与 `store credit`（店内额度）两个选项。
- [opt-b] 介词/副词 `Off` 不能引导一般疑问句，`collar`（衣领）也不是退款方式。
- [opt-c] `Still` 无法作疑问句助动词，且丝绸和图案不符合句末 `for your next visit` 的语境。

### 提示
- 句首需要一个情态动词来构成客气礼貌的询问。
- 后两空分别是退换货时的两种退款/补偿形式，且第三空对应“供下次光顾消费”。

### 讲解
客服沟通最常用 `Would you prefer A or B?`，其中 `money back` 退回真金白银，`store credit` 则留作下次在同家店铺抵扣消费。

</exercise>

<exercise id="u199-defects-02" type="choice" activity="cloze" goal="defects-and-condition" stage="build">

目标词：label, still, exchange

### 题目
补全句子：The original ____ is ____ attached, so I can ____ this sweater for a larger size.（原装吊牌还挂在上面，所以我可以把这件毛衣换成大一号的。）

### 选项
- [opt-a] label / still / exchange
- [opt-b] stain / off / return
- [opt-c] stripe / wouldn't / replace

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！原装 `label`（标签/吊牌）`still`（仍然）连在衣服上是退换前提，`exchange ... for a larger size` 表示“换成大一码”。
- [opt-b] “原装污渍还挂着”不符合逻辑，且搭配 `for a larger size` 应使用换货动词 `exchange` 而非 `return`。
- [opt-c] 情态动词 `can` 后面接动词原形，但第二空在 `is` 和 `attached` 之间需要副词 `still` 而非 `wouldn't`。

### 提示
- 第一、二空说明证明衣服没穿过的凭证“吊牌仍然挂着”。
- 第三空搭配后面的 `for a larger size`，表示调换尺码。

### 讲解
`exchange A for B` 是商场换码、换色的核心句型；出发去商店前先确认 `The label is still attached/on`，能省去不少沟通周折。

</exercise>

<exercise id="u199-polite-02" type="choice" activity="cloze" goal="polite-negotiation" stage="build">

目标词：wouldn't, thick, silk

### 题目
补全句子：I ____ wear such a ____ wool coat in summer; I prefer a light ____ shirt instead.（夏天我是不会穿这么厚的羊毛大衣的；相比之下我更喜欢轻薄的真丝衬衫。）

### 选项
- [opt-a] wouldn't / thick / silk
- [opt-b] would / damaged / stain
- [opt-c] wouldn't / off / bra

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`wouldn't wear` 表示客观常理下“不会穿”，`thick wool coat`（厚羊毛大衣）与后半句轻薄的 `silk shirt`（真丝衬衫）形成鲜明对比。
- [opt-b] 夏天“会穿破损的羊毛大衣”与后半句 `instead` 转折逻辑矛盾，且 `stain` 不直接修饰轻薄衬衫。
- [opt-c] `off` 不能放在 `such a ... wool coat` 中描述大衣厚度，第三空后面已有 `shirt`，填 `silk` 作材质定语才合理。

### 提示
- 根据季节常识，夏天“不会”穿厚重冬装，第一空填否定情态动词。
- 第二空形容羊毛大衣“厚实的”，第三空填轻薄顺滑的天然面料修饰 `shirt`。

### 讲解
`wouldn't + 动词原形` 常用来说明在某种情境下自己肯定不会做的选择，语气自然委婉。

</exercise>

### 题目
把词块连成礼貌请求：“您能更换这枚受损的钻戒吗？”

### 词块
Could | you | replace | this | damaged | diamond | ring

### 答案
- Could you replace this damaged diamond ring?

### 讲解

<exercise id="u199-details-04" type="choice" activity="audio-choice" goal="garment-details" stage="recognize">

目标词：silk, diamond, pattern

### 题目
听顾客向店员的提问，选出与录音意思一致的一项。

### 听力
Does this silk scarf come in a diamond pattern?

### 选项
- [opt-pattern] 这条真丝围巾有菱形花纹款吗？
- [opt-stain] 这条真丝围巾上的污渍能退钱吗？
- [opt-thick] 这条厚围巾上的钻石是真的吗？

### 答案
opt-pattern

### 选项反馈
- [opt-pattern] 正确！录音用 `come in a diamond pattern` 询问这款真丝围巾是否有菱形格纹的花色。
- [opt-stain] 录音中并未提及污渍或退钱。
- [opt-thick] 录音里的 `diamond` 修饰后面的花纹词，指“菱形图案”而非镶嵌真钻石，也没提厚围巾。

### 提示
- 听清主语是哪种面料的围巾。
- 注意句末短语里 `diamond` 与表示“图案、花纹”的名词搭配时的含义。

### 讲解
录音原文为 `Does this silk scarf come in a diamond pattern?`。在服饰语境中，`diamond pattern` 指经典的菱形花纹，`come in...` 表示某商品提供某种颜色、尺码或花色。

</exercise>

<exercise id="u199-returns-03" type="input" activity="write" goal="returns-and-refunds" stage="recall">

目标词：would, return, bra

### 场景
你在内衣店柜台前，礼貌地向店员说明想退掉手里这件未拆吊牌的文胸。

### 题目
用英文写出：“我想退掉这件文胸。”（使用委婉表达 `I would like to ...` 或缩写形式）

### 答案
- I would like to return this bra.
- I'd like to return this bra.

### 提示
- 开头用 `I would like to`（或 `I'd like to`）表达客气的诉求。
- 后接表示“退回商品”的动词原形，宾语是 `this` 加“文胸”。

### 讲解
在商场提诉求时，`I would like to return...` 比直接说 `I want to return...` 得体得多，店员听起来也更舒服。

</exercise>
