<exercise id="u152-tech-phrasals-01" type="matching" activity="matching" goal="tech-phrasals" stage="recognize">

目标词：back up, look up, plug in, set up, sign up

### 题目
把下列五个高频数码短语动词和对应的中文意思配对。

### 配对
- [back-up] back up | 备份（文件或数据）
- [look-up] look up | 查阅（信息或单词）
- [plug-in] plug in | 插上电源
- [set-up] set up | 安装设置；创建
- [sign-up] sign up | 注册；报名

### 提示
- 带有 plug 的短语与插座供电有关，带有 back 的短语指留一份数据副本以防丢失。
- 区分 set up（搭建设置好设备或账户）与 sign up（填表注册成为用户）。

### 讲解
这五个短语几乎包揽了使用新电脑和手机的核心步骤：先 `plug in`（插电）并 `set up`（设置系统），再上网 `sign up`（注册账号）、`look up`（查资料），平时不忘 `back up`（备份文件）。

</exercise>

<exercise id="u152-system-upgrades-01" type="choice" activity="word-choice" goal="system-upgrades" stage="recognize">

目标词：update, upgrade, cost, sort of

### 场景
你的旧手机用了五年内存太小，你想加点钱换一部更高配置的新款机型。

### 题目
这种软硬件规格上的“升级换代”，最贴切的英文动词是哪一个？

### 选项
- [upgrade] upgrade
- [update] update
- [attach] attach
- [notice] notice

### 答案
upgrade

### 选项反馈
- [upgrade] 正确！`grade` 有“等级、档次”之意，`upgrade` 专门指设备换新、提高配置或升级套餐档次。
- [update] 不完全准确，`date` 指日期，`update` 侧重给现有软件打补丁“日常更新”或同步最新消息。
- [attach] 词义不符，`attach` 指在邮件中添加附件或把物体固定上去。
- [notice] 词义不符，`notice` 意为“注意到”。

### 提示
- 观察词根：一个是跟“日期（date）”保持同步，一个是往更高“档次（grade）”提升。
- 换高配新机或升舱、升套餐都选带 `grade` 的那个词。

### 讲解
记住词根秒分两词：`up + date` = 让软件跟上最新日期（日常系统更新）；`up + grade` = 提升一个档次（硬件换代或套餐升级）。

</exercise>

<exercise id="u152-tech-phrasals-02" type="choice" activity="cloze" goal="tech-phrasals" stage="build">

目标词：plug, plug in, set, set up

### 场景
新买的打印机还没插电，你让同伴先把插头插上，好一起安装调试。

### 题目
The ____ isn't in the wall yet—please ____ first so we can ____ the printer.

### 选项
- [plug-it-set] plug ... plug it in ... set up
- [plug-in-it-set] plug ... plug in it ... set up
- [set-plug-it] set ... plug it in ... sign up
- [plug-it-back] plug ... back it up ... look up

### 答案
plug-it-set

### 选项反馈
- [plug-it-set] 正确！第一空作名词指“插头（plug）”；第二空代词 `it` 夹在中间构成 `plug it in`（把它插上电）；第三空用 `set up` 表示安装设置打印机。
- [plug-in-it-set] 代词位置错误，不能说 `plug in it`，必须说 `plug it in`。
- [set-plug-it] 第一空名词不对（插头是 `plug` 而非 `set`），第三空“安装打印机”也不用 `sign up`（注册）。
- [plug-it-back] 后两空词义不通，没通电前不是“备份”或“查阅”打印机。

### 提示
- 第一空前有定冠词 `The`，需要名词“插头”。
- 第二空注意代词 `it` 的“夹心位置”，第三空表示“安装调试”新设备。

### 讲解
`plug` 既可作名词“插头”，也可组成短语动词 `plug in`（插上电源），搭配代词时说 `plug it in`；随后用 `set up the printer` 表示完成打印机的安装配置。

</exercise>

<exercise id="u152-tech-phrasals-03" type="choice" activity="cloze" goal="tech-phrasals" stage="build">

目标词：look, look up, back, back up

### 题目
If you don't know the answer, ____ online, and remember to ____ your notes afterward.

### 选项
- [look-it-back] look it up ... back up
- [look-up-it] look up it ... back up
- [back-it-look] back it up ... look up
- [look-only-back] look it ... back

### 答案
look-it-back

### 选项反馈
- [look-it-back] 正确！上网查阅答案用 `look it up`（代词 `it` 放中间），事后备份笔记用动词短语 `back up`。
- [look-up-it] 语序错误，代词 `it` 作宾语时必须夹在 `look` 和 `up` 中间。
- [back-it-look] 两个短语贴反了，应该是先上网“查阅”答案，再“备份”笔记。
- [look-only-back] 缺少关键副词 `up`，`look` 和 `back` 单独使用无法表达“查阅”和“备份”。

### 提示
- 第一空指代前文的 `the answer`（单数代词 `it`），表达“在网上查一下它”。
- 第二空后面接名词短语 `your notes`，表达“备份你的笔记”。

### 讲解
无论是 `look it up`（查一下它）还是 `back up your notes` / `back them up`（备份笔记），加上小品词 `up` 才具有完整的数码操作含义。

</exercise>

<exercise id="u152-system-upgrades-02" type="choice" activity="word-choice" goal="system-upgrades" stage="recognize">

目标词：sort of, update, cost

### 题目
同事问你刚更新完的系统用起来怎么样，你回答 `It's sort of slow today.` 句中的 `sort of` 表达什么意思？

### 选项
- [a-little] 有点儿、稍微（委婉缓和语气）
- [completely] 完全地、彻底地
- [never] 从不、绝对不
- [accidentally] 不小心地、误操作地

### 答案
a-little

### 选项反馈
- [a-little] 正确！`sort of` 在口语中相当于 `kind of` 或 `a little`，表示“有点儿、算是吧”，让评价听起来更委婉客观。
- [completely] 不对，`sort of` 是减弱程度而非加强到“完全”。
- [never] 不对，`sort of` 不含否定含义。
- [accidentally] 不对，表示“不小心”的是 `accidentally`。

### 提示
- 当你不想把话说得太绝对（不是快得飞起，但也没卡死）时常会用它。
- 它放在形容词 `slow` 前面修饰程度。

### 讲解
`sort of` 是母语者日常聊天最高频的缓冲表达之一，`sort of slow`（有点儿慢）、`sort of expensive`（稍微有点贵）听起来都非常自然。

</exercise>

用英文写出完整句子：“我每周都会备份我的照片。”（主语用 `I`，“我的照片”译为 `my photos`，句尾用 `every week`）。

<exercise id="u152-device-controls-03" type="choice" activity="audio-choice" goal="device-controls" stage="recognize">

目标词：smartphone, notice, voicemail, update

### 听力
She did not notice the new voicemail because her smartphone was doing a system update.

### 题目
听录音，选出与你听到的内容一致的一项。

### 选项
- [voicemail-update] 她没注意到那条新的语音留言，因为她的智能手机正在进行系统更新。
- [volume-button] 她不小心把手机音量调到了最低，所以没听到闹钟响。
- [upgrade-cost] 她花了不少钱把旧手机升级换成了最新款智能手机。
- [attach-email] 她连上无线网后才发现刚才发的邮件忘了加附件。

### 答案
voicemail-update

### 选项反馈
- [voicemail-update] 正确！录音清楚说明了没注意到新语音信箱留言的原因是智能手机正在做系统更新。
- [volume-button] 不对，录音没有提到音量按钮或闹钟。
- [upgrade-cost] 不对，录音里是免费的系统更新（system update），不是花钱换新机（upgrade）。
- [attach-email] 不对，录音说的是语音留言，没有提到发邮件和附件。

### 提示
- 先听清她漏看了手机里的哪一项消息功能。
- 再留意 `because` 后面她的手机当时正在执行什么操作。

### 讲解
听力原文为 `She did not notice the new voicemail because her smartphone was doing a system update.`，真实再现了手机更新期间收不到提醒的日常场景。
