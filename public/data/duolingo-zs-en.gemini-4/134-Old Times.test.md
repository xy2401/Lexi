目标词：sunrise, stream, rock, corn, outdoors, indoors

### 题目
将往昔田园自然与空间方位副词同对应的中文释义配对。

### 配对
- [sunrise] sunrise | 日出
- [stream] stream | 小溪；溪流
- [rock] rock | 岩石；石块
- [corn] corn | 玉米
- [outdoors] outdoors | 在户外
- [indoors] indoors | 在室内

### 提示
- 先找出一对末尾都带 -s、本身即可作状语的空间反义副词。
- 由 sun 与 rise 合成的词指清晨太阳升起的时刻。

### 讲解
儿时记忆常围绕自然展开：清晨看 sunrise（日出），去小溪（stream）边捡石块（rock），看田里的不可数作物 corn（玉米），晴天待在 outdoors（在户外）而非闷在 indoors（在室内）。

<exercise id="u134-use-to-grammar-01" type="choice" activity="word-choice" goal="use-to-grammar" stage="recognize">

目标词：did, use to, outdoors, stream

### 场景
奶奶正给孙子看自己小时候在乡下老家的黑白照片。

### 题目
如果孙子想用英语问奶奶“你以前夏天常常在那条小溪里游泳吗？”，哪一句拼写完全正确？

### 选项
- [opt-a] Did you use to swim in that stream in summer?
- [opt-b] Did you used to swim in that stream in summer?
- [opt-c] Do you use to swim in that stream in summer?
- [opt-d] Did you use to swam in that stream in summer?

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！句首有了过去时助动词 Did，后面必须去掉字母 d 还原为 use to，再接动词原形 swim。
- [opt-b] 最经典的拼写陷阱：有了助动词 Did 之后，不能再保留过去式尾巴 d 写成 used to。
- [opt-c] 询问过去的习惯必须用过去时助动词 Did，不能用一般现在时的 Do。
- [opt-d] use to 后面必须接动词原形 swim，不能用过去式 swam。

### 提示
- 回忆“有 did 去 d”规则：当句首已经出现过去时助动词 Did 时，use 后面还能带 d 吗？
- 检查 to 后面的实义动词是否保持了原形。

### 讲解
一般疑问句借助助动词 Did 提问过去习惯时，结构固定为“Did + 主语 + use to + 动词原形...?”。

</exercise>

<exercise id="u134-use-to-grammar-02" type="choice" activity="cloze" goal="use-to-grammar" stage="build">

目标词：didn't use to, never used to, indoors, web

### 题目
People ____ search on the ____ back then, and children ____ stay ____ all day on sunny weekends.

### 选项
- [opt-a] didn't use to / web / never used to / indoors
- [opt-b] never use to / web / didn't used to / indoors
- [opt-c] didn't use to / rock / never used to / sunrise
- [opt-d] use to / indoors / swept / web

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！前半句含助动词 didn't 故去 d 用 didn't use to，搭配 search on the web（在网上搜索）；后半句用副词 never 否定、无助动词故留 d 用 never used to，搭配 stay indoors（待在室内）。
- [opt-b] 两处 d 的去留刚好全反了：never 后应保留 used to，而 didn't 后必须去掉 d 写 use to！
- [opt-c] search on the rock 与 stay sunrise 均搭配不当。
- [opt-d] 肯定句不能直接写原形 use to（缺少 d），且句意完全不通。

### 提示
- 对比两种过去否定写法：有 didn't 的去 d，只有 never 的留 d！
- 在网上搜索用 on the...，晴朗周末不整天闷在屋里用副词“在室内”。

### 讲解
didn't use to 与 never used to 意思相同，唯一的拼写区别取决于有没有助动词 didn't；stay indoors 意为“待在室内”。

</exercise>

<exercise id="u134-school-work-contrast-02" type="choice" activity="cloze" goal="school-work-contrast" stage="build">

目标词：fewer, however, know how to, tax

### 题目
We had ____ machines in the old days; ____, most adults still didn't ____ fill out complex ____ forms by themselves.

### 选项
- [opt-a] fewer / however / know how to / tax
- [opt-b] however / fewer / know how to / corn
- [opt-c] fewer / outdoors / use to / inch
- [opt-d] swept / however / fly / accountant

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！可数复数名词 machines 前用 fewer（更少的）；分号后、逗号前用转折副词 however（然而）；didn't know how to fill out 表示“不知道怎么填写”；tax forms 指“税务表格”。
- [opt-b] 前两空词性颠倒，且“填写复杂的玉米表格”不合常理。
- [opt-c] 第二空分号与逗号之间需要转折逻辑副词而非空间副词 outdoors，inch forms 也不通。
- [opt-d] 词性和搭配均不成立。

### 提示
- 第一空修饰可数名词复数 machines，表达“更少的”。
- 第二空夹在分号与逗号之间作正式转折；第三空接动词原形 fill out 表示“懂得如何做”。

### 讲解
fewer 专门修饰可数复数名词；however 承接分号并后跟逗号表转折；know how to do something 表示掌握做某事的方法。

</exercise>

<exercise id="u134-country-memories-03" type="choice" activity="cloze" goal="country-memories" stage="build">

目标词：sunrise, swept, sweep, corn

### 题目
Grandma woke up at ____, ____ the front yard, and boiled sweet ____ before asking me to ____ my room.

### 选项
- [opt-a] sunrise / swept / corn / sweep
- [opt-b] sunrise / sweep / corn / swept
- [opt-c] stream / swept / tax / fly
- [opt-d] indoors / rock / web / sweep

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！at sunrise（在日出时）；第二空与 woke、boiled 并列用过去式 swept（扫净了前院）；煮甜玉米（sweet corn，不可数）；末尾不定式 to 后接动词原形 sweep。
- [opt-b] 时态位置反了：与过去式 woke 并列的谓语必须用过去式 swept，而 ask me to 后必须用原形 sweep。
- [opt-c] woke up at stream 缺少冠词，且“煮甜税款”荒谬不通。
- [opt-d] 第二空名词 rock 不能充当并列谓语动词。

### 提示
- 注意句中三个过去式动作（woke up、扫前院、boiled）的时态一致，而句末不定式 to 后面要用动词原形！
- 早餐锅里煮的香甜农作物是不可数名词“玉米”。

### 讲解
sweep 的过去式为 swept；at sunrise 是固定零冠词搭配“在日出时分”；corn 作不可数名词不加 -s。

</exercise>

目标词：accountant, favorite, religion, assignment

### 题目
My aunt works as an ____ now, though in college her ____ subject was world ____ and she loved every writing ____.

### 选项
- [opt-a] accountant / favorite / religion / assignment
- [opt-b] assignment / favorite / accountant / cover
- [opt-c] accountant / fewer / stream / tax
- [opt-d] court / outdoors / religion / assignment

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！不定冠词 an 后接以元音音素开头的职业 accountant（会计师）；favorite subject（最喜爱的科目）是世界宗教（world religion），喜欢每一项写作作业（writing assignment）。

### 提示
- 留意第一空前面的不定冠词是 an，说明这个职业名词以元音音素开头！

### 讲解
accountant 以元音音素开头，前接不定冠词 an；writing assignment 指学校布置的写作任务。

将词块连成一般疑问句：“孩子们以前常常在户外放纸风筝吗？”

目标词：rock, stream, inch, cover

### 听力
Every flat rock in the clear stream was under an inch of water, and snow began to cover the hills.

### 题目
听录音，选出与句子描绘的冬日郊外景象一致的一项。

### 选项
- [opt-a] 清澈小溪里的每块扁平石头都在不到一英寸深的水下，积雪开始覆盖山丘。
- [opt-b] 夏天日出后，孩子们在小溪边捡石头并给课本包书皮。
- [opt-c] 暴雪把整条小溪冻成了厚厚的冰面，看不见任何石头。
- [opt-d] 会计师在室内办公室里整理了一英寸厚的税务文件。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！录音清楚描述了清澈溪流中的扁平石块在水下一英寸处（under an inch of water），且白雪开始覆盖山丘（cover the hills）。
- [opt-b] 录音中的 cover 是动词“覆盖（山丘）”而非包书皮，季节也不是夏天。
- [opt-c] 溪水依然清澈可见石头，并未完全冻住看不见。
- [opt-d] 录音描绘的是户外自然风光，完全未提办公室或文件。

### 提示
- 听清前半句清澈小溪里的扁平石块上面有多深的水（注意长度单位）。
- 留意后半句 snow began to... 中 cover 作动词时的含义。

### 讲解
原文为“Every flat rock in the clear stream was under an inch of water, and snow began to cover the hills.”，其中 cover 作及物动词表示“覆盖、遮盖”。
