目标词：device, webcam, microphone, robot, switch

### 题目
把下列数码硬件与外设词汇和对应的中文释义配对。

### 配对
- [device] device | 设备；装置
- [webcam] webcam | 网络摄像头
- [microphone] microphone | 麦克风；话筒
- [robot] robot | 机器人
- [switch] switch | 开关；切换

### 提示
- 由 `web`（网络）与 `cam`（相机缩略）合成的词专门用于线上视频画面。
- `micro-`（微小）加 `-phone`（声音）是放大说话声音的收音工具。

### 讲解
这组词覆盖了现代办公与智能硬件：手机平板统称 `device`，远程会议离不开 `webcam` 和 `microphone`，机身背面常有电源 `switch`，而自动化助手则是 `robot`。

### 题目
把下列互联网软件及系统词汇与对应的中文意思连起来。

- [browser] browser | 浏览器
- [server] server | 服务器
- [graphics] graphics | 图像；画质效果

<exercise id="u204-compare-01" type="choice" activity="word-choice" goal="old-vs-new-tech" stage="recognize">

目标词：used to, get used to, giant

### 场景
你在科技展上对比老式计算机与现代触屏平板，感叹今昔变化以及人们适应新操作的过程。

### 题目
下列哪一句中的 `used to` 与 `get used to` 语法搭配完全正确？

### 选项
- [opt-correct] Computers used to be giant, and people quickly got used to typing on touchscreens.
- [opt-base] Computers used to being giant, and people quickly got used to type on touchscreens.
- [opt-swap] Computers got used to be giant, and people used to typing on touchscreens.

### 答案
opt-correct

### 选项反馈
- [opt-correct] 正确！表“过去曾经是”用 `used to + 动词原形 be`；表“习惯于做某事”用 `get/got used to + 动名词 typing`。
- [opt-base] 把两者的规则完全弄反了：`used to` 后不接 `being`，而 `got used to` 里的 `to` 是介词，不能接原形 `type`。
- [opt-swap] 混淆了两个短语的含义与搭配规则。

### 提示
- 前半句回顾早年计算机“曾经巨大”的历史状态，后接动词原形。
- 后半句描述人们“慢慢适应”在触屏上打字，注意末尾的 `to` 是介词。

### 讲解
攻克这组易混词只需盯住两点：没有 `get/be` 的 `used to` 表过去，接动词原形；带有 `get` 的 `get used to` 表适应习惯，接名词或 `-ing`。

</exercise>

<exercise id="u204-actions-01" type="choice" activity="word-choice" goal="tech-actions" stage="recognize">

目标词：log out of, browser

### 场景
你在图书馆的公用电脑上查完资料，管理员提醒你离开前务必退出个人账号再关网页。

### 题目
选出介词搭配最地道、完整的一句提醒。

### 选项
- [opt-of] Always log out of your account before you close the browser.
- [opt-no-prep] Always log out your account before you close the browser.
- [opt-locate] Always locate out of your browser before you press the server.

### 答案
opt-of

### 选项反馈
- [opt-of] 正确！当 `log out` 后面接退出的具体账号或平台作宾语时，必须加上介词 `of`（`log out of your account`）。
- [opt-no-prep] 漏掉了介词 `of`：`log out` 是不及物短语，不能直接跟宾语 `your account`。
- [opt-locate] `locate` 意为“定位查找”，不能搭配 `out of` 表示退出登录。

### 提示
- `log out` 单独在句尾时不用加介词，但后面紧跟 `your account` 时必须补上一个表示“脱离”的介词。
- 句末表示“关闭浏览器”。

### 讲解
和 *log in to*（登录进……）相对应，退出某个账号要说 `log out of + 账号/网站`，这是公用设备安全提示里的常客。

</exercise>

<exercise id="u204-actions-02" type="choice" activity="cloze" goal="tech-actions" stage="build">

目标词：install, press, key, restart

### 题目
补全安装向导提示：After you ____ the new software, ____ any ____ on the keyboard to ____ your laptop.（安装完新软件后，按键盘上的任意键重启你的笔记本电脑。）

### 选项
- [opt-a] install / press / key / restart
- [opt-b] locate / switch / browser / log out of
- [opt-c] restart / install / webcam / press

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！先 `install`（安装）软件，再 `press any key`（按任意键），最后 `restart`（重启）电脑使设置生效。
- [opt-b] 键盘上没有“任意浏览器”可切换。
- [opt-c] 操作顺序颠倒，且键盘上没有“任意摄像头”可按。

### 提示
- 第一空搭配 `the new software` 表示把程序装进电脑。
- 中间两空是经典电脑提示语“按任意键”，最后一空表示“重新启动”。

### 讲解
`press any key`（按任意键）是电脑史上最著名的一句提示语，键盘上的按键在英语里一律用 `key` 来称呼。

</exercise>

<exercise id="u204-actions-03" type="choice" activity="cloze" goal="tech-actions" stage="build">

目标词：take a look, locate, switch

### 题目
补全求助句：Could you ____ at the back of this machine and help me ____ the power ____?（你能看一眼这台机器背面，帮我找到电源开关在哪里吗？）

### 选项
- [opt-a] take a look / locate / switch
- [opt-b] get used to / press / user
- [opt-c] log out of / install / graphics

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`take a look at...` 意为“看一眼、检查一下”，`locate` 意为“找出……的准确位置”，`power switch` 指“电源开关”。
- [opt-b] `get used to` 不搭配介词 `at`，且机器背面没有“电源用户”。
- [opt-c] `log out of at` 介词冲突，且硬件背面不是用来“安装画质”的。

### 提示
- 第一空与后面的介词 `at` 组成礼貌请求“看一看”。
- 第二空表示“确定位置、找到”，第三空与 `power` 组成“电源开关”。

### 讲解
`take a look at...` 是请同事或技术人员帮忙排查故障时的万能开场白；寻找隐藏在机身背面的接口或 `power switch` 用 `locate` 最贴切。

</exercise>

<exercise id="u204-web-02" type="choice" activity="cloze" goal="software-and-web" stage="build">

目标词：server, once a, frequent

### 题目
补全句子：To keep the main ____ safe, we check it ____ month and install ____ security updates.（为了保证主服务器安全，我们每月检查一次，并安装频繁的安全更新。）

### 选项
- [opt-a] server / once a / frequent
- [opt-b] user / used to / giant
- [opt-c] key / get used to / webcam

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！维护后台主 `server`（服务器），`once a month` 表示“每月一次”，`frequent security updates` 表示“频繁的安全更新”。
- [opt-b] `used to month` 完全不符合语法。
- [opt-c] `get used to month` 缺少冠词且句意不通。

### 提示
- 第一空填支撑网站运行的核心后台主机名。
- 第二空接单数时间词 `month` 表示“每月一次”，第三空填形容词修饰 `security updates`。

### 讲解
`once a + 单数时间单位`（如 `once a day / week / month / year`）是表达固定周期频率最简洁的结构。

</exercise>

This new game has amazing graphics on a fast device.

### 选项
