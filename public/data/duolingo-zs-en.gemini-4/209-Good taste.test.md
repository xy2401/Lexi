目标词：entertainment, drama, comic, folk, circus, direct

### 题目
把下列影视文娱体裁及创作词汇和对应的中文意思配对。

### 配对
- [entertainment] entertainment | 娱乐，文娱节目
- [drama] drama | 剧情片；戏剧
- [comic] comic | 喜剧的；漫画杂志
- [folk] folk | 民间的，民俗的
- [circus] circus | 马戏团
- [direct] direct | 执导，导演（动词）

### 提示
- 留意 direct 在电影语境里作动词表示导演拍片的动作。
- folk 常用来修饰传统民谣或民间艺术。

### 讲解
大众文化与 entertainment（娱乐）形式多样，既有严肃的 drama（剧情片）和轻松的 comic（喜剧/漫画），也有传统 folk（民间）音乐与热闹的 circus（马戏团）；而拍电影的“执导”用动词 direct。

<exercise id="u209-opin-01" type="choice" activity="word-choice" goal="film-opinions" stage="recognize">

目标词：real, realistic, marvelous, rare

### 场景
影评人盛赞一部改编自真实历史事件、且演员表演极为逼真的罕见佳作。

### 题目
哪句话最准确地用对了“真实事件”与“逼真演技”？

### 选项
- [opt-a] Based on a real event, this marvelous film features rare and realistic acting.
- [opt-b] Based on a realistic circus, this public film features divorce and real trend.
- [opt-c] Based on a comic folk, this rare film features dislike and decide acting.
- [opt-d] Based on a display event, this direct film features generally and marvelous trend.

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！a real event 表示客观真实发生过的事件，realistic acting 表示逼真可信的演技，搭配 marvelous（绝妙的）与 rare（难得的）非常地道。
- [opt-b] real trend 与 divorce acting 搭配生硬，且未区分“真实历史”与“写实表现”。
- [opt-c] dislike 与 decide 是动词，不能直接修饰名词 acting。
- [opt-d] 词性混乱，generally 是副词不能与形容词并列修饰名词。

### 提示
- 区分一对近义形容词：客观非虚构的“真事”用短词，艺术上栩栩如生的“写实”用带 -istic 的长词。
- 夸赞电影“妙极了”用 m 开头的形容词。

### 讲解
影评写作一定要分清 real（现实中真实存在的，如 a real story/event）和 realistic（艺术刻画逼真写实的，如 realistic acting/characters）；marvelous 与 rare 则用来表达高度赞赏。

</exercise>

<exercise id="u209-opin-02" type="choice" activity="word-choice" goal="film-opinions" stage="recognize">

目标词：generally, dislike, get used to

### 场景
朋友平时不太爱看慢节奏文艺片，但看多了也渐渐适应了带字幕的外语片。

### 题目
哪句话地道表达了“通常来说我不喜欢慢节奏电影，但我很快就习惯了看带字幕的影片”？

### 选项
- [opt-a] Generally, I dislike slow movies, but I quickly got used to watching films with subtitles.
- [opt-b] Publicly, I direct slow movies, but I quickly got used to watch films with subtitles.
- [opt-c] Rarely, I display slow movies, but I quickly decided watching films with subtitles.
- [opt-d] Marvelously, I divorce slow movies, but I quickly trended watching films with subtitles.

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！Generally（大体上、通常）引出整体偏好 dislike（不喜欢），got used to 后接动名词 watching 表示“习惯了做某事”。
- [opt-b] got used to 里的 to 是介词，后面不能接动词原形 watch，且 direct 意为“执导”。
- [opt-c] display 意为“展出”，且 decide 后面应接不定式 to watch 而非 watching。
- [opt-d] divorce（离婚）和 trend（趋势）用在这里语义完全不通。

### 提示
- 表达整体习惯“通常来说”用副词 Generally，委婉表达“不喜爱”用 dislike。
- 固定短语 get used to 后面跟动词时，必须变成 -ing 形式。

### 讲解
Generally 放在句首说明普遍倾向，比绝对化的 always 更客观；dislike 比 hate 更温和有礼；get used to doing something 是“渐渐习惯做某事”的核心结构。

</exercise>

<exercise id="u209-hypo-01" type="choice" activity="cloze" goal="past-hypotheticals" stage="build">

目标词：if, if you had, would have

### 场景
展览昨天已经闭幕了，你惋惜朋友错过了那批难得一见的复古海报。

### 题目
___ come to the gallery with me yesterday, you ___ seen those rare posters, and ___ the artist had been there, she might have signed your book!

### 选项
- [opt-a] If you had / would have / if
- [opt-b] Would have / if you had / would've
- [opt-c] Get used to / hadn't / realistic
- [opt-d] Generally / dislike / trend

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！对昨天已结束的事情做假设：从句用 If you had come，主句推想结果用 you would have seen，后半句再用连词 if 引出第二个过去假设。
- [opt-b] 把 would have 放进条件从句、把 if 放进主句，颠倒了主从句结构。
- [opt-c] 词性与第三类条件句语法均不匹配。
- [opt-d] 无法构成条件状语从句和虚拟主句。

### 提示
- 事情发生在 yesterday（昨天），与过去事实相反的假设，条件从句用“If + 主语 + had + 过去分词”。
- 对应的主句要用“would have + 过去分词”说明本来会发生的结果。

### 讲解
第三类条件句专门复盘过去的遗憾或假设：条件句里用 If you had come（要是你昨天来了），主句里用 you would have seen（你本来就能看到了），切忌在 if 从句里混入 would have。

</exercise>

<exercise id="u209-contr-01" type="choice" activity="cloze" goal="spoken-contractions" stage="build">

目标词：if you'd, hadn't, would've

### 场景
散场后讨论剧情：幸好没提前退场，而且要是你先看过原版漫画就更能看懂彩蛋了。

### 题目
___ read the comic book first, you ___ noticed the hidden joke—and if we ___ stayed until the end, we would have missed the best scene!

### 选项
- [opt-a] If you'd / would've / hadn't
- [opt-b] Would've / if you'd / realistic
- [opt-c] If you had / display / public
- [opt-d] Hadn't / decide / direct

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！If you'd 是 If you had 的缩略，you would've 是 you would have 的缩略，后半句 if we hadn't stayed 表示“要是我们刚才没留到最后”。
- [opt-b] 主从句位置颠倒，且第三空填形容词 realistic 无法接过去分词 stayed。
- [opt-c] 第二空和第三空不能构成完成体虚拟结构。
- [opt-d] 语法与句意均不成立。

### 提示
- 第一空是 If you had 在口语里的缩略形式，后面紧跟过去分词 read。
- 第二空是 would have 的缩略形式；第三空表示否定假设“要是没有留下”。

### 讲解
日常口语谈论电影时，母语者极爱把 If you had 缩成 If you'd，把 would have 缩成 would've（注意拼写绝不是 would of！），否定假设则用 hadn't + 过去分词。

</exercise>

<exercise id="u209-hypo-02" type="compose" activity="compose" goal="past-hypotheticals" stage="build">

目标词：would have, drama, if you had

### 题目
把词块连成完整句子，表达“要是你跟我们一起来看，你本来会很喜欢那部剧情片的”（主句在前，if 从句在后）。

### 词块
You | would | have | loved | that | drama | if | you | had | watched | it | with | us

### 答案
- You would have loved that drama if you had watched it with us.

### 提示
- 先写主句结果“你本来会很喜欢那部剧情片”（You would have loved...）。
- 再接 if 引导的过去条件从句“要是你和我们一起看了它”。

### 讲解
当主句放在前面、if 从句放在后面时，句中不需要加逗号：You would have loved that drama if you had watched it with us. 语流紧凑自然。

</exercise>

<exercise id="u209-contr-02" type="compose" activity="compose" goal="spoken-contractions" stage="build">

目标词：would've, comic, if you'd

### 题目
把词块连成句子，表达“要是你早点告诉我，我本来就会买那本漫画了”（主句在前，if 从句在后）。

### 词块
I | would've | bought | that | comic | if | you'd | told | me | earlier

### 答案
- I would've bought that comic if you'd told me earlier.

### 提示
- 主句使用缩略形式 I would've 加上过去分词 bought。
- 条件从句用缩略形式 if you'd 加上过去分词 told 和时间副词 earlier。

### 讲解
这句完整展示了口语里最地道的过去假设缩略搭配：主句 I would've bought... 对应从句 if you'd told me earlier（其中 you'd = you had）。

</exercise>

<exercise id="u209-opin-05" type="choice" activity="audio-choice" goal="film-opinions" stage="recognize">

目标词：generally, dislike, entertainment, rare, real

### 听力
Generally, I dislike loud action movies as entertainment, so it is rare for me to enjoy one—unless it tells a real historical story.

### 题目
听录音，说话人对吵闹的动作片持什么态度？在什么例外情况下才会喜欢？

### 选项
- [opt-a] 通常不喜欢拿它当消遣，除非影片讲述的是真实的历史故事。
- [opt-b] 平时最爱看吵闹动作片，尤其喜欢马戏团和漫画改编的虚构故事。
- [opt-c] 打算亲自执导一部动作片，并在市博物馆向公众免费放映。
- [opt-d] 觉得动作片太慢热，后悔昨晚没有留下来看到大结局。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！录音用 Generally, I dislike... 表明通常不喜欢，随后用 unless 引出唯一例外：tells a real historical story（讲述真实历史故事）。
- [opt-b] 与录音的 dislike 完全相反。
- [opt-c] 录音是在谈个人观影口味，没有提到亲自当导演或博物馆放映。
- [opt-d] 录音讨论的是吵闹的动作片（loud action movies），并非慢节奏电影或昨晚退场。

### 提示
- 听清开头的副词与好恶动词，把握说话人的整体倾向。
- 重点捕捉连词 unless（除非）后面的条件。

### 讲解
原文为：Generally, I dislike loud action movies as entertainment, so it is rare for me to enjoy one—unless it tells a real historical story. 清晰示范了用 Generally + dislike + rare + unless 表达有层次的审美观点。
