目标词：empty out, store, dusty, junk, unwanted

### 题目
把整理储物间时常用的词汇与中文意思配成对。

### 配对
- [empty-out] empty out | 彻底清空
- [store] store | 存放；储藏
- [dusty] dusty | 布满灰尘的
- [junk] junk | 破烂；无用杂物
- [unwanted] unwanted | 不再需要的；闲置的

### 提示
- `store` 在这里作动词，不是“商店”。
- `empty` 加上 `out` 强调把容器或房间里的东西全腾出来。

### 讲解
断舍离时，我们常把平时 `store`（存放）旧物的阁楼 `empty out`（清空），丢掉落灰的 `dusty` `junk`，再处理 `unwanted`（闲置的）物品。

<exercise id="u277-haggle-01" type="matching" activity="matching" goal="polite-haggling" stage="recognize">

目标词：bargain hunter, a steal, reasonably priced, final offer, deal

### 题目
把二手淘货与讲价高频表达和中文释义配对。

### 配对
- [bargain-hunter] bargain hunter | 淘便宜货达人
- [a-steal] a steal | 便宜得超值的好货
- [reasonably-priced] reasonably priced | 定价公道的
- [final-offer] final offer | 最后一口价
- [deal] deal | 划算交易；成交

### 提示
- `hunter` 是“猎人”，专门搜寻便宜好货的人就是淘货达人。
- `a steal` 是口语里的夸张赞叹，形容价格低到像白捡一样。

### 讲解
`bargain hunter` 最擅长发现 `reasonably priced`（价格合理）甚至堪称 `a steal` 的宝贝；谈妥 `final offer` 后说一声 `Deal!` 就代表成交。

</exercise>

<exercise id="u277-cond-01" type="choice" activity="word-choice" goal="item-condition" stage="recognize">

目标词：shape, lid, handle

### 场景
你在跳蚤市场看中了一只复古搪瓷水壶，卖家正在向你展示它的细节。

### 题目
卖家想表达“虽然壶盖不见了，但提手很结实，整体品相依然很好”，哪句英文最准确？

### 选项
- [opt-shape] The lid is missing, but the handle is sturdy and the pot is still in great shape.
- [opt-steal] The handle is missing, and the lid is out ofjunk.
- [opt-store] The shape is missing, so the lid cannot store water.

### 答案
opt-shape

### 选项反馈
- [opt-shape] 正确！`lid` 是壶盖，`handle` 是提手/把手，`in great shape` 地道表示“品相极佳”。
- [opt-steal] 把“壶盖”和“提手”说反了，且后半句搭配不合语法。
- [opt-store] `shape` 单独作主语表示“形状不见了”不合逻辑。

### 提示
- 盖在上面的部件叫 `lid`，手握着提起的部分叫 `handle`。
- 表示旧物“保存状态好、成色佳”常用短语 `in great ____`。

### 讲解
验货时常检查器物的 `lid`（盖子）和 `handle`（把手），并用 `in good/great shape` 评价整体品相。

</exercise>

<exercise id="u277-cond-02" type="choice" activity="word-choice" goal="item-condition" stage="recognize">

目标词：piece, restore, last

### 题目
下面哪句话表达了“只要我们把这件实木家具翻新一下，它还能耐用很多年”？

### 选项
- [opt-restore] If we restore this wooden piece, it will last for many more years.
- [opt-raise] If we raise this wooden junk, it will store for many more years.
- [opt-empty] If we empty out this wooden deal, it will wear for many more years.

### 答案
opt-restore

### 选项反馈
- [opt-restore] 正确！`restore` 意为修复、翻新（旧家具），`piece` 指这件家具，动词 `last` 表示“耐用、持续使用”。
- [opt-raise] `raise` 是抬高或涨价，且 `store` 不能用来表示“耐用多年”。
- [opt-empty] `empty out` 是清空，`deal` 是交易，均不符合翻新家具的句意。

### 提示
- “修复、翻新老物件”是以 `re-` 开头的动词。
- `last` 在这里作不及物动词，表示维持、经久耐用。

### 讲解
`a piece of furniture`（一件家具）在上下文明确时可简称为 `this piece`；经过 `restore`（翻新）后能 `last`（耐用）很久。

</exercise>

<exercise id="u277-cond-03" type="choice" activity="cloze" goal="item-condition" stage="build">

目标词：fur, been, been worn

### 题目
补全卖家对一件闲置冬装的介绍：
"This faux ____ coat has ____ stored in a garment bag and has never ____."（这件人造毛皮大衣一直存放在防尘袋里，从来没被穿过。）

### 选项
- [opt-a] fur / been / been worn
- [opt-b] fur / been / wore
- [opt-c] lid / be / been worn

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`faux fur coat` 是人造毛皮大衣，`has been stored` 与 `has never been worn` 都是现在完成时被动语态。
- [opt-b] 大衣是“被穿”的，且助动词 `has` 后面不能接过去式 `wore`，必须用被动形式 `been worn`。
- [opt-c] `lid` 是盖子，且 `has` 后面应接过去分词 `been` 而非原形 `be`。

### 提示
- 第一空填衣服材质“毛皮”。
- 后两空都位于助动词 `has` 之后，且主语“大衣”是动作的承受者，需用完成时被动结构。

### 讲解
英语中物品“被存放、被穿戴”必须体现被动关系：`has been stored` 和 `has never been worn`（`wear` 的过去分词是 `worn`）。

</exercise>

<exercise id="u277-haggle-02" type="choice" activity="cloze" goal="polite-haggling" stage="build">

目标词：do you happen to, wondering

### 题目
补全顾客在旧书摊前礼貌询问的两句话：
"Excuse me, ____ have another copy? Also, I was ____ if you accept cash only."（打扰一下，请问您碰巧还有一本吗？另外，我在想您是不是只收现金。）

### 选项
- [opt-a] do you happen to / wondering
- [opt-b] are you wondering / happen to
- [opt-c] do you happen to / unwanted

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`Do you happen to + 动词原形` 与 `I was wondering if ...` 都是最得体的礼貌询问句式。
- [opt-b] 第一空后接动词原形 `have`，不能用 `are you wondering`；第二空在 `was` 后应接现在分词 `wondering`。
- [opt-c] `I was unwanted if ...` 语义不通，委婉提问需用 `I was wondering if ...`。

### 提示
- 第一空后面紧跟动词原形 `have`，表示“您碰巧……吗”。
- 第二空接在 `I was` 与 `if` 之间，构成委婉询问“我在想是否……”。

### 讲解
`Do you happen to ...?` 和 `I was wondering if ...` 能瞬间软化提问语气，在购物、求助与社交中极其实用。

</exercise>

<exercise id="u277-haggle-03" type="choice" activity="cloze" goal="polite-haggling" stage="build">

目标词：raise, purchase

### 题目
补全慈善义卖现场的对话：
"Every ____ you make today helps us ____ money for the local animal shelter."（您今天购买的每一件物品，都在帮助我们为当地动物收容所筹集善款。）

### 选项
- [opt-a] purchase / raise
- [opt-b] junk / restore
- [opt-c] steal / last

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！`make a purchase` / `every purchase you make` 表示购买行为或所购物品，`raise money` 表示筹集资金。
- [opt-b] `junk` 是不可数名词不能直接接在 `every` 后，且 `restore money` 搭配不当。
- [opt-c] `last` 不能表达“筹集善款”的意思。

### 提示
- 第一空作名词，与动词 `make` 搭配表示“购买”。
- 第二空与宾语 `money` 搭配，构成固定短语“筹钱、募捐”。

### 讲解
`purchase` 既可作动词也可作可数名词（一次购买或买到的东西）；`raise` 除了“提高（出价/价格）”，还常搭配 `money` 表示“筹款”。

</exercise>

<exercise id="u277-declutter-02" type="input" activity="write" goal="declutter-home" stage="recall">

目标词：empty out, unwanted, junk

### 题目
用英文写出：“我们需要把那些闲置的杂物清空。”（使用 We need to ... the ...）

### 答案
- We need to empty out the unwanted junk.

### 提示
- “彻底清空”使用两个词的动词短语，接在 `We need to` 后面。
- “闲置的杂物”在 `the` 后面依次放形容词“不再需要的”和不可数名词“杂物”。

### 讲解
`empty out` 表示清空、腾出；`junk` 是不可数名词，不能加复数 `-s`，写成 `the unwanted junk` 即可。

</exercise>

<exercise id="u277-haggle-06" type="choice" activity="audio-choice" goal="polite-haggling" stage="recognize">

目标词：do you happen to, lid, handle

### 听力
Do you happen to have the lid for this pot with the wooden handle?

### 题目
听录音，这位顾客在向摊主询问什么？

### 选项
- [opt-right] 碰巧有没有这只木柄锅配套的锅盖
- [opt-wrong1] 能不能把这只破了把手的旧锅退掉
- [opt-wrong2] 这只落满灰尘的木箱最低多少钱卖

### 答案
opt-right

### 选项反馈
- [opt-right] 正确！顾客用 `Do you happen to have ...` 礼貌询问有没有这只带木制把手（`wooden handle`）的锅的盖子（`lid`）。
- [opt-wrong1] 录音没有提到把手破损或退货，而是询问配套盖子。
- [opt-wrong2] 录音说的是带木柄的锅（`pot`），没有提到落灰的木箱或价格。

### 提示
- 开头是礼貌询问“您碰巧有……吗”。
- 注意听清锅缺少的上方部件，以及修饰锅的特征短语 `with the wooden ...`。

### 讲解
原句为："Do you happen to have the lid for this pot with the wooden handle?" 清晰点出了器物的两个关键部位 `lid`（盖子）和 `handle`（把手）。

</exercise>
