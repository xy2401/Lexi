# Internet

还记得十几年前开机要等两分钟、主机箱大得像小茶几的台式电脑吗？如今我们揣着轻薄的智能设备随时随地视频通话，甚至跟智能机器人对话。科技日新月异，我们在怀念老物件的同时，也得不断适应新软件和新界面。这一单元围绕 **Internet（互联网与新旧科技对比）**，带你攻克英语里最经典的今昔对比结构 **used to** 与 **get used to**，并把电脑软硬件与排障口令一次装进词库。

## 本课核心收获

- 彻底分清回顾过去的 **used to + 动词原形** 与适应变化的 **get used to + 名词 / -ing**
- 掌握软硬件与外设高频词：**device**、**browser**、**server**、**webcam**、**microphone**、**graphics**、**robot**、**user**
- 熟练运用数码操作指令：**install**、**restart**、**press**、**key**、**switch**、**locate**、**log out of** 与 **take a look**
- 用 **giant**、**frequent** 与 **once a ...** 描述设备规模与更新、备份的频率

## 今昔科技对比：`used to` 还是 `get used to`？

这两个长相酷似的结构，一个是“回头看历史”，一个是“往前适应新生活”，语法规则截然不同：

1. **used to + 动词原形（过去曾经……，但现在不了）**
   专门用来对比今昔反差，说明过去长期存在的状态或习惯如今已经改变。这里的 *to* 是不定式符号，后面直接跟**动词原形**：
   > Early computers **used to** be **giant** machines that filled a whole room.（早期的电脑曾经是占满整间屋子的庞然大物。）

2. **get used to + 名词 / 动名词 `-ing`（逐渐习惯于、慢慢适应）**
   刚换了新手机系统或新办公软件，一开始觉得别扭，用着用着顺手了，就叫 **get used to**。请把这里的 **to** 圈出来——它是**介词**！后面只能接名词、代词或 **-ing** 形式：
   > Don't worry—every **user** takes time to **get used to** a new **browser**（接名词）or **getting used to** typing on a small screen（接动名词）.

## 屏幕内外的数码图鉴

无论是线上开会还是聊游戏配置，这组软硬件词汇几乎天天见面：

| 分类 | 核心词汇 | 地道语境与实用提示 |
| :--- | :--- | :--- |
| **终端与智能** | **device**（设备；装置）、**robot**（机器人）、**giant**（巨大的；科技巨头） | 手机、平板统称 smart **devices**；**giant** 既能作形容词表巨大，也能指行业巨头 |
| **视频与音频** | **webcam**（网络摄像头）、**microphone**（麦克风；话筒） | 远程会议最常听到：检查 **webcam** 画面与 **microphone** 声音是否开启 |
| **软件与后台** | **browser**（浏览器）、**server**（服务器）、**user**（用户）、**graphics**（图像；画质） | 网页打不开可能是后台 **server** 崩了；聊游戏与显卡“画质”固定用带 `-s` 的 **graphics** |
| **按键与切换** | **key**（键盘按键）、**switch**（开关；切换） | 键盘上的回车键、空格键都叫 **key**；**switch** 作名词是电源开关，作动词则是“切换（账号/网络）” |

## 电脑卡住了？一套地道排障与操作指令

朋友电脑出小毛病向你求助，或者你在阅读软件提示时，下面这套动作链条非常管用：

- **请人帮忙看一眼**：先礼貌来一句 *Could you **take a look** at my tablet?*（你能帮我看一下平板吗？）。
- **安装、按键与万能重启**：装新软件叫 **install**；按键盘上的某个键用 **press**（如 **press** *the Escape **key***）；遇到卡死最有效的绝招永远是 **restart**（重新启动）。
- **精准查找与安全退出**：在密密麻麻的文件夹或机箱背面寻找某个文件、接口，用 **locate**（定位、找出位置）比普通的 *find* 更专业；在公共电脑用完网页，离开前千万记得 **log out of**（退出登录，注意接账号或系统时介词 **of** 不能漏！）。
- **谈论维护频率**：软件如果隔三差五就弹窗，叫 **frequent** *updates*（频繁的更新）；而表达“每隔固定周期一次”，只需用 **once a** + 单数时间名词，如 **once a** *week*（一周一次）、**once a** *day*（一天一次）。

## 数码生活原创例句

1. **Video game graphics used to look very simple, and we only played once a week.**
   以前的电子游戏画面看起来很简单，而且我们那时一周才玩一次。
   *点拨：`used to look` 描述过去的状态，`once a week` 清晰交代频率。*

2. **It took my mom a month to get used to turning on the webcam and microphone for family calls.**
   我妈妈花了一个月才习惯在家庭视频通话时打开网络摄像头和麦克风。
   *点拨：`get used to` 后接动名词短语 `turning on...`，切忌写成 *turn on*。*

3. **After you install the software, press any key to restart your device.**
   安装好软件之后，按任意键重启你的设备。
   *点拨：软件安装向导最经典的提示语，串起 `install`、`press`、`key`、`restart` 与 `device`。*

4. **The website crashed because the main server couldn't handle such frequent visits from millions of users.**
   网站崩溃了，因为主服务器扛不住数百万用户如此频繁的访问。
   *点拨：`server`、`frequent` 与复数 `users` 准确还原网络拥堵原因。*

5. **Always log out of your bank account before you close the browser on a shared computer.**
   在公用电脑上关闭浏览器之前，务必退出你的银行账户。
   *点拨：`log out of + 账号/平台` 是网络安全必备表达。*

6. **Can you take a look and help me locate the power switch on the back of this giant robot?**
   你能过来看一眼，帮我找到这台巨型机器人背面的电源开关吗？
   *点拨：`take a look` 开启求助，`locate` 表确定位置，`switch` 此处作名词指“开关”。*

## 常见易错点排查

- **混淆 `used to do` 与 `get used to doing`**：看到前面没有 *be* 或 *get*，纯属回忆往昔，接原形（*I **used to** use that old browser*）；看到前面有 **get**（或 *be*），表示适应习惯，后接名词或 `-ing`（*I can't **get used to** using this keyboard*）。
- **漏掉 `log out of` 的介词 `of`**：如果不带宾语，可以直接说 *Remember to log out!*；但只要后面接了退出的具体网站、邮箱或设备，必须加上 **of**：**log out of** *the system*。
- **把键盘上的“键”说成 `button`**：鼠标、电梯或机箱外壳上的按钮常叫 *button*，但电脑键盘上敲打的字母键、功能键，地道说法一律是 **key**。
