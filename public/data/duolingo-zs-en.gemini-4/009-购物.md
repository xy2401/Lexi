# 购物

走进服装店挑一件合身的衬衫或夹克，看中款式后第一反应往往是看看吊牌：“这件多少钱？贵不贵？”这一课不仅带你学会询价和挑选衣物，更要帮你跨过英语初学者非常重要的一道门槛——**名词的单数与复数变化**。

## 学完本课，你将掌握

- 常见衣物的单数与复数说法（**hat / hats**、**shirt / shirts**、**coats**、**jacket**）。
- 用 **How much is ...?** 礼貌询价，并结合数字 **one / two / three / ten** 和 **dollar / dollars** 报出价格。
- 用 **need**（需要）、**like**（喜欢）、**expensive**（昂贵的）和 **lots**（许多）表达真实的购物想法。
- 借助发音规律巧记拼读伙伴：**shirt** 与 **bird**、**hat** 与 **sat**。

## 服装店里的挑选时刻

周末你和朋友一起逛街，推开店门，店员热情地迎上来：

> **Clerk:** Welcome!
> （欢迎光临！）
> **You:** Thanks! We need two new shirts. How much is this black shirt?
> （谢谢！我们需要两件新衬衫。这件黑衬衫多少钱？）
> **Clerk:** This nice shirt is ten dollars. And we have lots of hats!
> （这件好看的衬衫十美元。而且我们有很多帽子！）
> **You:** One dollar or three dollars for a hat? Oh, this jacket is expensive!
> （一顶帽子是一美元还是三美元？噢，这件夹克好贵！）

## 核心表达与语法拆解

### 1. 一件与多件：数量超过“一”，词尾加 -s

中文里无论说“一顶帽子”还是“十顶帽子”，“帽子”两个字永远不变。但英语对数量非常敏感——只要可数物品达到 **two**（二）、**three**（三）、**ten**（十）或者 **lots of**（许多），名词词尾就要加上 **-s**：

- 一件单品：**one hat**（一顶帽子）、**this shirt**（这件衬衫）、**one dollar**（一美元）
- 多件物品：**two hats**（两顶帽子）、**three shirts**（三件衬衫）、**new coats**（几件新大衣）、**ten dollars**（十美元）

> **金钱单位也要变复数**：哪怕中文只说“十美元”，英文也必须写成 **ten dollars**；只有刚好“一美元”时才用单数 **one dollar**！

### 2. 询价万能句：How much is this ...?

想知道某件单品的价格，直接把 **How much**（多少钱）放在句首，接上 **is this + 衣物名称**：

- **How much is this jacket?**（这件夹克多少钱？）
- **How much is this nice black hat?**（这顶好看的黑帽子多少钱？）
- 回答价格也很简单，直接用 **is + 数字 + dollar(s)**：**This jacket is ten dollars.**（这件夹克十美元。）如果觉得超预算了，可以感叹一句：**This is expensive!**（这太贵了！）

### 3. 购物心态对比：like（喜欢）与 need（需要）

逛街时最常纠结的就是“喜欢”还是“真需要”：

- **I like this jacket.**（我喜欢这件夹克。——表达审美与喜爱）
- **We need warm coats.**（我们需要暖和的大衣。——表达实际需求）

## 衣物、数字与拼读对照表

| 类别 | 本课词汇 | 记忆与拼读巧招 |
| :--- | :--- | :--- |
| **衣物清单** | **hat / hats**, **shirt / shirts**, **coats**, **jacket** | **coats** 是第 5 课 *coat*（外套、大衣）的复数；**jacket** 指短款“夹克衫”。 |
| **外观与价格评价** | **black**, **new**, **nice**, **expensive** | **expensive**（昂贵的）音节较长，可按 *ex-pen-sive* 三拍节奏朗读记忆。 |
| **数字与货币** | **one**, **two**, **three**, **ten**, **dollar / dollars**, **how much**, **much** | **how much** 连在一起问价格；其中的 **much** 本身表示“许多（不可数）”。 |
| **互动与数量** | **welcome**, **we**, **this**, **is**, **like**, **need**, **lots** | 店员说 **Welcome!** 表示“欢迎光临！”；口语中常用 **lots of + 复数名词** 表示“许多……”。 |
| **拼读同族词** | **bird**, **sat** | **bird**（鸟）和 **shirt**（衬衫）中间都是字母组合 *ir*，发相同的卷舌元音；**sat**（*sit* 的过去式“坐下了”）则和 **hat** 完美押韵！ |

## 原创例句精选

1. **Welcome! How much is this new jacket?**
   欢迎光临！（顾客问：）这件新夹克多少钱？
   *点拨：**this** 只能搭配单数名词（**this new jacket**），后面动词配 **is**。*

2. **We need three white shirts and two black hats.**
   我们需要三件白衬衫和两顶黑帽子。
   *点拨：数字大于 1 时，后面的 **shirts** 和 **hats** 都要记得加 **-s**。*

3. **This nice hat is only one dollar.**
   这顶好看的帽子只要一美元。
   *点拨：数字是 **one**，所以后面用单数 **dollar**。*

4. **Ten dollars is not expensive for a coat.**
   一件大衣十美元并不贵。
   *点拨：**expensive** 是形容词，前面必须搭配 **is**（或否定 *is not*），不能单独作谓语。*

5. **We like lots of nice shirts here.**
   我们喜欢这里的许多好看衬衫。
   *点拨：**lots of** 接可数名词时，后面的名词要用复数形式。*

6. **A black bird sat on a hat.**
   一只黑鸟坐在了一顶帽子上。
   *点拨：用生动的小画面同时串联颜色 **black**、拼读词 **bird / sat** 和衣物 **hat**。*

## 常见易错点提醒

1. **说了数字 two / three / ten，却忘了给名词加 -s**
   - 误：*two shirt* / *ten dollar*
   - 正：**two shirts** / **ten dollars**

2. **把 this 和复数名词混搭**
   - **this** 只指“这一个”，不能说 *this shirts* 或 *this coats*；单数说 **this shirt**，复数以后会用到 *these*。

3. **问价格时漏掉谓语动词 is**
   - 误：*How much this hat?*
   - 正：**How much is this hat?**

4. **把 two 和 three 的拼写或读音搞混**
   - **two**（2）里的字母 *w* 不发音，读作 `/tuː/`；**three**（3）以咬舌音 *th* 开头，不要读成 *tree*（树）。
