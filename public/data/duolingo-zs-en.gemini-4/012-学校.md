# 学校

走进校园，无论是聊今天有什么课、吐槽考题有点难，还是祝愿同学顺利通过考试，都会用到一套鲜活的校园高频词。同时，这一课还会解锁英语语法里三个超实用的升级技能：**元音音素前的冠词 an**、**表示“有”的 have / has 切换**，以及**复数指代词 these**。

## 本课学习目标

- 熟练运用 **school**、**class**、**exam / exams**、**question / questions** 与 **pass** 聊起校园日常。
- 掌握不定冠词 **an** 的使用时机（如 **an exam**、**an easy question**、**an important class**）。
- 根据主语准确切换 **have** 与 **has**，结合 **today** 和 **many** 安排或描述学业。
- 用 **easy / difficult**、**a little**、**cool**、**that is** 与 **these** 自然评价课程与考卷。

## 课间走廊的考前对话

今天有一场随堂测验，下课铃一响，两个同学在走廊里聊了起来：

> **Leo:** We have an important exam today!
> （我们今天有一场重要的考试！）
> **Maya:** Really? Is it difficult?
> （真的吗？难不难？）
> **Leo:** The book has many questions, and these questions are a little difficult.
> （书上有很多道题，而且这些题有点难。）
> **Maya:** Don't worry. Your English class is cool, and the teacher is nice. You can pass!
> （别担心。你的英语课很棒，老师人也很好。你能通过的！）

## 核心语法拆解

### 1. 冠词 a 的“顺口变身”：遇见元音音素改用 an

之前我们学过单数名词前加 *a*（如 **a book**、**a school**）。但如果紧跟在冠词后面的那个词是以**元音音素**（听起来像 `a, e, i, o, u` 开头的声音）起头，连读两个元音会拗口，这时 *a* 就要加上小尾巴变成 **an**：

- **an exam**（一场考试）
- **an easy question**（一道简单的问题——注意看紧挨着冠词的 **easy** 是元音开头！）
- **an important class**（一节重要的课）
- **an exact number**（一个确切的数字）

> **判断口诀**：用不用 **an**，只看**紧挨着冠词右边那一个词**的开头读音！比如单独说 *a question* 用 *a*，但一旦中间插进 *easy*，就要变成 **an easy question**。

### 2. 表示“有 / 上某门课”：have 还是 has？

英语里表示“拥有某物”或者“某天有课/有考试”，都要看主语是谁来选词：

- **I / you / we / they** 以及复数主语，一律用原形 **have**：
  **We have a class today.**（我们今天有一节课。）
  **They have many exams.**（他们有很多场考试。）
- **he / she / it** 或单数人名、单数事物（如 *this book*），要换成三单形式 **has**：
  **She has an exam today.**（她今天有一场考试。）
  **This book has many easy questions.**（这本书里有许多简单的题目。）

### 3. 远近与单复数指代：that is、these 与 many

- 指着远处的一个事物说“那是……”，用 **That is ...**（对应近处的 *This is ...*）：**That is a cool school!**（那是一所很酷的学校！）
- 指着眼前的**多个**事物说“这些”，把 *this* 升级为复数伙伴 **these**：**These exams are important.**（这些考试很重要。）
- 想说“许多”可数事物（题、书、考试），用 **many + 复数名词**：**many questions**（许多问题）、**many books**（许多书）。

## 校园词汇关系与拼读巧记

| 分组 | 本课词汇 | 辨析与记忆妙招 |
| :--- | :--- | :--- |
| **校园与考试** | **school**, **class**, **book**, **exam / exams**, **question / questions**, **pass**, **speak**, **today** | **pass an exam** 意为“通过考试”；**class** 既指“班级”，也指“一堂课”（如 *in class* 在课堂上）。 |
| **难易与评价** | **easy**, **difficult**, **important**, **cool**, **a little** | **easy**（容易的）与 **difficult**（困难的）是一对核心反义词；第 6 课的 **a little** 放在形容词前表示“有一点……”（如 **a little difficult** 有点难）。 |
| **-ass 拼读三兄弟** | **class**, **pass**, **glass** | 三个词词尾完全一致：**class**（课/班）、**pass**（通过）、**glass**（玻璃杯；玻璃），顺口一串就能记牢！ |
| **ex- 形近双胞胎** | **exam**, **exact** | 初学者极易看走眼：**exam** 是名词“考试”，而 **exact** 是形容词“确切的、精确的”。 |

## 原创例句精选

1. **We have an important class today.**
   我们今天有一节重要的课。
   *点拨：时间词 **today**（今天）通常自然地放在句末，前面不加介词。*

2. **He has an easy exam, and they have a difficult exam.**
   他有一场简单的考试，而他们有一场难考的试。
   *点拨：一句之内对比单数主语 **He has** 与复数主语 **they have**，以及 **an easy** 与 *a difficult*。*

3. **These questions are a little difficult.**
   这些问题有一点难。
   *点拨：**these** 搭配复数 **questions**，be 动词用 *are*；**a little** 让语气更委婉客观。*

4. **That is an exact question!**
   那是一个非常精准的问题！
   *点拨：**exact** 以元音音素开头，前面同样搭配 **an**。*

5. **We speak English in class and pass these exams.**
   我们在课上说英语，并通过这些考试。
   *点拨：把旧朋友 **speak** 放进新场景 **in class** 中活用。*

6. **This is a glass of water on my book.**
   这是我书旁边的一玻璃杯水。
   *点拨：对比上一课的热饮杯 *cup*，透明的玻璃杯通常叫 **glass**。*

## 中文母语者常见易错点

1. **在 exam / easy / important 前习惯性写成 a**
   - 误：*a exam* / *a easy question* / *a important book*
   - 正：**an exam** / **an easy question** / **an important book**

2. **第三人称单数主语后面误用 have**
   - 误：*She have a book.* / *My school have many classes.*
   - 正：**She has a book.** / **My school has many classes.**

3. **在 today 前面画蛇添足加 in 或 on**
   - 误：*We have an exam on today.*
   - 正：**We have an exam today.**（**today** 本身就是时间副词，直接放句尾或句首！）

4. **混淆 these（这些）与 this（这个）**
   - 看到复数词尾 *-s*（如 **exams**、**questions**），前面的指示词一定要换成 **these**，不能说 *this questions*。
