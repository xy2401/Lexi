目标词：childhood, neighborhood, shy, strict, card, joke

### 题目
将描述童年环境、性格与日常游戏的词汇同对应的中文释义配对。

### 配对
- [childhood] childhood | 童年
- [neighborhood] neighborhood | 街区；邻里
- [shy] shy | 害羞的
- [strict] strict | 严格的
- [card] card | 纸牌；卡片
- [joke] joke | 笑话

### 提示
- 两个带有 -hood 后缀的长名词分别对应人生阶段与居住社区。
- 注意区分形容孩子腼腆和形容长辈管教严厉的两个形容词。

### 讲解
childhood（童年）与 neighborhood（街区）共享后缀 -hood；shy（害羞的）与 strict（严格的）常用来回忆儿时的性格与家规；play cards（打牌）与 tell a joke（讲笑话）则是经典的聚会娱乐。

<exercise id="u128-past-habits-01" type="choice" activity="word-choice" goal="past-habits" stage="recognize">

目标词：used to, shy, now

### 场景
同学聚会上，大家惊讶地发现当年最安静的林浩如今成了健谈的主持人。

### 题目
林浩笑着说：“I used to be very shy, but now I love speaking on stage.”这句话是什么意思？

### 选项
- [opt-a] 我以前非常害羞，但现在我喜欢在台上发言。
- [opt-b] 我现在已经习惯了害羞，不过还是得上台发言。
- [opt-c] 我一直都很害羞，现在也不敢上台说话。
- [opt-d] 我偶尔会害羞，所以很少在舞台上讲话。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！used to be 表示“过去曾经是（但现在不再是）”，与后半句的 but now 形成鲜明的今昔对比。
- [opt-b] 把 used to do（过去常常）误解成了 be used to doing（习惯于）。
- [opt-c] 忽略了 used to 暗含“如今已改变”的含义，也看反了后半句的 love。
- [opt-d] used to 不表示“偶尔”，而是回顾过去一段时期的常态。

### 提示
- 注意 used to 前面没有 am，它专门用来谈论已经过去的旧状态。
- 后半句由 but now 转折，说明如今的变化。

### 讲解
used to + 动词原形（如 used to be shy）专门用来描述过去存在、如今已改变的状态或习惯。

</exercise>

<exercise id="u128-past-habits-02" type="choice" activity="cloze" goal="past-habits" stage="build">

目标词：never used to, spinach, now, do

### 题目
I ____ like ____ when I was little, but ____ I ____!

### 选项
- [opt-a] never used to / spinach / now / do
- [opt-b] used to / now / spinach / do
- [opt-c] do / spinach / never used to / now
- [opt-d] never used to / frying pan / strict / caught

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！never used to like spinach 表示“以前从不喜欢菠菜”，后半句用 but now I do 简洁代指“但现在我喜欢了”。
- [opt-b] 第二空 like 后应接食物名词 spinach，不能接时间副词 now。
- [opt-c] 时态与逻辑颠倒：when I was little 是童年过去时间，不能用现在时的强调形式与后半句 never used to 搭配。
- [opt-d] 词义混乱，不能构成合理的今昔口味对比。

### 提示
- 前半句有时间从句 when I was little，表达“小时候从不喜欢某种蔬菜”。
- 后半句为了不重复前面的动词短语 like...，在主语 I 后面用一个简短的代动词收尾。

### 讲解
“I never used to..., but now I do!”是英语口语表达“以前从不……，但现在会了”的黄金模板，末尾的 do 巧妙替代了前文的实义动词短语。

</exercise>

<exercise id="u128-memory-actions-02" type="choice" activity="cloze" goal="memory-actions" stage="build">

目标词：strict, stay, up

### 题目
Our parents were ____ about bedtime, so we couldn't ____ ____ past nine.

### 选项
- [opt-a] strict / stay / up
- [opt-b] shy / stay / over
- [opt-c] strict / come / up
- [opt-d] caught / hide / up

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！be strict about bedtime 表示“对就寝时间要求严格”，couldn't stay up past nine 表示“不能熬夜超过九点”。
- [opt-b] 父母对睡觉时间不会“害羞（shy）”，且 stay over 意为留宿过夜而非熬夜晚睡。
- [opt-c] come up 意为“走上前、被提及”，不能表达晚睡不就寝。
- [opt-d] 词性和搭配均不成立。

### 提示
- 第一空接在 were 后，说明父母对作息管教“严格”。
- 后两空组成固定短语动词，表示“熬夜、晚睡”。

### 讲解
be strict about something 意为“对某事要求严格”；stay up 是由 stay 与副词 up 组成的常用短语，意为“熬夜、不睡觉”。

</exercise>

<exercise id="u128-memory-actions-03" type="choice" activity="cloze" goal="memory-actions" stage="build">

目标词：caught, frog, dirt, kicked

### 题目
My brother ____ the ball into the ____ and then ____ a little green ____ by the pond.

### 选项
- [opt-a] kicked / dirt / caught / frog
- [opt-b] caught / frog / kicked / dirt
- [opt-c] kicked / pie / hide / bug
- [opt-d] hide / dirt / caught / trumpet

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！先把球踢进泥地里（kicked the ball into the dirt），接着在池塘边捉到一只小绿青蛙（caught a little green frog）。
- [opt-b] 把动词和宾语配反了：kicked a little green frog into the dirt 不合常理，球也不会自己出现在池塘边被“捉”。
- [opt-c] 把球踢进馅饼里不合逻辑，且过去时并列结构中 hide 没有用过去式。
- [opt-d] 第一空缺少过去式，且池塘边不会捉到“绿色的小号”。

### 提示
- 搭配宾语 the ball（球）的动作是“踢”，进入的地方是不可数名词“泥地”。
- 在池塘边（by the pond）抓到的绿色小动物是“青蛙”。

### 讲解
kicked 与 caught 均为过去式，分别对应 kick（踢）和 catch（捕捉），生动串联起童年户外玩耍的两个连续镜头。

</exercise>

<exercise id="u128-childhood-scenes-03" type="choice" activity="audio-choice" goal="childhood-scenes" stage="recognize">

目标词：frying pan, pie, spinach

### 听力
Dad cooked fresh spinach in a frying pan and baked an apple pie.

### 题目
听录音，选出爸爸在厨房里做了哪两样食物。

### 选项
- [opt-a] 用平底煎锅炒了新鲜菠菜，还烤了一个苹果派。
- [opt-b] 用大汤锅煮了蔬菜汤，并买了一盒巧克力卡片。
- [opt-c] 把苹果派放进平底煎锅里热了一下，没有做蔬菜。
- [opt-d] 让孩子们把盘子里的菠菜吃完才能吃冰淇淋。

### 答案
opt-a

### 选项反馈
- [opt-a] 正确！录音清楚描述了在平底煎锅里烹调新鲜菠菜，以及烘烤苹果派。
- [opt-b] 录音中的炊具不是汤锅，也没有提到汤或卡片。
- [opt-c] 录音明确提到了烹调新鲜蔬菜，且苹果派是烤出来的（baked）。
- [opt-d] 录音里没有出现冰淇淋或要求孩子吃完蔬菜的对话。

### 提示
- 听清前半句 in a... 里提到的厨房炊具和绿叶蔬菜。
- 留意 and 后面动词 baked 的宾语是什么甜点。

### 讲解
原文为“Dad cooked fresh spinach in a frying pan and baked an apple pie.”，注意 spinach 是不可数名词，前面不加冠词 a。

### 答案
