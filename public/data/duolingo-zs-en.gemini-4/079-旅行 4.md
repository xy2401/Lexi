# 旅行 4

出门旅行时，最考验英语实战能力的就是那些临场沟通的瞬间：在火车上想打开窗户怎么礼貌征求邻座同意？航班延误不得不改签怎么说？到了陌生城市想找最近的自动取款机或换点欧元，又该怎么开口？这一课我们把旅途中最实用、最地道的高情商沟通表达一网打尽。

## 本课学习目标

- 用 **Do you mind (if)...?** 礼貌征询许可，并学会用 **Of course not!** 得体回应
- 用 **if you like / if you want** 给出轻松不强迫的提议
- 分清过去的客观必须（**had to**）与现在的毫无压力（**don't have to / doesn't have to**）
- 熟练处理问路取款、货币兑换、往返航班与酒店入住（**where's / closest / ATM / euro / change / flight / return / double / up to / stairs**）

## 旅途高情商礼貌语：征求同意与贴心提议

在车厢、机舱或酒店大堂与陌生人打交道时，直接命令会显得生硬，换成 **Do you mind...?**（你介意……吗？）瞬间就能拉近距离：

- **Do you mind waiting a minute?**（你介意等一分钟吗？）
- **Do you mind if I sit here?**（你介意我坐这儿吗？**do you mind if** 后面接完整小句子。）

这里有一个**中文学习者最容易踩坑的回应细节**：因为 **mind** 的意思是“介意、反感”，所以当你想热情表示“**一点也不介意，请便！**”时，必须用否定回答：

> **— Do you mind if I put my bag here?**（你介意我把包放这儿吗？）
> **— Of course not!**（当然不介意！/ 请便！）

给同伴提建议时，如果想把决定权温柔地交给对方，可以在 **can**（可以）引导的建议句末尾加上 **if you like** 或 **if you want**（如果你愿意 / 如果你想的话）：

- **We can stop here for coffee if you like.**（如果你愿意的话，我们可以在这儿停下来喝杯咖啡。）
- **I can change seats with you if you want.**（如果你想的话，我可以跟你换座位。）

此外，旅行预订中常遇到 **offer**，作动词表示“提供”（如 **They offer free Wi-Fi**），作名词则表示“特价优惠、提议”。

## “不得不做”还是“不必着急”？

旅途计划常有变动，这组表达能帮你精准区分“被迫必须”和“轻松随意”：

| 表达形式 | 核心含义 | 典型旅行语境 |
| --- | --- | --- |
| **had to** + 动词原形 | （过去）不得不、必须 | **Our flight was late, so we had to wait.**（航班晚点了，我们不得不等。） |
| **don't have to** + 动词原形 | 不必、不需要（主语 I / you / we / they） | **You don't have to pay tonight.**（你今晚不必付钱。） |
| **doesn't have to** + 动词原形 | 不必、不需要（主语 he / she / it） | **He doesn't have to return the key now.**（他现在不必归还钥匙。） |

记住：**don't / doesn't have to** 表示“没必要做”，而不是“禁止做”。

## 问路取钱、航班往返与酒店细节

把剩下的高频旅行词放进三个真实场景里，记忆会特别牢固：

### 1. 街头找设施与换钱

- **Where's the closest ATM / bus station?**（最近的自动取款机 / 公共汽车站在哪儿？**where's** 是 **where is** 的缩写；**closest** 是 **close** 的最高级“最近的”；**ATM** 三个字母固定全大写。）
- **euro** 与 **thousand**：欧洲旅行常用货币 **euro**（欧元，复数 **euros**），大额预算常搭配 **thousand**（一千，如 **one thousand euros**）。
- **get** 与 **change**：去取款机取钱可以说 **get some cash**；**change** 是旅行多面手——既能表示“兑换外币”（**change dollars into euros**）、“零钱”，还能表示“换乘、改签”（**change flights**）。
- **here** 与 **anywhere**：**here** 是“这里”，**anywhere** 是“任何地方”，常用于否定句和疑问句，如 **I still can't find an ATM anywhere**（我仍然在任何地方都找不到取款机，**still** 意为“仍然”）。

### 2. 航班与返程

- **a long night flight**：一趟长途夜间航班（**long** 长的，**night** 夜晚，**flight** 航班）。
- **return**：作动词指“返回”（**return tonight** 今晚返回），作定语时 **a return ticket / flight** 指“往返票 / 返程航班”。
- **stop**：作动词指“停下”，作名词指沿途的“公交站点”（注意 **bus stop** 是路边停靠站牌，而 **bus station** 是大型汽车总站）。

### 3. 酒店房间与楼梯

- **double**：双人的、双倍的，如预订一间双人房 **a double room for two nights**（住两晚，持续时长前用介词 **for**）。
- **up to**：表示数量上限“最多可达”，如 **This room holds up to three people**（这间房最多可住三人）；口语里 **It's up to you** 则是“由你决定”。
- **down the stairs**：走下楼梯（**down** 向下；**stairs** 指连接楼层的楼梯，日常总是用复数形式）。

## 原创旅途例句精选

1. **Excuse me, where's the closest ATM? I need to get two hundred euros.**
   打扰一下，最近的自动取款机在哪儿？我需要取两百欧元。
   *点拨：旅行街头问路最直接实用的模板。*
2. **— Do you mind if we walk down the stairs? — Of course not!**
   ——你介意我们走下楼梯吗？——当然不介意！
   *点拨：电梯排队太长时，礼貌询问同行伙伴的经典对话。*
3. **It was a long flight, so you don't have to go anywhere tonight if you want to rest.**
   这趟航班飞了很久，如果你想休息的话，今晚不必去任何地方。
   *点拨：串联了 long flight、don't have to、anywhere、tonight 与 if you want。*
4. **We missed the last stop, so we had to take a taxi back to the bus station.**
   我们坐过了最后一站，所以不得不打车回汽车总站。
   *点拨：同句对比路边站点 stop 与大型车站 bus station。*
5. **Hotels here still offer double rooms for under a thousand yuan a night.**
   这里的酒店仍然提供每晚不到一千元的双人房。
   *点拨：offer 表示“提供”，for 引出对应的价格。*
6. **She doesn't have to change her return flight; we can wait for her if you like.**
   她不必改签她的返程航班；如果你愿意的话，我们可以等她。
   *点拨：第三人称单数用 doesn't have to，后接动词原形 change。*

## 常见易错点提醒

- **别把 Do you mind...? 答反了**：只要你同意对方的请求，一定要答 **Of course not!** 或 **No, go ahead**。如果回答 *Yes*，意思就变成了“是的，我很介意（请不要这样做）”。
- **ATM 保持全大写**：作为 Automatic Teller Machine 的缩写，英文书写中固定写作 **ATM**，且因为首字母 A 发元音 /eɪ/，说“一台取款机”要用 **an ATM**。
- **stairs 别漏掉词尾的 s**：走上走下的一整段楼梯由许多级台阶组成，习惯说 **up / down the stairs**，单数 **stair** 很少单独使用。
