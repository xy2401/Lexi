# Unit 282: Excuses

> Excuses: Follow up on a conversation

## 单词

background information, corporation, credit, efficient, failure to, follow up, given that, guidelines, had been, had it been, hadn't been, hadn't it, making excuses, matter, obligation, observation, potential, practical, prior, prior to, priority, send out, target, technical, the case that

## 单元讲解

本单元设定在职场跟进对话的场景中：你需要就某个未完成任务进行后续沟通，对方可能正在 making excuses，而你要礼貌但坚定地推进。

语法核心是过去完成时的虚拟与倒装结构。Had it been 是 If it had been 的倒装形式，用于正式书面或口语中的假设回顾；hadn't it 则是反义疑问句的缩略。这些结构让表达更紧凑、更正式。

词汇可按功能分组：职场流程词（follow up, send out, guidelines, priority, obligation）、因果推理词（given that, prior to, the case that, failure to）、以及评价判断词（efficient, practical, potential, technical）。它们共同服务于"陈述事实—分析原因—提出期望"的沟通逻辑。

学完本单元，你能在英语工作环境中跟进任务进度、指出问题并给出合理要求，而不显得咄咄逼人。

## Tips

- **had it been** — If it had been 的倒装，省略 if 后主谓倒装，语气更正式；如 Had it been handled earlier, we wouldn't be here
- **given that** — "鉴于、考虑到"，引导已知前提，比 because 更客观冷静，常用于论证
- **prior to** — 比 before 更正式，多见于商务邮件和规章文件；日常口语用 before 即可
- **failure to** — "未能做某事"，名词化表达，如 failure to respond = 未回复；比 didn't 更书面
- **follow up** — 作动词短语时中间可插宾语（follow it up），作名词/形容词时加连字符（follow-up meeting）
- **credit** — 此处取"功劳、认可"义，如 give credit where credit is due；不要只记"信用"义
- **the case that** — "……这一情况"，用于引出需要讨论的事实，比 the fact that 语气更留有余地
