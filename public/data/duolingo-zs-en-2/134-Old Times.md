# Unit 134: Old Times

> Old Times: Share childhood memories

## 单词

accountant, assignment, corn, court, cover, did, didn't use to, favorite, fewer, fly, however, inch, indoors, know how to, never used to, outdoors, religion, rock, stream, sunrise, sweep, swept, tax, use to, web

## 单元讲解

本单元以回忆童年和过去的生活为主题，场景涵盖儿时的户外活动、学校作业和家庭日常。你将学会用 "used to" 结构讲述过去的习惯，对比今昔变化。

语法核心是 used to / didn't use to / never used to 这一过去习惯表达，表示"过去常常……（现在不再）"。注意否定形式中 use 不加 d："I didn't use to like vegetables." 另外，fewer 修饰可数名词，与 less 形成对比。

词汇按场景分组：童年与学校（assignment, favorite, know how to）、户外自然（outdoors, stream, rock, sunrise, corn, fly）、室内与成人世界（indoors, accountant, tax, religion, court）。sweep → swept 是不规则动词变化的典型例子。

学完本单元，你将能够用英语描述童年记忆，对比过去与现在的生活方式，如 "I never used to go outdoors, but now I hike every weekend."

## Tips

- **used to** — 仅用于过去，没有现在时形式；不要与 be used to（习惯于）混淆，后者接动名词。
- **swept** — sweep 的过去式和过去分词，同族变化还有 sleep → slept, keep → kept, weep → wept。
- **fewer** — 修饰可数名词复数（fewer books），less 修饰不可数名词（less water），这是常见考试陷阱。
- **accountant** — 来自 account（账目）+ -ant（人），注意双 c 和双 t 的拼写。
- **stream** — 指小溪、溪流，比 river 小；也可比喻为"一连串"，如 a stream of complaints。
- **however** — 比 but 更正式，常用于书面语；放在句中时前后需加逗号。
- **inch** — 英寸，约 2.54 厘米；口语中 "every inch" 表示"完完全全"，如 "He's every inch a gentleman."
