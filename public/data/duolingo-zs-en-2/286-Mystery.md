# Unit 286: Mystery

> Mystery: Debate theories about pyramids

## 单词

alien, archeologist, classified, coincidence, conclusion, convinced, couldn't, for the sake of argument, galaxy, have been, if so, if we assume, improbable, let's say, pyramids, ruins, skeptical, solar system, spaceship, suppose, theory, ufo, wonder, wouldn't

## 单元讲解

本单元围绕"未解之谜的讨论"展开，典型场景是朋友间辩论金字塔是否由外星人建造。话题虽轻松，但训练的是假设推理和表达怀疑/信服的语言能力。

语法核心是假设与推测的表达链：suppose / let's say / if we assume 用于提出假设前提，if so 承接上文假设推出结论，couldn't / wouldn't 表达"不可能/不会"的推断。have been 暗示"也许早就……"的完成时推测。

词汇分三组：学术与证据（archeologist, theory, conclusion, classified, ruins）、怀疑与信服（skeptical, convinced, improbable, coincidence, wonder）、科幻元素（alien, ufo, spaceship, galaxy, solar system, pyramids）。

学完本单元，你能用英语提出假设、表达怀疑或信服，并进行一场有趣的"阴谋论"式讨论。

## Tips

- **for the sake of argument** — "为了讨论方便起见"，表示暂时接受某前提并不代表自己认同
- **skeptical vs convinced** — 一对反义：skeptical 是"持怀疑态度"，convinced 是"深信不疑"
- **improbable** — 比 unlikely 更正式，强调"概率极低"；impossible 是完全不可能，improbable 留有余地
- **let's say** — 口语中引出假设的轻松说法，等于 suppose；如 Let's say aliens did build them, then what?
- **classified** — "机密的"，常指政府或军方文件；与 secret 相比更正式、更有制度色彩
- **coincidence** — "巧合"，常用 What a coincidence! 感叹；注意拼写中 -ci- 的发音 /kəʊˈɪnsɪdəns/
- **if so** — 承接前文假设的简略表达，避免重复整个 if 从句；反义为 if not
