# Unit 209: Good taste

> Good taste: Share opinions about movies

## 单词

circus, comic, decide, direct, dislike, display, divorce, drama, entertainment, folk, generally, get used to, hadn't, if, if you had, if you'd, marvelous, public, rare, real, realistic, trend, would have, would've

## 单元讲解

本单元围绕影视与娱乐品味展开，场景多发生在讨论电影类型、评价作品或表达个人喜好时，比如聊喜剧、马戏、民间艺术或某部新上映的影片。语法重点是 if 引导的虚拟条件句与 would have done 的搭配，用来谈论与过去事实相反的假设，例如 If you had seen it, you would've loved it. 词汇可分为三类：娱乐类型与作品（circus、comic、drama、folk、entertainment、display）、评价与判断（marvelous、realistic、real、rare、dislike、decide、generally、trend），以及虚拟结构标志（if、if you had、if you'd、would have、would've、hadn't）。学完本单元，你能评价影视与艺术作品，并用虚拟语气讨论"如果看过会怎样"。

## Tips

- **would've** — would have 的口语缩略，虚拟语气中表"本会……"，写作正式文体仍用完整形式。
- **if you'd** — if you had 的缩略，引导与过去相反的虚拟条件，注意与 if you would 区分。
- **realistic** — 形容词，表示"逼真的、现实的"，与 real（真实的）和 realistic 的"写实风格"含义有别。
- **comic** — 既可指漫画，也可指喜剧演员；与 comedy（喜剧体裁）区分使用。
- **folk** — 指民间的、民俗的，如 folk music 民谣、folk art 民间艺术。
- **marvelous** — 极好的，来自 marvel（奇迹），语气比 wonderful 更强烈、略带文学色彩。
- **trend** — 趋势、潮流，常说 follow/set a trend，与 fashion（时尚）近义但更广泛。
- **get used to** — 后接名词或 -ing 表逐渐习惯，与 used to do（过去常做）结构不同，注意区分。
