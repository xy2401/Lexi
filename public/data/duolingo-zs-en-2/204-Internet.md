# Unit 204: Internet

> Internet: Compare old and new technology

## 单词

browser, device, frequent, get used to, giant, graphics, install, key, locate, log out of, microphone, once a, press, restart, robot, server, switch, take a look, used to, user, webcam

## 单元讲解

本单元聚焦科技与互联网，场景多发生在比较新旧技术、说明设备操作或谈论使用习惯时，比如安装软件、登录登出、重启设备等。语法重点是 used to 与 get used to 的区分：used to do 表示过去常做现在不再做，get used to (doing) 表示逐渐习惯某事，例如 I used to use a desktop, but I'm getting used to this tablet. 词汇可分为三类：硬件与外设（device、webcam、microphone、server、robot）、软件操作（browser、install、log out of、restart、press、switch、locate），以及频率与习惯表达（frequent、once a、get used to、used to、user）。学完本单元，你能描述科技变迁并指导他人完成基本的设备与软件操作。

## Tips

- **used to / get used to** — used to 后接动词原形表过去习惯；be/get used to 后接名词或 -ing 表习惯成自然，切勿混淆。
- **browser** — 浏览网页的程序，来自动词 browse（浏览、随意翻看），常见搭配 default browser。
- **install** — 安装软件，与 uninstall 相对；注意双写 l，名词 installation。
- **log out of** — 退出登录，反义为 log in to；口语中也说 sign out / sign in。
- **restart** — re- 前缀表"重新"，restart 即重新启动；与 start over（从头再来）略有不同。
- **frequent** — 作形容词读 /ˈfriːkwənt/，作动词"常去某地"时重音后移读 /friˈkwent/。
- **webcam** — web + camera 的合成词，指网络摄像头，视频会议常用。
- **locate** — 强调找到具体位置，与 find（找到结果）和 search（搜寻过程）区分使用。
