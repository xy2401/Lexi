# Unit 283: Outdoors 2

> Outdoors: Suggest outdoor activities

## 单词

assuming that, attempt, attempt to, be able to, canyon, conditions, daylight, dehydrated, enough to, gear, how about we, leopard, overdo it, picturesque, poisonous, provided, rafting, safari, so long as, summit, too, trail, trekking, try to, wild

## 单元讲解

本单元的场景是朋友之间商量户外活动计划——徒步、漂流、Safari 等。对话中需要提出建议、评估条件、提醒风险。

语法重点是条件与假设表达的多样化：assuming that、provided、so long as 都可以替代 if 来引出前提条件，但语域和侧重点不同。此外，enough to 和 too...to 结构用于评估能力与限度，如 Is the daylight long enough to finish the trail?

词汇可分为三类：活动与地形（rafting, trekking, safari, canyon, summit, trail）、安全与条件（dehydrated, poisonous, conditions, gear, wild, leopard）、以及建议与尝试（how about we, attempt to, try to, overdo it）。三组词串联起来就是一段完整的户外计划讨论。

学完本单元，你能用英语提议户外活动、讨论可行性条件并给出安全提醒。

## Tips

- **provided** — 作连词时等于 on the condition that，比 if 更强调"只有满足此条件才行"
- **so long as** — 与 as long as 同义，但 so long as 在口语中更常见，语气稍随意
- **overdo it** — "做过头、逞强"，户外语境下常指运动量超出体力，如 Don't overdo it on the first day
- **picturesque** — 源自 picture + -esque（……风格的），形容风景"如画般美丽"
- **dehydrated** — de-（去除）+ hydrate（水合），即"脱水的"；户外活动中比 thirsty 严重得多
- **attempt to vs try to** — attempt 更正式且暗示难度较大，try 更日常；attempt 还可作名词（make an attempt）
- **gear** — 不可数名词，指"装备"的总称；不能说 a gear 或 gears（除非指齿轮）
