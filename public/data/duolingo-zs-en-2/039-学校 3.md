# Unit 039: 学校 3

> 使用形容词的比较级

## 单词

class, classroom, course, courses, desk, dictionary, down, how, in the classroom, learn, more difficult, more interesting, of, oldest, on, paint, paper, pass, pencil, picture, short, shortest, small, smaller, smallest, stop, subject, take a test, tallest, test, the, youngest

## 单元讲解

本单元以学校生活为背景，话题涉及教室里的物品（desk, pencil, dictionary）、课程内容（subject, course）和考试（take a test, pass）。你将学会用比较级和最高级描述学校中的人与物。

语法核心是形容词的三个等级：原级 → 比较级（-er / more）→ 最高级（-est / most）。本单元集中出现最高级形式：oldest, youngest, tallest, shortest, smallest，以及多音节比较级 more difficult, more interesting。最高级前必须加 the。

词汇分三组：教室物品（desk, pencil, paper, dictionary, picture, paint）、课程与考试（class, course, subject, test, take a test, pass, learn）、形容词等级（small/smaller/smallest, short/shorter/shortest, old/oldest, young/youngest, tall/tallest）。down, on, in the classroom 提供方位表达。

学完本单元，你能用比较级和最高级谈论学校生活，比如"这是最难的科目""她是最年轻的学生"。

## Tips

- **最高级 + the** — 最高级前必须加定冠词 the：the tallest, the youngest。漏掉 the 是最常见的语法错误。
- **more difficult / more interesting** — 三音节及以上形容词用 more 构成比较级，不能加 -er（不说 difficulter）。
- **take a test** — "参加考试"用 take（美式）或 sit（英式）；pass a test 是通过，fail a test 是没通过。
- **course / class / subject** — course 指一门完整课程，class 可指一节课或一个班级，subject 指学科（如 math, English）。
- **dictionary** — 注意拼写：diction + ary；复数把 y 变 i 加 es → dictionaries。
- **smallest / shortest** — 单音节形容词直接加 -est；以 e 结尾的只加 -st（如 tallest 而非 talleest）。
- **pass** — 既可指"通过考试"也可指"传递物品"（Pass me the pencil），一词多义需看语境。
