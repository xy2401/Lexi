# Unit 019: 旅行

> 介绍地点

## 单词

airport, bathroom, bus, closed, first name, go, here, hotel, in, last, last name, late, need to, over, over there, pass, passport, plane, port, right, right here, station, subway, taxi, the, ticket, ticket office, to, train, what is, where is

## 单元讲解

本单元围绕旅行与出行展开，涉及交通方式、场所和方位指引。语法重点是 where is...? 询问地点，以及 need to 后接动词原形表示“需要做某事”。还会接触 over there、right here 等方位短语和 first name / last name 的姓名结构。

词汇可分三组：交通工具类（bus、plane、train、taxi、subway），场所类（airport、hotel、station、port、bathroom、ticket office），以及方位与证件类（here、over there、right、in、to、passport、ticket、first name、last name）。注意 first name 是名，last name 是姓，与中文顺序相反。

学完本单元，你能够在旅途中问路、说明地点并办理基本的出行手续。

## Tips

- **where is** — 询问“……在哪里”，后接单数名词，如 Where is the station?。
- **need to** — 表示“需要做某事”，to 后接动词原形，如 I need to buy a ticket。
- **first name / last name** — first name 是名，last name 是姓；西方姓名顺序与中文相反。
- **over there** — 意为“在那边”，用于指明较远的地点。
- **right here** — right 在此加强语气，表示“就在这里”，强调位置精确。
- **passport** — 护照，由 pass（通过）+ port（港口）构成，本义是“通行港口的证件”。
- **closed** — 形容词“关闭的”，与 open（营业的、开着的）相对。
