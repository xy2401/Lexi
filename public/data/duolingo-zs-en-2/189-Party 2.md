# Unit 189: Party 2

> Party: Plan a party with friends

## 单词

accent, bunch, can, can't, charming, clean up, come in, could, couldn't, doing, gorgeous, like, lyrics, mustache, right, set up, should, shouldn't, well-dressed, whose, will, won't

## 单元讲解

本单元围绕"与朋友策划派对"展开，涉及布置场地、邀请客人、讨论着装和音乐等细节。你将学会用英语协商安排、分配任务并表达期待。

语法重点是情态动词 can / could / should / will 及其否定形式在建议和安排中的运用。"Should we set up the decorations?" "You shouldn't forget the music." 这类句型是策划讨论的核心。whose 引导的所有格疑问句用于确认物品归属。

词汇可分为：派对准备类（set up, clean up, come in, bunch）、外貌与着装类（gorgeous, charming, well-dressed, mustache, accent）、情态与功能类（can, can't, could, couldn't, should, shouldn't, will, won't, whose）。歌词 lyrics 和 doing 则服务于派对中的娱乐话题。

学完本单元，你能用英语与朋友协商派对细节、分配准备工作，并在聚会中自然地闲聊和赞美他人。

## Tips

- **set up** — 指"搭建、布置"，如 set up tables / set up speakers；区别于 set off（出发）和 set aside（留出）。
- **whose** — 所有格疑问代词，问"谁的"；注意与 who's（who is 的缩写）区分，书写时不可混淆。
- **gorgeous** — 比 beautiful 语气更强烈，含"华丽、惊艳"之意；口语中常用来夸人外貌或赞叹事物。
- **bunch** — a bunch of 意为"一群、一堆"，口语中替代 a group of 或 a lot of；a bunch of friends = 一群朋友。
- **well-dressed** — 复合形容词，由副词 well + 过去分词 dressed 构成；类似结构有 well-known, well-behaved。
- **lyrics** — 指"歌词"，通常用复数形式；单数 lyric 指"抒情诗"。注意与 music（曲）搭配：lyrics and music。
- **charming** — 来自 charm（魅力），-ing 形容词描述"令人着迷的"；比 nice 更文雅，常用于社交赞美。
