# Unit 089: 高中

> 分享高中学习经历

## 单词

Harvard, already, diploma, fail, failed, geography, got, grade, graduate, happy for, hasn't, haven't, mistake, once, pass, passed, pleased, prepare, prepared, principal, question, report card, score, semester, studies, taken, twice, understand, well-known, worried, yet

## 单元讲解

本单元以高中学习生活为背景：考试（pass、fail、score、grade）、成绩（report card、diploma）、学业进程（graduate、semester、studies）以及情感反应（worried、pleased、happy for）。场景贴近学生日常，也适用于回忆往事。

语法核心是现在完成时（hasn't、haven't、already、yet）与一般过去时（failed、passed、got、taken）的对比。already 用于肯定句表示"已经"，yet 用于否定句和疑问句表示"还没有"。once、twice 是频率副词，修饰经历次数。

词汇可分为三组：学业评价（grade、score、pass、fail、report card、diploma）、学校人物与制度（principal、semester、graduate、Harvard）、情感态度（worried、pleased、happy for、mistake）。

学完本单元，你能用英语谈论自己的学业经历：考得如何、是否毕业、对成绩的感受。

## Tips

- **already / yet** — already 用于肯定句（I've already passed）；yet 用于否定句和疑问句（I haven't passed yet）。位置：already 在 have 后或句末，yet 在句末。
- **diploma** — 指毕业证书或文凭；与 degree（学位）不同，diploma 侧重那张纸质证书。
- **report card** — 成绩单，美式用法；英式常说 school report。card 在此不是"卡片"而是"记录表"。
- **graduate** — 动词"毕业"，搭配 graduate from：She graduated from Harvard；名词形式 graduation。
- **fail / pass** — 一对反义词；fail an exam（不及格）、pass an exam（通过）；也可作名词 a pass / a fail。
- **well-known** — 复合形容词，意为"著名的"，等同于 famous；注意连字符不可省略，否则语法错误。
- **principal** — 指学校"校长"；与 principle（原则）拼写相近但含义完全不同，是常见混淆点。
