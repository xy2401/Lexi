# Unit 128: Memories

> Memories: Share stories about childhood

## 单词

bug, card, caught, childhood, come over, dirt, do, frog, frying pan, hide, joke, kicked, knee, neighborhood, never used to, now, pie, shy, spinach, stay, strict, trumpet, up, used to

## 单元讲解

本单元以回忆童年为主题，场景包括在邻居院子里玩耍、捉青蛙、被严格的家长管教等。你会学到如何用 used to 讲述过去的习惯和状态，与现在形成对比。

语法核心是 used to + 动词原形，表示"过去常常做但现在已经不做"的事。否定形式 never used to 比 didn't use to 更强调"从来没有过"。注意 used to 只用于过去，不能描述现在的习惯。

词汇充满童年画面：户外玩耍（bug, frog, dirt, hide, kicked, knee, neighborhood）、家庭食物（pie, spinach, frying pan）、性格与管教（shy, strict, joke, card, trumpet）。这些词共同勾勒出一幅怀旧的生活图景。

学完本单元，你能用英语讲述童年趣事、描述过去的习惯，并表达对往昔的怀念。

## Tips

- **used to** — 只表过去习惯，不与 now 的习惯混淆；疑问句为 Did you use to...?（注意没有 d）。
- **never used to** — 强调"过去从不"，如 I never used to like spinach, but now I love it.
- **caught** — catch 的过去式和过去分词；注意 -aught 拼写模式，类似 taught（teach 的过去式）。
- **come over** — 口语中意为"来我家/过来玩"，比 visit 更随意：Why don't you come over after school?
- **strict** — 搭配 be strict with someone / be strict about something；不要说 strict to。
- **frying pan** — 复合名词，frying 是动名词作定语；口语中常简称 pan。
- **neighborhood** — 美式拼写，英式为 neighbourhood（多一个 u）；指"街坊、社区"而非城市。
