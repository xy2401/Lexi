# Unit 281: Old Friend

> Old Friend: Catch up with someone

## 单词

all grown up, any, back in town, can't complain, catch you up on, compliment, design, expecting, forties, get, get used to, going, how long has it been, how's, it's been, kindergarten, liking, loving, on the whole, overall, overseas, promise to, run into, so far, things

## 单元讲解

本单元围绕"与老朋友重逢叙旧"这一场景展开。你可能在街上 run into 一位多年未见的老同学，需要寒暄、交换近况、感叹时光飞逝。

语法上，本单元大量使用现在完成时来表达"从过去持续到现在"的状态，如 How long has it been? 和 It's been years。同时涉及 used to 与 get used to 的对比：前者表示过去的习惯，后者强调"逐渐适应"的过程。

词汇可分为三组：重逢寒暄用语（how's, can't complain, so far）、人生阶段描述（forties, kindergarten, expecting, all grown up）、以及评价与总结表达（on the whole, overall, things）。这些词共同构建出一段完整的叙旧对话。

学完本单元，你能用地道的英语与老友打招呼、聊近况、感叹变化，并自然地结束对话。

## Tips

- **run into** — 偶遇，比 meet by chance 更口语化；注意不要与"跑进某处"的字面义混淆
- **catch you up on** — "给你补一下近况"，catch up 本身有"赶上进度"之意，加 on 后接具体话题
- **get used to** — 强调"变得习惯"的动态过程，后接名词或动名词；区别于 used to do（过去常常）
- **can't complain** — 老式寒暄回应，意为"还不错，没啥好抱怨的"，语气比 I'm fine 更随意
- **expecting** — 委婉表达"怀孕了"，完整说法是 expecting a baby；直接说 pregnant 在某些场合显得突兀
- **on the whole** — 与 overall 近义，都表示"总体来说"，但 on the whole 更偏英式口语
- **all grown up** — 感叹孩子"都长这么大了"，常带感慨语气，如 Look at you, all grown up!
