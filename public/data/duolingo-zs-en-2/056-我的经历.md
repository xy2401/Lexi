# Unit 056: 我的经历

> 使用现在完成时

## 单词

always, been, been to, for, for a long time, has, have, lived, loved, never, same, showed, so, stayed, the same, traveled, wanted, worked

## 单元讲解

本单元引入现在完成时（have/has + 过去分词），用来谈论人生经历和从过去持续到现在的状态。典型场景如 "I have been to Japan" 或 "She has lived here for a long time"。

语法核心是 have / has 作助动词 + 过去分词构成现在完成时。been to 表示"去过（已回来）"，for 引导时间段表示持续。never 和 always 是常见的时间副词，放在 have 和过去分词之间。

词汇高度集中在过去分词形式：been, lived, loved, stayed, traveled, wanted, worked, showed。功能词包括 has, have, never, always, for, so, the same。学完本单元，你能用现在完成时谈论自己去过哪里、做过什么、某状态持续了多久。

## Tips

- **been to** — 表示"去过某地（已返回）"，区别于 gone to（去了还没回）；Have you been to Paris?
- **for a long time** — for + 时间段是现在完成时的标志搭配，表示动作或状态持续至今
- **never** — 放在 have/has 之后、过去分词之前：I have never traveled abroad
- **has / have** — has 用于 he/she/it，have 用于 I/you/we/they；这里是助动词不是"拥有"
- **the same** — 固定短语"相同的"，常与 stay / remain 搭配：Everything stayed the same
- **showed** — show 的过去分词也可写作 shown，showed 作过去式更常见，shown 作分词更正式
- **so** — 此处作副词"如此、这么"，如 I have wanted to go for so long
