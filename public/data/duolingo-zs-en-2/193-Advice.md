# Unit 193: Advice

> Advice: Imagine being in charge

## 单词

athletic, clap, curriculum, dangerously, fancy, foreigner, goalkeeper, if he were, if she were, if they were, if we were, if you were, lonely, mean, obviously, permission, permit, position, route, second-hand, style, that reminds me

## 单元讲解

本单元围绕"提建议、设想自己当家做主"展开：如果你来负责，会怎么做？话题涉及课程、运动位置、许可与规则等管理情境。语法核心是虚拟语气中的 if 条件句——if I/he/she/they/we/you were 用 were 表示与现在事实相反的假设，常与 would 搭配，如 If I were you, I'd change the route.

词汇可分组理解：身份与角色（foreigner、goalkeeper、athletic）、规则与许可（permission、permit）、抽象名词（curriculum、position、route、style）以及描述性形容词副词（fancy、lonely、mean、obviously、dangerously、second-hand）。注意 permission 是名词，permit 多作动词或正式许可证。学完本单元，你能用虚拟语气提出假设性建议，并谈论规则与角色安排。

## Tips

- **if I were** — 虚拟语气中 be 动词一律用 were，不用 was；这是与真实条件句的关键区别。
- **permission / permit** — permission 是不可数名词（ask permission），permit 多作动词或指书面许可证，词性不同。
- **goalkeeper** — 守门员，由 goal + keeper 构成；同理 goalkeeper、shopkeeper 都是"做某事的人"。
- **curriculum** — 学校课程体系，复数为 curricula 或 curriculums，源自拉丁语"跑道"。
- **second-hand** — 二手的，也可写作 secondhand；与 brand-new（全新）相对。
- **obviously** — 副词，意为"显然"，由 obvious 加 ly 构成，常用于句首加强语气。
- **that reminds me** — 口语固定句，意为"这让我想起来"，用于自然引出相关话题。
- **mean** — 既可作动词"意思是、意味着"，也可作形容词"刻薄的"，需依语境判断。
