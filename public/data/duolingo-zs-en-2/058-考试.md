# Unit 058: 考试

> 谈论考试经历

## 单词

age, all, answer, art, blackboard, board, did, do, don't worry, eraser, example, forgot, forgot to, how long, late, lesson, listening, math, on, page, reading, right, speaking, take, to, took, very well, well, word, worry, writing, wrong

## 单元讲解

本单元围绕"考试"场景展开，你将学会谈论考试科目、考试中的表现以及考后感受。例如 "I forgot to write my name" 或 "The listening part was very difficult"。

语法重点包括：forgot / forgot to 的用法区别，how long 引导的时间疑问，以及 don't worry 等安慰性祈使句。take a test / took a test 是"参加考试"的固定搭配。

词汇按功能分组：考试科目与技能（math, art, listening, reading, speaking, writing）、考试物品（blackboard, eraser, page, word, example）、情感与评价（don't worry, right, wrong, well, very well, late, worry）。学完本单元，你能用英语描述一次考试经历，包括准备、过程和结果。

## Tips

- **forgot to** — forget to do 表示"忘记要去做"（没做），forget doing 表示"忘记做过"（做了但忘了）
- **took** — take 的过去式，take a test / take an exam 是"参加考试"，不说 do a test（英式可用）
- **don't worry** — 祈使句安慰他人，worry 后常接 about：Don't worry about the exam
- **listening / reading / speaking / writing** — 四项语言技能，-ing 形式在此作名词/形容词使用
- **blackboard** — 黑板，现代教室多用 whiteboard（白板）；board 单独使用可指任何"板"
- **how long** — 问时间长度，How long did the test take? 回答用 for + 时间段
- **example** — 固定搭配 for example（例如），缩写 e.g. 来自拉丁语 exempli gratia
