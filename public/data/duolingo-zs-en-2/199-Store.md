# Unit 199: Store

> Store: Request help with returns

## 单词

bra, button, collar, damaged, diamond, exchange, label, money back, off, pattern, replace, return, silk, stain, still, store credit, stripe, thick, would, wouldn't

## 单元讲解

本单元聚焦购物售后的退换场景：退货、换货、退款、商店抵用券，以及衣物上的瑕疵——污渍、破损、纽扣、领口。话题是向店员说明问题并提出诉求。语法重点是 would / wouldn't 的礼貌用法，用于委婉提出请求或表达意愿，如 Would you exchange this for me?，比直接说要更得体。

词汇可分三组：退换流程（return、exchange、replace、refund 概念如 money back、store credit、label）、衣物部位（bra、button、collar）以及材质与瑕疵（silk、diamond、stripe、pattern、stain、damaged、thick）。注意 store credit 是"商店抵用券"而非现金退款；stain 指污渍，damaged 指破损。学完本单元，你能用英语说明商品问题，并礼貌地要求退货、换货或退款。

## Tips

- **store credit** — 商店抵用券，退款以店内消费额度形式给出，而非现金；退货时常见选项。
- **money back** — 现金退款，与 store credit 相对；money-back guarantee 即退款保证。
- **exchange / replace** — exchange 强调"以旧换新"的对调，replace 侧重"重新补一个"，方向略有不同。
- **stain** — 污渍，作名词也可作动词"弄脏"；与 spot（斑点）相比更指难以清除的污迹。
- **damaged** — 受损的、有破损的，形容词；描述商品瑕疵时比 broken 适用范围更广。
- **label** — 标签，衣物上常含洗涤说明与材质；退货时通常要求 label 仍在。
- **silk** — 丝绸，不可数名词；由蚕丝制成，常与 cotton、wool 等材质并列比较。
- **would / wouldn't** — 用于礼貌请求或假设意愿，比 will 更委婉客气，是售后沟通的得体表达。
