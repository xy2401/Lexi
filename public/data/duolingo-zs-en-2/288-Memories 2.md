# Unit 288: Memories 2

> Memories: Share childhood activities

## 单词

always used to, another thing, berries, blow bubbles, bubble gum, dodgeball, every so often, fond, good old days, hide and seek, jump rope, lollipop, nostalgic, recess, reminisce, scouts, slide, tag, tree house, used to, were always, would, would usually, yo-yo

## 单元讲解

本单元的场景是与朋友或家人回忆童年游戏和校园生活。话题轻松温馨，但语言上需要熟练运用"过去习惯性动作"的多种表达。

语法核心是 used to、would 和 were always doing 三种过去习惯表达的对比：used to 强调"过去如此，现在不再"；would 用于回忆具体反复发生的动作（不用于状态）；were always doing 带有感情色彩，常暗示"老是……"。

词汇可分为三组：童年游戏（hide and seek, tag, dodgeball, jump rope, blow bubbles, yo-yo, slide）、零食与物件（berries, bubble gum, lollipop, tree house）、怀念与回忆（nostalgic, reminisce, fond, good old days, recess, scouts）。

学完本单元，你能用英语生动地讲述童年趣事，区分不同"过去习惯"句式的语感差异。

## Tips

- **reminisce** — 来自拉丁语 reminisci（回忆），指"沉浸在过去的美好回忆中"，比 remember 更有感情温度
- **would vs used to** — would 只能用于动作（would play），不能用于状态；状态动词只能用 used to（used to live）
- **nostalgic** — 形容词，"怀旧的"；名词 nostalgia 原指"思乡病"（希腊语 nostos 回家 + algos 痛苦）
- **tag** — 儿童游戏"抓人/捉迷藏"的一种，被拍到的人变成追逐者；也指"标签"
- **recess** — 美式英语中特指学校课间休息时间；英式更常说 break time
- **every so often** — "时不时、偶尔"，比 sometimes 更强调间隔不规律
- **fond** — 常用于 be fond of（喜爱）或 fond memories（美好回忆），语气温暖而克制
