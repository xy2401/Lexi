# Unit 144: Marriage

> Marriage: Ask about wedding details

## 单词

anniversary, did, event, has, hasn't, have, haven't, honeymoon, in a relationship, incredible, lately, more often, nice and, peaceful, rarely, set, than, tradition, typical, van, wave

## 单元讲解

本单元围绕婚姻与亲密关系展开，场景包括询问婚礼细节、讨论恋爱状态、描述婚后生活节奏。你会用到 in a relationship 描述恋爱中，用 honeymoon 谈蜜月，用 anniversary 纪念结婚周年。

语法重点是现在完成时的肯定与否定（has/hasn't, have/haven't），用来谈论从过去延续到现在的经历或状态，例如 "They haven't set a date yet." 同时，频率副词 rarely、more often、lately 与完成时搭配，描述生活节奏的变化。

词汇可分为三组：关系与仪式（in a relationship, honeymoon, anniversary, tradition, event）、频率与比较（rarely, more often, lately, than）、描述性形容词（incredible, peaceful, typical, nice and）。nice and + 形容词是口语中加强语气的结构，意为"非常、恰到好处地"。

学完本单元，你能用英语询问和描述恋爱关系、婚礼安排以及婚后生活的变化。

## Tips

- **honeymoon** — 由 honey + moon 组成。最古老的解释是：新婚第一个月（moon 即 month，月亮的一个周期）甜蜜如蜜。另一种说法来自巴比伦习俗——新娘父亲在新婚一个月内每天供给女婿蜂蜜酒（mead）。无论哪种，moon 在此不是"月亮"而是"月份"，记录了 lunar calendar 时代的计时方式。
- **anniversary** — 来自拉丁语 anniversarius，由 annus（年）+ versus（转）构成，字面意思"每年转回来一次"。古罗马人用这个词标记任何年度纪念日。同根词有 annual（年度的）和 millennium（千年，mille 千 + annus 年）。
- **tradition** — 来自拉丁语 traditio（交付、传递），由 trans-（跨越）+ dare（给予）构成。传统本质上是"从一代人手中交到下一代人手中的东西"。同根词有 trade（贸易，即"交换"）和 traitor（叛徒，即"把东西交出去的人"）——背叛就是"把本该守护的东西交给了敌人"。
- **incredible** — 来自拉丁语 incredibilis，由 in-（不）+ credere（相信）构成。credere 是拉丁语中"信任"的核心动词，同根词有 credit（信用）、creed（信条）和 credential（证书）。incredible 从"不可信的"演变为口语中的"太棒了"，语义从否定滑向了极致的肯定。
- **peaceful** — peace 来自拉丁语 pax（和平），经古法语 pais 进入英语。pax 在罗马神话中是一位女神的名字，她的祭坛（Ara Pacis）至今矗立在罗马。从"没有战争"到"内心宁静"（a peaceful evening），这个词的语义从政治领域扩展到了个人感受。
- **typical** — 来自希腊语 typos（印记、模型），原指印章在蜡上留下的印痕。从"符合某个模型/类型"到"典型的、有代表性的"，typical 保留了"像模子刻出来一样"的意象。同根词有 type（类型）和 prototype（原型，proto- 第一 + type 模型）。
- **van** — 是 caravan 的缩写，caravan 来自波斯语 kārwān（商队）。17世纪英语中 caravan 指沙漠中结伴旅行的商队，后来指大型有篷马车，再后来缩成 van 指厢式货车。从波斯沙漠到英国公路，一个词走了一千年的路。
