# Unit 072: 工作 4

> 在工作场合向人求助

## 单词

anybody, ask for, broken, business, by, complete, could, customer, daily, discuss, discussion, email, everybody, good job, help, help with, how, hurry, machine, meeting room, might, must, regular, several, sir, somebody, thing, to, try, unfortunately, weekly, with, work

## 单元讲解

本单元模拟职场中向同事或上级求助的场景：机器坏了需要帮忙、请人协助完成日常任务、在会议室讨论客户问题。核心语法是情态动词 could / might / must 表达请求、可能性和必要性，以及 help with / ask for 等动词短语搭配。

词汇可分为三组：请求与协助（could, help, help with, ask for, try）、工作场景（business, customer, meeting room, email, machine, work）、频率与程度（daily, weekly, regular, several, unfortunately）。注意 anybody / everybody / somebody 这组不定代词在疑问句和陈述句中的分布规律。

学完本单元，你能在职场中礼貌地请求帮助、描述设备故障，并用 must / might 判断事情的紧急程度。

## Tips

- **could** — can 的过去式，源自古英语 cūþe（知道、能够），与 can 共享原始日耳曼语 *kunnaną（知道如何做）。在请求语境中 could 比 can 更委婉，因为它用"过去时态"制造心理距离——仿佛给对方留出拒绝的余地。这种"时态后退表礼貌"是英语语用的核心策略。
- **unfortunately** — 由 un-（否定）+ fortunate（幸运的）+ -ly 构成。fortunate 来自拉丁语 fortuna（命运、运气），罗马神话中 Fortuna 是掌管命运的女神，她转动轮盘决定人的祸福。unfortunately 在商务邮件中几乎是"坏消息"的固定开场词，语气正式而克制。
- **discuss** — 来自拉丁语 discutere，由 dis-（分开）+ quatere（敲打）组成，字面意思"打散、抖开"。古罗马人用这个词形容"把问题抖开来看清楚"，后来演变为"讨论"。注意 discuss 后直接接宾语，不加 about——这是中文母语者最常犯的错误。
- **must** — 源自古英语 mōtan（被允许、必须），与德语 müssen 同源。有趣的是，古英语中 must 最初表示"被允许"，后来语义反转为"必须"。在现代英语中 must 语气强于 have to，暗示说话者本人的权威判断，而非外部规则。
- **customer** — 来自古法语 coustume（习惯），与 custom（习俗）同源。中世纪商家把"常来的人"称为 customer，即"习惯性光顾者"。拉丁语 consuetūdo（习惯）是更远的源头。英语中 client 偏专业服务关系，customer 偏商业买卖关系。
- **several** — 来自中世纪拉丁语 separālis（可分离的），经古法语进入英语，原意"各自分开的"。从"分开的"到"几个的"，语义经历了从"各自独立"到"数量有限但多于二"的滑动。在正式文体中 several 比 a few 更精确，通常暗示三到七个。
