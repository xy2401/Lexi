# Unit 193: Advice

> Advice: Imagine being in charge

## 单词

athletic, clap, curriculum, dangerously, fancy, foreigner, goalkeeper, if he were, if she were, if they were, if we were, if you were, lonely, mean, obviously, permission, permit, route, second-hand, style, that reminds me

## 单元讲解

本单元设定"假如你是管理者"的假设场景，让你练习用虚拟语气对他人提出建议和设想。话题涉及学校课程、运动、交通规则等日常领域，但核心是"如果换作你，会怎么做"。

语法核心是虚拟条件句 if + 主语 + were 结构（if he were, if she were, if you were 等），表达对非现实情况的假设。注意无论主语人称如何，be 动词一律用 were，这是虚拟语气最显著的形式标记。

词汇可分为三组：假设框架类（if he/she/they/we/you were, obviously, that reminds me）、制度与规则类（curriculum, permission, permit, route）和描述类（athletic, dangerously, fancy, lonely, second-hand, style）。虚拟语气赋予这些词一种"推演"的色彩——不是陈述事实，而是设想另一种可能。

学完本单元，你能用 if I were... 结构对管理、教育、生活等话题提出假设性建议。

## Tips

- **curriculum** — 直接借自拉丁语 curriculum，原意是"跑道"（来自 currere，奔跑）。古罗马战车竞赛中，curriculum 指战车必须跑完的那一圈赛道。教育领域借用此词，把学生比作赛道上的奔跑者——课程就是"你必须跑完的那段路"。复数形式为 curricula。
- **permission** — 来自拉丁语 permissio，由 per-（穿过）+ mittere（送出）构成，字面意思"让它通过"。古罗马官员在文件上写下 permittere，意思是"放行、准许通过"。permission 就是那张"通行证"——你被允许穿过某道门槛。同根词还有 mission（被派出的任务）和 missile（被投掷出去的东西）。
- **foreigner** — 来自古法语 forain（外部的），源自拉丁语 foranus，词根 foris（门外）。foreigner 的字面意义是"门外之人"——不属于这个家、这个城、这个国家的人。英语中 door 与 foris 共享原始印欧语词根 *dʰwer-，"门"的概念贯穿了"内"与"外"的全部想象。
- **goalkeeper** — 复合词，goal + keeper。goal 的词源有趣：可能来自古英语 gāl（障碍、边界），最初指赛马中的终点标记。keeper 来自 keep（守卫）。goalkeeper 就是"守卫终点标记的人"。这个位置在足球中被称为守门员，但在曲棍球和手球中同样存在——一切有"门"的运动都需要一个 keeper。
- **fancy** — 是 fantasy 的缩略形式，来自希腊语 phantasia（显现、想象），经由古法语 fantaisie 进入英语。最初 fancy 和 fantasy 意思完全相同，都指"脑中的幻象"。后来 fancy 语义缩小为"一时的喜好、花哨的装饰"，而 fantasy 保留了更宏大的"幻想"含义。a fancy restaurant 就是"装饰得如梦似幻的餐厅"。
- **obviously** — 来自拉丁语 obvius，由 ob-（对面）+ via（路）构成，字面意思"挡在路上的、迎面而来的"。一个 obviously 的事实，就像横在路中间的巨石——你不可能绕过它、忽视它。via（路）还贡献了 obvious 的兄弟词汇：deviate（偏离道路）、trivial（三条路交汇处，即琐碎的）。
- **permit** — 与 permission 同源，来自拉丁语 permittere（per- 穿过 + mittere 送出）。作为动词重音在第二音节 /pərˈmɪt/，作为名词（许可证）重音在第一音节 /ˈpɜːrmɪt/。这种重音区分词性的模式在英语中极为常见：record, present, conduct 都遵循同一规律。
- **lonely** — 由 lone + -ly 构成。lone 是 alone 的截短形式，alone 又来自 all + one（全然独自一人）。lonely 比 alone 多了一层情感色彩：alone 只是物理上的独处，lonely 则是心理上的孤寂。一个人可以 alone 而不 lonely，也可以身处人群却 deeply lonely。
