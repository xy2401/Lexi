# Unit 194: Ambition 2

> Ambition: Talk about finding a job

## 单词

advantage, babysit, baker, change, dream job, employment, face to face, had, hairdresser, hourly wage, if, if I, interview, make, one day, role, talent, tech, vet, wouldn't

## 单元讲解

本单元延续职业抱负话题，聚焦求职过程中的具体环节：面试、薪资、岗位角色。你将学会谈论理想工作、面试经历，以及对未来职业的设想。

语法重点是 if I 引导的条件句与 wouldn't 的搭配，表达对求职情境的假设性思考。had 在此单元中既可能是 have 的过去式，也可能出现在虚拟条件中（if I had...），需要结合语境判断。

词汇可分为三组：职业名称类（baker, hairdresser, vet, tech）、求职流程类（interview, employment, hourly wage, role, dream job）和条件假设类（if, if I, wouldn't, one day, advantage, talent）。三组词串联起来，构成一条从"设想"到"行动"的求职叙事线。

学完本单元，你能用英语讨论求职面试、比较不同职业的优劣，并表达自己的职业理想。

## Tips

- **interview** — 来自古法语 entrevue（会面），由 entre-（相互）+ voir（看）构成，字面意思"互相看一看"。拉丁语 videre（看）是其最终词源。求职面试的本质从未改变：雇主看你能否胜任，你看雇主是否值得托付。interview 与 view（视野）、television（远距离观看）共享同一词根。
- **wage** — 源自古法语 wage（报酬、赌注），与古日耳曼语 *wadi（ pledge, 抵押品）同源。中世纪雇工先得到一枚代币作为"抵押"，证明雇主承诺日后付款。wage 最初不是"工资"本身，而是"保证你会收到钱的那个信物"。今天 hourly wage 仍保留着"按时间兑现的承诺"这层含义。
- **vet** — 是 veterinarian 的口语缩略，源自拉丁语 veterinarius，词根 veterinae 指"驮畜"（与 vetus 老的 可能有关——老牲口需要更多照料）。在英国英语中 vet 也用作动词，意为"审查、审核"（vet a candidate），因为给动物做检查需要极其细致的观察。
- **baker** — 来自古英语 bæcere，词根 bacan（烘烤），与 back（背部）可能共享原始印欧语词根 *bhē-（温暖）。日耳曼人最早的"烤"是把面团贴在热石头上。baker 在中世纪城镇中是受严格监管的职业——面包重量不足会被公开惩罚，因为面包是穷人的主食。
- **talent** — 来自拉丁语 talentum，最初是一种重量/货币单位（约34公斤白银）。《圣经》马太福音中"才干的比喻"讲主人按 talent 分银子给仆人，后来 talent 从"一笔钱"演变为"天赋才能"——你被赋予的"资本"不再只是金银，而是能力本身。
- **employment** — 来自古法语 emploi（使用），源自拉丁语 implicare（卷入、缠绕），由 in- + plicare（折叠）构成。被 employ 就是被"卷入"一项工作中。同根词有 imply（暗示，把意思折叠进话语里）、complicate（使复杂，多次折叠）和 accomplice（同谋，被折叠在一起的人）。
- **advantage** — 来自古法语 avantage，由 avant（前面）派生，avant 源自拉丁语 abante（从前面来）。have an advantage 字面意思是"站在前面"——赛跑时领先一步。与 advance（前进）、adventure（即将发生的事）同源。求职中的 advantage 就是让你"站到别人前面"的那个条件。
- **hairdresser** — 复合词，hair + dresser。dress 来自古法语 dresser（整理、摆正），源自拉丁语 directiare（使直、使正）。dresser 最初指"整理物品的人"，后来专指整理仪容的人。hairdresser 就是"把头发摆正的人"。dress 从"使直"到"穿衣打扮"的语义跳跃，记录了人类对"整洁即正直"的古老联想。
