# Unit 202: Mistakes

> Mistakes: Express regret for a decision

## 单词

act, argument, be able to, common sense, control, disappoint, drawn, drunk, guilty, had, hadn't, if, loud, lucky, mistaken, promise, selfish, stupid, warn, would, would have had, wouldn't have

## 单元讲解

本单元围绕"为某个决定感到后悔"展开，是典型的反思与道歉场景：你回想当初的争吵、冲动或自私，承认自己错了。语法核心是虚拟语气对过去的假设——would have had / wouldn't have，配合 if 引导的条件句，表达"如果当时……就不会……"。词汇可分三组：情绪与品性评价（guilty、selfish、stupid、lucky），行为与后果（act、argument、disappoint、warn、promise），以及能力与状态（be able to、control、drunk、drawn）。这些词共同构成"复盘一次失误"的语义网。学完本单元，你能用虚拟语气坦诚地表达对过往决定的懊悔与反思。

## Tips

- **guilty** — 源自古英语 gyltig，由 gylt（罪行、债务）派生，最初与"欠下的债"紧密相连。在日耳曼法里，犯罪被视为对社会欠下的债，因此"有罪"和"负债"共享同一逻辑。今天 guilty 既指法律上的有罪，也指内心的愧疚——那份"亏欠感"千年未变。
- **selfish** — 由 self + -ish 构成，17 世纪才进入英语，是较晚的造词。它把"自我"标记为一种过度的、令人不悦的状态，与 selfless 形成道德两极。词缀 -ish 带有"略带、趋于"的贬义色彩，暗示这种自我已越界。
- **disappoint** — 来自古法语 desapointer，字面是"从职位上撤下"（dis- + appointer 任命）。原本指被免去官职的失落，后泛化为一切"期望落空"。被任命又被撤销，那种从高处跌下的画面，正是失望最原始的隐喻。
- **warn** — 源自古英语 warnian，与 wehr（防御、警惕）同源，德语 wehren（抵抗）是它的远亲。它的本意是"让人提前戒备危险"，所以 warn 总带着"危险尚未发生"的时间感，与单纯告知不同。
- **drunk** — 是 drink 的过去分词，源自古英语 druncen。它从"喝下的动作完成"演变为"醉酒的状态"，记录了酒精如何从行为变成身份标签。同源词在德语是 trunken，保留了更文雅的"微醺"诗意。
- **common sense** — 直译"共同的感知"，借自拉丁语 sensus communis，原指亚里士多德所说的统合五感的"共通感"。中世纪经院哲学把它世俗化为"人皆有之的常识"，于是哲学概念落地为日常判断力的代名词。
- **argument** — 来自拉丁语 argumentum，由 arguere（使清楚、证明）派生，最初指"证据、论点"。它先指逻辑上的论证，后才偏向"争吵"——从摆事实讲道理，滑向情绪对抗，词义里藏着理性向火药味的退化。
- **promise** — 来自拉丁语 promittere，pro-（向前）+ mittere（送出），字面是"把话送出去"。古罗马人视承诺为一种预先交付的抵押，话一旦送出便有了约束力。mission（派遣）与它共享 mittere 词根。
