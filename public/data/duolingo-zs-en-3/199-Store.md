# Unit 199: Store

> Store: Request help with returns

## 单词

bra, button, collar, damaged, diamond, exchange, label, money back, off, pattern, replace, return, silk, stain, still, store credit, stripe, thick, would, wouldn't

## 单元讲解

本单元设定在服装店或百货商店的退换货柜台，你将学会描述商品问题（污渍、破损）、请求退款或换货，以及讨论面料和图案细节。

语法重点是 would / wouldn't 在礼貌请求中的用法（Would you exchange this?），以及被动含义的表达（damaged 表示"被损坏的"状态）。store credit 和 money back 代表两种不同的退款方式，是购物英语中的关键区分。

词汇可分为三组：服装细节类（bra, button, collar, silk, stripe, pattern, thick）、商品问题类（damaged, stain, label, off）和退换流程类（exchange, return, replace, money back, store credit, would, wouldn't）。三组词串联起一次完整的退换货对话：指出问题、说明诉求、协商解决方案。

学完本单元，你能用英语在商店柜台描述商品缺陷、要求退换货，并理解不同的退款政策。

## Tips

- **collar** — 来自拉丁语 collare（项圈），词根 collum（脖子）。古罗马的 collare 是奴隶或狗佩戴的金属颈环。中世纪后 collar 演变为衣服的领子——从"束缚脖子的铁环"到"装饰脖子的布条"，语义的软化记录了人身自由的获得。今天 white-collar（白领）和 blue-collar（蓝领）仍用"领子"标记社会身份。
- **silk** — 源自古英语 seolc，借自拉丁语 sericum，而 sericum 来自希腊语 Σηρικός（Seres 的），Seres 是古希腊人对"丝国人"（中国人）的称呼。丝绸之路的贸易让这个词从东亚一路传到西欧。英语 silk、拉丁语 sericum、希腊语 Seres，都指向同一个源头：古代中国养蚕织丝的文明。
- **diamond** — 来自古法语 diamant，源自拉丁语 adamas（不可征服的），由 a-（不）+ daman（驯服）构成。古希腊人认为钻石是众神的眼泪或天上掉落的星辰碎片，其硬度"不可被任何力量驯服"。adamas 也是 adamant（坚定不移的）的词源——钻石和坚定共享"不可征服"这一核心意象。
- **stain** — 源自古法语 esteindre（使褪色、弄脏），与拉丁语 exstinguere（熄灭）有关。stain 的原始意象是"熄灭颜色"——一块污渍让织物的色彩"死掉"。与 extinguish（熄灭）同源。一个 stain 不只是脏，而是"那个位置的颜色被杀死了"。
- **label** — 来自古法语 label（布条、飘带），可能与日耳曼语 *lappa（布片）有关。中世纪纹章学中，label 是盾牌上的一条横带，用来区分家族分支。后来 label 变为"贴在物品上标明信息的纸条"。今天 label 还有"给人贴标签"的比喻义——你给别人一个 label，就像在纹章上画一条横带，把他归入某个类别。
- **exchange** — 来自古法语 eschangier，由 es-（出）+ changier（改变）构成，最终源自拉丁语 cambiare。exchange 的字面意义是"把东西拿出来换掉"。中世纪集市上，货币兑换商叫 exchanger——他们把一种钱币"换出"为另一种。今天 exchange 在商店语境中专指"以旧换新"。
- **pattern** — 来自古法语 patron（模型、保护人），与 patron（赞助人）同源，都来自拉丁语 pater（父亲）。pattern 最初指"父亲传下来的模板"——一个可反复复制的标准形状。后来 pattern 分化为两个义项：一是"图案"（布料的重复花纹），二是"模式"（行为的重复规律）。
- **button** — 来自古法语 boton（凸起、花蕾），源自 bouter（推、顶出），与 butt（顶撞）同源。button 最初指"像花蕾一样顶出来的小圆球"。中世纪欧洲，纽扣是奢侈品——用珍珠或宝石制成。button 从"花蕾"到"纽扣"再到"按钮"，始终保留着"小而凸起、可以按压"的物理特征。
