# Unit 204: Internet

> Internet: Compare old and new technology

## 单词

browser, device, frequent, get used to, giant, graphics, install, key, locate, log out of, microphone, once a, press, restart, robot, server, switch, take a look, used to, user, webcam

## 单元讲解

本单元把话题拉到"科技的新旧对比"：从浏览器、服务器到麦克风、摄像头，你要谈论人们如何适应不断更新的设备。语法核心是 used to（过去常常）与 get used to（逐渐习惯）的对照——前者描述已逝的旧习惯，后者强调适应新事物的过程。词汇可分三组：硬件设备（device、microphone、webcam、server、robot），软件操作（install、restart、log out of、press、switch、locate），以及频率与规模（frequent、once a、giant、user）。这些词共同搭建起"回忆旧科技、解释新操作"的对话框架。学完本单元，你能比较过去与现在的科技，并描述使用新设备的适应过程。

## Tips

- **browser** — 来自 browse，原意是"牛羊啃食嫩叶"，源自古法语 brouster（啃芽）。19 世纪它先指"随意翻阅书籍"，1990 年代被借来命名"网上冲浪"的软件——像牛羊在草地漫游一样，用户在信息原野上随意啃食。一个农牧词，装下了整个互联网时代。
- **server** — 来自拉丁语 servire（服务），与 servant 同源。在餐厅它是"侍者"，在机房它是"为其他电脑提供数据的机器"。把冰冷的硬件称作"仆人"，正是计算机文化对主从关系的拟人化想象——你点击，它伺候。
- **robot** — 1920 年捷克作家恰佩克在剧本《罗素姆万能机器人》中首创，取自捷克语 robota（苦役、强制劳动）。它一出生就带着"被奴役的劳工"的底色，所以科幻作品里机器人反叛的母题，其实从词源那天起就埋下了伏笔。
- **install** — 来自中世纪拉丁语 installare，由 in- + stallum（座位、 stalls 畜栏）构成，原指"把某人安放到职位上"，如主教就职。从"给人一个座位"到"把软件装进系统"，install 始终保留着"为某物安排一个固定位置"的核心意象。
- **webcam** — 由 web + camera 拼合，web 本指蜘蛛网，源自古英语 webb。1991 年剑桥大学计算机实验室为监控咖啡壶而架起的第一台网络摄像头，让"网"从蛛丝变成了全球信息网——一个为看咖啡壶而生的发明，意外定义了视频时代。
- **microphone** — 来自希腊语 mikros（小）+ phōnē（声音），字面"放大微声的器具"。19 世纪电声学兴起时，科学家用希腊词根为新发明命名，telephone、megaphone 与它共享 phōnē——一根线，把人类对"听见远方"的古老渴望变成了现实。
- **device** — 来自拉丁语 dividere（分开），经古法语 devis 演变为"设计、装置"。原本指"被分别安排好的方案"，后泛指任何精巧的器具。divide 与它同根，从"分割"到"巧思"，记录的是人类把材料分拆重组、造出新物的能力。
- **giant** — 来自希腊语 gigas，神话中对抗奥林匹斯众神的巨人族。从《奥德赛》里的独眼巨人，到今天形容"巨头公司"（tech giant），giant 始终带着"压倒性体量"的威慑感——只是战场从神话搬到了市场。
