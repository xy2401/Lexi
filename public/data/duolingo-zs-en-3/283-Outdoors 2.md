# Unit 283: Outdoors 2

> Outdoors: Suggest outdoor activities

## 单词

assuming that, attempt, attempt to, be able to, canyon, conditions, daylight, dehydrated, enough to, gear, how about we, leopard, overdo it, picturesque, poisonous, provided, rafting, safari, so long as, summit, too, trail, trekking, try to, wild

## 单元讲解

本单元的场景是户外探险活动的规划与讨论——朋友之间商量去漂流、徒步还是登山，同时评估风险和条件。对话涉及天气状况、体力限制、装备准备，以及用条件句提出各种假设。

语法重点在于条件与假设的多种表达方式：assuming that（假设）、provided（只要）、so long as（只要）、enough to（足以）。这些结构比简单的 if 更正式、更精确，适合讨论需要权衡利弊的户外活动计划。同时 attempt to 与 try to 的微妙区别也值得注意：attempt 暗示难度更大、成功率不确定。

词汇可分为三组：户外活动（rafting, trekking, safari, summit, trail）、条件与能力（assuming that, provided, so long as, be able to, enough to）、风险与装备（dehydrated, poisonous, overdo it, gear, conditions, wild）。这些词构成了一次完整的户外规划对话所需的全部要素。

学完本单元，你能用英语与同伴讨论户外活动的可行性，提出条件、评估风险并给出建议。

## Tips

- **safari** — 来自斯瓦希里语 safari（旅行），而斯瓦希里语又借自阿拉伯语 safar（旅途）。19世纪英国殖民者进入东非后，将这个词带回英语，专指"非洲野生动物观赏之旅"。从阿拉伯商人的沙漠驼队，到维多利亚时代猎人的丛林远征，再到今天举着相机的游客——同一个词记录了人类与非洲大陆关系的变迁。
- **canyon** — 来自西班牙语 cañón（管子、峡谷），源自拉丁语 canna（芦苇、管子）。西班牙探险家在美洲大陆看到科罗拉多河切出的巨大裂缝时，觉得那像一根被劈开的巨管。英语保留了西班牙语的重音和拼写习惯，科罗拉多大峡谷（Grand Canyon）是这个词最著名的注脚。
- **picturesque** — 来自意大利语 pittoresco（如画般的），经法语进入英语。词根是意大利语 pittura（绘画），与英语 picture 同源。18世纪英国美学中，picturesque 是介于 beautiful（优美）和 sublime（崇高）之间的第三种审美范畴——指那种"像画一样值得入画"的不规则之美，比如一座爬满藤蔓的废墟。
- **trekking** — 来自南非荷兰语（Afrikaans）trek，原指"牛车长途跋涉"。19世纪布尔人赶着牛车穿越南非草原的大迁徙（Great Trek）让这个词进入英语。今天 trekking 专指多日徒步穿越山野，比 hiking 更艰苦、更持久。从牛车到登山靴，交通工具变了，"漫长而艰辛的旅途"这层意思没变。
- **dehydrated** — 由 de-（去除）+ hydrate（水合）构成，hydrate 来自希腊语 hydōr（水）。希腊神话中九头蛇 Hydra 的名字也来自 hydōr——因为它住在水里。脱水是户外活动中最危险的状况之一，英语中 "Stay hydrated!" 是登山向导和运动教练的口头禅。
- **poisonous** — 来自古法语 poison（毒药），最终源自拉丁语 potio（饮料、一饮）。拉丁语中 potio 本是中性词，指任何喝下去的东西；但在中世纪，"被下毒的饮料"太常见了，词义逐渐窄化为"毒物"。与 potion（药剂、魔药）同源——奇幻小说中巫师调制的 potion，词源上就是"一杯喝下去的东西"。
