# Unit 219: Permission

> Permission: Respond to requests

## 单词

absolutely not, as long as, ask, beg, curfew, do you think i'd be able to, how about if, if that's the case, make sure, not, past, react, school night, sleepover, stay out, take, talk it over, tell, that would be, the thing is, then, what about if, will you, would you

## 单元讲解

本单元模拟家庭或朋友之间请求许可的场景——青少年向父母争取晚归、参加 sleepover、突破 curfew。对话充满协商、妥协和拒绝的策略，是日常人际关系中最微妙的语言博弈。

语法重点是多种请求和条件句式：would you、will you 表达直接请求；do you think I'd be able to 是更委婉的试探；as long as 和 if that's the case 设定条件；how about if 和 what about if 提出替代方案。

词汇可分为三组：请求与回应（ask、beg、would you、will you、absolutely not、that would be）、条件与协商（as long as、if that's the case、how about if、what about if、talk it over、the thing is）、青少年生活（curfew、sleepover、school night、stay out、past）。

学完本单元，你能用不同礼貌程度提出请求，在协商中设定条件和替代方案，并得体地接受或拒绝他人的请求。

## Tips

- **curfew** — 来自古法语 cuevrefeu，由 cuevre（覆盖）+ feu（火）构成，字面意思"盖住火"。中世纪欧洲城镇晚间敲钟，要求居民用金属罩盖住壁炉中的火以防失火，这声钟响就叫 curfew。后来词义从"盖火"转为"必须回家的时间"。今天父母对孩子说的 curfew，背后是八百年前欧洲城镇防火的暮色钟声。

- **sleepover** — 由 sleep（睡觉）+ over（过夜）构成的美式英语复合词。over 在此表示"跨越一整夜"，如同 overnight。sleepover 是20世纪美国郊区文化的产物——孩子们带着睡袋去朋友家过夜，看恐怖片、吃爆米花。这个简单的复合词承载了一代美国青少年的集体记忆。

- **beg** — 源自古英语 bedecian（乞求），可能与古挪威语 biðja（请求、祈祷）同源。beg 比 ask 更卑微、更迫切——乞丐（beggar）就是"不断 beg 的人"。中世纪乞丐在教堂门口 beg，骑士向国王 beg 恩赐，孩子向父母 beg 多玩一小时。从生存到撒娇，beg 的强度在语境中伸缩自如。

- **permission** — 来自拉丁语 permittiō（允许通过），由 per-（穿过）+ mittō（送、放）构成。许可的字面意思是"放你穿过去"——想象一扇城门，守卫"放行"让你通过。mission（使命）是"被送出去"，admission（准入）是"被送到里面"，permission 则是"被允许穿过"。一扇门的开合，衍生出一整套"允许"词汇。

- **react** — 由 re-（回）+ act（行动）构成，act 来自拉丁语 agere（驱动、做）。react 字面意思是"反过来行动"——先有刺激，后有回应。agere 是英语中最多产的词根之一，留下了 action、agent、agenda、exact（ex- 出 + agere 驱动，即"逼出来"）。反应不过是被世界"推了一下"之后"推回去"。

- **past** — 来自拉丁语 passus（步伐），经古法语 passer（通过）进入英语。past 原意是"走过的"，即"已经迈步经过的"。pass（通过）、passage（通道）、passport（通行证，即"通过港口的许可"）都是同源词。说 "past curfew" 时，字面意思是"已经迈步走过了门禁时间"——时间被想象成一条路，你走过了某个标记点。

- **negotiate** — 虽不在本单元词表中，但与 talk it over 形成完美对照。negotiate 来自拉丁语 negōtiāri（做生意），由 nec-（不）+ ōtium（闲暇）构成——"不闲着"即"忙于事务"。古罗马人把商业谈判视为"有闲"的反面。talk it over 则是更口语化的"把事情谈透"，over 表示"彻底、从头到尾"。
