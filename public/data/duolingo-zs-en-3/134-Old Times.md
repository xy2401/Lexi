# Unit 134: Old Times

> Old Times: Share childhood memories

## 单词

accountant, assignment, corn, court, cover, did, didn't use to, favorite, fewer, fly, however, inch, indoors, know how to, never used to, outdoors, religion, rock, stream, sunrise, sweep, swept, tax, use to, web

## 单元讲解

本单元围绕"往昔时光"展开：回忆童年与过去的生活，对比从前和现在。你会谈到儿时在户外（outdoors）溪边（stream）玩耍、看日出（sunrise），也会说起如今在室内（indoors）对着网络（web）的日子。

语法核心是 used to 结构：used to 表示"过去常常做、如今不再"，否定式 didn't use to / never used to 强调"过去从不"。注意 use to 在否定与疑问中省去 d。however 用于句间转折，fewer 修饰可数名词表示"更少的"。

词汇可分三组：自然童年类（stream、rock、sunrise、fly、outdoors、indoors），职业制度类（accountant、tax、religion、assignment），以及度量与动作类（inch、cover、sweep/swept、corn、web）。学完你能用 used to 讲述一段今昔对比的回忆。

## Tips

- **used to** — 这里的 use 不是"使用"，而是古义"习惯于"，源自拉丁语 uti（使用、惯于）。I used to swim 字面是"我惯于游泳"。否定式写作 didn't use to（省 d），因为 did 已承载过去时；*used not to 已属老式。
- **accountant** — 来自古法语 aconter（计算、记账），词根是拉丁语 computare（计算），与 count、compute 同源。accountant 字面是"负责算账的人"。它和 account（账户、说明）共享同一词根——一切都要"算清楚、说得清"。
- **tax** — 来自拉丁语 taxare，意为"评估、触碰、指责"，词根 tangere（触摸）也是 contact（接触）、tangent（切线）的源头。古罗马官员"伸手估量"百姓财产以定税额，tax 便从"触碰估价"演变为"税"。
- **religion** — 来自拉丁语 religio，词源有争议：一说源自 religare（重新捆绑），re-（再次）+ ligare（绑），意为"把人重新系于神明"；ligare 也是 ligament（韧带）和 ally（盟友）的源头。宗教，在词源里是一根"重新联结"的纽带。
- **stream** — 来自古英语 strēam，与德语 Strom（大河、电流）同源，可上溯到原始印欧语 *sreu-（流动）。英语里 stream 既指小溪，也指"数据流、人流"，"流动"这一核心意象贯穿古今。
- **sunrise** — 由 sun + rise 合成的复合词，字面"太阳升起"。rise 来自古英语 rīsan，与德语 reisen（旅行）同源——古人把"起身、升起"和"启程上路"看作同一动作。sunrise 因此既是天文现象，也暗含"一日之始即一段启程"。
- **web** — 来自古英语 webb，意为"编织物"，词根与 weave（编织）同源。它本指蜘蛛网或织物，互联网时代被借用来翻译 World Wide Web（万维网），因为链接交织的页面恰似一张巨网。一个古老的纺织词，覆盖了整个数字世界。
- **corn** — 来自古英语 corn，本意是"任何谷物的籽粒"，在欧洲指小麦、大麦，到了美洲才被用来专指玉米（maize）。它和 grain 同源，拉丁语 granum（谷粒）经由法语进入英语。同一个词，在不同大陆指代了不同的主食。
