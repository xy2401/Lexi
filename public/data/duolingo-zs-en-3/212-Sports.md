# Unit 212: Sports

> Sports: Describe an athletic event

## 单词

captain, come on, cyclist, defense, diving, equipment, expect to, final, gymnastics, helmet, high, hope to, hunt, offense, perfectly, race, record, ski, snowboard, swimmer, there can't be, there may not be, there might be, there might not be, there should not be, there shouldn't be, track

## 单元讲解

本单元以体育赛事为场景，描述比赛中的攻防、选手表现和观赛感受。从 captain 带领 defense 和 offense 的对抗，到 cyclist、swimmer 在 track 上的竞速，再到 diving 和 gymnastics 的技巧展示，涵盖了竞技运动的多个面向。

语法核心是"there + 情态动词"的推测表达：there might be、there can't be、there shouldn't be 等结构用于对赛场情况做出判断和预期。expect to 和 hope to 则表达对结果的期待，副词 perfectly 修饰动作的完成度。

词汇可分为三组：人物与角色（captain、cyclist、swimmer）、运动项目与场地（diving、gymnastics、ski、snowboard、race、track、hunt）、比赛用语与判断（defense、offense、final、record、equipment、helmet）。

学完本单元，你能描述一场体育赛事的进程，对比赛结果做出合理推测，并表达对选手表现的期待。

## Tips

- **captain** — 来自拉丁语 caput（头），经古法语 capitaine 进入英语。军队中"头领"即指挥者，这个词从军事领域扩展到运动队，因为团队竞技本质上是一场模拟战争——captain 就是那个"头脑"，负责战术决策和鼓舞士气。同源的还有 capital（首都，即"头"城市）和 cabbage（卷心菜，因其圆如头）。

- **gymnastics** — 源自希腊语 gymnastikós，词根 gymnós 意为"裸体的"。古希腊运动员赤身裸体在体育馆训练和比赛，gymnasium 原意就是"裸体训练的地方"。这个令人意外的词源记录了古希腊人对人体美的崇尚——运动与裸体在他们眼中毫无矛盾，反而是力量与自由的象征。

- **helmet** — 来自古法语 helme，最终源自日耳曼语 *helmaz（保护、遮盖），与古英语 helm（保护者）同源。中世纪骑士的头盔是全身铠甲中最关键的部分，helm 既是实物也是隐喻——"under someone's helm"意为在某人庇护之下。今天自行车和滑雪头盔虽轻如蛋壳，却继承了千年护头的使命。

- **offense** — 来自拉丁语 offendere（撞击、冒犯），由 ob-（朝向）+ fendere（打击）构成。在军事语境中，offense 是"主动出击"；转入体育后，它指进攻方。有趣的是，defend（防守）来自同一词根 fendere，只是加了 de-（远离）前缀——进攻是"朝对方打"，防守是"把打击挡开"，一攻一守共享同一个"击打"动作。

- **record** — 来自拉丁语 recordārī（回忆），由 re-（再次）+ cor/cord-（心）构成——古人认为记忆储存在心中，record 就是"再次用心记住"。中世纪法庭书记员把证词"记入心中"即写成文书，后来 sports record 指"值得被记住的最佳成绩"。从"心"到"纪录"，record 完成了一次从情感到数据的语义迁移。

- **track** — 源自古法语 trac，意为"足迹、痕迹"，可能来自日耳曼语 *trakjan（拖拽）。最初指动物或人走过的路径，后来专指赛跑的环形跑道——因为运动员一圈圈跑过，在地面留下重复的"痕迹"。火车铁轨也叫 track，同样是因为两条钢轨像大地上被拖出的两道印痕。

- **cyclist** — 来自希腊语 kýklos（圆），经拉丁语 cyclus 和法语 cycle 进入英语。自行车的两个轮子是"圆"的最直观体现，cyclist 即"驾驭圆形的人"。同源词包括 cycle（循环）、cyclone（气旋，旋转的风）和 encyclopedia（原意"知识的圆环"）。希腊人用一个"圆"字，串联了车轮、风暴和学问。
