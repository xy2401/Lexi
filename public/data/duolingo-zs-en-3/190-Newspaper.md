# Unit 190: Newspaper

> Newspaper: Report on recent events

## 单词

against, crash, damage, decrease, explode, flood, happen, has there been, have there been, improvement, increase, involve, most of, murder, protest, recent, shoot, shot, there has been, there hasn't been, there have been, there haven't been, unemployment, warning

## 单元讲解

本单元模拟新闻报道与事件讨论场景：描述突发事件、分析社会趋势、转述新闻内容。语法重点是 "there has been / there have been" 及其否定和疑问形式，用于报道近期发生的事件，构成新闻英语的核心句式。词汇可分为三组：突发事件（crash, explode, flood, murder, shoot, shot, damage）；社会趋势与数据（decrease, increase, unemployment, improvement, protest）；以及报道框架词（happen, involve, recent, warning, most of, against）。学完本单元后，你能用英语概述新闻事件、描述社会变化趋势，并使用 there has/have been 结构进行客观报道。

## Tips

- **explode** — 来自拉丁语 explodere，由 ex-（出）+ plaudere（拍手）构成，原义竟然是"把演员嘘下台"。古罗马剧场中，观众不满时用力拍手、跺脚，将表演者"拍出去"（ex-plaudere）。17 世纪火药时代，这个词被借用来描述火药"猛烈释放"——从"把演员轰下台"到"把物体轰成碎片"，暴力的程度升级了，但"向外猛烈释放"的核心意象未变。
- **protest** — 来自拉丁语 protestari，由 pro-（公开地）+ testari（作证）构成，字面意思是"公开作证"。testari 与 testis（证人）同源，也是 testimony（证词）和 test（测试）的词源。中世纪宗教改革中，1529 年德国路德宗诸侯在帝国议会上"公开作证"反对天主教禁令，这一事件被称为 Protestation，参与者成为 Protestants（新教徒）。
- **murder** — 来自古英语 morðor，与德语 Mord 同源，可追溯到原始印欧语 *mrtro-（死亡）。在盎格鲁-撒克逊法律中，morðor 特指"秘密杀人"——区别于公开战场上的杀戮。诺曼征服后，征服者威廉规定：若发现不明尸体且无法证明死者是英格兰人，则推定为被谋杀的诺曼人，全村须缴纳"murdrum 罚金"。
- **crash** — 拟声词，模仿物体猛烈碰撞时发出的刺耳声响。14 世纪进入英语时写作 crasshen，描述金属或玻璃碎裂的声音。20 世纪后词义急剧扩展：飞机坠毁（plane crash）、股市崩盘（market crash）、电脑死机（system crash）——每一次技术革命都给这个古老的拟声词增添了新的灾难场景。
- **unemployment** — 由 un-（无）+ employ（雇用）+ -ment（状态）构成。employ 来自古法语 emploier，源自拉丁语 implicare（卷入、缠绕），即 in-（进入）+ plicare（折叠）。"雇用"的词源意象是"把人卷入、折叠进组织中"。unemployment 因此是"被从组织中展开、释放出来"的状态——你不再被"折叠"进任何工作结构。
- **warning** — 来自古英语 warnian（警惕、注意），与德语 warnen 同源。古英语中 warnian 既是"警告他人"也是"自己警惕"，这种双向性保留至今：warning 既是发出的信号（警告牌），也是接收的状态（引起警觉）。在新闻语境中，warning 是灾难叙事的前奏——它出现在事件之前，试图将"即将发生"转化为"可以预防"。
