# Unit 075: 生活方式

> 谈论生活方式

## 单词

and, at, before bed, deck, enough, feel, for too long, get, get sick, get some fresh air, get some sleep, go for a walk, heavy, if, jump, laugh, lazy, loud, mad, makeup, mouth, neck, really, sit, stand, storm, strong, talk, thirsty, upset, what's wrong with, when, wind

## 单元讲解

本单元聚焦"日常生活习惯与身体感受"：睡前该做什么、久坐后需要出去走走、感到疲倦或口渴时如何表达。场景贴近生活——有人觉得你太懒，有人劝你别在暴风雨中待太久。

语法上，本单元大量使用 get + 形容词/名词的结构（get sick, get some sleep, get some fresh air），这是英语口语中表达"变得……"或"获得……"最灵活的模式。词汇可分为身体感受（thirsty, upset, mad, feel）、动作（sit, stand, jump, laugh, talk）和环境（storm, wind, heavy, loud）。

学完本单元，你能用英语描述自己的日常作息、表达身体不适，并给出简单的生活建议。

## Tips

- **lazy** — 词源有争议，可能来自低地德语 läsig（缓慢的、疲倦的），16 世纪进入英语。在此之前英语用 slow 或 idle 表达类似含义。lazy 最初带有道德谴责色彩——在清教徒文化中，懒惰是"七宗罪"之一。现代用法中 lazy 语气已大大减轻，甚至可以自嘲：I'm feeling lazy today.
- **storm** — 源自古英语 storm，与德语 Sturm 同源，追溯到原始日耳曼语 *sturmaz。更远的祖先可能是原始印欧语 *(s)twer-（旋转、搅动），与拉丁语 turba（混乱）有关，英语 disturb 即出于此。storm 从"天气现象"引申为"任何猛烈爆发"，如 a storm of criticism。
- **thirsty** — 源自古英语 þyrstig，与 þurst（口渴）相关，原始日耳曼语 *þurstuz。德语 durstig、荷兰语 dorstig 是同源词。有趣的是，thirst 在古英语中也可比喻"渴望"，如 thirst for knowledge，这一隐喻用法从《圣经》时代延续至今。
- **makeup** — 由 make + up 构成的复合词，19 世纪才开始指"化妆品"。make up 作为动词短语历史更久，原意"组成、弥补、编造"。化妆品义来自戏剧界——演员"把自己装扮起来"。注意 makeup 是不可数名词，不说 a makeup，而说 some makeup 或 a makeup look。
- **upset** — 由 up + set 构成，字面意思"翻倒、打翻"。17 世纪原指物理上的倾覆（如 upset a boat），后来隐喻为情绪上的"被打翻"——内心平衡被破坏。这种从物理到心理的隐喻路径在英语中极为常见，与中文"心乱如麻"异曲同工。
- **enough** — 源自古英语 genōg，与德语 genug 同源，原始日耳曼语 *ganōgaz。更远的祖先是原始印欧语 *ne-（不）+ *nek-（达到），字面意思"达到了、不再缺少"。enough 在句中位置灵活：作形容词放在名词前（enough time），作副词放在形容词后（good enough）。
