# Unit 071: 健康 2

> 描述健康问题

## 单词

appointment, available, back, body, break, broke, brush, cold, dentist, down, fall, fell, for, go to, have, how often should, keep, made, make, meals, move, office, remember to, rest, should, should not, shouldn't, toothache, wake up, well, went to, when should, with, woke up

## 单元讲解

本单元围绕"看医生、谈健康"这一真实场景展开：预约牙医、描述身体疼痛、询问用药频率。你会学到如何用 should / shouldn't 给出健康建议，用 how often should... 和 when should... 询问医嘱，以及用 remember to... 提醒自己按时吃药或刷牙。

语法上，本单元核心是情态动词 should 表建议，以及不规则动词过去式（break → broke, fall → fell, wake → woke up, go → went）在叙述病情经过时的运用。词汇可分为三组：身体部位与症状（body, back, toothache, cold）、医疗行为（appointment, dentist, office, rest）、日常习惯（brush, meals, wake up, move）。

学完本单元，你能用英语描述自己的不适、询问就医建议，并听懂医生关于频率和注意事项的简单嘱咐。

## Tips

- **dentist** — 来自拉丁语 dens（牙齿），与法语 dent、西班牙语 diente 同源。中世纪欧洲拔牙是理发师的副业，直到 18 世纪才出现专职 dentist。英语中 -ist 后缀表示"从事某事的人"，如同 artist、pianist，所以 dentist 字面即"与牙齿打交道的人"。
- **toothache** — 古英语 tōþ（牙齿）+ āce（疼痛），ache 源自古英语 acan，意为"持续地痛"。日耳曼语族中，德语 Zahn（牙齿）与英语 tooth 同源，都追溯到原始印欧语 *h₃dónts。ache 作为后缀可构成 headache、stomachache，是英语中最直觉的"疼痛构词法"。
- **should** — 源自古英语 sceolde，是 shall 的过去式，原意"欠、有义务"。从"命运注定要做"逐渐弱化为"建议做"，语义从强制走向温和。德语中对应的 sollen 仍保留更强的"被要求"意味，而英语 should 已几乎只用于委婉建议。
- **appointment** — 来自古法语 apointier（安排、约定），由 à（向）+ point（点、时刻）构成，字面意思"定在一个时间点上"。中世纪骑士决斗前需"约定时间地点"，后来泛指一切正式预约。法语中 rendez-vous 更口语化，而 appointment 保留了书面正式感。
- **broke** — break 的过去式，源自古英语 brecan，与拉丁语 frangere（打碎）同源，英语中 fragment、fragile 都来自这条拉丁线。日耳曼语中德语 brechen、荷兰语 breken 保留了几乎相同的形式。break → broke → broken 是英语中最常见的不规则变化之一。
- **rest** — 来自古英语 ræst（休息、睡眠），与德语 Rast 同源，原始日耳曼语 *rōstō 本意是"停下来、不再移动"。在医疗语境中 rest 特指"静养"，医生说的 get some rest 不是普通休息，而是"停止一切活动让身体修复"，语气比 relax 更严肃。
- **woke up** — wake 源自古英语 wacan（醒来、苏醒），与拉丁语 vigilāre（保持清醒）有远亲关系，英语 vigil（守夜）即出于此。wake 的过去式在历史上曾与 waken、awake 混用，现代英语固定为 woke/woken。woke up 强调"从睡眠中醒来"的瞬间动作。
