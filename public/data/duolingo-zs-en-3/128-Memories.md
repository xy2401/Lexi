# Unit 128: Memories

> Memories: Share stories about childhood

## 单词

bug, card, caught, childhood, come over, dirt, do, frog, frying pan, hide, joke, kicked, knee, neighborhood, never used to, now, pie, shy, spinach, stay, strict, trumpet, up, used to

## 单元讲解

本单元以回忆童年为主题：在邻居家院子里捉青蛙、躲猫猫、玩泥巴、被严格的父母要求吃菠菜。这些画面感极强的童年片段是英语叙事中常见的怀旧话题，也是与英语母语者建立情感连接的绝佳素材。

语法上，本单元核心是 used to 结构表达"过去常常做但现在不再做的事"，以及其否定形式 never used to。caught（catch 的过去式）和 kicked 等不规则/规则动词的过去式用于叙述具体事件。

词汇可分为三组：童年游戏与场景词（hide, come over, neighborhood, dirt, frog, bug, knee）、食物与家居词（pie, spinach, frying pan, card）、以及性格与规则词（shy, strict, joke, used to, never used to）。学完本单元，你能用英语生动地讲述童年趣事，用 used to 对比过去与现在，描述成长中的变化。

## Tips

- **childhood** — 由 child + -hood 构成，-hood 来自古英语 -hād（状态、身份），与德语 -heit 同源。古英语中 cild（孩子）原指"未出生的胎儿"，后扩展为"幼童"。-hood 这个后缀标记"处于某种状态"，因此 childhood 字面意思是"处于孩子的状态中"。brotherhood（兄弟情谊）、neighborhood（邻里关系）都用同一后缀。
- **frog** — 来自古英语 frogga，与古挪威语 frauki 同源，可能模仿青蛙的叫声。日耳曼语中 frog 和 toad 有明确区分：frog 指水栖、皮肤光滑的蛙类，toad 指陆栖、皮肤粗糙的蟾蜍。英语习语 frog in one's throat（嗓子沙哑）源自人们认为喉咙不适是"有只青蛙卡在那里"的民间想象。
- **spinach** — 来自古法语 espinache，经由阿拉伯语 isfānākh 传入，最终源自波斯语 aspanākh。菠菜原产波斯（今伊朗），中世纪经阿拉伯商人传入欧洲。英语中 spinach 的拼写保留了法语痕迹，而 -ach 的发音则反映了其漫长的东方旅行路线。
- **trumpet** — 来自古法语 trompette，是 trompe（号角）的指小词。trompe 可能模仿号角的"嘟嘟"声（拟声词）。中世纪欧洲，trumpet 是战场和宫廷的信号乐器，只有贵族和军队有权使用。"吹自己的小号"（blow one's own trumpet）意为"自吹自擂"，因为号角手总是最引人注目的。
- **strict** — 来自拉丁语 strictus（拉紧的），是 stringere（绑紧）的过去分词。古罗马军事语境中，strictus 形容"绷紧的纪律"。英语中 strict 保留了"严格、严厉"之义，而同一词根还产生了 restrain（约束）、district（区域，"被划紧的范围"）和 stress（压力）。一个"绑紧"的动作，分化出了纪律、地理和心理三个领域的词汇。
- **dirt** — 来自古英语 dritan（排泄），原始日耳曼语 *dritan。是的，dirt 最初与排泄物直接相关，后泛化为一切"脏东西、泥土"。古英语中 drēah（粪便）是其近亲。语义的"雅化"让现代使用者几乎忘记了这个词的粗俗起源，但 dirty 在俚语中仍保留"下流的"含义。
- **shy** — 来自古英语 scēoh（受惊的、警惕的），与古挪威语 skýr（清晰的）无直接关系，但与德语 scheu（害羞的、怕人的）同源。原始日耳曼语 *skeuhwaz 意为"受惊后退"。shy 的核心意象是"像受惊的动物一样退缩"，英语中 shy away from（回避）保留了这一动物性隐喻。
