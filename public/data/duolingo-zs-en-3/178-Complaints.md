# Unit 178: Complaints

> Complaints: Ask someone to adjust something

## 单词

apology, besides, blame, disappointed, disappointing, end up, end up in, fault, hang, hang up, hang up on, negative, out-of-date, put, put away, put up with, refund, refuse, run out, run out of, take, take back, that sounds like, turn, turn up, unfair, what a, would it be possible

## 单元讲解

本单元的场景是表达不满和投诉——产品有问题、服务不到位、要求退款或换货，同时也包括电话沟通中的挂断、等待等情境。学习者需要掌握既坚定又礼貌的投诉表达。

语法重点是动词短语（phrasal verbs）的大量出现：hang up（挂电话）、put away（收起来）、put up with（忍受）、run out of（用完）、take back（退回）、turn up（调大/出现）。would it be possible 是礼貌请求的经典句式。

词汇可分为：投诉核心词（apology, blame, fault, refund, refuse, unfair, disappointed, disappointing）、动词短语（hang up, hang up on, put away, put up with, run out, run out of, take back, turn up, end up）、连接与评价（besides, negative, out-of-date, what a, that sounds like, would it be possible）。

学完本单元，你能用英语进行有效投诉，表达不满的同时保持礼貌，提出合理的解决方案。

## Tips

- **apology** — 来自希腊语 apologia（辩护、申辩），由 apo-（远离）+ logos（话语）构成，字面意思"用话语把自己从指控中拉出来"。苏格拉底的《申辩篇》标题就是 Apologia。有趣的是，apology 从"为自己辩护"演变为"承认错误"，语义发生了180度反转——从"我没错"变成了"我错了"。

- **blame** — 来自古法语 blasmer，源自拉丁语 blasphemare（亵渎、说坏话），而 blasphemare 又来自希腊语 blasphēmein（说恶言）。从"亵渎神灵"到"责怪某人"，语义从宗教领域下移到日常领域。blame 与 blasphemy（亵渎）同源，但前者已经世俗化为普通的"归咎"，后者仍保留宗教色彩。

- **refund** — 来自拉丁语 refundere（倒回去），由 re-（回）+ fundere（倾倒）构成。fundere 在拉丁语中是"倒、流"的动词，同族的有 fountain（喷泉——水涌出来）、found（铸造——把金属倒入模具）、confuse（混淆——倒在一起）。refund 的字面画面是"把钱倒回给你"，即退款。

- **fault** — 来自古法语 faute（缺乏、过失），源自拉丁语 fallita（欺骗），与 fallere（欺骗、使跌倒）有关。fallere 也是 false（虚假）、fail（失败）的词源。fault 从"欺骗"到"过失"再到"地质断层"，语义沿着"不诚实→有缺陷→有裂缝"的路径演变。It's my fault 就是"这个'缺陷'在我身上"。

- **hang up on** — hang 来自古英语 hangian（悬挂），与德语 hängen 同源。hang up 最初指"把听筒挂回钩子上"——老式电话的听筒是挂在墙上的。hang up on someone 就是"在对方还在说话时把听筒挂上"，即"挂某人电话"。这个短语保存了老式电话的物理形态：不挂回去，线路就不断。

- **put up with** — 这个三词短语动词中，put 来自古英语 putian（推、放），up 表"向上、到位"，with 在古英语中表"对抗"。put up 原意是"举起来、竖起来"（如 put up a tent），加上 with 后变成"把不满举起来放在心里与之共存"，即"忍受"。17世纪出现，是英语短语动词"小词组合产生全新含义"的典型例子。
