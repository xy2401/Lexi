# Unit 218: Wishes

> Wishes: Express wishes about life

## 单词

afraid, as many, chance, come true, count, encourage, habit, hope, hopeful, if only, lottery, marry, oh well, regret, satisfied, silly, step, take advantage, unlikely, wish

## 单元讲解

本单元围绕人生愿望与遗憾展开——许愿、期待、后悔、满足，这些情感构成了日常对话中最柔软的部分。从 lottery 的暴富幻想到 marry 的人生承诺，从 habit 的日常积累到 regret 的事后叹息，话题触及每个人内心的渴望与不甘。

语法重点是 if only 引导的虚拟语气，表达对未实现愿望的感叹；come true 描述愿望成真；unlikely 和 as many 用于评估可能性和数量。hopeful 与 satisfied 构成情感光谱的两端。

词汇可分为三组：愿望与期待（wish、hope、hopeful、chance、come true、if only、lottery）、行动与习惯（habit、step、count、encourage、take advantage、marry）、情感与评价（afraid、regret、satisfied、silly、oh well、unlikely）。

学完本单元，你能表达对未来的期许，谈论人生遗憾，并在对话中给予他人鼓励或安慰。

## Tips

- **wish** — 源自古英语 wȳscan，与古高地德语 wunsken 同源，原始日耳曼语 *wunskijanan 意为"渴望"。在北欧神话中，Óðinn（奥丁）的别名 Óski 意为"愿望之神"，日耳曼人相信愿望可以传达给神灵。wish 从"向神祈祷"逐渐世俗化为"希望某事发生"，但 "make a wish" 的仪式感仍保留了向超自然力量求助的古老记忆。

- **lottery** — 来自意大利语 lotteria，词根 lotto（份额、命运），源自日耳曼语 *hlutaz（签、份额）。古代日耳曼人用抽签（casting lots）来分配土地和决定命运，lottery 就是"用签来决定份额"的制度。英语 lot（许多、命运）和 allot（分配）都是同源词。从维京人分地到现代彩票，"抽签定命运"的冲动从未改变。

- **regret** — 来自古法语 regreter，可能源自古挪威语 gráta（哭泣）加前缀 re-（再次）。regret 字面意思是"再次哭泣"——为已经发生的事反复悲伤。同源的 greet（问候）在古英语中也有"哭泣"义，因为迎接和告别都伴随泪水。后悔就是"在记忆中重新经历一次痛苦"。

- **encourage** — 来自古法语 encoragier，由 en-（使）+ corage（勇气）构成，corage 源自拉丁语 cor（心）。鼓励的字面意思是"使对方心中生出勇气"。古法语 corage 也留下了 courage（勇气）和 discouragement（气馁）。中世纪骑士出征前，领主会"往他们心里注入力量"——encourage 保存了这个充满仪式感的画面。

- **satisfied** — 来自拉丁语 satisfacere（使满足），由 satis（足够）+ facere（做）构成。字面意思是"做到足够的程度"。satis 还留下了 satisfy 的反面 insatiable（贪得无厌的，即"不够的"）。古罗马人用 satis 表达"够了、行了"，这个简单的"足够"概念，经过两千年演变为对人生成就的满足感。

- **habit** — 来自拉丁语 habitus（状态、持有方式），由 habēre（拥有、持有）演变而来。habit 原意是"一个人持续持有的行为模式"。habēre 还留下了 have（拥有）、inhabit（居住，即"持有某地"）和 exhibit（展示，即"向外持有"）。习惯就是"你一直握着不放手的东西"——这个比喻精准而深刻。

- **chance** — 来自拉丁语 cadere（落下），经古法语 cheance（骰子落下的结果）进入英语。骰子从手中落下，朝上的一面决定命运——chance 的字面画面就是"骰子落地的那一刻"。同源的 accident（事故，即"意外落下的事"）、cascade（瀑布，即"连续落下"）和 occasion（时机）都保留了 cadere 的"落"义。机遇，不过是命运骰子的一次落地。
