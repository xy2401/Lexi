# Unit 281: Old Friend

> Old Friend: Catch up with someone

## 单词

all grown up, any, back in town, can't complain, catch you up on, compliment, design, expecting, forties, get, get used to, going, how long has it been, how's, it's been, kindergarten, liking, loving, on the whole, overall, overseas, promise to, run into, so far, things

## 单元讲解

本单元的场景是多年未见的老友重逢——街头偶遇、叙旧寒暄、互相更新近况。这是英语社交中极常见的对话类型，从 "How long has it been?" 到 "Let me catch you up on things"，整段对话围绕时间跨度和生活变化展开。

语法上，本单元集中训练现在完成时与时间表达的搭配：it's been + 时间段、have been doing、have gotten used to。同时出现 "how long has it been" 这类以现在完成时提问的经典句式，强调从过去某刻延续至今的状态。

词汇可分为三组：重逢寒暄语（how's, can't complain, back in town）、时间与生活变化（all grown up, forties, kindergarten, overseas）、叙旧动作（catch you up on, run into, promise to, get used to）。这些词共同构建了一幅"久别重逢、互道近况"的完整画面。

学完本单元，你能在偶遇老朋友时自然地寒暄、询问对方近况并简要讲述自己的生活变化。

## Tips

- **compliment** — 来自拉丁语 complementum（补全、完成），经古法语 compliment 进入英语，原指"使礼节完备的一套客套话"。在宫廷时代，一句得体的恭维是社交仪式中不可或缺的"补全"环节。注意不要与 complement（补充）混淆——前者是赞美，后者是补足。
- **overseas** — 由 over + seas 构成，字面意思"越过海洋"。在中世纪英格兰，"across the sea" 几乎等同于"去法兰西或罗马"，因为英吉利海峡就是普通人认知的世界边界。这个词保留了岛国民族对"海外"最朴素的地理想象。
- **run into** — 短语动词，字面"跑进……里面"，引申为"不期而遇"。英语中大量偶遇表达都用碰撞隐喻：bump into、come across、run into——仿佛人与人的相遇是物理空间中两个运动物体的意外碰撞，非常生动。
- **kindergarten** — 直接借自德语，由 Kinder（孩子们）+ Garten（花园）组成，字面意思"儿童的花园"。1837年德国教育家福禄贝尔创立学前教育机构时，用这个比喻表达"孩子像植物一样在花园中被培育"的理念。英语原样借入，连拼写都未改。
- **forties** — 指四十多岁的年纪段。英语用复数形式 the forties 表示"40到49岁"，与 the 1940s（二十世纪四十年代）结构相同。这种用十年为单位的年龄表达非常口语化，比如 "She's in her forties" 比说具体数字更委婉、更常见于闲聊。
- **catch up on** — catch 本义"追赶、抓住"，加上 up 表示"追到同一水平"，再加 on 引出追赶的内容。整个短语的画面是：你落后了（信息滞后），现在要跑起来追上进度。"Let me catch you up on things" 就是"让我把近况给你补上"。
