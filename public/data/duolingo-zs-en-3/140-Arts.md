# Unit 140: Arts

> Arts: Talk about favorite books

## 单词

act, action, celebrity, cinema, comedy, commercial, create, culture, download, experience, fiction, fight, film, fought, loudly, novel, orchestra, perform, performance, performer, publish, review, sculpture, title

## 单元讲解

本单元的话题是艺术与娱乐：谈论最爱的书籍、电影、戏剧与音乐。你会聊小说（fiction / novel）、喜剧（comedy）、雕塑（sculpture）、管弦乐团（orchestra），也会说到下载（download）、发表（publish）、写评论（review）这些现代文艺生活。

语法重点是词族与词性的辨析：perform / performance / performer 展示"动词—名词—施事者"的派生链条；act / action、fight / fought 体现动词与名词、原形与过去式的对应。loudly 等副词修饰表演的方式。

词汇可分三组：艺术门类类（cinema、film、comedy、fiction、novel、sculpture、orchestra），创作演出类（create、act、perform、performance、performer、publish、action），以及评价传播类（review、title、celebrity、commercial、culture、experience、download、fought）。学完你能介绍一部作品并分享自己的感受。

## Tips

- **novel** — 来自意大利语 novella，意为"新故事、短篇轶事"，词根是拉丁语 novus（新的）。它和 news（新闻）、nova（新星）同源。小说最初指"新鲜的奇闻"，与"旧事重提"相对——novel 之名，永远带着"求新"的基因。
- **comedy** — 来自希腊语 kōmōidia，由 kōmos（狂欢的游行队伍）+ aoid（歌）构成，字面是"狂欢之歌"。古希腊酒神节上，人们载歌载游行，演成滑稽戏，comedy 由此诞生。它和 tragedy（悲剧，字面"山羊之歌"）一喜一悲，皆源于祭祀歌舞。
- **orchestra** — 来自希腊语 orkheisthai（跳舞），原指古希腊剧场中"供歌队起舞的圆形乐池"。后来这片场地让给了乐师，orchestra 便从"跳舞的地方"变成了"管弦乐团"本身。一个空间的名称，记录了一种艺术的迁移。
- **sculpture** — 来自拉丁语 sculpere（雕刻），词根与希腊语 glyphein（刻）相关，glyph（字符、雕刻符号）即出于此。sculpture 字面是"被雕凿出来的作品"，从石头中"减去"多余部分，形象才显现——这正是雕刻的本质。
- **cinema** — 来自希腊语 kinēma（运动），词根 kinein（移动），与 kinetic（运动的）、cinema 同源。电影被命名为"运动的艺术"，因为它的本质就是让静止的画面动起来。同根词还有 cinema 的兄弟 kinesiology（运动机能学）。
- **fiction** — 来自拉丁语 fingere（塑造、捏造），词根与 figure（形象）、feign（假装）同源。fiction 字面是"被捏塑出来的东西"，如同陶匠抟土成形。小说家用文字"捏造"世界，与雕塑家用石头"塑形"共享同一个动作。
- **perform** — 来自古法语 parfornir，由 par-（彻底，源自拉丁语 per-）+ fornir（提供、完成）构成，字面是"彻底做完"。它和 furnish（提供、布置）同源。perform 不只是登台演出，更是"把一件事自始至终完成"。
- **publish** — 来自拉丁语 publicare，词根 publicus（公共的）意为"使之公之于众"。public、republic（共和国，字面"公共事务"）都源于此。出版，在词源里就是"把私下的文字交给公众"——一次从私人到公共的跨越。
