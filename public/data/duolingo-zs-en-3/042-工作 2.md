# Unit 042: 工作 2

> 用序数词表达顺序

## 单词

because, building, change, check, companies, company, early, finish, first, floor, hard, have, having, later, learn, message, next year, schedule, second, send, speak, speaking, third, where, why, work for, work from home, writing

## 单元讲解

本单元将工作场景进一步细化，涉及描述公司楼层、日程安排、发送消息以及居家办公等现代职场话题。你会学习如何有条理地说明顺序和原因。

语法重点是序数词（first, second, third）表达顺序，以及 because 引导原因状语从句。序数词前通常加 the（the first floor, the second building），用于描述楼层、步骤或时间排列。同时，work for 与 work from home 展示了介词搭配如何改变动词短语的含义。

词汇可按功能分组：序数与顺序词（first, second, third, early, later）；办公场所与组织（building, floor, company, companies）；沟通动作（send, speak, speaking, writing, message, check）；以及工作方式（work for, work from home, schedule）。

学完本单元，你能用英语描述"我在第几层工作""因为……所以……"以及日常办公沟通的基本流程。

## Tips

- **company** — 来自拉丁语 com-（一起）+ panis（面包），字面意思是"一起吃面包的人"。古罗马军队中，同帐共食的士兵组成一个 companio。从"共食者"到"商业组织"，这个词记录了人类协作从餐桌走向写字楼的漫长历程。复数 companies 去 y 变 ies 是英语拼写规则。
- **schedule** — 来自拉丁语 schedula，是 scheda（小纸条）的指小形式，源自希腊语 skhedē（纸莎草纸的一页）。中世纪学者将待办事项写在小纸片上，schedule 从"小纸条"演变为"时间表、日程"。美式发音 /ˈskedʒuːl/ 保留了 sk- 的希腊痕迹，英式 /ˈʃedjuːl/ 则走了法语化路线。
- **floor** — 源自古英语 flōr，与德语 Flur（走廊、门厅）同源，原始日耳曼语 *flōruz 意为"平坦的表面"。在英语中 floor 既指"地面"也指"楼层"，而德语中 Floor 仅指地面，楼层用 Stock（层）或 Etage（来自法语）。the first floor 在美式英语指一楼，在英式英语指二楼——这一差异常令学习者困惑。
- **message** — 来自古法语 message，源自拉丁语 missus（被派出的人），是 mittere（发送）的过去分词。中世纪的 message 不是"信息"本身，而是"被派出去传话的信使"。从"人"到"人所携带的内容"，语义经历了转喻。send a message 保留了最原始的"派遣"意象。
- **because** — 由 by + cause 复合而成，字面意思是"由于那个原因"。14 世纪进入英语时写作 bi cause，最初是介词短语（because of），后来语法化为连词直接接从句。这是英语中典型的"短语词汇化"现象——两个独立词逐渐融合为一个不可分割的语法单位。
- **building** — 来自古英语 byldan（建造），与 bold（大胆的）同源，原始日耳曼语 *budlą 意为"住所"。building 作名词时指"建筑物"，作动名词时指"建造的过程"。注意 -ing 形式在此兼具名词和动词性质：The building is tall（名词）/ Building a house takes time（动名词）。
