# Unit 111: 开学

> 进行返校购物

## 单词

back-to-school, best, bottom, calf, case, certainly, comic, crayon, cute, gym, haircut, half price, look nice, lunch box, pack, perfume, piece, prefer, receipt, round, ruler, running shoes, sale, scene, school, school uniform, scissors, skate, sort, square, supply, support, top, union, which

## 单元讲解

本单元围绕返校购物这一真实场景展开：新学期开始前，学生和家长需要采购文具、校服、运动鞋等各类用品。对话中会涉及挑选商品、询问价格折扣、表达个人偏好等交际环节。

语法上，本单元重点训练 prefer 和 which 引导的选择疑问句，以及 half price、sale 等购物高频表达。形容词如 round、square、cute 用来描述物品外观，帮助学习者做出具体描述和比较。

词汇可按功能分组：文具类（crayon, ruler, scissors, comic）、服饰类（school uniform, running shoes）、购物用语（half price, sale, receipt, pack）以及描述性词汇（cute, round, square, best）。这些词共同构成一次完整的购物对话所需的语料。

学完本单元，你能用英语完成一次返校采购对话：询问价格、表达偏好、确认尺寸和形状。

## Tips

- **receipt** — 来自古法语 receite，原意是"收到的东西"，源自拉丁语 recepta（被接收的）。中世纪商人将交易凭证称为"收据"，因为它证明买方"收到了"货物。注意 receipt 中的 p 不发音，这与同源的 recipe（处方、食谱）形成有趣对比——两者都来自拉丁语 recipere（接收），但走了不同的语义路径。

- **scissors** — 来自古法语cisoires，最终源自拉丁语 caedere（切割）。英语中 scissors 始终以复数形式出现，因为剪刀由两片刀刃组成。类似的还有 pants、glasses。有趣的是，拉丁语 caedere 还衍生出 precise（精确的，字面义"预先切好的"）和 decide（决定，字面义"切断犹豫"）。

- **crayon** — 来自法语 crayon，原意是"铅笔"，源自 craie（粉笔），再追溯到拉丁语 creta（白垩土）。最初 crayon 指任何用白垩或炭做的书写工具，后来才专指彩色蜡笔。法语中 crayon 至今仍泛指铅笔，而英语把它窄化为蜡笔——同一个词在英吉利海峡两岸各走了一条路。

- **ruler** — 来自古法语 riule（规则、直尺），源自拉丁语 regula（直木条、规则）。从"一根直的木条"到"测量工具"再到"规则"，语义演变反映了人类用物理标准建立抽象规范的思维过程。同源的 regular（规则的）和 regulate（管理）保留了"使之直、使之正"的核心意象。

- **perfume** — 来自拉丁语 per fumum，字面意思是"通过烟雾"。古人在宗教仪式中焚烧香料，烟气升腾即为 perfumum。这个词记录了香水最古老的用途——不是涂抹身体，而是让香气随烟雾弥漫神殿。法语 parfum 保留了这一形式，英语加上 -e 后拼写更接近拉丁原形。

- **gym** — 是 gymnasium 的缩写，来自希腊语 gymnasion，源自 gymnos（裸体的）。古希腊运动员赤身训练，因此训练场被称为"裸体之所"。从裸体竞技场到现代健身房，词义经历了巨大的文化跨越，但词根忠实地保存了两千多年前地中海阳光下的运动场景。

- **skate** — 来自荷兰语 schaats（冰鞋），原为单数形式，但英语使用者误以为词尾 -s 是复数标记，于是反推出单数 skate。这种"逆构词"现象在英语中并不罕见（如 pea 来自 pease）。荷兰人发明了冰鞋，英语连词带误解一起借了过来。
