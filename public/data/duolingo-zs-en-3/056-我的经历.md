# Unit 056: 我的经历

> 使用现在完成时

## 单词

always, been, been to, for, for a long time, has, have, lived, loved, nationality, nation, never, same, showed, so, stayed, the same, traveled, wanted, worked

## 单元讲解

本单元引入现在完成时（have/has + 过去分词），让你谈论人生经历和持续状态。典型句子如 "I have been to Japan" 或 "She has lived here for a long time"。这是英语时态体系中最重要也最难掌握的一环。

语法核心是 have/has + 过去分词的结构，以及 for + 时间段表示持续。been to 表示"去过某地（已回来）"，与 went to（去了还没回来）形成对比。注意 never 和 always 常与现在完成时搭配，表达"从未"或"一直"。

词汇可分为经历动词类（been, lived, traveled, worked, stayed, showed）、时间标记类（for, for a long time, always, never）和身份类（nation, nationality, same）。nation 和 nationality 共享词根，前者指"国家/民族"，后者指"国籍"。

学完本单元，你能用英语谈论自己的人生经历：去过哪里、做过什么、持续了多久。

## Tips

- **nation** — 来自拉丁语 nātiō，源自 nāscī（出生），字面意思是"出生在一起的一群人"。在罗马时代它指"同族、部落"，中世纪进入法语后变为"国家"。同根词还有 native（本土的）、nature（自然——万物"出生"的方式）。nationality 在 nation 基础上加了 -ality 后缀，从"民族"细化为"法律上的国籍"。
- **been** — be 的过去分词，来自古英语 bēon，与梵语 bhavati（成为）、希腊语 phýein（生长）同源，原始印欧语 *bheue- 意为"存在、生长"。be 动词是英语中最不规则的词：am/is/are/was/were/been/being 七个形式来自三个不同的古英语词根，是千年语言融合的活标本。
- **traveled** — 注意美式拼写 traveled（单 l），英式拼写 travelled（双 l）。这个拼写差异源于 Noah Webster 十九世纪的美国英语改革，他系统性地简化了双写字母。travel 本身来自古法语 travailler（折磨），旅行在词源上就是"受苦"。
- **never** — 由古英语 ne（不）+ ǣfre（永远）缩合而成，字面意思是"永远不"。ǣfre 与 ever 同源。在现在完成时中，never 放在 have 和过去分词之间：I have never been there。这种位置是固定的，不能移到句末。
- **same** — 来自古诺尔斯语 sami，维京人留给英语的又一个基础词。原始日耳曼语 *samaz 与拉丁语 similis（相似的）、梵语 samá 同源。注意 same 前几乎总要加 the：the same，因为"相同"在逻辑上指向特定对象。
- **nationality** — 由 nation + -al（形容词后缀）+ -ity（名词后缀）层层叠加而成。拉丁语 -itas 经法语 -ité 进入英语变为 -ity，表示"……的状态或性质"。类似结构：personal → personality, real → reality。一个词上叠了三层后缀，像地质层一样记录了构词历史。
