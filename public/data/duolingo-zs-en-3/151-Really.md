# Unit 151: Really?

> Surprise: Ask for an explanation

## 单词

all right, anything, be, by the way, can't, care, embarrassed, embarrassing, forgave, forgive, forgiven, forgotten, go on, guess what, have, hold on, impossible, just now, lie, like this, must, no way, old friend, seriously, something, spoken

## 单元讲解

本单元围绕"惊讶与追问"这一日常交际场景展开：朋友突然告诉你一件意想不到的事，你需要表达震惊、要求对方解释。对话中充满了口语化的感叹与追问，如 "No way!" "Seriously?" "Guess what!"，这些都是英语母语者在非正式场合表达惊讶的高频反应。

语法上，本单元重点涉及过去分词的不规则变化（forgive → forgave → forgiven，speak → spoke → spoken）以及 must 表推测的用法（"It must be..."）。同时，embarrassed 与 embarrassing 的 -ed/-ing 形容词对比也是核心难点：前者描述人的感受，后者描述事物的性质。

词汇可分为三组：表达惊讶与追问的口语短语（no way, seriously, hold on, go on）；描述情感状态的形容词（embarrassed, impossible）；以及涉及"原谅"与"遗忘"的动词族（forgive, forgave, forgiven, forgotten）。学完本单元，你能在朋友分享惊人消息时自然地表达震惊并追问细节。

## Tips

- **forgive** — 来自古英语 forgiefan，由 for-（完全、彻底）+ giefan（给予）构成，字面意思是"完全给出"，即放弃追讨对方欠你的情感债务。德语 vergeben、荷兰语 vergeven 保留了相同结构。从"给予"到"宽恕"的语义跳跃，映射了日耳曼文化中"宽恕即赠予自由"的伦理观——你释放了对方，也释放了自己。

- **embarrassed** — 源自西班牙语 embarazada（怀孕的），再追溯到葡萄牙语 embaraçar，由 em-（使）+ baraça（绳索、套索）组成，原意是"被绳索缠住"。想象一个人被绳子绊住、动弹不得、满脸通红的画面——这正是尴尬的身体隐喻。后来 embarazar 在西班牙语中专指怀孕（身体被"束缚"），而英语只保留了"窘迫"义。

- **lie** — 英语中 lie 有两个完全不同的来源：表"躺"的 lie 来自古英语 licgan，与德语 liegen 同源；表"说谎"的 lie 来自古英语 lēogan，与德语 lügen 同源。两个 lie 在中古英语时期恰好合流为同一拼写，造成至今困扰学习者的同形异义现象。

- **impossible** — 来自拉丁语 impossibilis，由 in-（不）+ possibilis（可能的）构成，而 possibilis 来自 posse（能够）。posse 在拉丁语中是"有能力、有力量"的意思，罗马人用它来描述政治权力（potestas 即由此而来）。所以 impossible 的深层含义不仅是"做不到"，更是"没有任何力量能使之实现"。

- **seriously** — 来自拉丁语 serius（严肃的、认真的），经古法语 sérieux 进入英语。在口语中 "Seriously?" 已从字面的"你认真的吗"演变为纯粹的惊讶标记，功能等同于中文的"真的假的？"。这种从疑问到感叹的语用漂移在口语中极为常见，类似的还有 "Really?" 本身。

- **spoken** — speak 的过去分词，来自古英语 specan/sprecan，原始日耳曼语 *sprekaną。注意英语中 speak/spoke/spoken 与德语 sprechen/sprach/gesprochen 的元音交替（ablaut）几乎完全对应——这是印欧语系动词变位最古老的遗产，比任何语法规则都更深层地刻在日耳曼语言的血脉中。

- **no way** — 这个口语短语的完整形式是 "There is no way (that)..."，字面意思是"没有路径"。way 来自古英语 weg，原指物理上的道路。从"没有路可走"到"绝不可能"，是一个从空间隐喻到认知判断的经典映射——人类总是用行走的经验来理解可能性。
