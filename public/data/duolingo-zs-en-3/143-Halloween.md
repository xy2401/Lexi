# Unit 143: Halloween

> Halloween: Ask about someone's preferences

## 单词

Halloween, bat, costume, did, didn't, do, does, doesn't, don't, fashionable, fit, loose, match, shop, so that, tear, tie, tight, tore, torn, tying, witch

## 单元讲解

本单元以万圣节为背景，场景涉及挑选和试穿 costume、讨论衣物是否合身，以及表达个人偏好。你会用到 fit（合身）、tight（紧）、loose（松）来描述穿着感受，用 so that 说明目的，比如 "I chose this costume so that everyone would recognize me."

语法核心是一般现在时的否定与疑问（do/does/don't/doesn't）以及一般过去时（did/didn't, tore/torn）的对比。注意 tear-tore-torn 是不规则动词三态，tie-tying 则是现在分词去 e 加 -ing 的规则变化。

词汇围绕"服装与穿着"展开：costume, fashionable, fit, loose, tight, match 构成描述衣物的核心语义场；tear, tie, torn 描述穿脱动作与衣物状态；witch, bat 则提供万圣节的文化色彩。

学完本单元，你能用英语讨论服装偏好、描述衣物合身程度，并表达选择某样东西的目的。

## Tips

- **Halloween** — 是 All Hallows' Eve 的缩写，即"诸圣节前夕"。hallow 来自古英语 hālig（神圣的），与 holy 同源。凯尔特人的萨温节（Samhain）认为这一夜亡者世界与活人世界的边界最薄，人们点燃篝火、戴上面具驱鬼——这些习俗后来与基督教诸圣节融合，演变为今天的万圣节。
- **witch** — 来自古英语 wicce（女）/ wicca（男），可能与 witan（知道）有关，原意是"有知识的人、智者"。在基督教化之前的盎格鲁-撒克逊社会，wicce 是受人尊敬的草药师和占卜者。中世纪猎巫运动将这个词彻底污名化，"智慧"变成了"邪恶"。
- **costume** — 来自意大利语 costume（风俗、习惯），源自拉丁语 consuetudo（习俗）。最初指一个时代或民族的"典型穿着方式"，后来才专指戏剧或节日中的"戏服、装扮服"。从"日常风俗"到"刻意扮演"，词义经历了一次有趣的反转。
- **fashionable** — 来自拉丁语 factio（制作、行为），经古法语 façon 进入英语。fashion 最初指"制作方式"，14世纪后专指"流行的穿着方式"。fashionable 即"符合当下制作/穿着潮流的"。同根词有 fact（事实，即"已做成之事"）和 factory（工厂，即"制作之地"）。
- **bat** — 这个"蝙蝠"的词源不确定，可能来自中古英语 bakke，与斯堪的纳维亚语有关。万圣节与蝙蝠的联系源于萨温节的篝火——火焰吸引昆虫，昆虫吸引蝙蝠，于是蝙蝠成了这个夜晚的固定意象，与 witch 和 ghost 并列成为万圣节三大符号。
- **tight** — 来自古英语 þēon（拉紧、压缩），与德语 dicht（紧密的）同源。在日耳曼语族中，这个词始终围绕"紧密、无间隙"的核心意象。从描述绳索拉紧，到衣物贴身，再到 tight schedule（紧凑的日程），"紧"的隐喻从物理空间延伸到了时间维度。
- **torn** — 是 tear（撕裂）的过去分词，来自古英语 teran（撕裂、扯碎），与德语 zerren（拉扯）同源，最终追溯到原始印欧语 *der-（剥皮、撕裂）。注意区分 tear（撕裂，/tɛr/）和 tear（眼泪，/tɪr/），它们拼写相同但词源完全不同——眼泪来自古英语 tēar，与拉丁语 lacrima 无关，是日耳曼语独有的词。
