# 拼写规则、例外与词族：陌生词如何查证

> **中心问题**：拼写线索遇到例外或词形变化时，怎样核验陌生词？<br>
> **适用背景**：已了解常见拼读线索。<br>
> **阅读材料**：词族、词典条目、借词及来源录音。<br>
> **篇章边界**：重心是查证流程；词源机制与词重音分别由构词篇和相邻篇解释。



## 1. 词族比孤立单词更有用

拼写的价值之一是把词族连在一起。`sign` 中的 <lexi-notation>`g`</lexi-notation> 不明显，却能在 `signal` 里看见它与发音的联系；`define`、`definition`、`definitive` 也共享可识别的核心。

`A familiar spelling can reveal an unfamiliar member of a word family.`

读术语时尤其值得先认出词根和词尾：`analysis`、`analytical`，`predict`、`prediction`。这能同时帮助辨义、猜重音和记忆。

## 2. 面对新词的阅读顺序

1. 先圈出看起来像词缀、词根或熟悉词族的部分。
2. 按可能的音节切分，找最可能的重音。
3. 用拼写单元而不是单个字母估计元音和辅音。
4. 把词放回句子，看它是不是被弱读、被强调或与下一个词连在一起。
5. 听到可靠读音后，以实际读音为准，并把它和拼写、意义一起记住。

这门课的目标不是让人「按规则拼出所有词」，而是让陌生词不再像一串随机字母：它有结构、有重音、有可验证的读音假设。

## 3. 词尾如何提示读音和词类

词尾经常同时提示构词和重音。`-tion`、`-sion` 常形成名词；`-ity` 会让词尾前的音节成为重要观察点；`-ive`、`-ous` 常出现在形容词中。它们不能机械决定每个词的读音，却能在词典查证前提供可靠的分组线索。

`The pronunciation changes when the word family changes.`

例如 `produce`、`production`、`productive` 共享词族，却会发生重音和元音变化。把它们并排记录，远比把每个词当作独立拼写更容易建立长期记忆。

## 4. 常见拼写线索怎样校验

`-ough`、`ea`、`ch` 等组合有多种读法，正好说明拼写线索不是判决书。面对它们时，可先提出猜读，再用词典音标、可靠朗读或 TTS 校验；校验后把该词放回词族与重音模式，而不是只把「例外」孤立收藏。

`Spelling patterns create expectations, but usage confirms pronunciation.`

## 5. 把例外放进具体的来源

有些例外来自词的借入历史，有些来自语音变化而书写保留，有些是词典转写或口音区别。只是把词贴成“不规则”，无法帮助理解下一次遇到的关系。

但来源不能凭字形编造。读到词源解释时，要查看可靠词典或研究。对当前读音的核验和对历史变化的说明，是两个相关但不相同的证据任务。

## 6. 同形词和新名称要连同语境查

`record` 的名词和动词可能重音不同，拼写本身不足以确定读法。先根据句子判断词类与词义，再核对相应条目。

遇到缩写、产品名或人名时，还要确定作者采用逐字母名称、缩略词读音还是其他习惯。查证记录应包含来源与语境，不能把一次偶然听到的形式当作所有场景的标准。

## 7. 读音查证与继续阅读

现代示范以通用美式为主。遇到口音或词典记号差异，应把词、音标和来源录音一起核对。国际音标表示声音，网页 TTS 不能可靠朗读音标符号本身。
