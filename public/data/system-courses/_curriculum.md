# Lexi 系统课程规划

> **版本**：3.0<br>
> **状态**：七大类目录已接入；已有主题完成首轮正文重构，其余篇章分批编写。<br>
> **配套规范**：正文写作、标签、排版和发布验收见 [`_spec.md`](./_spec.md)。

## 定位与组织

面向中文学习者，建立两条相互连接的学习线：**发音、构词、语法**解释英语本身；**生活、中学、大学、工作**把读者已有的经验、学科知识或职业技能连接到英语中的命名、区分、搭配和表述。后四类是英语材料导读，不从零教授专业技能。

目录采用 **大类 → 系列 → 篇章 → 章节**。每篇解决一个完整的英语理解问题，保持小册子式连续讲解。章节沿着问题、核心关系、对比、材料语言和误读展开；不按单个词或单条规则拆成薄课，也不以术语列表代替讲解。

### 如何读本目录

- 每篇记录所属系列、标题、中心问题、适用背景、目标材料、章节范围、相邻篇章边界和旧课对应关系。
- **所属系列**由上级标题确定；**适用背景**继承系列说明，篇章有额外要求时单独注明。每篇的“问题／材料”“章节／边界”“旧课”补齐其余字段。
- `P`、`V`、`G`、`L`、`S-`、`U-`、`J-` 是本文件内部的规划号，依次对应七大类；不是发布 `id`、`slug`、文件名或进度键。
- “旧课”数字引用末尾的[39 门旧课归属表](#legacy-map)。它表示主题承接或语言规则复用，不代表旧课已覆盖新篇的全部内容，实际拆分、合并与发布范围见末尾的当前发布记录。“无”表示旧目录没有独立对应课。
- 章节范围是连续论述的边界，不是正文已经完成的目录。具体章节可在编写时合并，但中心问题变化须先更新本规划。
- 本目录不预设最终篇数，不要求按全目录顺序阅读。新增或合并篇章以独立阅读任务为依据。

### 共通边界

通用语言规则集中在发音、构词和语法；领域篇通过链接复用。例如公式中的数量表达链接[生活数字篇](#l01)，专业名词形成链接[术语构词篇](#v08)，长句解释链接[从句篇](#g12)，研究证据链接[学术证据篇](#u-a04)。相关知识只解释到足以区分英文说法、读懂材料的程度。

制度、岗位、学历、教材名称和专业分类涉及地区差异时，注明国家、地区、机构或材料语境，不强行与中文名称一一对应。引用材料须核对来源；本文件列出的材料类型是后续选材方向，不是已核验的正文事实或已确定教材。

## 1. 发音

按“认识声音 → 读懂标音 → 建立拼读能力 → 理解连续语流”组织。现代读音以通用美式为主要示范，英式及其他变体明确标注；不把口音差异当作正误差异，也不固定所有口音的音素数量。

### 声音与标音系列

**适用背景**：认识英文字母的中文学习者；不要求语言学基础。材料从字母表、词典条目延伸到录音和发音图示。

<a id="p01"></a>

#### P01 字母、声音、音素与音节：几套系统之间的关系

- **问题／材料**：为什么字母数不等于声音数？读字母名、拼写、音标和音节划分示例，分清四种表示对象。
- **章节／边界**：字母名与读音 → 具体声音与音素 → 音节 → 四套系统对照；音标符号细节交给 [P02](#p02)，拼读规则交给 [P07](#p07)。
- **旧课**：1、21。

<a id="p02"></a>

#### P02 国际音标与词典标音：符号、重音和读音变体

- **问题／材料**：如何用词典标音查证一个词的读音？对读词典发音栏、符号表及美英变体标注。
- **章节／边界**：音位与语音标记 → 元辅音符号 → 重音、音节与变体 → 不同词典的惯例；发音动作交给 [P03](#p03)，口音整体差异交给 [P12](#p12)。
- **旧课**：1、21。

<a id="p03"></a>

#### P03 发音动作：气流、声带、舌位与口型

- **问题／材料**：怎样把发音说明转成可观察的动作？理解口腔图、发音演示及动作描述中的英文名称。
- **章节／边界**：气流 → 声带 → 舌位与唇形 → 动作组合与听感；元音和辅音系统分别在 [P04](#p04)、[P05](#p05) 展开。
- **旧课**：1。

<a id="p04"></a>

#### P04 元音：单元音、双元音与容易混淆的声音

- **问题／材料**：如何听辨、描述容易混淆的元音？结合元音图、词典录音和自然词例，联系舌位与声音变化。
- **章节／边界**：单元音 → 双元音 → 相近声音对比 → 口音相关差异；非重读元音集中在 [P09](#p09)，不靠汉字近似音替代示范。
- **旧课**：1。

<a id="p05"></a>

#### P05 辅音：发音部位、发音方式与清浊

- **问题／材料**：如何读懂辅音表并区分相近声音？使用发音部位图、辅音录音和词首词尾实例。
- **章节／边界**：部位 → 方式 → 清浊 → 易混音与词尾听辨；辅音群交给 [P06](#p06)，语流变化交给 [P10](#p10)。
- **旧课**：1。

<a id="p06"></a>

#### P06 音节与辅音群：英语单词如何组织声音

- **问题／材料**：为什么一个词不能按每个字母逐个加元音读？观察音节标注、词首词尾辅音群和多音节录音。
- **章节／边界**：音节结构 → 辅音组合 → 词尾与词界 → 拼写划分和语音划分；词重音交给 [P09](#p09)，跨词连接交给 [P10](#p10)。
- **旧课**：1、21。

### 拼写与语流系列

**适用背景**：已经能区分字母与声音；可先查阅声音与标音系列。目标是从书面提示走向词典查证和连续语音理解。

<a id="p07"></a>

#### P07 自然拼读：字母组合如何提供读音线索

- **问题／材料**：看到陌生拼写时，怎样提出合理的读音猜测？对照字母组合、词族和录音。
- **章节／边界**：常见字母音 → 元音拼写模式 → 组合与位置 → 规则的适用范围；查证和例外交给 [P08](#p08)，不把拼读写成无例外算法。
- **旧课**：21。

<a id="p08"></a>

#### P08 拼写规则、例外与词族：陌生词如何查证

- **问题／材料**：猜测读音后怎样核验，遇到词形变化怎样修正？结合词典、派生词族和借词拼写实例。
- **章节／边界**：拼写线索 → 例外来源 → 词形与读音变化 → 查词及录音核验；构词结构链接 [V02](#v02)、[V04](#v04)，不在这里重讲词源史。
- **旧课**：21、16。

<a id="p09"></a>

#### P09 词重音与非重读元音

- **问题／材料**：为什么词典读音和逐音节念法不同？观察重音标记、词族录音及非重读音节。
- **章节／边界**：主次重音 → 音节强弱 → 非重读元音 → 词形与重音变化；句子的信息焦点交给 [P11](#p11)，后缀构词交给 [V04](#v04)。
- **旧课**：21、2。

<a id="p10"></a>

#### P10 连读、弱读、同化与省音

- **问题／材料**：为什么录音中的词听起来不像孤立词典读音？对照简短对话、转写与分段音频。
- **章节／边界**：词界连接 → 功能词弱读 → 相邻音影响 → 音的省略与听辨；单词内部结构交给 [P06](#p06)，节奏和语调交给 [P11](#p11)。
- **旧课**：2。

<a id="p11"></a>

#### P11 句子重音、节奏、语调与信息焦点

- **问题／材料**：同一句话怎样通过声音突出不同信息？对读问答、修正、对比和叙述的录音及重音标注。
- **章节／边界**：信息新旧 → 焦点重音 → 节奏分组 → 语调与说话者意图；句法强调链接 [G14](#g14)，不把语调轮廓当作固定情绪标签。
- **旧课**：2、21。

<a id="p12"></a>

#### P12 常见口音与听辨：通用美式为主，明确介绍英式及其他变体

- **问题／材料**：面对不同地区的自然语音，怎样识别同一个词？使用标明来源的多口音录音与词典变体。
- **章节／边界**：示范基准 → 常见元辅音差异 → 重音与语流差异 → 听辨查证；不训练口音模仿，不把某一地区习惯泛化为全部英语。
- **旧课**：1、2、21。

### 历史记音系列

**适用背景**：已理解现代字母、声音与标音的区别，对语言交流史感兴趣。历史材料和现代发音示范分开呈现。

<a id="p13"></a>

#### P13 明清时期的外语记音与拼读方法

- **问题／材料**：现代标音工具普及之前，人们怎样记录、学习异语言声音？候选为《西儒耳目资》《英语集全》的原本、序跋和相关研究。
- **章节／边界**：明代中西语音交流背景 → 清代英语学习材料 → 汉字对音及方言基础 → 早期方法与现代标音比较；不把不同语言、时代的材料合成一套“古代英语音标”。
- **旧课**：无。

编写时逐本记录年代、作者、版本、记录对象、教学用途、语言方向及汉字读音的方言背景。《西儒耳目资》作为明代中西记音交流的候选材料，不能直接称为英语教材；《英语集全》的英语学习语境另行核验。旧对音不能直接按现代普通话解释；缺少音值证据时保留不确定性。早期方法也有自己的体系，比较的是工具和适用条件，不预设“旧方法没有体系”。资料入口：[《西儒耳目资》原文目录](https://ctext.org/library.pl?if=en&remap=gb&res=1537)、[中国人民大学清史研究所相关材料](https://iqh.ruc.edu.cn/old/qdzwgxyj/zwgx_yjqy/my/4745426a3c3b4c0a8c5bfba3de6c9fde.htm)。

## 2. 构词

从“认识一个词”走向“理解一个词族和术语系统”。数字、时间、空间归入生活；具体化学等学科命名归入对应学科，本类负责通用机制。

### 词形与来源系列

**适用背景**：认识基础单词，希望读懂词典、词形变化与陌生词；不要求拉丁语、希腊语或语言学基础。

<a id="v01"></a>

#### V01 词汇的基本单位：单词、词形、词义、词族与语块

- **问题／材料**：学习“一个词”究竟要认识哪些单位？用词典条目、语料句和词族图区分词形、义项及语块。
- **章节／边界**：词与词形 → 义项 → 词族 → 多词表达 → 查词与记录；具体变化交给 [V02](#v02)，搭配语域交给 [V06](#v06)。
- **旧课**：22、16、17。

<a id="v02"></a>

#### V02 屈折与派生：语法变化和造词之间的关系

- **问题／材料**：一个词形是在表达语法关系，还是形成了新词？对照词典词形栏、句子与派生词族。
- **章节／边界**：屈折功能 → 派生意义 → 词类与词义变化 → 同形不同功能；时态、数量规则分别链接 [G06](#g06)、[G03](#g03)。
- **旧课**：16、4、8。

<a id="v03"></a>

#### V03 词根与词源：英语本族词、拉丁与希腊来源、借词

- **问题／材料**：词的来源怎样帮助理解词族，又在哪些地方不能用来猜现代词义？阅读有来源的词源条目及借词例句。
- **章节／边界**：本族词与借词 → 拉丁希腊来源 → 词根关系 → 音形语义变化 → 词源证据；不凭外形编词源，形态规则交给 [V04](#v04)。
- **旧课**：16。

<a id="v04"></a>

#### V04 前缀、后缀与形态变体

- **问题／材料**：怎样拆出可用的构词线索并确认词类和意义？对读派生词条、词族和专业材料中的词形。
- **章节／边界**：前缀意义 → 后缀与词类 → 形态变体 → 组合限制 → 实际词义核验；读音变化链接 [P08](#p08)、[P09](#p09)，学科专用命名留给领域篇。
- **旧课**：16、25。

<a id="v05"></a>

#### V05 复合、转类、缩略、混成与新词

- **问题／材料**：不认识的新表达是怎样造出来的？阅读标题、界面名称、新词词条和缩写说明。
- **章节／边界**：复合结构 → 转类 → 缩略与首字母词 → 混成 → 新词的语境查证；不把所有缩写猜成通用术语，专业命名链接 [V08](#v08)。
- **旧课**：16、18、20。

### 词义与表达系列

**适用背景**：能读简单句，想从“中文释义”走向真实用法。以词典用例、语料片段、不同语域中的完整句子为材料。

<a id="v06"></a>

#### V06 多义、近义、搭配与语域

- **问题／材料**：中文释义接近的词为什么不能随意互换？对照语料搭配、义项和日常／学术／职业句子。
- **章节／边界**：义项与上下文 → 近义边界 → 搭配限制 → 正式程度与语域 → 语块；句法结构链接 [G02](#g02)，不以同义词清单代替分析。
- **旧课**：22。

<a id="v07"></a>

#### V07 核心动词、短语动词与固定表达

- **问题／材料**：熟悉动词加上小词后，怎样读出新的关系和用法？结合对话、说明文件和短语词典。
- **章节／边界**：核心动词意义 → 小词关系 → 整体义与搭配 → 宾语位置 → 固定表达；空间小词可链接 [G10](#g10)，不把所有短语硬还原为方向隐喻。
- **旧课**：17。

<a id="v08"></a>

#### V08 学术和专业术语的形成：名词化、缩写、命名与跨领域词义

- **问题／材料**：怎样识别专业材料中的新名称，避免按日常义误读？观察教材定义、论文缩写表、标准和行业术语。
- **章节／边界**：名词化 → 组合命名 → 缩写首次定义 → 跨领域义项 → 术语版本与语境；化学命名链接 [S-CHEM01](#s-chem01)、[U-CHEM02](#u-chem02)，不代替行业规范。
- **旧课**：16、18、20、24、25。

## 3. 语法

语言对比贯穿各篇：以汉语为主要参照，选择日语、韩语、德语、法语、西班牙语、俄语、阿拉伯语、土耳其语的代表结构。每次对比服务于当前英语问题，不要求先学其他语言。编写时核验具体语言、变体和例句，不把“某语言全都如此”当作规则。

### 句子系统系列

**适用背景**：能识别常见单词，希望建立句子关系；以完整句、对话和教材说明为材料，不以术语背诵为先修。

<a id="g01"></a>

#### G01 从语言对比认识英语：词类、语序、形态与句子关系

- **问题／材料**：不同语言如何表示相似意思，英语依靠什么形式？对读有解释的短句及词形、语序标注。
- **章节／边界**：词类与功能 → 语序 → 形态 → 句子关系 → 汉语主参照和其他语言例证；具体句型进入 [G02](#g02)，不做各国语法概论。
- **旧课**：4—15 的入门关系；没有独立对应课。

<a id="g02"></a>

#### G02 句子成分、基本句型与动词配价

- **问题／材料**：怎样找到句子主干并判断动词要求哪些成分？读取词典动词结构和简单／扩展句。
- **章节／边界**：主谓关系 → 宾语与补语 → 动词配价 → 必需与可选成分 → 基本句型扩展；从句交给 [G12](#g12)，信息语序交给 [G14](#g14)。
- **旧课**：14、15、23。

<a id="g03"></a>

#### G03 名词短语：数量、冠词、限定与修饰

- **问题／材料**：英语怎样确定说的是哪一个、多少个、什么范围的对象？观察对话、物品说明及教材定义中的名词短语。
- **章节／边界**：可数性与数量 → 冠词 → 限定词 → 前后修饰 → 指称范围；代词指代交给 [G04](#g04)，数字读法交给 [L01](#l01)。
- **旧课**：4、5。

## 按阅读问题选路

- **认识英语声音**：[P01](#p01) → [P02](#p02) → 按需读元辅音 → [P07](#p07)、[P08](#p08) → [P10](#p10)、[P11](#p11)。历史篇独立选读，不作为现代发音先修。
- **从熟词到词族**：[V01](#v01) → [V02](#v02)、[V04](#v04) → [V06](#v06)、[V07](#v07)；遇到专业名称再读 [V08](#v08)。
- **读懂句子与段落**：[G01](#g01)、[G02](#g02) → 当前困惑对应的句子篇 → [G12](#g12)、[G15](#g15)。其他语言对比随篇阅读。
- **生活材料**：按账单、日期、地图、就医、旅行或办事材料直接选篇；只在需要时回查语法。
- **英文中学教材**：先读该系列的教材导读，再按当前概念选篇；不用从全部中学科目依次学起。
- **教材到研究文献**：[U-A01](#u-a01) → 相应学科篇的本科／研究生／博士材料层 → 按需回看 [U-A03](#u-a03)、[U-A04](#u-a04)。阅读层不是强制按序的课程链。
- **工作材料**：先按文书问题选共通篇，再查行业篇；工程任务、诊疗、法律判断等专业问题回到对应专业资料。

- [ ] 每篇有独立的英语理解任务，以及背景、材料、章节范围、边界和旧课关系；不是只有术语或学科知识提纲。
