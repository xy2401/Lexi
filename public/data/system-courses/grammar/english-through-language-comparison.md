# 从语言对比认识英语：词类、语序、形态与句子关系

> **中心问题**：汉语熟悉的意思进入英语后，为什么需要不同的词形和句子组织？<br>
> **适用背景**：以汉语为母语，不要求掌握其他外语。<br>
> **阅读材料**：有语境的中英短句、词形与关系标注。<br>
> **篇章边界**：建立比较的方法；具体名词、动词与长句规则由后续篇展开。



## 1. 比较的是表达同一问题的方法

中文“他昨天已经发过报告了”能通过时间词、状态词和语境表达事件关系。英语也表达这些关系，但需要同时观察主语、限定动词和时态体。两种表达不能逐字拼成同一串单位。

语言对比的目的，是发现自己容易省略或误读的形式，不是评判哪种语言更简单。先给出明确情境，再比较各自怎样组织信息。

## 2. 词类与句子功能不是一个维度

一个词属于什么词类，与一个短语在句子里承担什么功能，需要分别判断。名词短语可以作主语、宾语等；一个词类标签本身还不能说明它与动词怎样相连。

`The report surprised Maya.` 中，报告是主语，Maya 是宾语；中文可以用不同的表达组织同一情况。阅读英语时要按原句关系判断，不能只按“通常是谁做动作”猜主语。

## 3. 语序帮助表示关系

`Maya called Leo.` 与 `Leo called Maya.` 使用相同词，却交换了关系。英语默认语序对主语与宾语的判断很重要，但从句、被动、强调等结构还会改变表面排列。

汉语也使用语序，不能把比较简化成“中文没有语法，英语只有语序”。真正有用的问题是：当前句子用哪些明确形式，把对象连接起来？

## 4. 形态把语法信息放到词里

`book` 与 `books`、`walk` 与 `walked` 提醒我们：英语可以在词形上标出数量与语法关系。中文中的对应信息可能出现在数量词、时间词或上下文中。

并不是中文一句没有明显复数词尾，英语就可以把相关形式全部省略。反过来，也不能为了逐项对译，把每个中文“了”都固定写成过去式。先确定含义和视角，再选择英语形式。

## 5. 名词指称需要额外观察

中文“门开着”可以在语境中确定是哪扇门。英语往往需要通过限定方式说明是在引入一个对象，还是指向双方可以识别的对象。`A door is open.` 与 `The door is open.` 的阅读重点不同。

这不是给每个中文名词配一条永久冠词。必须看当前指称、数量与可数性。进入名词短语篇后，会把这些条件放在同一个模型中解释。

## 6. 对照其他语言时控制比较范围

日语、韩语、德语、法语、西班牙语、俄语、阿拉伯语、土耳其语会在后续对照中按具体结构选用。比较时要同时说明例句所属语言、语境与分析层次，不能只用“某语言的语序”概括所有结构。

读者不需要先学这些语言。一个对照只需帮助看清当前英语问题：信息放在词形、词序、功能词还是语境里？具体对照例证经来源核验后逐篇加入，不把陌生语言变成新的记忆负担。

## 7. 阅读路径与规则查证

遇到长句时先找主干与关系；遇到用法选择时再看上下文、语域和作者的表达目的。通用结构可以复用，具体搭配仍需词典与原句支持。
