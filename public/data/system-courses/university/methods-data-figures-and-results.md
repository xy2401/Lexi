# 方法、数据、图表与结果表达

> **中心问题**：怎样把方法、数据、图表和结果读成一条有条件的证据链？<br>
> **适用背景**：理解所在领域的测量或分析方法。<br>
> **阅读材料**：方法段、数据说明、图题、结果和附录。<br>
> **篇章边界**：重点是报告关系和适用条件；具体方法计算由专业材料提供。



## 1. 变量、比较与测量语言

`variable` 是可取不同值的特征；`condition` 指比较情境；`control` 和 `baseline` 提供参照；`confounder` 是可能同时影响两边、从而扰乱解释的因素。

`The analysis controls for age and prior experience.`

测量还要区分 `accuracy`、`precision` 与 `calibration`：接近真实值、重复结果彼此接近、以及对齐已知标准不是同一件事。`uncertainty` 也不等于错误；它说明结果能被报告到多精确的范围。

`The instrument was calibrated before each measurement.`

## 2. 结果、统计与因果的语气

`sample` 是实际观察的一部分，`population` 是想讨论的更大范围。`estimate`、`effect size`、`confidence interval`、`distribution` 和 `median` 在结果段中帮助读者区分大小、差异与不确定范围。

`The estimated effect was small, although the interval excluded zero.`

`is associated with` 和 `correlates with` 只描述关系；`causes`、`leads to` 则是更强的因果主张。读到强动词时，应回头检查方法能否排除合理的替代解释。

## 3. 开放材料与可追溯性

`reproducible` 常指他人能用同一数据和流程得到相同结果；`replicable` 更常指独立研究在新数据或新情境下得到相近发现。`repository`、`metadata`、`license`、`de-identified` 和 `restricted access` 说明材料怎样获得、怎样理解、以及为什么可能不能完全公开。

`The anonymized dataset and analysis code are available in a public repository.`

开放不等于忽略隐私、同意或安全限制。读数据可得性说明时，应同时看材料在哪里、以何种条件取得、是否完整，以及是否足以让读者追溯论文中的主张。

## 4. 方法段说明怎样得到材料

`collected`、`measured`、`estimated`、`computed` 描述不同的获取过程。数据来源、处理步骤与分析方法需要区分：一个值可以先由仪器测量，再通过模型估计另一个量。

`We estimated the parameter from the observed data.` 把 observed data 与 estimated parameter 分开。理解方法时可以按输入、处理、输出记录，但仍要保留假设、对象筛选与条件。

## 5. 读图题，再读图中的数值

图题说明对象与条件，坐标说明变量和单位，图例说明各组线条或符号。只看到曲线上升，还不知道升的是哪个量，也不知道比较条件是否一致。

`Values are shown as means with error bars.` 提醒我们继续查误差条的定义。不能凭图形外观认定它必然是同一种区间；作者或图题的说明决定当前表示方式。

## 6. 结果句与解释句的分工

`We observed an increase...` 报告观察，`This may indicate...` 提出解释。两句可以相邻，却不承担相同的证据地位。读结果时先核对对象、比较、大小和不确定性，再看作者如何解释。

`No difference was detected under these conditions.` 不等于所有条件下都完全相同。保留 detected 与 under these conditions，就能避免把有限实验结果扩展成无条件规律。

## 7. 本科、研究生与博士的阅读层次

本科教材层先读图题、坐标和测量说明，区分输入、操作与报告结果。

研究生专题层核对样本筛选、比较条件、处理步骤和不确定性，联系正文与附录的说明。

博士文献层审查方法选择、替代解释与可追溯材料，判断证据能支持多大范围的主张。

层次表示材料深度和所需背景。已熟悉专题的读者可以直接选读，不必把同一主题按学历重复学习。

## 8. 体裁查证与相邻篇章

具体教材、期刊和机构可以采用不同结构。先看原材料的作者指南与目录，再使用本系列的阅读关系；格式名称不能替代实际段落的功能。
