# 复合、转类、缩略、混成与新词

> **中心问题**：陌生表达怎样通过复合、转类和缩略形成，如何确认它的实际用法？<br>
> **适用背景**：能读简单句并识别常见词类。<br>
> **阅读材料**：标题、界面名称、复合词与缩写首次定义。<br>
> **篇章边界**：解释通用造词方式，不为所有行业缩写编制清单。



## 1. 复合、转类、截短与混成

英语造词不只依赖词缀：

- 复合：`database / greenhouse / user-friendly`
- 转类：`to email / a download / to bottle`
- 截短：`lab` ← `laboratory`
- 混成：`brunch` ← `breakfast + lunch`
- 首字母形式：`NASA / API / URL`

复合词重音和拼写会变化：两个词、连字符或一个词并不总由统一规则决定。新词往往经历拼写竞争，需查目标领域的惯例。

---

## 2. 复合词怎样确定中心

`notebook`、`school bus` 和 `coffee shop` 都让两个熟悉部分建立新关系。理解时先判断整个表达指向什么类型的对象，再判断前面的部分是在说明用途、材料、地点还是其他关系。

不能把所有名词串都逐词翻成并列名词。书写时连写、分写或使用连字符又受惯例影响，需要以具体词条和材料为准。

## 3. 转类需要句子提供证据

`email` 可以命名一种信息，也可以出现在 `Please email the report.` 这样的动词位置。没有新增后缀，不等于词类不能变化。

读新表达时，查看它后面是否接宾语、是否出现动词形式，或是否受冠词和形容词修饰。这些句法证据比熟悉的中文释义更能说明它在此处承担什么。

## 4. 缩写要先找全称与作用

遇到字母缩写，先找首次定义，再确认它指机构、对象、方法还是指标。相同字母在不同领域可以表示不同概念，不能用自己熟悉的展开方式覆盖当前文档。

逐字母读还是作为一个词读，属于具体缩写的使用习惯。全文有定义，不代表读法也能从字母自动推断；重要名称应查来源录音或作者说明。

## 5. 截短和混成不总能完整还原

新词可以缩短已有形式，也可以融合多个部分。`brunch` 是常见混成词，实际使用时作为完整词理解，不需要在每次阅读中重新拆成一顿早餐和一顿午餐。

认识形成方式有助于理解来源，却不能单凭来源预测所有语境。一个新词是否已经成为通用词、是否只限某个社群，还需查当前材料和词典。

## 6. 新词的语域与可迁移性

产品名称、社区简称和行业新词常有明确使用范围。在某份文档里已经定义清楚，未必适合直接用于面向所有人的邮件。

记录新词时保留全称、来源、读法和一个原句。表达时再根据读者背景决定是否解释。造词机制帮助读懂创新形式，沟通仍需要共享语境。

## 7. 查证词形与用法

构词线索先帮助提出假设，再由词典义项、词类和语境确认。词族中的成员需要分别观察搭配与语域，不把切分结果直接当作翻译。
