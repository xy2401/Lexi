# 数字与数学表达

> **导读**：英语数字在日常交流、听力理解与专业文献中应用广泛。本课通过**基数词三列表格规律对照**、**三位分节大数读法**以及**四则运算常用句型**，系统梳理数字与算术的英文表达方式。

---

## 一、 基数词规律对比：个位 / 十几 / 几十

英语数字中，`-teen`（十几）和 `-ty`（几十）在拼写与发音上具有明显的对应规律。通过**三列表格对照**可清晰掌握构词与发音差异：

### 1. 核心基数词三列表格对照

| 个位数 (1-9) | 十几 (-teen: 重音在后) | 几十 (-ty: 重音在前) | 发音与拼写要点 |
| :--- | :--- | :--- | :--- |
| `1` `one` | `11` `eleven` | `10` `ten` | 特殊词汇，单独记忆 |
| `2` `two` | `12` `twelve` | `20` `twenty` | 均以 `tw-` 开头（同源词根） |
| `3` `three` | `13` `thirteen` | `30` `thirty` | 词根变异为 `thir-`，注意 `/θɜː/` 咬舌发音 |
| `4` `four` | `14` `fourteen` | `40` `forty` | **注意拼写**：`fourteen` 保留 `u`，而 `forty` 没有 `u` |
| `5` `five` | `15` `fifteen` | `50` `fifty` | 词根变异为 `fif-`（`five` → `fif`） |
| `6` `six` | `16` `sixteen` | `60` `sixty` | 规则变化：直接加 `-teen` 或 `-ty` |
| `7` `seven` | `17` `seventeen` | `70` `seventy` | 规则变化：直接加 `-teen` 或 `-ty` |
| `8` `eight` | `18` `eighteen` | `80` `eighty` | 词尾已有 `t`，直接加 `-een` 或 `-y` |
| `9` `nine` | `19` `nineteen` | `90` `ninety` | 规则变化：直接加 `-teen` 或 `-ty`（保留 `e`） |

> [!TIP]
> **-teen 与 -ty 的听音辨析要领**：
> - **-teen（十几）**：重音在后，尾音拉长，发清晰长音 `/tiːn/`；
> - **-ty（几十）**：重音在前，尾音急促短弱，日常口语中常弱化为轻快的 `[ti]` 或 `[di]`。

## 二、 大数读法：三位分节逗号法则

中文以**四位**（万、亿）为一个分阶单位，而英语以**三位**（每三个数位加一个逗号 `,`）为分阶单位：

> **三位一节对应口诀**：  
> 从右向左每 3 位加一个逗号 `,`，每个逗号对应一个进阶单位：  
> - **第 1 个逗号 `,`** → `thousand` (千)  
> - **第 2 个逗号 `,`** → `million` (百万)  
> - **第 3 个逗号 `,`** → `billion` (十亿)  
> - **第 4 个逗号 `,`** → `trillion` (万亿)

| 数位单位 | 英文表达 | 对应数值 | 示例读法 |
| :--- | :--- | :--- | :--- |
| 百 | `hundred` | 100 | `three hundred` (300) |
| 千 | `thousand` | 1,000 | `five thousand` (5,000) |
| 百万 | `million` | 1,000,000 | `twelve million` (12,000,000) |
| 十亿 | `billion` | 1,000,000,000 | `two billion` (2,000,000,000) |
| 万亿 | `trillion` | 1,000,000,000,000 | `one trillion` (1,000,000,000,000) |

> [!WARNING]
> `hundred`, `thousand`, `million`, `billion` 前面有具体数字修饰时，**通常不加复数 -s**：  
> - 正确：`five thousand people` (5,000人)  
> - 仅在表示“成千上万”的不确定泛指时，才加 -s 并搭配 of：`thousands of people`。

### 大数读法示例

- `385`  
  → `three hundred and eighty-five`
- `2,450`  
  → `two thousand four hundred and fifty`
- `1,234,567`  
  → `one million two hundred thirty-four thousand five hundred sixty-seven`

## 三、 序数词、分数、小数与百分比

### 1. 序数词构成规则与对照表

> **速记口诀**：  
> **“一二三单独记，八去 t 九去 e，ve 换 f 再加 th，几十变 y 为 ie 再加 th；几十几只变个位！”**

| 数值 (基数词) | 序数词 (Ordinal) | 缩写形式 | 构词变化要领与变异点 |
| :--- | :--- | :--- | :--- |
| `1` `one` | <code class="ord-special">first</code> | `1st` | **独立特殊词**：取词尾 `st` |
| `2` `two` | <code class="ord-special">second</code> | `2nd` | **独立特殊词**：取词尾 `nd` |
| `3` `three` | <code class="ord-special">third</code> | `3rd` | **独立特殊词**：取词尾 `rd` |
| `4` `four` | `fourth` | `4th` | 常规：直接加 `-th` |
| `5` `five` | <code class="ord-variant">fifth</code> | `5th` | **特殊变异**：`five` 的 `ve` 变为 `f`，加 `-th` |
| `6` `six` | `sixth` | `6th` | 常规：直接加 `-th` |
| `7` `seven` | `seventh` | `7th` | 常规：直接加 `-th` |
| `8` `eight` | <code class="ord-variant">eighth</code> | `8th` | **特殊变异**：末尾已有 `t`，直接加 `-h`（省 t） |
| `9` `nine` | <code class="ord-variant">ninth</code> | `9th` | **特殊变异**：去掉不发音的 `e`，加 `-th` |
| `10` `ten` | `tenth` | `10th` | 常规：直接加 `-th` |
| `11` `eleven` | `eleventh` | `11th` | 常规：直接加 `-th` |
| `12` `twelve` | <code class="ord-variant">twelfth</code> | `12th` | **特殊变异**：`twelve` 的 `ve` 变为 `f`，加 `-th` |
| `13` `thirteen` | `thirteenth` | `13th` | 常规：直接加 `-th` |
| `20` `twenty` | <code class="ord-variant">twentieth</code> | `20th` | **特殊变异**：`twenty` 变 `y` 为 `ie`，加 `-th` |
| `21` `twenty-one` | <code class="ord-special">twenty-first</code> | `21st` | **复合词**：几十几只变个位 (`first`) |
| `30` `thirty` | <code class="ord-variant">thirtieth</code> | `30th` | **特殊变异**：`thirty` 变 `y` 为 `ie`，加 `-th` |
| `100` `hundred` | `hundredth` | `100th` | 常规：直接加 `-th` |

### 2. 分数表达规则

> **构成规则**：分子使用基数词，分母使用序数词；分子大于 1 时，分母序数词需加 `-s`。

- `1/3` → `one-third` 或 `a third`
- `2/3` → `two-thirds`（分子为 2，分母加 s）
- `1/2` → `a half` 或 `one-half`
- `1/4` → `a quarter` 或 `one-fourth`
- `3/4` → `three-quarters` 或 `three-fourths`

### 3. 小数与百分比

- `0.5` → `zero point five` 或 `point five`
- `3.1415` → `three point one four one five`（小数点后逐位单独读出）
- `25%` → `twenty-five percent`
- `0.08%` → `zero point zero eight percent`

## 四、 四则运算与常用数学符号表达

### 1. 加法（Addition: `+`）

- **表达词汇**：`plus`、`and`、`add`，等号用 `equals` 或 `is`
- **例句**：
  - `2 + 3 = 5`  
    → `two plus three equals five`  
    → `two and three is five`
  - `If you add 10 to 20, you get 30.`（10 加 20 等于 30。）

---

### 2. 减法（Subtraction: `-`）

- **表达词汇**：`minus`、`take away`、`subtract`
- **例句**：
  - `10 - 4 = 6`  
    → `ten minus four is six`  
    → `ten minus four equals six`
  - `Subtract 5 from 15, and the result is 10.`（15 减 5 结果为 10。）

---

### 3. 乘法（Multiplication: `×`）

- **表达词汇**：`times`、`multiplied by`、`multiply`
- **例句**：
  - `3 × 4 = 12`  
    → `three times four is twelve`  
    → `three multiplied by four equals twelve`
  - `Multiply 6 by 7, and you get 42.`（6 乘以 7 等于 42。）

---

### 4. 除法（Division: `÷`）

- **表达词汇**：`divided by`、`divide`
- **例句**：
  - `20 ÷ 5 = 4`  
    → `twenty divided by five equals four`  
    → `twenty divided by five is four`
  - `Divide 100 by 10.`（100 除以 10。）

---

### 5. 比较与等式常用符号

| 符号 | 符号名称 | 英文读法 / 表达句型 | 示例 |
| :--- | :--- | :--- | :--- |
| `=` | 等于号 | `equals` / `is equal to` | `x is equal to y` |
| `≠` | 不等于 | `is not equal to` | `a is not equal to b` |
| `>` | 大于号 | `is greater than` | `ten is greater than five` |
| `<` | 小于号 | `is less than` | `three is less than eight` |
| `≈` | 约等于 | `is approximately equal to` | `pi is approximately equal to 3.14` |
