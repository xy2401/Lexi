# Unit 111: 开学

> 进行返校购物

## 单词

back-to-school, best, bottom, calf, case, certainly, comic, crayon, cute, gym, haircut, half price, look nice, lunch box, pack, perfume, piece, prefer, receipt, round, ruler, running shoes, sale, scene, school, school uniform, scissors, skate, sort, square, supply, support, top, union, which

## 单元讲解

本单元围绕"进行返校购物"展开。核心是购物表达：I need to buy school supplies—rulers, scissors, crayons.（我得买学习用品——尺子、剪刀、蜡笔。）、The running shoes are half price!（跑鞋半价！）、Which school uniform do you prefer?（你更喜欢哪套校服？）、Can I have the receipt, please?（请给我收据好吗？）。

词表里有文具词汇（ruler, scissors, crayon, comic）和购物词汇（sale, half price, receipt, pack）。你可以练习：I need a new lunch box. / These look nice—what sort are they? / The case is round. / I certainly need new running shoes for gym.

half price 表示"半价"。prefer 表示"更喜欢"。

## Tips

- **school uniform / supply** — 校服 / 学习用品。搭配：wear a school uniform, school supplies, buy supplies。例句：We have to wear a school uniform. / I bought all my school supplies. 注意 supplies 通常用复数。

- **half price / sale** — 半价 / 打折。搭配：half price, on sale, at half price。例句：The shoes are half price! / Everything is on sale. 注意 half price 可作形容词（a half-price item）或副词。

- **receipt / pack** — 收据 / 包（打包）。搭配：keep the receipt, a receipt for, pack a bag。例句：Can I have the receipt? / I need to pack my lunch box. 注意 receipt 的 p 不发音。

- **ruler / scissors / crayon** — 尺子 / 剪刀 / 蜡笔。搭配：a ruler, a pair of scissors, a box of crayons。例句：I need a ruler and some crayons. / Where are the scissors? 注意 scissors 总是复数（a pair of scissors）。

- **prefer / which** — 更喜欢 / 哪个。搭配：prefer A to B, Which do you prefer? 例句：Which do you prefer—the round case or the square one? / I prefer the blue one. 注意 prefer A to B（不是 ✗ than）。

- **running shoes / gym / skate** — 跑鞋 / 体育馆 / 滑冰。搭配：running shoes for gym, go to the gym, go skating。例句：I need running shoes for gym class. / Let's go skating! 注意 gym = gymnasium 的缩写。

- **lunch box / comic** — 午餐盒 / 漫画。搭配：a lunch box, pack a lunch box, a comic book。例句：I got a new lunch box. / He reads comics at school. 注意 comic book 常缩写为 comic。

- **look nice / cute** — 好看 / 可爱。搭配：look nice on you, a cute design。例句：These shoes look nice! / The lunch box is so cute. 注意 look nice 后面不接名词（主语是物品）。

- **sort / round / square** — 种类 / 圆的 / 方的。搭配：what sort of, a round case, a square ruler。例句：What sort of case do you want? / I prefer the round one. 注意 sort of = kind of。

- **certainly / best** — 当然 / 最好的。搭配：Certainly! / the best price。例句：— Can I help you? — Certainly! / This is the best deal. 注意 Certainly 比 Yes 更正式。

- **bottom / top / case** — 底部 / 顶部 / 盒子。搭配：at the bottom, on top, a pencil case。例句：The receipt is at the bottom of the bag. / My pencil case is full. 注意 case 可指各种"盒/箱"。

- **haircut / perfume / support** — 理发 / 香水 / 支持。搭配：get a haircut, wear perfume, support the team。例句：I got a haircut before school. / She wears perfume. / I support the school union.
