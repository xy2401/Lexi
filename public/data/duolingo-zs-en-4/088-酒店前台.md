# Unit 088: 酒店前台

> 与酒店前台沟通

## 单词

across, activities, another, awful, do, extra, fine, fix, front desk, full, heat, how many, id, include, might, ocean view, off, parking lot, rat, ride, sightseeing, sorry, staff, straw, suitcase, the matter, till, time, toothbrush, toothpaste, type, wake-up call, will, won't

## 单元讲解

本单元围绕"与酒店前台沟通"展开。核心句型包括：What's the matter?（怎么了？）、The heat is off.（暖气关了。）、Could you fix it?（能修一下吗？）、I'd like a wake-up call at seven.（我想要一个七点的叫醒服务。）、Is breakfast included?（包含早餐吗？）。

词表里有酒店词汇（front desk, ocean view, parking lot, wake-up call, staff）和日用品（toothbrush, toothpaste, straw）。你可以练习：The room is full. / I need another toothbrush. / What activities do you offer? / I'd like to go sightseeing.

the matter 表示"问题/麻烦"。might 表示"可能"。won't 表示"不会/不愿"。

## Tips

- **front desk** — 前台。搭配：at the front desk, call the front desk, front desk staff。例句：Please call the front desk. / The front desk is open 24 hours. 注意 front desk 是酒店/办公楼的接待处。

- **wake-up call** — 叫醒服务。搭配：a wake-up call, request a wake-up call, set a wake-up call。例句：I'd like a wake-up call at seven. / Can I get a wake-up call? 注意这是酒店特有服务。

- **ocean view** — 海景。搭配：an ocean view room, a room with an ocean view。例句：I'd like a room with an ocean view. / The ocean view is beautiful. 注意 view 是"景色/视野"。

- **the matter** — 问题、麻烦。搭配：What's the matter? / What's the matter with...? 例句：What's the matter? / What's the matter with the heat? 注意 What's the matter? = What's wrong?

- **fix** — 修理。搭配：fix the heat, fix the problem, Can you fix it? 例句：Could you fix the air conditioning? / The staff will fix it. 注意 fix 比 repair 更口语。

- **include** — 包含。搭配：Is breakfast included? / include activities, included in the price。例句：Is breakfast included? / The price includes parking. 注意 include 和 contain 的区别：include 强调"包含其中一部分"。

- **parking lot** — 停车场。搭配：in the parking lot, a parking lot, free parking lot。例句：Is there a parking lot? / The parking lot is across the street. 注意美式 parking lot = 英式 car park。

- **toothbrush / toothpaste** — 牙刷 / 牙膏。搭配：a toothbrush, some toothpaste, need a toothbrush。例句：I need another toothbrush. / Do you have toothpaste? 注意 toothpaste 不可数。

- **might / won't** — 可能 / 不会。搭配：It might rain. / It won't work. / might be full。例句：The hotel might be full. / The heat won't turn on. 注意 might 表示可能性，won't 表示"不会"或"拒绝"。

- **sightseeing / activities** — 观光 / 活动。搭配：go sightseeing, sightseeing tour, hotel activities。例句：I'd like to go sightseeing. / What activities do you have? 注意 sightseeing 不可数。

- **awful / sorry** — 糟糕的 / 抱歉。搭配：That's awful! / I'm sorry about... / Sorry about the rat! 例句：The room is awful! / I'm sorry, sir. We'll fix it. 注意 awful 比 bad 程度更强。

- **staff / type** — 员工 / 类型。搭配：hotel staff, friendly staff, what type of room。例句：The staff is very helpful. / What type of room would you like? 注意 staff 是集合名词（全体员工）。
