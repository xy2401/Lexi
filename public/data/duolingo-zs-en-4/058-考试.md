# Unit 058: 考试

> 谈论考试经历

## 单词

age, all, answer, art, blackboard, board, did, do, don't worry, eraser, forgot, forgot to, how long, late, lesson, listening, math, on, page, reading, right, speaking, take, to, took, very well, well, word, worry, writing, wrong

## 单元讲解

本单元围绕"谈论考试经历"展开。词表里有学科词（art, math）和语言技能词（listening, reading, speaking, writing），加上考试相关词汇（answer, lesson, page, word, eraser, blackboard）。你可以练习：I took a math test. / The listening part was hard. / I forgot to write my name. / Don't worry! You did very well.

forgot / forgot to 是 forget 的过去式。注意 forget to do（忘记要去做）和 forget doing（忘记做过）的区别：I forgot to bring my eraser.（我忘了带橡皮——没带。）/ I forgot bringing it.（我忘了带过它——带了但忘了。）

how long 问时间长度：How long was the test? / How long did you study? Don't worry 是安慰用语。

## Tips

- **forgot / forgot to** — 忘记了。forget → forgot → forgotten。搭配：forgot my bag, forgot to study, forgot the answer。注意 forget to do（忘记要做）vs forget doing（忘记做过）：I forgot to take the test.（我忘了去考试。）

- **don't worry / worry** — 别担心 / 担心。搭配：Don't worry! / Don't worry about it. / I'm worried about the test. 注意 worry 是动词，worried 是形容词：I worry about exams. / I am worried.

- **listening / reading / speaking / writing** — 四项语言技能。搭配：listening test, reading comprehension, speaking practice, writing skills。注意这些是动名词作形容词：a listening exercise（听力练习）。

- **take / took** — 参加（考试）。take 的过去式是 took。搭配：take a test, take an exam, took a math test。注意"参加考试"用 take（不说 ✗ join a test / ✗ attend a test）。

- **very well / well** — 非常好 / 好。搭配：do very well（考得很好）、speak English well。例句：I did very well on the test. / She speaks English very well. 注意 well 是副词（修饰动词），good 是形容词。

- **blackboard / board** — 黑板。搭配：on the blackboard, write on the board, look at the board。注意现代教室多用 whiteboard（白板），但 blackboard 仍常用。board 更通用，可以指任何板。

- **eraser** — 橡皮擦。搭配：use an eraser, need an eraser。注意美式 eraser = 英式 rubber。但 rubber 在美式英语中有其他含义（橡皮筋/避孕套），所以美式用 eraser 更安全。

- **page / word / answer** — 页 / 单词 / 答案。搭配：on page ten, a new word, the right answer, the wrong answer。注意 page 前用 on：on page five。answer 可以是名词也可以是动词。

- **right / wrong** — 正确的 / 错误的。搭配：the right answer, the wrong answer, get it right, get it wrong。例句：Your answer is right. / That's wrong. 注意 right 和 correct 同义，wrong 和 incorrect 同义。

- **how long** — 多久、多长。搭配：How long was the lesson? / How long did the test take? 回答：Two hours. / About forty minutes. 注意 how long 问时间长度，how often 问频率。

- **math / art** — 数学 / 美术。搭配：a math test, an art class, math teacher。注意 math 是美式（mathematics 的缩写），英式用 maths。art 可以指美术也可以泛指艺术。

- **late** — 迟到的、晚的。搭配：be late for, arrive late, too late。例句：I was late for the test. / Don't be late! 注意 late 前不加介词：✗ I arrived in late → ✓ I arrived late。
