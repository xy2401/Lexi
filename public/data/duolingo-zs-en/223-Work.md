# Unit 223: Work

> Work: Explain qualifications

## Tips

"Deadline"这个词的起源令人不寒而栗。美国内战期间，南方战俘营（如佐治亚州的安德森维尔监狱）在地面画了一条线，任何越过这条线的囚犯会被立即射杀——这条线就叫"dead line"（死亡线）。战后，这个词被新闻界借用，指报纸排版的最后期限——错过deadline，新闻就"死"了。如今deadline是职场中最常见的压力来源，但比起它的原始含义，今天的deadline已经温和太多了。

"Qualification"来自拉丁语"qualis"（什么样的）和"facere"（使成为），即"使某人具备某种品质"。中世纪大学中，学生必须通过一系列"qualifications"才能获得学位——先是文法、修辞、逻辑（三艺），再是算术、几何、天文、音乐（四艺）。这"七艺"构成了中世纪教育的全部。如今qualification泛指一切资质证明，从学历证书到职业资格证。

"Flexibility"来自拉丁语"flectere"（弯曲）。在古罗马，"flexibilis"形容柳条——能弯曲而不断裂。这个比喻完美地描述了职场中"灵活性"的含义：不是软弱，而是能够适应变化而不折断。2020年全球疫情后，"flexibility"成为职场最热门的词汇之一——弹性工作制、远程办公、灵活工时，工作形态发生了百年未有的变革。

"Deserve"来自拉丁语"deservire"（彻底服务），由"de-"（完全）和"servire"（服务）构成。一个人"deserve"某样东西，意味着他通过"完全的服务"赢得了它。这个概念与"entitle"（使有资格）不同：entitle强调权利，deserve强调付出。在英语职场文化中，"I deserve a raise"（我应该加薪）比"I'm entitled to a raise"更强调个人贡献，语气也更为自信。

- "as far as I'm concerned"表达个人立场，比"I think"更坚定：就我而言/在我看来
- "come up with"意为"想出（主意、方案）"，是职场头脑风暴中的高频短语
- "figure out"比"understand"更强调"经过思考后弄明白"的过程
- "without a doubt"是最高程度的肯定表达，比"certainly"和"definitely"语气更强
