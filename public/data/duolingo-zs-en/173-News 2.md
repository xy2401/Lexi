> News: Check if information is true

## 单元讲解

本单元围绕"核实新闻信息是否属实"展开。话题涉及社会公共事务：政治、法律、灾难、战争与和平。I wonder if the news is true—has the army really won the battle?（我想知道这新闻是不是真的——军队真的赢了那场战役吗？）The mayor said there's been progress against pollution, but I wonder if the majority supports the new law.（市长说治污有进展，但我想知道多数人是否支持新法律。）

词表里有大量社会/政治词汇：army, battle, defeat, mayor, law, political, society, peace。也有社会议题词：pollution, poverty, charity, disaster, rescue。wonder / wonder if / wondered 是本单元的核心表达——表示"想知道、怀疑"，用来对信息提出温和的质疑：I wondered if the report was fair.（我当时在想那份报道是否公正。）

recently 和 mainly 是副词，帮助限定信息范围：Recently, there has been a disaster. The damage was mainly in the north. powerful 可以形容人（a powerful mayor）也可以形容事物（a powerful army）。

## Tips

- **wonder / wonder if / wondered** — wonder 表示"想知道"，比 ask 更委婉。wonder if + 从句 = 想知道是否：I wonder if it's true. wondered 是过去式，用于转述当时的想法：I wondered if he was fair. 注意 wonder if 和 wonder whether 可互换。

- **army / battle / defeat** — army 是陆军/军队。battle 是战役（比 war 规模小）。defeat 可作动词（击败）也可作名词（失败）：The army defeated the enemy. / They suffered a defeat. 注意 defeat 作名词时搭配 suffer a defeat 或 a defeat for。

- **mayor / law / political** — mayor 是市长（注意 mayor 的发音：/ˈmeɪər/，不是"马约尔"）。law 是法律。political 是形容词，名词是 politics，人是 politician。注意 political 和 politician 在英语中有时带负面含义。

- **pollution / poverty / charity** — 三个社会议题词。pollution 来自 pollute + -ion。poverty 是贫困，搭配 in poverty / poverty line。charity 是慈善机构/慈善行为：donate to charity。

- **fair / true / mainly** — fair 含义丰富：公平的、合理的、尚可的。true 搭配 come true（实现）/ Is it true that...? mainly = 主要地，同义词 mostly：The audience was mainly students.

- **majority / society / progress** — majority 是多数，搭配 the majority of：The majority of people support the law. society 是社会。progress 是不可数名词：make progress（不能说 make a progress）。

- **disaster / rescue / recently** — disaster 是灾难。rescue 可作动词（营救）或名词（救援）：a rescue team. recently = 最近，常与现在完成时搭配：There has been a disaster recently.

- **powerful / support / peace** — powerful = 有权势的/强大的。support 可作动词或名词：support the mayor / show support. peace 搭配 in peace / at peace / peace treaty（和平条约）。
