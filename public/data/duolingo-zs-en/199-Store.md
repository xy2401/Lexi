# Unit 199: Store

> Store: Request help with returns

## 单元讲解

本单元的主题是"退换货与售后服务"。词表可以分成三组：衣物细节词（bra, button, collar, silk, stripe, pattern, thick, label, diamond）、退换流程词（return, exchange, replace, money back, store credit, damaged, stain, still, off）、以及礼貌请求用语（would, wouldn't）。拼起来就是售后场景：I would like to return this shirt. It has a stain on the collar and the button is off. Can I get my money back, or would store credit work?

语法主线是 would like 的礼貌请求：I would like to return this.（我想退这个。）比 I want 客气得多，是服务场景的标准开场。另一条主线是退换概念的区分：return 退货；exchange 换货（换另一件）；replace 更换（商家补发）；money back 退款；store credit 店内抵用金。这四个词决定了你能拿到什么结果，是售后对话的核心词汇。off 在本单元表"脱落"：The button is off.（扣子掉了。）

学完这些词，你能用英语礼貌地要求退货、换货或退款，描述商品的瑕疵，并理解商家的补偿方案。

## Tips

- **would / wouldn't** — 礼貌请求骨架。would like to + 动词原形：I would like to exchange this.（我想换这个。）wouldn't 表委婉否定：I wouldn't wear this.（我不会穿这个。）would 比 want 更适合服务场景。

- **return / exchange / replace** — 售后三动词。return 退货（拿回钱或抵用金）；exchange 换货（换成别的尺码/款式）；replace 更换（店家给新的）：replace the damaged item. 三者都接被处理的物品作宾语。

- **money back / store credit** — 两种退款方式。money back 现金退回：get your money back（拿回钱）；store credit 店内抵用金，只能在该店消费。商家常用 store credit 代替退款，听清区别很重要。

- **damaged / stain** — 瑕疵两词。damaged 损坏的：The package is damaged.；stain 污渍，名词动词皆可：There is a stain on the collar.（领子上有污渍。）

- **button / collar / bra / silk** — 衣物部位与材质。button 纽扣：The button is off.（扣子掉了。）；collar 衣领；bra 内衣；silk 丝绸：a silk shirt（真丝衬衫）。

- **stripe / pattern / thick / label** — stripe 条纹：a striped shirt 常说 a shirt with stripes；pattern 图案；thick 厚的，与 thin（薄）相对；label 标签、吊牌：Keep the label on.（保留吊牌。）退货常要求标签完好。

- **off / still** — off 本单元表"脱落、离开"：The button is off. / Take the label off.；still 仍然：Is it still available?（还有货吗？）两词都是高频小品词。

- **diamond** — "钻石"：a diamond ring（钻戒）。贵重商品的退换常需要收据（receipt）。构词上来自拉丁语，意为"不可征服的"。

<quiz-sentence-builder>

1. **中文**：我想退这件衬衫。
   **英文**：I would like to return this shirt.
   > **解析**：would like to + 动词原形是礼貌请求句型；this shirt 是 return 的宾语。

2. **中文**：领子上有一处污渍。
   **英文**：There is a stain on the collar.
   > **解析**：there is 表示"有"；on the collar 是地点状语。

3. **中文**：扣子掉了。
   **英文**：The button is off.
   > **解析**：off 作表语表示"脱落"；is 与单数主语搭配。

4. **中文**：这件商品损坏了。
   **英文**：The item is damaged.
   > **解析**：is damaged 表示状态；damaged 由过去分词转化为形容词。

5. **中文**：我能换一件吗？
   **英文**：Can I exchange it for another one?
   > **解析**：Can I 表请求；exchange A for B 表示"用 A 换 B"。

6. **中文**：我想换成大一号的。
   **英文**：I'd like to exchange it for a larger size.
   > **解析**：I'd like = I would like；for a larger size 表示换成大号。

7. **中文**：你们能更换损坏的商品吗？
   **英文**：Could you replace the damaged item?
   > **解析**：Could you 是委婉请求；the damaged item 是宾语。

8. **中文**：我能拿回我的钱吗？
   **英文**：Can I get my money back?
   > **解析**：get my money back 是固定表达；back 是副词，表示"退回"。

9. **中文**：我们提供店内抵用金。
   **英文**：We offer store credit.
   > **解析**：offer 是及物动词；store credit 是不可数名词短语。

10. **中文**：吊牌还在上面吗？
   **英文**：Is the label still on?
   > **解析**：still 强调"仍然"；on 作表语表示"在上面"。

11. **中文**：这是真丝的。
   **英文**：This is silk.
   > **解析**：silk 是不可数名词，作表语；is 与单数主语搭配。

12. **中文**：这件外套太厚了。
   **英文**：This coat is too thick.
   > **解析**：too 修饰形容词 thick；is 与单数主语搭配。

13. **中文**：我喜欢条纹图案。
   **英文**：I like the stripe pattern.
   > **解析**：stripe 作定语修饰 pattern；like 是及物动词。

14. **中文**：这是钻石戒指。
   **英文**：This is a diamond ring.
   > **解析**：diamond 作定语修饰 ring；ring 是可数名词，用 a。

15. **中文**：标签上写着什么？
   **英文**：What does the label say?
   > **解析**：does 是第三人称单数疑问助动词；say 用原形。

16. **中文**：我不会穿这件的。
   **英文**：I wouldn't wear this.
   > **解析**：wouldn't 后接动词原形 wear；表委婉的否定意愿。

17. **中文**：请把标签取下来。
   **英文**：Please take the label off.
   > **解析**：take off 是动词短语"取下"；宾语 label 放中间。

18. **中文**：这件还能换吗？
   **英文**：Can this still be exchanged?
   > **解析**：can be exchanged 是被动语态；still 表示"仍然"。

19. **中文**：收据在这里。
   **英文**：The receipt is here.
   > **解析**：is 与单数主语搭配；here 是副词作表语。

20. **中文**：我要退货。
   **英文**：I want to make a return.
   > **解析**：want 后接不定式；make a return 是退货的名词化表达。
