# Unit 199: Store

> Store: Request help with returns

## 单元讲解

本单元围绕"请求退换货帮助"展开，场景是服装店或百货商店的售后服务。词表里有服装部件（button, collar, stripe, pattern, silk, bra, thick）和退换货表达（return, exchange, replace, money back, store credit, damaged, stain）。

你可以练习售后对话：I'd like to return this shirt—it has a stain. / Can I exchange it for a different pattern? / The collar is damaged; I want my money back. / Would you replace the button, or should I get store credit? / I wouldn't buy silk without checking the label.

would / wouldn't 在这里用于礼貌请求和假设。still 表示"仍然"。off 可以表示"折扣"（20% off）或"脱落"（The button came off.）。

## Tips

- **return / exchange / replace** — return = 退货（I want to return this.）。exchange = 换货（exchange it for a bigger size）。replace = 替换（replace the damaged item）。三者是售后场景的核心动词，注意 exchange 强调"以旧换新"，replace 强调"补一个新的"。

- **money back / store credit** — money back = 退款（I want my money back.）。store credit = 商店抵用金（不给现金，只能在本店消费）。搭配：get a refund / get store credit。注意很多店只给 store credit 不给 cash back。

- **damaged / stain / label** — damaged = 损坏的（The item is damaged.）。stain = 污渍（There's a stain on the collar. / a coffee stain）。label = 标签（Check the label for washing instructions.）。

- **button / collar / stripe / pattern** — button = 纽扣（The button came off.）。collar = 衣领。stripe = 条纹（a striped shirt）。pattern = 图案、花样（a floral pattern）。搭配：a shirt with stripes, a checkered pattern。

- **silk / thick / bra** — silk = 丝绸（a silk dress, silk is delicate）。thick = 厚的（thick fabric），反义词 thin。bra = 胸罩（brassiere 的缩写）。注意 silk 做面料不可数。

- **would / wouldn't / still / off** — would 用于礼貌请求（Would you help me?）和假设（I would return it.）。wouldn't = would not。still = 仍然（It's still damaged.）。off 可表折扣（30% off）或脱离（fall off, come off）。

- **diamond** — diamond = 钻石，也可指菱形图案。搭配：a diamond ring, a diamond pattern。注意发音 /ˈdaɪmənd/，重音在第一个音节。

1. **中文**：夹克袖口上的纽扣松了，需要缝一下。
   **英文**：He lost a plastic button from his winter shirt.
   > **解析**：button 表示“纽扣/按钮”。

2. **中文**：这件正式衬衫的衣领挺拔干净。
   **英文**：The white shirt collar was neat and clean.
   > **解析**：collar 表示“衣领/领子”。

3. **中文**：包裹到达时，里面的外包装箱已经损坏的。
   **英文**：The store replaced the damaged electronic goods.
   > **解析**：damaged 表示“损坏的/受损的”。

4. **中文**：戒指上镶嵌了一颗闪闪发光的钻石。
   **英文**：She wore a ring with a sparkling diamond.
   > **解析**：diamond 表示“钻石”。

5. **中文**：如果尺码不合身，你可以在店内调换其他尺码。
   **英文**：Can I exchange this sweater for a larger size?
   > **解析**：exchange 表示“调换/交换”。

6. **中文**：清洗前请仔细阅读服装洗涤标签上的说明。
   **英文**：Check the care label on clothing before washing.
   > **解析**：label 表示“标签/牌子”。

7. **中文**：商家承诺如果不满意可享受全额退钱保修。
   **英文**：The shop offers a full money back guarantee.
   > **解析**：money back 表示“退钱/退款”。

8. **中文**：这块面料上印着精美的复古花卉图案。
   **英文**：She likes the colorful pattern on the silk scarf.
   > **解析**：pattern 表示“图案/花纹”。

9. **中文**：店家同意免费为你更换受损的零部件。
   **英文**：We will replace your broken device free of charge.
   > **解析**：replace 表示“更换/替换”。

10. **中文**：请在三十天内凭发票将商品退货。
   **英文**：Customers can return unused items within a month.
   > **解析**：return 表示“退货/返回”。

11. **中文**：这领带是由高档纯天然丝绸制作而成的。
   **英文**：The elegant dress was made of smooth Italian silk.
   > **解析**：silk 表示“丝绸”。

12. **中文**：白衬衫上沾了一块难以清洗的茶水污渍。
   **英文**：Use detergent to remove the coffee stain on shirt.
   > **解析**：stain 表示“污渍/印迹”。

13. **中文**：退货时商家退还了五十美元的商店代金券。
   **英文**：I accepted store credit instead of cash refund.
   > **解析**：store credit 表示“商店代金券/购物金”。

14. **中文**：运动衫上设计有两道黑白相间的条纹。
   **英文**：The shirt features vertical blue and white stripe.
   > **解析**：stripe 表示“条纹”。

15. **中文**：冬天地板上铺了一层厚厚的手工羊毛毯。
   **英文**：Wear a thick coat during the cold winter months.
   > **解析**：thick 表示“厚的/粗的”。

16. **中文**：我非常乐意在明天下午陪你去商场购物。
   **英文**：I would like to return this defective product.
   > **解析**：would 表示“会/愿意”。

17. **中文**：如果不合适，商家绝不会拒绝退换的。
   **英文**：They wouldn't charge extra for exchanging items.
   > **解析**：wouldn't 即 would not。

18. **中文**：这件商品现在正在以半价折扣出售。
   **英文**：Get twenty percent off on selected items today.
   > **解析**：off 表示“折扣/减价/关掉”。

19. **中文**：尽管已经过了一周，我仍然保留着购物发票。
   **英文**：She still has the original receipt for warranty.
   > **解析**：still 表示“仍然/还”。

20. **中文**：这位女士在内衣店选购了一件合身的文胸。
   **英文**：She bought a supportive sports bra for running.
   > **解析**：bra 表示“文胸/胸罩”。
