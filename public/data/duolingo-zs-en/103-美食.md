## 单元讲解

本单元围绕"讲述一次吃饭的经历"展开。核心是餐厅用餐表达：We were going to book a table, but it was sold out.（我们本来想订位，但已经满了。）、The main course was salmon with cream sauce.（主菜是奶油酱三文鱼。）、The service was horrible.（服务太糟糕了。）、I was going to try the spicy curry.（我本来想尝辣咖喱的。）。

词表里有食物词汇（salmon, steak, curry, mushroom, omelet, yogurt）和餐厅词汇（buffet, brunch, main course, service, sold out）。你可以练习：The steak was too spicy. / We had champagne and toast for brunch. / The mango jam was delicious. / I felt sick after the seafood.

was/were going to 表示"本来打算"（但没做成）。sold out 表示"售罄"。

## Tips

- **was going to / were going to** — 本来打算。搭配：was going to do, were going to eat。例句：I was going to order steak, but it was sold out. / We were going to book a table. 注意表示"计划了但没实现"。

- **main course / course** — 主菜 / 一道菜。搭配：the main course, a three-course meal, first course。例句：The main course was salmon. / We had a three-course meal. 注意 course 在餐饮中指"一道菜"。

- **buffet / brunch** — 自助餐 / 早午餐。搭配：a buffet lunch, all-you-can-eat buffet, have brunch。例句：We had a seafood buffet. / Let's have brunch on Sunday. 注意 brunch = breakfast + lunch（10-14点）。

- **sold out / book** — 售罄 / 预订。搭配：sold out, book a table, book in advance。例句：The steak was sold out. / We should have booked a table. 注意 book 在餐厅语境中是"预订"。

- **salmon / steak / seafood** — 三文鱼 / 牛排 / 海鲜。搭配：grilled salmon, a steak, fresh seafood。例句：The salmon was delicious. / I ordered a steak. / The seafood was fresh. 注意 salmon 的 l 不发音。

- **spicy / curry / sauce** — 辣的 / 咖喱 / 酱。搭配：too spicy, a spicy curry, cream sauce。例句：The curry was too spicy for me. / I love the cream sauce. 注意 spicy = hot（辣），不是"香料多"。

- **service / horrible / sick** — 服务 / 糟糕的 / 恶心。搭配：the service was bad, horrible service, feel sick。例句：The service was horrible. / I felt sick after eating. 注意 horrible 比 bad 程度更强。

- **champagne / toast** — 香槟 / 吐司（祝酒）。搭配：a glass of champagne, make a toast, toast and jam。例句：We had champagne at brunch. / Let's make a toast! 注意 toast 可指"吐司面包"也可指"祝酒"。

- **cream / yogurt / jam** — 奶油 / 酸奶 / 果酱。搭配：cream sauce, a cup of yogurt, strawberry jam。例句：The cream sauce was rich. / I had yogurt with mango. / Toast with jam, please.

- **omelet / mushroom / garlic** — 煎蛋卷 / 蘑菇 / 大蒜。搭配：a cheese omelet, mushroom soup, garlic bread。例句：I had an omelet for brunch. / The mushroom sauce was great. / I love garlic bread.

- **mango / lemon / little** — 芒果 / 柠檬 / 一点。搭配：mango jam, a slice of lemon, a little spicy。例句：The mango was sweet. / Add a little lemon. / It's a little spicy. 注意 a little = 一点（肯定），little = 几乎没有（否定）。

- **special / drop / out** — 特色菜 / 掉落 / 外面。搭配：today's special, drop by, eat out。例句：What's today's special? / Let's eat out tonight. / I dropped my fork! 注意 eat out = 外出就餐。
