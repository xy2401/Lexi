## 单元讲解

本单元的主题是"在旅行中交流"，重点是礼貌询问与实际需求。词表分成四组：礼貌表达（do you mind, do you mind if, of course not, if you like, if you want）、必要与选择（can, don't have to, doesn't have to, had to, offer）、旅途设施（ATM, bus station, stairs, stop, closest, double, return, here, anywhere）、以及行程与货币（flight, long, night, tonight, euro, thousand, change, still, get, up to, down, for）。拼在一起，就是一段地道的旅行对话：Where's the closest ATM? Do you mind if I sit here? Of course not.

语法主线有两条。第一条是"不必做某事"：don't have to / doesn't have to 表示"没有必要"——You don't have to pay now.（不必现在付钱。）注意它和 must not（禁止）不同。过去式是 had to（当时不得不）：She had to change her flight. 第二条是 Do you mind...? 礼貌询问，回答同意时说 Of course not（当然不介意）。

学完这单元，你能用英语找 ATM、换钱、问最近的设施、礼貌请求许可，还能讨论航班、车票和房间类型，把旅行中的实际问题逐一解决。

## Tips

- **do you mind / do you mind if / of course not** — 礼貌询问"你介意吗"：Do you mind the noise?（你介意噪音吗？）Do you mind if I sit here?（我坐这儿你介意吗？）注意回答的逻辑：不介意（同意）要说 Of course not 或 Not at all，说 Yes 反而是"我介意"。

- **don't have to / doesn't have to / had to** — "不必"与"不得不"。don't have to 表没有必要：You don't have to hurry.（不必着急。）第三人称单数用 doesn't have to。过去式 had to 表"当时不得不"：He had to change his flight. 注意 ✗ must to → ✓ have to，have to 是 must 的近义表达。

- **where's / closest** — where's 是 where is 的缩写，问地点：Where's the closest ATM?（最近的取款机在哪？）closest 是 close 的最高级"最近的"：the closest bus station（最近的车站）。

- **ATM / euro / thousand / change** — 金融词。ATM 是 automatic teller machine（自动取款机）的缩写。euro 欧元，复数 euros；change 既是动词"兑换、找零"也可作名词零钱：change some money（换钱）。thousand 千，数字后不加 s。

- **can / get / offer** — can 表能力或请求：Can I get a double room?（能给我一间双人房吗？）get 是万能动词"获得"；offer 主动提供：He offered to carry my bag.（他主动提出帮我拿包。）

- **flight / return / long / tonight** — flight 航班；return 可作形容词"返程的"：a return ticket（往返票）；long 形容航班时间长：a long flight（长途航班）；tonight 今晚，直接作时间状语。

- **bus station / stop / stairs / up / down** — bus station 汽车站（较大的枢纽），bus stop 是路边小站。stairs 楼梯：Go up the stairs.（上楼。）up/down 与动词搭配表方向。

- **anywhere / here / if you like / if you want** — anywhere 任何地方：You can sit anywhere.（你随便坐。）here 这里；if you like / if you want 是礼貌的补充语"如果你愿意的话"：We can stop here, if you like.

- **double / still / night / for** — double 双重的：a double room（双人房）；still 仍然：I still have some euros.（我还剩些欧元。）night 夜晚；for 表目的或时间段：for two nights（住两晚）。

<quiz-sentence-builder>

1. **中文**：最近的取款机在哪里？
   **英文**：Where's the closest ATM?
   > **解析**：Where's 是 where is 的缩写；closest 是最高级"最近的"，修饰 ATM。

2. **中文**：我坐这儿你介意吗？
   **英文**：Do you mind if I sit here?
   > **解析**：Do you mind if 是礼貌询问结构；if 引导条件从句，sit 用原形。

3. **中文**：当然不介意。
   **英文**：Of course not.
   > **解析**：Of course not 是固定应答，表示"当然不介意"，同意对方请求。

4. **中文**：你不必现在付款。
   **英文**：You don't have to pay now.
   > **解析**：don't have to 表示"没有必要"；pay 用动词原形。

5. **中文**：他不得不改了航班。
   **英文**：He had to change his flight.
   > **解析**：had to 是 have to 的过去式"不得不"；change 用动词原形。

6. **中文**：我能要一间双人房吗？
   **英文**：Can I get a double room?
   > **解析**：Can 引导请求；a double room 中 double 作定语修饰 room。

7. **中文**：汽车站在街那头。
   **英文**：The bus station is down the street.
   > **解析**：down the street 是"沿着街往前"的习惯表达；is 与单数主语搭配。

8. **中文**：我还剩一些欧元。
   **英文**：I still have some euros.
   > **解析**：still 是副词"仍然"，放在实义动词 have 之前；euros 是 euro 的复数。

9. **中文**：这张票一千欧元。
   **英文**：The ticket is one thousand euros.
   > **解析**：one thousand 后接复数 euros；is 与单数主语 the ticket 搭配。

10. **中文**：我今晚可以帮你。
   **英文**：I can help you tonight.
   > **解析**：can 是情态动词，后接动词原形 help；tonight 作时间状语。

11. **中文**：上楼梯。
   **英文**：Go up the stairs.
   > **解析**：祈使句以 Go 开头；up the stairs 表示"上楼梯"。

12. **中文**：他主动提出帮我拿包。
   **英文**：He offered to carry my bag.
   > **解析**：offered 是 offer 的过去式；offer to + 动词原形表示"主动提出做某事"。

13. **中文**：你可以随便坐。
   **英文**：You can sit anywhere.
   > **解析**：can 表允许；anywhere 作地点副词，表示"任何地方"。

14. **中文**：这是往返票吗？
   **英文**：Is this a return ticket?
   > **解析**：疑问句把 is 提前；return 作定语修饰 ticket，表示"返程的"。

15. **中文**：这是一趟长途航班。
   **英文**：It is a long flight.
   > **解析**：It 作主语用 is；long 作定语修饰 flight。

16. **中文**：公共汽车站就在旅馆附近。
   **英文**：The bus stop is near the hotel.
   > **解析**：The bus stop 是单数主语，用 is；near the hotel 是地点状语。

17. **中文**：如果你愿意，我可以和你一起去。
   **英文**：If you want, I can go with you.
   > **解析**：If you want 是礼貌的条件短语；主句用 can + 动词原形。

18. **中文**：如果你愿意，我们可以在这里停一下。
   **英文**：If you like, we can stop here.
   > **解析**：If you like 是礼貌补充语；we can stop 中 can 后接动词原形。

19. **中文**：她今晚不必来。
   **英文**：She doesn't have to come tonight.
   > **解析**：doesn't have to 表示"不必"（第三人称单数）；come 用动词原形。

20. **中文**：你介意噪音吗？
   **英文**：Do you mind the noise?
   > **解析**：Do you mind 后直接接名词 the noise；这是一般疑问句。
