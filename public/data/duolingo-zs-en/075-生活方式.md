## 单元讲解

本单元的主题是"谈论生活方式"，核心是关心自己和别人的身心状态。词表分成四组：健康习惯（get some sleep, get some fresh air, go for a walk, before bed, enough, for too long, get sick, get）、情绪与感受（feel, upset, mad, laugh, talk, thirsty, what's wrong with）、身体与日常（mouth, neck, makeup, sit, stand, jump, heavy, lazy）、以及天气与程度（storm, wind, strong, really, loud, when, if）。拼在一起，就是一段关心朋友的对话：What's wrong with you? You should get some sleep. Let's go for a walk.

语法主线是 get + 名词/形容词构成的生活化短语：get some sleep（睡一会儿）、get some fresh air（呼吸新鲜空气）、get sick（生病）——get 表示"获得"或"变得"。另一条主线是 if 与 when 引导的条件/时间从句：If you are tired, get some sleep.（如果累了就睡会儿。）注意条件从句中用现在时表将来。

学完这单元，你能用英语关心别人的状态、给生活建议、描述天气对身体的影响，也能表达自己开心、生气或口渴等各种感受。

## Tips

- **what's wrong with** — 关心他人的固定问句：What's wrong with you?（你怎么了？）回答可以说 I feel upset. 或 My neck hurts. 类似表达：What's the matter?

- **get some sleep / get some fresh air / get some sleep 等 get 短语** — get + 名词表示"获得"：get some sleep（睡一觉）、get some fresh air（透透气）；get + 形容词表示"变得"：get sick（生病）、get mad（生气）。get 是英语中最高频的万能动词之一。

- **go for a walk / sit / stand / jump** — 动作词。go for a walk 散步，是"go for a + 名词"结构，类似 go for a run（去跑步）。sit 坐、stand 站、jump 跳：Stand up and jump!

- **before bed / for too long / enough** — 时间表达。before bed 睡前：Brush your teeth before bed. for too long 太久：Don't sit for too long. enough 足够，作副词时放形容词后：good enough（足够好）。

- **feel / upset / mad / thirsty** — 感受词。feel 是系动词"感觉"，后接形容词：I feel thirsty. upset 心烦的、难过的；mad 生气的（口语）；thirsty 口渴的。注意 ✗ I feel thirstily → ✓ I feel thirsty，系动词后接形容词。

- **laugh / talk** — 社交动作。laugh 大笑：Laugh more!（多笑笑！）talk 交谈：talk with friends（和朋友聊天）。laugh 与 smile 的区别：laugh 出声笑，smile 微笑。

- **storm / wind / strong** — 天气词。storm 暴风雨；wind 风；strong 形容风力大：The wind is really strong. 习惯表达：weather the storm（渡过难关，字面"经受住风暴"）。

- **heavy / lazy / loud / really** — heavy 重的，也形容食物"油腻难消化"：heavy food（厚重的食物）；lazy 懒惰的：Don't be lazy! loud 大声的：The music is too loud. really 是程度副词"真的、非常"：really strong（非常强）。

- **mouth / neck / makeup** — 身体与装扮。mouth 嘴；neck 脖子：My neck hurts.（我脖子疼。）makeup 化妆品、化妆：put on makeup（化妆）。makeup 由 make + up 构成，字面"装扮起来"。

- **if / when / and / at** — if 引导条件句"如果"：If you are tired, rest. when 引导时间句"当……时"：When you are thirsty, drink water. and 连接并列成分；at 表示时间点或地点：at night（在夜里）。

<quiz-sentence-builder>

1. **中文**：你怎么了？
   **英文**：What's wrong with you?
   > **解析**：What's wrong with 是关心他人的固定问句；with 后接 you 表示询问对象。

2. **中文**：你应该睡一会儿。
   **英文**：You should get some sleep.
   > **解析**：should 后接动词原形 get；get some sleep 是"睡一觉"的固定搭配。

3. **中文**：我们去公园散步吧。
   **英文**：Let's go for a walk in the park.
   > **解析**：Let's 后接动词原形；go for a walk 是"去散步"的固定结构。

4. **中文**：每天早上呼吸些新鲜空气。
   **英文**：Get some fresh air every morning.
   > **解析**：祈使句以 Get 开头；get some fresh air 是"透透气"的固定搭配。

5. **中文**：别坐太久。
   **英文**：Don't sit for too long.
   > **解析**：否定祈使句用 Don't + sit；for too long 表示"太久"，作时间状语。

6. **中文**：睡前刷牙。
   **英文**：Brush your teeth before bed.
   > **解析**：祈使句以 Brush 开头；before bed 是时间状语"睡前"。

7. **中文**：今天风真的很大。
   **英文**：The wind is really strong today.
   > **解析**：The wind 是单数主语，用 is；really 修饰形容词 strong。

8. **中文**：暴风雨要来了。
   **英文**：A storm is coming.
   > **解析**：现在进行时 is coming 表示即将发生；A storm 是可数名词单数。

9. **中文**：她今天感觉很沮丧。
   **英文**：She feels upset today.
   > **解析**：She 是第三人称单数，feel 加 s；upset 作表语表示感受。

10. **中文**：暴风雨之后他病了。
   **英文**：He got sick after the storm.
   > **解析**：got 是 get 的过去式；get sick 表示"生病"，after the storm 是时间状语。

11. **中文**：他为什么对我生气？
   **英文**：Why is he mad at me?
   > **解析**：Why 问原因，is 提前；mad at somebody 是"对某人生气"的固定搭配。

12. **中文**：口渴的时候喝水。
   **英文**：Drink water when you are thirsty.
   > **解析**：when 引导时间状语从句；主句是祈使句 Drink water。

13. **中文**：睡前别吃太油腻的食物。
   **英文**：Don't eat heavy food before bed.
   > **解析**：否定祈使句；heavy 作定语修饰 food，before bed 是时间状语。

14. **中文**：多笑，多和朋友聊天。
   **英文**：Laugh and talk with your friends.
   > **解析**：两个祈使动词 laugh 和 talk 由 and 并列；with your friends 表示对象。

15. **中文**：站起来跳一跳！
   **英文**：Stand up and jump!
   > **解析**：stand up 是"起立"的短语动词，与 jump 由 and 并列。

16. **中文**：她每天早上化妆。
   **英文**：She puts on makeup every morning.
   > **解析**：She 是第三人称单数，put 加 s；put on makeup 是"化妆"的固定搭配。

17. **中文**：我的脖子疼。
   **英文**：My neck hurts.
   > **解析**：My neck 是第三人称单数主语，hurt 加 s 表示"疼痛"。

18. **中文**：如果你累了，就睡一会儿。
   **英文**：If you are tired, get some sleep.
   > **解析**：If 引导条件从句，从句用现在时；主句是祈使句 get some sleep。

19. **中文**：音乐太吵了。
   **英文**：The music is too loud.
   > **解析**：The music 是单数主语，用 is；too 修饰形容词 loud 表示"太吵"。

20. **中文**：别偷懒！起来活动活动。
   **英文**：Don't be lazy! Get up and move.
   > **解析**：否定祈使句用 Don't be + 形容词；Get up and move 是两个并列的祈使动词。

> **解析**：What's wrong with 是固定问句"……怎么了"；at 和 if 都不构成这个搭配。

### 2

You should get some ____.

- [x] sleep
- [ ] storm
- [ ] heavy

> **解析**：get some sleep 是"睡一会儿"的固定搭配；storm 和 heavy 语义不符。

### 3

- [x] for
- [ ] at
- [ ] if

> **解析**：go for a walk 是"去散步"的固定结构；at 和 if 都不能构成这个搭配。

### 4

Get some fresh ____ every morning.

- [x] air
- [ ] mouth
- [ ] makeup

> **解析**：fresh air 是"新鲜空气"的固定搭配；mouth 和 makeup 语义不符。

### 5

Don't sit ____ too long.

- [x] for
- [ ] if
- [ ] really

> **解析**：for too long 表示"太久"，for 引导时间段；if 和 really 都不能表示时长。

### 6

Brush your teeth before ____.

- [x] bed
- [ ] wind
- [ ] jump

> **解析**：before bed 是"睡前"的固定表达；wind 和 jump 都不表示就寝。

### 7

- [ ] laugh

> **解析**：wind 用 strong 形容"风大"；makeup 是名词，laugh 是动词。

- [ ] thirsty

> **解析**：A 后需要名词 storm"暴风雨"；neck 语义上不会"来临"，thirsty 是形容词。

- [x] feels

> **解析**：She 是第三人称单数主语，feel 加 s；feeling 不能单独作谓语。

### 10

- [x] sick
- [ ] talk
- [ ] mouth

> **解析**：get sick 是"生病"的固定搭配；talk 是动词，mouth 是名词，都不能与 got 构成这个表达。

### 11

- [x] at

### 12

- [x] when
- [ ] storm

### 13

- [ ] jump

> **解析**：food 前需要形容词 heavy"油腻厚重的"；get 和 jump 是动词。

### 14
