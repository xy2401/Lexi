## 单元讲解

本单元围绕"谈论生活方式"展开。核心是健康建议的表达：You should get some fresh air.（你应该呼吸新鲜空气。）、Get some sleep!（去睡会儿！）、Go for a walk.（去散散步。）、Don't sit for too long.（别坐太久。）。

词表里有身体部位（mouth, neck）和感受词（thirsty, upset, mad, lazy）。你可以练习：What's wrong with you? I feel thirsty. / You look upset. / Don't be lazy—go for a walk! / The wind is really strong.

if 引导条件句：If you sit for too long, you'll get sick. what's wrong with 询问状况。

## Tips

- **get some fresh air / get some sleep** — 呼吸新鲜空气 / 睡会儿。搭配：go outside and get some fresh air, get some sleep before bed。例句：You look tired—get some sleep! / Go get some fresh air.

- **go for a walk** — 去散步。搭配：go for a walk, take a walk。例句：Let's go for a walk after dinner. / She goes for a walk every morning. 注意 go for a walk = take a walk。

- **for too long** — 太久。搭配：sit for too long, wait for too long, stay for too long。例句：Don't sit for too long. / I waited for too long. 注意 too long 表示"过长"（否定意味）。

- **get sick** — 生病。搭配：get sick, don't get sick, might get sick。例句：You'll get sick if you don't rest. / I don't want to get sick. 注意 get sick 强调"变得生病"（过程），be sick 强调状态。

- **thirsty** — 渴的。搭配：feel thirsty, I'm thirsty, thirsty for water。例句：I'm really thirsty. / Are you thirsty? 反义词 hungry（饿的）。注意 thirsty 也可以比喻"渴望的"：thirsty for knowledge。

- **upset / mad** — 心烦的 / 生气的。搭配：feel upset, get mad, upset about。例句：She's upset about the storm. / Don't be mad! 注意 mad 在美式口语中 = angry。upset 程度较轻。

- **lazy** — 懒惰的。搭配：don't be lazy, a lazy day, feel lazy。例句：Don't be lazy—go for a walk! / I feel lazy today. 反义词 hardworking（勤奋的）。

- **what's wrong with** — ……怎么了？搭配：What's wrong with you? / What's wrong with your neck? 例句：What's wrong with you? You look upset. 注意比 What's wrong? 更具体（with + 对象）。

- **strong / heavy** — 强的 / 重的。搭配：strong wind, heavy rain, a heavy storm。例句：The wind is really strong. / There was a heavy storm last night. 注意 wind 用 strong，rain 用 heavy。

- **storm / wind** — 暴风雨 / 风。搭配：a big storm, strong wind, windy。例句：There's a storm coming. / The wind is strong today. 注意 storm 包含风、雨、雷等。

- **before bed** — 睡前。搭配：before bed, before going to bed。例句：Get some sleep before bed. / I read before bed. 注意 before bed = before bedtime = before going to sleep。

- **laugh / jump / sit / stand** — 笑 / 跳 / 坐 / 站。搭配：laugh at, jump up, sit down, stand up。例句：She laughed at his joke. / Don't just sit there—stand up and go for a walk!
