# Unit 072: 工作 4

> 在工作场合向人求助

## 单词

anybody, ask for, broken, business, by, complete, could, customer, daily, discuss, discussion, email, everybody, good job, help, help with, how, hurry, machine, meeting room, might, must, regular, several, sir, somebody, thing, to, try, unfortunately, weekly, with, work

## 单元讲解

本单元围绕"在工作场合向人求助"展开。核心句型包括：Could you help me with this?（你能帮我处理这个吗？）、I need to ask for help.（我需要求助。）、The machine is broken.（机器坏了。）、We must complete this by Friday.（我们必须在周五前完成。）。

词表里有职场词汇（customer, meeting room, email, business）和频率词（daily, weekly, regular）。你可以练习：I have a meeting in the meeting room. / Send an email to everybody. / Good job! / Unfortunately, the machine is broken.

must 表示"必须"（比 should 更强）。might 表示"可能"。unfortunately 表示"不幸地"。

## Tips

- **could / might / must** — 能够 / 可能 / 必须。搭配：Could you help? / It might rain. / You must finish. 注意语气强度：must > should > could。might 表示可能性较小：It might work.

- **help with / ask for** — 帮忙处理 / 请求。搭配：help me with this, ask for help, ask for advice。例句：Could you help me with this email? / Don't be afraid to ask for help.

- **broken** — 坏了的。搭配：a broken machine, broken window, It's broken。例句：The machine is broken. / My phone is broken. 注意 broken 是形容词（来自 break 的过去分词）。

- **daily / weekly / regular** — 每天的 / 每周的 / 定期的。搭配：daily meeting, weekly report, regular customer。例句：We have a daily meeting. / She is a regular customer. 注意 -ly 在这里是形容词后缀（不是副词）。

- **customer / sir** — 顾客 / 先生。搭配：a regular customer, help the customer, Excuse me, sir。注意 sir 用于礼貌称呼男性（服务行业常用）。对应女性用 ma'am / madam。

- **meeting room** — 会议室。搭配：in the meeting room, book a meeting room。例句：The meeting is in the meeting room. / Let's go to the meeting room. 注意 meeting room 是复合名词。

- **discuss / discussion** — 讨论。搭配：discuss the problem, have a discussion, discuss with。例句：Let's discuss this in the meeting. / We had a long discussion. 注意 discuss 是动词，discussion 是名词。

- **complete** — 完成。搭配：complete the task, complete by Friday。例句：We must complete this by tomorrow. 注意 complete 比 finish 更正式。complete 强调"做完全部"，finish 强调"结束"。

- **unfortunately** — 不幸地、遗憾的是。搭配：Unfortunately, ... / Unfortunately, the machine is broken。例句：Unfortunately, we can't help you today. 注意 unfortunately 通常放在句首，后接逗号。

- **good job** — 做得好！搭配：Good job! / do a good job。例句：Good job on the presentation! / You did a good job. 注意 good job 是口语中的表扬用语。正式场合用 well done。

- **several / everybody / anybody** — 几个 / 每个人 / 任何人。搭配：several things, everybody knows, Does anybody have...? 注意 several = a few（几个）。everybody / anybody 后接单数动词：Everybody is here.

- **try** — 尝试。搭配：try to do, try doing, try again。例句：Try to complete it by five. / I'll try. 注意 try to do（努力去做）和 try doing（试着做做看）的细微区别。
