## 单元讲解

本单元的主题是"在工作场合向人求助"，词汇围绕办公室场景展开。词表分成四组：求助与请求（help, help with, ask for, could, might, must, try, hurry）、办公室事务（work, business, email, meeting room, machine, complete, discuss, discussion）、频率与规律（daily, weekly, regular, several）、以及人物与评价（anybody, everybody, somebody, customer, sir, good job, unfortunately）。拼在一起，就是一套典型的职场求助对话：Could you help me? The machine is broken. Unfortunately, everybody is busy.

语法主线是情态动词三兄弟的分工：could 用于礼貌请求（Could you help me?），might 表示可能性或更委婉的请求，must 表示必须（Everybody must complete the work.）。另一条主线是不定代词：somebody（某人）、anybody（任何人，多用于疑问和否定）、everybody（每个人），它们都按第三人称单数对待：Everybody is here.

学完这单元，你能用英语在工作中礼貌求助、描述设备故障、安排日常工作、感谢同事，还能主持简单的讨论。

## Tips

- **help / help with / ask for** — 求助核心。help 直接加宾语：Could you help me? help with 说明求助的内容：I need help with this machine. ask for 是"索要、请求"：She asked for a meeting. 注意 help 后的 to 可省略：help me (to) fix it。

- **could / might / must** — 三个情态动词。could 是 can 的委婉形式，礼貌请求首选：Could you help me? might 表可能性"也许"：It might rain. must 表"必须"，语气最强：You must finish it today. 三者后面都接动词原形。

- **anybody / somebody / everybody** — 不定代词三兄弟。somebody 用于肯定句（Somebody sent you an email），anybody 用于疑问和否定（Can anybody help me?），everybody 指所有人（Everybody is here）。注意它们作主语时谓语用单数。

- **broken / machine** — broken 是 break 的过去分词，作形容词表示"坏掉的"：The machine is broken. machine 机器，常说 coffee machine（咖啡机）、washing machine（洗衣机）。构词上 -ine 来自拉丁语，如 engine 也同源。

- **complete / work / business** — complete 是"完成"，比 finish 更正式：Complete the form. work 既是"工作"也是"干活"：I must work today. business 生意、业务：a business meeting（商务会议）。注意 business 的拼写：busy → busi + ness。

- **email / meeting room** — email 电子邮件，可作名词也可作动词：I emailed him.（我给他发了邮件。）meeting room 会议室，是 meeting（会议）+ room（房间）的复合词。

- **discuss / discussion** — discuss 是动词"讨论"，直接接宾语：We discussed the plan. ✗ discuss about → ✓ discuss，不要加 about。discussion 是名词形式（discuss + -ion）：have a discussion。

- **daily / weekly / regular / several** — 频率词。daily 每天的，weekly 每周的（day/week + -ly 变形容词）：a daily meeting, a weekly report. regular 定期的、常规的：a regular customer（常客）。several 几个的，修饰复数名词：several customers.

- **customer / sir / good job** — customer 顾客（custom 原义"习惯"→"光顾"）；sir 是对男士的尊称"先生"，服务场合常用；good job 是表扬用语"干得好"，也可以说 well done。

- **unfortunately / hurry / try / how / by** — unfortunately 是"不幸的是"，常用于句首报坏消息：Unfortunately, the machine is broken. hurry 催促：Hurry up! try 是"尝试"：Try again. how 问方式；by 表截止时间：Complete this by Friday.（周五前完成。）

<quiz-sentence-builder>

1. **中文**：你能帮帮我吗？
   **英文**：Could you help me, please?
   > **解析**：Could 引导礼貌请求，help 用原形；please 放句末加强礼貌。

2. **中文**：我需要帮忙处理这台机器。
   **英文**：I need help with this machine.
   > **解析**：help with 表示"在……方面帮忙"，with 后接 this machine。

3. **中文**：每个人都必须完成工作。
   **英文**：Everybody must complete the work.
   > **解析**：Everybody 是不定代词，作主语按单数对待；must 后接动词原形 complete。

4. **中文**：机器坏了。
   **英文**：The machine is broken.
   > **解析**：The machine 是单数主语，用 is；broken 作形容词表示"坏掉的"。

5. **中文**：有人能帮我吗？
   **英文**：Can anybody help me?
   > **解析**：anybody 用于疑问句表示"任何人"；help 用原形。

6. **中文**：她要求开一个每日例会。
   **英文**：She asked for a daily meeting.
   > **解析**：asked 是 ask 的过去式；ask for 是"请求、索要"的固定搭配。

7. **中文**：我们讨论了业务计划。
   **英文**：We discussed the business plan.
   > **解析**：discussed 是 discuss 的过去式；discuss 是及物动词，直接接宾语，不加 about。

8. **中文**：不幸的是，机器又坏了。
   **英文**：Unfortunately, the machine is broken again.
   > **解析**：Unfortunately 是句首副词，用逗号隔开；again 放句末表示"又"。

9. **中文**：试试修理这台机器。
   **英文**：Try to fix the machine.
   > **解析**：祈使句以 Try 开头；try to + 动词原形表示"尝试去做"。

10. **中文**：我怎么发这封邮件？
   **英文**：How do I send this email?
   > **解析**：How 问方式，借助助动词 do 构成疑问句；send 用原形。

11. **中文**：有人给你发了邮件。
   **英文**：Somebody sent you an email.
   > **解析**：Somebody 用于肯定句作主语；sent 是 send 的过去式，后接双宾语 you 和 an email。

12. **中文**：项目干得漂亮！
   **英文**：Good job on the project!
   > **解析**：Good job 是表扬用语；on the project 限定表扬的范围。

13. **中文**：快点！会议九点开始。
   **英文**：Hurry! The meeting starts at nine.
   > **解析**：Hurry 是催促的祈使句；The meeting 是第三人称单数主语，start 加 s。

14. **中文**：他每天为几位顾客服务。
   **英文**：He works with several customers every day.
   > **解析**：He 是第三人称单数，work 加 s；several 修饰复数 customers。

15. **中文**：这是一个例会。
   **英文**：This is a regular meeting.
   > **解析**：This 作主语用 is；regular 作定语修饰 meeting，表示"常规的"。

16. **中文**：我今天必须完成工作。
   **英文**：I must finish the work today.
   > **解析**：must 是情态动词，后接动词原形 finish；today 是时间状语。

17. **中文**：我们能帮你处理这件事吗？
   **英文**：Can we help you with this thing?
   > **解析**：Can 引导疑问句；help somebody with something 是固定结构。

18. **中文**：我们每周都有一次讨论。
   **英文**：We have a discussion every week.
   > **解析**：We 是复数主语，have 用原形；a discussion 是可数名词单数。

19. **中文**：周五之前完成这个。
   **英文**：Complete this by Friday.
   > **解析**：祈使句以 Complete 开头；by Friday 表示截止时间"周五之前"。

20. **中文**：先生，这是您的邮件。
   **英文**：Sir, this is your email.
   > **解析**：Sir 是尊称，用逗号隔开；this 作主语用 is，your 修饰 email。
