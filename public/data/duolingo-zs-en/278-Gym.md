## 单元讲解

本单元的主题是"设定健身目标"。词表可以分成四组：训练项目（cardio, weights, squats, push-up, pull-up, abs, stretch, treadmill）、训练流程（warm-up, cool down, session, trainer）、身体状态（sore, injury, out of shape）、目标与规则（resolution, ground rules, effective, have to, need to, want to, make, get, rather, left）。拼起来就是一段健身计划：My resolution is to get in shape. I need to warm up before every session.

语法主线是"义务表达"的三档语气：have to（客观必须）→ need to（有需要）→ want to（想要）。三者后都接动词原形，但强制程度递减：You have to stretch. / I need to rest. / I want to start. 另一条主线是健身流程词汇的动词短语搭配：warm up（热身）、cool down（放松）、get in shape / out of shape（体形好坏）、make progress（进步）。

学完这单元，你能用英语制定健身计划：说出目标、安排训练内容与流程、描述训练后的身体反应。

## Tips

- **cardio / weights / treadmill** — 训练大类。cardio 是有氧训练（cardiovascular 的缩写）；weights 是力量训练（举重）；treadmill 是跑步机（tread 踩 + mill 磨坊，原义踏车）。

- **squats / push-up / pull-up / abs** — 动作与部位。squats 是深蹲，常用复数；push-up 是俯卧撑（推起）；pull-up 是引体向上（拉起）；abs 是腹肌（abdominal muscles 的缩写），总用复数。push-up / pull-up 带连字符，复数加 s：two push-ups。

- **stretch / warm-up / cool down** — 准备与放松。stretch 是拉伸；warm up 是热身（动词短语），名词写作 warm-up；cool down 是运动后放松。✗ 注意动词短语不带连字符（warm up），名词/形容词带连字符（a warm-up routine）。

- **session / trainer** — 课程两词。session 是一节训练课：a training session。trainer 是健身教练（英式英语；美式多说 personal trainer）。

- **sore / injury / out of shape** — 身体状态。sore 是"酸痛的"：My legs are sore. injury 是受伤：avoid injury。out of shape 是"体形走样、缺乏锻炼"，反义 in shape。

- **resolution / ground rules** — 目标与规则。resolution 是决心/新年目标：a New Year's resolution。ground rules 是基本规则（ground 此处取"基础"义）：Let's set some ground rules.

- **effective** — "有效的"：an effective workout。来自 effect（效果）+ -ive。与 efficient（高效率的）区分：effective 强调"有作用"，efficient 强调"少浪费"。

- **have to / need to / want to** — 义务三档。have to 客观必须：You have to drink water. need to 有需要：I need to stretch. want to 想要：I want to try squats. 三者后都接动词原形，强度递减。

- **make / get / rather / left** — 万能动词组。make progress（取得进步）；get better / get stronger（变得更强）；rather 表偏好：I'd rather do cardio. left 是 leave 的过去式，也可表"剩下的"：I have one set left.（我还剩一组。）

<quiz-sentence-builder>

1. **中文**：我的新年目标是练出好体形。
   **英文**：My resolution is to get in shape.
   > **解析**：resolution 作主语用 is；to get in shape 是不定式作表语。

2. **中文**：我得在每次训练前热身。
   **英文**：I have to warm up before every session.
   > **解析**：have to 后接动词原形 warm up；before every session 是时间状语。

3. **中文**：我需要拉伸一下。
   **英文**：I need to stretch.
   > **解析**：need to 后接动词原形 stretch；主语 I 时 need 用原形。

4. **中文**：我想试试深蹲。
   **英文**：I want to try squats.
   > **解析**：want to 后接动词原形 try；squats 用复数。

5. **中文**：有氧运动对心脏有效。
   **英文**：Cardio is effective for the heart.
   > **解析**：Cardio 作主语用 is；effective 作表语，for 引出对象。

6. **中文**：教练安排了举重训练。
   **英文**：The trainer planned a weights session.
   > **解析**：planned 是过去式；a weights session 中 weights 作定语修饰 session。

7. **中文**：我做了二十个俯卧撑。
   **英文**：I did twenty push-ups.
   > **解析**：did 是 do 的过去式；push-ups 是可数名词复数。

8. **中文**：他只能做三个引体向上。
   **英文**：He can only do three pull-ups.
   > **解析**：can 后接动词原形 do；three pull-ups 作宾语。

9. **中文**：我的腹肌很酸。
   **英文**：My abs are sore.
   > **解析**：abs 是复数，用 are；sore 作表语。

10. **中文**：小心别受伤。
   **英文**：Be careful not to get an injury.
   > **解析**：Be careful 祈使句；not to get 是否定不定式。

11. **中文**：我好久不锻炼，体形走样了。
   **英文**：I'm out of shape because I haven't exercised.
   > **解析**：out of shape 作表语；because 引导原因状语从句，现在完成时 haven't exercised。

12. **中文**：训练后别忘了放松。
   **英文**：Don't forget to cool down after the workout.
   > **解析**：否定祈使句 Don't forget；to cool down 是不定式宾语。

13. **中文**：我们先定一些基本规则。
   **英文**：Let's set some ground rules first.
   > **解析**：let's 后接动词原形 set；ground rules 用复数，first 作状语。

14. **中文**：跑步机上跑了十分钟。
   **英文**：She ran on the treadmill for ten minutes.
   > **解析**：ran 是 run 的过去式；on the treadmill 是地点状语。

15. **中文**：我宁愿做有氧而不是举重。
   **英文**：I'd rather do cardio than lift weights.
   > **解析**：would rather do A than do B 是固定比较结构；两处都用动词原形。

16. **中文**：我在进步。
   **英文**：I'm making progress.
   > **解析**：现在进行时 am making；make progress 是固定搭配。

17. **中文**：我还剩最后一组。
   **英文**：I have one set left.
   > **解析**：left 作后置定语表示"剩下的"；one set 作宾语。

18. **中文**：你必须多喝水。
   **英文**：You have to drink more water.
   > **解析**：have to 表客观必要；more 修饰不可数名词 water。

19. **中文**：这次训练很有效。
   **英文**：This session was very effective.
   > **解析**：was 与 This session 搭配；very 修饰 effective。

20. **中文**：热身包括拉伸。
   **英文**：The warm-up includes stretching.
   > **解析**：warm-up 作名词带连字符；includes 加 s 与单数主语一致，stretching 动名词作宾语。
