## 单元讲解

本单元围绕"讨论名人八卦"展开。核心是名人话题表达：Did you hear? The celebrity got engaged!（你听说了吗？那个名人订婚了！）、To be honest, I think they're attractive together.（说实话，我觉得他们在一起很般配。）、The paparazzi followed them for a mile.（狗仔队跟了他们一英里。）、Who won the prize?（谁得了奖？）。

词表里有名人词汇（celebrity, paparazzi, album, record）和关系词汇（engaged, divorced, fiancé, fiancée）。你可以练习：They got divorced last year. / She's his fiancée. / He won the first prize. / The winner is from the mainland.

fiancé（未婚夫）和 fiancée（未婚妻）拼写不同。to be honest 表示"说实话"。

## Tips

- **celebrity / paparazzi** — 名人 / 狗仔队。搭配：a celebrity, a famous celebrity, the paparazzi。例句：The celebrity was surrounded by paparazzi. / She's a huge celebrity. 注意 paparazzi 是复数（单数 paparazzo）。

- **engaged / divorced** — 订婚 / 离婚。搭配：get engaged, be engaged to, get divorced。例句：They just got engaged! / She got divorced last year. 注意 engaged to（不是 ✗ with）。

- **fiancé / fiancée** — 未婚夫 / 未婚妻。搭配：my fiancé, her fiancée。例句：This is my fiancé, Tom. / Her fiancée is a singer. 注意 fiancé（一个 e）= 男方，fiancée（两个 e）= 女方。

- **to be honest / honest** — 说实话 / 诚实的。搭配：To be honest, ..., an honest person。例句：To be honest, I don't like their music. / He's very honest. 注意 honest 的 h 不发音（用 an）。

- **attractive / handsome** — 有魅力的 / 英俊的。搭配：very attractive, a handsome man。例句：They're both very attractive. / He's so handsome! 注意 attractive 男女通用，handsome 通常形容男性。

- **won / winner / prize** — 赢了 / 获胜者 / 奖品。搭配：won the prize, the winner is, first prize。例句：She won first prize! / The winner is from the mainland. 注意 win → won → won。

- **album / record** — 专辑 / 唱片。搭配：a new album, release an album, a record deal。例句：Their new album is amazing. / The record sold a million copies. 注意 album 和 record 都可指音乐专辑。

- **who / whom** — 谁（主格）/ 谁（宾格）。搭配：Who is that? / To whom...? / Whom did you see? 例句：Who won the prize? / Whom did she marry? 注意 whom 是 who 的宾格（正式用法）。

- **the same / together** — 一样 / 一起。搭配：the same as, together with, get together。例句：They always wear the same thing. / They're together now. 注意 the same 前加 the。

- **polite / luck / soul** — 礼貌的 / 运气 / 灵魂。搭配：be polite, good luck, a kind soul。例句：The celebrity was very polite. / Good luck with the interview! / She's a beautiful soul.

- **straight / mainland / mile** — 直的 / 大陆 / 英里。搭配：straight hair, the mainland, a mile away。例句：She has long straight hair. / He's from the mainland. / The hotel is a mile away.

- **like / first / all** — 像 / 第一 / 所有。搭配：look like, the first time, all of them。例句：What does she look like? / It's their first album together. / All the fans were excited.
