## 单元讲解

本单元的主题是"描述你家有什么"。词表可以分成四组：房间（apartment, bedroom, kitchen, room, bathroom 概念 shower, toilet, garden）、家具与物品（bed, chair, chairs, clock, coffee table, fridge, box, boxes, pot, door, wall, floor）、动物与植物（flower, tree, kitten, fox）、以及存在句型（there is, there are, is there, on, under, clean）。拼起来就能完整描述一个家：There is a bed in the bedroom. There are two chairs in the kitchen. The kitten is under the coffee table.

语法主线是 there is / there are 的"存在句"，表示"某处有某物"。单数或不可数用 there is：There is a fridge. 复数用 there are：There are two boxes. 疑问句把 is/are 提前：Is there a garden? 另一条主线是方位介词 on（在……上面）与 under（在……下面），用于描述物品位置。

学完这单元，你能用英语描述家里的房间布局、家具摆放、宠物和植物。

## Tips

- **there is / there are / is there** — 存在句核心。there is 接单数：There is a clock. there are 接复数：There are three chairs. 疑问把 is/are 提前：Is there a kitchen? 注意 there 只是引导词，真正的主语在其后。

- **on / under** — 一对方位介词。on 在……上面（接触表面）：The box is on the floor. under 在……下面：The kitten is under the bed.

- **bed / bedroom / room / apartment** — 居住空间词。bed 床、bedroom 卧室、room 房间、apartment 公寓。bedroom 是 bed + room 合成词。

- **kitchen / shower / toilet** — 功能区。kitchen 厨房、shower 淋浴/淋浴间、toilet 厕所。搭配 in the kitchen、take a shower。

- **chair / chairs、box / boxes** — 家具与容器，单复数成对入表。chair 椅子（复数 chairs）、box 盒子（复数 boxes，以 x 结尾加 es）。

- **clock / coffee table / fridge / door / wall / floor** — 家具与结构。clock 时钟、coffee table 茶几、fridge 冰箱（refrigerator 的简称）、door 门、wall 墙、floor 地板。

- **garden / tree / flower** — 室外植物与场所。garden 花园、tree 树、flower 花。There are flowers in the garden.

- **kitten / fox** — 动物。kitten 小猫（cat 的幼崽）、fox 狐狸。

- **clean** — 干净的（形容词）：The room is clean. 也可作动词"打扫"：I clean my room.

- **pot** — 花盆/锅：a pot of flowers（一盆花）。与 flower 搭配常见。

- **block** — 街区/积木：a block（一个街区）。

### 1

There ____ a bed in the bedroom.

- [x] is
- [ ] are
- [ ] am

> **解析**：a bed 是单数，用 there is；are 用于复数，am 只与 I 搭配。

### 2

There are two ____ in the kitchen.

- [x] chairs
- [ ] chair
- [ ] a chair

> **解析**：two 后接可数名词复数 chairs；单数 chair 与 two 不符，a chair 与 two 冲突。

### 3

____ there a garden?

- [x] Is
- [ ] Are
- [ ] There

> **解析**：garden 是单数，疑问句用 is 提前；are 用于复数，there 不能构成疑问。
