# Unit 081: 购物 4

> 分享一次购物经历

## 单词

amazing, and, earrings, everything, for free, got, here, how can, hundred, in, large, line, on, on sale, paid, perfect, return, scarf, sell, shop, sixty, size, small, sold, star, swimsuit, that, total cost, try, try on, yeah

## 单元讲解

本单元围绕"分享一次购物经历"展开。核心句型包括：These earrings are on sale!（这耳环在打折！）、Can I try it on?（我能试穿吗？）、I paid sixty dollars.（我付了60美元。）、The total cost was a hundred.（总共花了一百。）、I got this scarf for free!（我免费得到了这条围巾！）。

词表里有购物词汇（on sale, try on, return, paid, sold, total cost）和衣物（earrings, scarf, swimsuit）。你可以练习：The shop is having a sale. / Everything is on sale. / I tried on a swimsuit. / They sold out of my size.

try on 表示"试穿"。on sale 表示"打折"。for free 表示"免费"。

## Tips

- **on sale** — 打折、促销。搭配：on sale, for sale, a big sale。例句：These earrings are on sale! / Everything is on sale this week. 注意 on sale（打折）和 for sale（出售）不同：on sale 强调降价。

- **try on** — 试穿。搭配：try on a swimsuit, try it on, Can I try this on? 例句：Can I try on this scarf? / I tried on three sizes. 注意 try on 是 separable phrasal verb：try it on / try on the dress。

- **paid / pay** — 付了。pay → paid → paid。搭配：paid sixty dollars, pay with cash, pay for。例句：I paid sixty dollars for the earrings. / How much did you pay? 注意 pay for + 物品。

- **sold / sell** — 卖了。sell → sold → sold。搭配：sold out（卖光）、sell earrings, on sale。例句：They sold out of my size. / This shop sells scarves. 注意 sell 和 buy 方向相反。

- **for free** — 免费。搭配：got it for free, for free, free of charge。例句：I got this scarf for free! / They gave it to me for free. 注意 for free 是口语用法，正式用 free of charge。

- **total cost** — 总费用。搭配：the total cost, total cost was...。例句：The total cost was a hundred dollars. / What's the total cost? 注意 total 是形容词（总的），cost 是名词（费用）。

- **return** — 退货、归还。搭配：return a swimsuit, return policy, I'd like to return this。例句：I want to return these earrings. / Can I return this? 注意 return 在购物语境中是"退货"。

- **earrings / scarf / swimsuit** — 耳环 / 围巾 / 泳衣。搭配：a pair of earrings, a silk scarf, try on a swimsuit。注意 earrings 通常用复数（一对）。swimsuit = swimming suit。

- **size** — 尺寸。搭配：What size? / my size, a large size, a small size。例句：What size do you wear? / They sold out of my size. 注意 size 的常见表达：size S / M / L / XL。

- **line** — 队列、线条。搭配：in line, wait in line, a long line。例句：There was a long line at the shop. / I waited in line for an hour. 注意美式 line = 英式 queue。

- **amazing / perfect** — 惊人的 / 完美的。搭配：amazing deal, perfect fit, absolutely perfect。例句：These earrings are amazing! / The size is perfect. 注意 amazing 比 great 程度更强。

- **yeah** — 是的（口语）。搭配：Yeah! / Yeah, sure. / Yeah, I like it. 注意 yeah 是 yes 的非正式口语形式。写作中用 yes，口语中 yeah 更自然。
