## 单元讲解

本单元的主题是"分享一次购物经历"，是"购物"系列的进阶篇，重点用过去时讲述买到的东西。词表分成四组：商品（earrings, scarf, swimsuit, star）、交易与价格（on sale, for free, paid, got, sold, sell, sixty, hundred, total cost）、试穿与退换（try, try on, return, size, large, small）、以及评价与场景（amazing, perfect, yeah, everything, line, shop, here, that, and, in, on, how can）。拼在一起，就是一段完整的购物分享：Everything was on sale! I got these earrings for sixty dollars. The total cost was amazing.

语法主线是购物的不规则过去式：get → got（买到）、pay → paid（付钱）、sell → sold（卖出）。讲述已经完成的购物：I got a swimsuit. I paid sixty dollars. They sold everything. 另一条主线是 try on（试穿）——代词宾语要放中间：try it on（✗ try on it）。

学完这单元，你能用英语分享一次购物经历：买了什么、花了多少钱、哪里打折、试穿哪个尺码、怎么退货，把购物故事讲得有声有色。

## Tips

- **got / paid / sold / sell** — 购物四动词。get 的过去式 got 表"买到"：I got these earrings.（我买了这副耳环。）pay 的过去式 paid：I paid sixty dollars. sell（卖）的过去式 sold：They sold everything.（他们全卖光了。）注意 sell 与 buy 方向相反：顾客 buy，商家 sell。

- **on sale / for free** — 两个购物短语。on sale 打折促销：Everything is on sale today.（今天全场打折。）for free 免费：I got it for free.（我免费得到的。）注意 ✗ for freely → ✓ for free。

- **try / try on** — try 尝试；try on 试穿（衣物）：Can I try this on? 代词宾语必须放中间：✓ try it on，✗ try on it。试尺码常说：Try on the large size.

- **return / size / large / small** — return 退货：How can I return this scarf?（我怎么退这条围巾？）size 尺码；large 大号、small 小号，也可说 L 和 S。中号是 medium。

- **earrings / scarf / swimsuit** — 三件商品。earrings 耳环（ear + ring），总用复数；scarf 围巾；swimsuit 泳衣（swim + suit）。注意 scarf 的复数是 scarves 或 scarfs。

- **star** — 星星，也指"明星"：a movie star（电影明星）。购物中常见 star 图案：a star necklace（星星项链）。习惯表达：born under a lucky star（天生幸运）。

- **sixty / hundred / total cost** — 数字与金额。sixty 六十；hundred 一百，前面有 a/one 或具体数字时不加 s：a hundred dollars. total cost 是"总价"：What is the total cost?

- **amazing / perfect / yeah** — 评价词。amazing 令人惊叹的（amaze + -ing）：These earrings are amazing! perfect 完美的；yeah 是 yes 的口语形式，购物分享中表达肯定：Yeah, it was a good deal.

- **everything / line / shop / here** — everything 一切、所有东西；line 队伍：The line is long.（队伍很长。）shop 商店（英式，美式常说 store）；here 这里：Everything here is on sale.

- **that / and / in / on / how can** — that 指示代词"那个"：That swimsuit is perfect. and 并列；in 和 on 是介词；how can 询问方式：How can I return this?（我该怎么退这个？）

<quiz-sentence-builder>

1. **中文**：我趁打折买了这副耳环。
   **英文**：I got these earrings on sale.
   > **解析**：got 是 get 的过去式"买到"；on sale 表示"打折"，作方式状语。

2. **中文**：今天全场打折。
   **英文**：Everything is on sale today.
   > **解析**：Everything 作主语按单数对待，用 is；on sale 是固定短语。

3. **中文**：我怎么退这条围巾？
   **英文**：How can I return this scarf?
   > **解析**：How 问方式，can 后接动词原形 return；this scarf 作宾语。

4. **中文**：我花六十美元买了这件泳衣。
   **英文**：I paid sixty dollars for the swimsuit.
   > **解析**：paid 是 pay 的过去式；pay money for something 是固定结构。

5. **中文**：他们卖出了一百条围巾。
   **英文**：They sold one hundred scarves.
   > **解析**：sold 是 sell 的过去式；one hundred 后接复数 scarves。

6. **中文**：试试大号的。
   **英文**：Try on the large size.
   > **解析**：祈使句以 Try on 开头；the large size 作宾语。

7. **中文**：小号的我穿着合适。
   **英文**：The small size fits me.
   > **解析**：The small size 是第三人称单数主语，fit 加 s；me 作宾语。

8. **中文**：她在这里卖泳衣。
   **英文**：She sells swimsuits here.
   > **解析**：She 是第三人称单数，sell 加 s；here 作地点副词。

9. **中文**：总价是一百美元。
   **英文**：The total cost was one hundred dollars.
   > **解析**：讲述过去用 was；one hundred dollars 作表语。

10. **中文**：这个是我免费得到的。
   **英文**：I got this for free.
   > **解析**：got 是过去式；for free 是"免费"的固定短语。

11. **中文**：队伍很长。
   **英文**：The line is long.
   > **解析**：The line 是单数主语，用 is；long 作表语。

12. **中文**：这副耳环太惊艳了！
   **英文**：These earrings are amazing!
   > **解析**：These earrings 是复数主语，用 are；amazing 作表语。

13. **中文**：是的，这家店很棒。
   **英文**：Yeah, the shop is perfect.
   > **解析**：Yeah 是口语肯定词，用逗号隔开；perfect 作表语。

14. **中文**：那件泳衣对我来说太小了。
   **英文**：That swimsuit is too small for me.
   > **解析**：That swimsuit 是单数主语，用 is；too small 表示"太小"，for me 说明对象。

15. **中文**：我能试戴一下这条围巾吗？
   **英文**：Can I try on this scarf?
   > **解析**：Can 引导请求；try on 是"试穿/试戴"的短语动词。

16. **中文**：我该怎么付款？
   **英文**：How can I pay?
   > **解析**：How 问方式；can 后接动词原形 pay。

17. **中文**：她付了一百美元。
   **英文**：She paid a hundred dollars.
   > **解析**：paid 是过去式；a hundred 表示"一百"。

18. **中文**：这里的东西都很便宜。
   **英文**：Everything here is cheap.
   > **解析**：Everything 作主语按单数对待；here 作后置定语修饰 Everything。

19. **中文**：这家店卖围巾和耳环。
   **英文**：The shop sells scarves and earrings.
   > **解析**：The shop 是第三人称单数主语，sell 加 s；and 连接两个并列宾语。

20. **中文**：我们排队等了一个小时。
   **英文**：We stood in line for an hour.
   > **解析**：stood 是 stand 的过去式；stand in line 是"排队"的固定搭配。
