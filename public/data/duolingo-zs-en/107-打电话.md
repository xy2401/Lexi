## 单元讲解

本单元围绕"打电话"展开。核心是电话用语：This is Tom speaking. Who's calling?（我是Tom。您是哪位？）、I'm calling to ask about my order.（我打电话来问一下我的订单。）、Sorry, the line is breaking up.（抱歉，信号不好。）、Can I leave a message?（我能留言吗？）。

词表里有电话词汇（hang up, ring, answer, press, leave a message）和礼貌用语（how may I, one moment, speaking）。你可以练习：The phone rang but nobody answered. / She hung up on me! / Give me a call later. / I got a call from customer service.

this is... speaking 是电话中自我介绍的标准说法。hang up 表示"挂断"。

## Tips

- **this is / speaking** — 我是……（电话用语）。搭配：This is Tom speaking. / This is she. 例句：— Hello? — Hi, this is Anna speaking. 注意电话中不说 ✗ I am...，而说 This is...。

- **who's calling / how may i** — 您是哪位 / 有什么可以帮您。搭配：Who's calling, please? / How may I help you? 例句：Who's calling, please? / How may I help you today? 注意这些是接电话的礼貌用语。

- **hang up / hung up** — 挂断。搭配：hang up the phone, She hung up on me。例句：Don't hang up! / He hung up on me! 注意 hang → hung → hung，hang up on sb = 挂某人电话。

- **ring / rang / answer** — 响铃 / 响了 / 接电话。搭配：the phone rang, answer the phone。例句：The phone rang three times. / Nobody answered. 注意 ring → rang → rung。

- **leave a message / calling to** — 留言 / 打电话来……。搭配：leave a message, Can I leave a message? / calling to ask。例句：Can I leave a message? / I'm calling to ask about my bill. 注意 calling to + 动词原形。

- **break up / broke up** — 信号不好。搭配：You're breaking up, the line broke up。例句：Sorry, you're breaking up. / The call broke up. 注意 break up 在电话中指"信号断断续续"。

- **customer service / press** — 客服 / 按（键）。搭配：call customer service, press 1, press 2。例句：Press 1 for customer service. / I called customer service. 注意 press + 数字（电话菜单）。

- **give me a call / got a call** — 给我打电话 / 接到电话。搭配：Give me a call later, got a call from。例句：Give me a call when you're free. / I got a call from work. 注意 give sb a call = call sb。

- **at the moment / one moment** — 此刻 / 稍等。搭配：at the moment, One moment, please。例句：She's busy at the moment. / One moment, please. 注意 at the moment = right now。

- **never mind / sorry** — 算了 / 抱歉。搭配：Never mind, Sorry about that。例句：— Can I speak to Tom? — He's out. — Never mind. / Sorry, wrong number. 注意 Never mind = 没关系/算了。

- **talk to you soon / all the best** — 回头聊 / 一切顺利。搭配：Talk to you soon! / All the best! 例句：OK, talk to you soon! / All the best! Bye! 注意这些是电话结束时的常用语。

- **text / hang out / then** — 发短信 / 出去玩 / 那么。搭配：send a text, hang out with friends, See you then。例句：I'll text you later. / Let's hang out this weekend. / OK, see you then!
