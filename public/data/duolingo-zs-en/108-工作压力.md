## 单元讲解

本单元围绕"表达工作压力"展开。核心是工作感受表达：My job is really stressful—I work long hours.（我的工作压力真大——工作时间很长。）、It is not relaxing at all.（一点都不轻松。）、I'm not happy with my occupation.（我对我的职业不满意。）、The boss is very strict.（老板很严格。）。

词表里有职业词汇（lawyer, mechanic, player, occupation）和感受词汇（stressful, relaxing, painful, awful）。你可以练习：How was work? / It was awful—especially the hours. / I wasn't able to finish on time. / Anyway, it's time to relax.

stressful 描述事物（工作有压力），stressed 描述人（感到有压力）。

## Tips

- **stressful / relaxing** — 有压力的 / 放松的。搭配：a stressful job, a stressful day, a relaxing evening。例句：My job is very stressful. / Yoga is relaxing. 注意 stressful 修饰事，stressed 修饰人（I'm stressed）。

- **occupation / lawyer / mechanic** — 职业 / 律师 / 机械师。搭配：What's your occupation? / work as a lawyer。例句：What's your occupation? / She's a lawyer. / He works as a mechanic. 注意 occupation 比 job 更正式。

- **hours / on time** — 工作时间 / 准时。搭配：long hours, work long hours, on time。例句：I work long hours. / I need to be on time. 注意 long hours = 长时间工作（不一定指"小时"）。

- **happy with / awful** — 对……满意 / 糟糕的。搭配：happy with my job, an awful day。例句：I'm not happy with my job. / Today was awful. 注意 happy with = satisfied with。

- **strict / necessary** — 严格的 / 必要的。搭配：a strict boss, strict rules, if necessary。例句：My boss is very strict. / Come early if necessary. 注意 strict 搭配 with（strict with sb）。

- **able to / possibly** — 能够 / 可能。搭配：be able to do, possibly, not possibly。例句：I wasn't able to finish on time. / Could you possibly help me? 注意 able to 和 can 意思相近，但能用于更多时态。

- **especially / even** — 尤其 / 甚至。搭配：especially the hours, even worse。例句：I hate Mondays, especially the meetings. / It's even more stressful now. 注意 especially 用于强调某一点。

- **how was / it is not** — 怎么样 / 不是。搭配：How was work? / It is not easy。例句：How was your day? / It is not relaxing at all. 注意 How was...? 用于询问过去的体验。

- **catch / ball / match** — 接住 / 球 / 比赛。搭配：catch the ball, a football match, watch a match。例句：Catch the ball! / Did you watch the match? 注意 catch 在这里是"接住"。

- **poor / painful / unusual** — 可怜的 / 痛苦的 / 不寻常的。搭配：poor thing, a painful experience, unusual behavior。例句：The poor player was injured. / Sitting all day is painful. / That's unusual.

- **anyway / time to / without** — 不管怎样 / 该……了 / 没有。搭配：Anyway, ..., It's time to relax, without a break。例句：Anyway, let's move on. / It's time to go home. / I can't work without a break.

- **really / so / small** — 真的 / 如此 / 小的。搭配：really stressful, so tired, a small problem。例句：It's really stressful. / I'm so tired. / It's just a small problem.
