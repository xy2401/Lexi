## 单元讲解

本单元的主题是"考试"，用过去时和现在时谈论考试经历与课堂场景。词表可以分成四组：考试科目与技能（math, art, listening, speaking, reading, writing, lesson）、课堂物品（blackboard, board, eraser, page, word, example）、考试动作（take, took, answer, forgot, forgot to, do, did）、以及评价与安慰语（right, wrong, well, very well, don't worry, worry, late, how long, on, to, age, all）。组合起来就是一段考试回忆：I took a math test yesterday. The listening part was hard, but I did the reading very well. Don't worry about the answer you forgot.

语法主线有两条。第一是 take a test（参加考试），过去式 took a test；第二是 forget to do（忘记做某事）与 forget doing（忘记做过某事）的区别：I forgot to write my name.（忘了写名字——没写。）另外，listening、speaking、reading、writing 这四个 -ing 形式在本单元作名词使用，指考试的"听、说、读、写"四个部分。

学完这个单元，你能用英语描述参加考试的经过、各个部分的表现，还能用 don't worry 安慰考砸的朋友。

## Tips

- **take / took** — take a test 是"参加考试"的固定搭配，过去式 took：I took the test yesterday. take 还可接 take a lesson（上课）、take notes（做笔记）。

- **forgot / forgot to** — forget 的过去式 forgot（不规则）。forget to do 忘记要做某事（结果没做）；forget doing 忘记做过某事（其实做了）：I forgot to answer the last question.（忘了答最后一题——没答。）

- **listening / speaking / reading / writing** — 听说读写四技能，-ing 形式作名词：the listening part（听力部分）、the writing test（写作考试）。它们也是动名词，可作主语：Reading is important.

- **math / art / lesson** — math 数学（美式，英式 maths）；art 美术；lesson 一节课、一课：Lesson Five（第五课）。科目名前通常不加冠词：I like math.

- **blackboard / board / eraser / page / word** — 课堂物品。blackboard 黑板（black + board）；board 泛指"板"，白板叫 whiteboard；eraser 橡皮擦；page 页码：page ten（第十页）；word 单词。

- **answer / right / wrong** — answer 是"答案"也可作动词"回答"。right 正确的，wrong 错误的：The answer is right/wrong. 搭配：the right answer, a wrong answer。

- **well / very well** — well 是副词"好"，修饰动词：I did well on the test.（考得好。）very well 加强语气。注意 well 不是 good 的形容词形式——good 是形容词，well 是副词（well 作形容词仅表"身体好"）。

- **example** — "例子"，固定短语 for example（例如），常缩写 e.g.。give an example（举例）。

- **don't worry / worry** — worry 是"担心"，don't worry 安慰语"别担心"，常接 about：Don't worry about the test. worry about sb/sth。

- **do / did / late / how long / on / to / age / all** — do 和 did 既是实义动词"做"也是助动词；late 迟到：be late for the test；how long 问时长；on the test（在考试中）；to 表方向；at the age of...（在……岁时）；all 全部：all the questions。

<quiz-sentence-builder>

1. **中文**：我昨天参加了一场数学考试。
   **英文**：I took a math test yesterday.
   > **解析**：take a test 的过去式是 took a test；math 作定语修饰 test。

2. **中文**：听力部分很难。
   **英文**：The listening part was hard.
   > **解析**：listening 作定语修饰 part；was 与单数主语搭配。

3. **中文**：我阅读部分做得很好。
   **英文**：I did the reading part very well.
   > **解析**：did 是 do 的过去式；very well 是副词短语修饰 did。

4. **中文**：别忘了在试卷上写名字。
   **英文**：Don't forget to write your name on the test.
   > **解析**：forget to do 表示"忘记要做某事"；on the test 表示"在试卷上"。

5. **中文**：老师把答案写在黑板上。
   **英文**：The teacher wrote the answer on the blackboard.
   > **解析**：wrote 是 write 的过去式；on the blackboard 表示"在黑板上"。

6. **中文**：请擦掉黑板上的字。
   **英文**：Please clean the board with an eraser.
   > **解析**：祈使句以动词原形开头；with an eraser 表示工具。

7. **中文**：请翻到第十页。
   **英文**：Please open your book to page ten.
   > **解析**：open... to 表示"翻到"；page ten 中数字放名词后。

8. **中文**：这个单词怎么读？
   **英文**：How do you read this word?
   > **解析**：How 提问方式；this word 是单数宾语。

9. **中文**：你能举个例子吗？
   **英文**：Can you give an example?
   > **解析**：give an example 是固定搭配"举例"；example 以元音音素开头，用 an。

10. **中文**：答案是错的。
   **英文**：The answer is wrong.
   > **解析**：wrong 作表语表示"错误的"；主语 The answer 是单数，用 is。

11. **中文**：别担心考试。
   **英文**：Don't worry about the test.
   > **解析**：don't worry 是安慰语；worry about 表示"担心……"。

12. **中文**：考试持续了两个小时。
   **英文**：The test lasted for two hours.
   > **解析**：lasted 是 last 作动词"持续"的过去式；for two hours 表时长。

13. **中文**：你考得怎么样？
   **英文**：How did you do on the test?
   > **解析**：How did + 主语 + do 提问表现；on the test 表示"在考试中"。

14. **中文**：我全部题目都答对了。
   **英文**：I answered all the questions right.
   > **解析**：answered 是过去式；all the questions 表示"所有题目"；right 作副词表"正确地"。

15. **中文**：我上学迟到了。
   **英文**：I was late for school.
   > **解析**：be late for 是固定搭配"……迟到"；was 与 I 搭配。

16. **中文**：美术课很有趣。
   **英文**：The art lesson is fun.
   > **解析**：art 作定语修饰 lesson；主语是单数，用 is。

17. **中文**：他八岁就学会了写字。
   **英文**：He learned to write at the age of eight.
   > **解析**：learned to write 表示"学会写字"；at the age of eight 表示"八岁时"。

18. **中文**：口语考试在周三。
   **英文**：The speaking test is on Wednesday.
   > **解析**：speaking 作定语修饰 test；具体星期前用介词 on。

19. **中文**：请把所有单词写两遍。
   **英文**：Please write all the words twice.
   > **解析**：祈使句用动词原形；twice 表示"两次"。

20. **中文**：写作考试持续了多久？
   **英文**：How long did the writing test last?
   > **解析**：How long 提问时长；did 引导过去时疑问句，last 用原形。

### 1

I ____ a math test yesterday.

- [x] took
- [ ] take
- [ ] taking

> **解析**：yesterday 表过去，用过去式 took；take 原形和 taking 都不符合。

### 2

The ____ part was hard.

- [x] listening
- [ ] listen
- [ ] listens

> **解析**：修饰 part 用动名词 listening（听力）；listen 是动词原形，listens 是第三人称单数。

### 3

I did the reading part very ____.

- [x] well
- [ ] good
- [ ] right

> **解析**：修饰动词 did 用副词 well；good 是形容词，right 语义不符。

### 4

Don't forget to ____ your name.

- [x] write
- [ ] wrote
- [ ] writing

> **解析**：to 后接动词原形 write；wrote 和 writing 都不用于 to 之后。

### 5

The teacher wrote the answer on the ____.

- [x] blackboard
- [ ] eraser
- [ ] word

> **解析**：写答案的地方是黑板 blackboard；eraser 是橡皮，word 是单词。

### 6

Please clean the board with an ____.

- [x] eraser
- [ ] example
- [ ] answer

> **解析**：擦黑板的工具是 eraser（板擦）；example 和 answer 语义都不成立。

### 7

Please open your book to page ____.

- [x] ten
- [ ] tenth's
- [ ] tens

> **解析**：page + 基数词表示页码，选 ten；tenth's 所有格不存在，tens 不合页码表达。

### 8

How do you read this ____?

- [x] word
- [ ] board
- [ ] late

> **解析**：能"读"的是单词 word；board（板）和 late（迟）语义都不成立。

### 9

Can you give an ____?

- [x] example
- [ ] eraser
- [ ] math

> **解析**：give an example 是固定搭配"举例"；eraser 和 math 都不与 give an 搭配。

### 10

The answer is ____.

- [x] wrong
- [ ] wrong's
- [ ] wrongly

> **解析**：is 后接形容词 wrong；wrongly 是副词，wrong's 所有格不存在。

### 11

Don't ____ about the test.

- [x] worry
- [ ] worries
- [ ] worrying

> **解析**：Don't 后接动词原形 worry；worries 和 worrying 都不用于祈使句否定式。

### 12

The test lasted ____ two hours.

- [x] for
- [ ] on
- [ ] at

> **解析**：for + 时间段表示持续时长；on 和 at 都不表时长。

### 13

How did you ____ on the test?

- [x] do
- [ ] did
- [ ] doing

> **解析**：did 后接动词原形 do；did 重复，doing 不用于 did 之后。

### 14

I answered ____ the questions.

- [x] all
- [ ] every
- [ ] much

> **解析**：all the questions 表示"所有题目"；every 后接单数名词，much 修饰不可数。

### 15

I was ____ for school.

- [x] late
- [ ] lately
- [ ] later

> **解析**：be late for 是固定搭配"迟到"；lately 意为"最近"，later 意为"稍后"。

### 16

The ____ lesson is fun.

- [x] art
- [ ] eraser
- [ ] page

### 17

### 20

How long did the writing test ____?

- [ ] lasting

> **解析**：did 后接动词原形 last；lasted 和 lasting 都不用于 did 之后。
