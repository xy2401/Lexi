## 单元讲解

本单元的场景是"旅行"，具体是介绍和询问地点。核心句型是 Where is...? 和 It's here / over there / right here。词表里有大量交通和旅行场所词：airport, bus, hotel, plane, station, subway, taxi, train, port，加上 ticket, passport 这些旅行必备物品。

方位表达是本单元的重点：here（这里）、over there（那边）、right here（正好在这里）。这些词在问路和指路时极其常用。closed 提示可以描述状态：The ticket office is closed.

first name / last name 引入了英文姓名的结构——first name 是名，last name 是姓，和中文"姓在前名在后"的顺序相反。need to 表达需求：I need to go to the airport.

## Tips

- **where is** — 询问地点：Where is the station? / Where is my passport? 缩写：Where's。回答用 It's + 地点：It's over there. / It's right here. 注意 where 引导从句时语序变化：I know where it is（不是 ✗ I know where is it）。

- **here / over there / right here** — 方位副词。here = 这里（近），over there = 那边（远），right here = 正好在这里（强调精确位置）。注意这些词前不加介词：✗ at here → ✓ here。right 在这里是副词"正好、恰好"。

- **airport** — 机场。air + port（港口）= 飞机的"港口"。搭配：at the airport, go to the airport, airport terminal（航站楼）。类似的构词：seaport（海港）。

- **passport** — 护照。pass（通过）+ port（港口）= 通过港口的证件。搭配：show your passport, passport control（护照检查）。注意和 visa（签证）的区别：passport 是本国发的身份证明，visa 是目的国发的入境许可。

- **ticket** — 票。搭配：buy a ticket, a train ticket, ticket office（售票处）。注意 ticket 也可以指交通罚单：get a parking ticket（被贴了停车罚单）。

- **subway** — 地铁（美式）。英式用 underground 或 tube（伦敦地铁的俗称）。搭配：take the subway, subway station。注意 subway 在英式英语中可能指地下通道（过街地道），不是地铁。

- **train / plane / bus / taxi** — 四种交通工具。搭配：take a train / take the bus / take a taxi / take a plane。注意 by + 交通工具时不加冠词：by train, by bus, by plane, by taxi。

- **station** — 车站。搭配：train station, bus station, subway station。注意 station 和 stop 的区别：station 是大站（有建筑），stop 是小站/站点（可能只有一个牌子）。

- **first name / last name** — 英文名在前（first name / given name），姓在后（last name / family name / surname）。中文相反：王小明 → first name: Xiaoming, last name: Wang。填表时特别注意不要搞反。

- **need to** — 需要做某事：I need to buy a ticket. She needs to go. 比 must 语气弱，比 want 语气强。否定：I don't need to go.（不需要去）vs I must not go.（不能去）——意思不同。

- **the** — 定冠词，指特定的、双方都知道的事物：the airport（那个机场）、the ticket（那张票）。中文没有冠词，the 的使用是长期语感培养的过程。基本规则：第一次提到用 a，再次提到用 the。

- **closed** — 关闭的（形容词）。反义词 open。搭配：The store is closed. / closed on Monday（周一休息）。注意 closed 和 close 的区别：close 是动词"关上"（Close the door），closed 是状态"关着的"。
