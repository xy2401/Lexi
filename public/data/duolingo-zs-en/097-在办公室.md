## 单元讲解

本单元围绕"与人谈论工作"展开。核心是电脑操作用语：Click the file.（点击文件。）、Right-click and paste.（右键点击并粘贴。）、Save the document.（保存文档。）、Download the software.（下载软件。）、Copy this page.（复制这一页。）。

词表里有电脑词汇（keyboard, mouse, screen, file, folder, software）和办公用语（sales, salesperson, copy, save）。你可以练习：As usual, the traffic was bad. / By the way, I asked the salesperson. / How long have you worked here? / I suppose we need more directions.

by the way 表示"顺便说一下"。as usual 表示"像往常一样"。

## Tips

- **click / right-click** — 点击 / 右键点击。搭配：click the file, right-click and copy, double-click。例句：Click on the folder. / Right-click and select "Paste". 注意 click 是鼠标左键，right-click 是右键。

- **copy / paste / save** — 复制 / 粘贴 / 保存。搭配：copy the file, paste it here, save the document。例句：Copy this page and paste it into the folder. / Don't forget to save! 注意这些是电脑操作的基本动词。

- **file / folder** — 文件 / 文件夹。搭配：open a file, save the file, create a folder, in the folder。例句：Save the file in this folder. / Click the file to open it. 注意 file 是单个文件，folder 是装文件的文件夹。

- **keyboard / mouse** — 键盘 / 鼠标。搭配：type on the keyboard, click the mouse, a wireless mouse。例句：Use the keyboard to type. / Click the mouse to select. 注意 mouse 的复数是 mice（和老鼠一样）。

- **download / software** — 下载 / 软件。搭配：download the software, download a file, install software。例句：You need to download the software. / The software is free. 注意 software 不可数（不说 ✗ a software）。

- **double-sided / single-sided** — 双面的 / 单面的。搭配：double-sided printing, single-sided copy。例句：Print it double-sided to save paper. / I need a single-sided copy. 注意 -sided 表示"……面的"。

- **by the way** — 顺便说一下。搭配：By the way, ... / BTW（缩写）。例句：By the way, I asked about the sales meeting. / BTW, the traffic was bad. 注意 by the way 用于引入新话题。

- **as usual** — 像往常一样。搭配：as usual, As usual, ... 例句：As usual, the traffic was terrible. / He was late, as usual. 注意 as usual 通常放在句首或句末。

- **sales / salesperson** — 销售 / 销售员。搭配：sales department, a salesperson, sales meeting。例句：She works in sales. / I asked the salesperson. 注意 salesperson 不分性别（比 salesman / saleswoman 更中性）。

- **i suppose** — 我想、我猜。搭配：I suppose so. / I suppose you're right. 例句：I suppose we need more time. / — Is it ok? — I suppose so. 注意 I suppose 表示不太确定的同意。

- **alarm clock / traffic** — 闹钟 / 交通。搭配：set the alarm clock, the alarm clock went off, bad traffic, traffic jam。例句：My alarm clock didn't go off! / The traffic was bad, as usual.

- **how long / told / asked** — 多久 / 告诉了 / 问了。搭配：How long have you worked here? / told me, asked me。例句：How long have you had this job? / She told me to save the file. / I asked the salesperson.

<quiz-sentence-builder>

1. **中文**：用鼠标右键点击以复制并粘贴文件。  
   **英文**：Right-click on the mouse to copy and paste the file.
   > **解析**：right-click 表示“右键点击”；mouse 意为“鼠标”；copy and paste 表示“复制并粘贴”。

2. **中文**：别忘了将你的文档保存在新文件夹里。  
   **英文**：Don't forget to save your document in the new folder.
   > **解析**：folder 表示“文件夹”；save 意为“保存”。

3. **中文**：你需要从网站上下载办公软件。  
   **英文**：You need to download the office software from the website.
   > **解析**：software 表示“软件”（不可数）；download 意为“下载”。

4. **中文**：请使用双面纸张打印这份报告。  
   **英文**：Please print this report using double-sided paper.
   > **解析**：double-sided 表示“双面的”。

5. **中文**：顺便问一下，你昨天和销售经理谈过了吗？  
   **英文**：By the way, did you talk to the sales manager yesterday?
   > **解析**：by the way 用于转移话题或补充询问，表示“顺便问一下/顺便说一句”。

6. **中文**：像往常一样，拥堵的交通导致我上班迟到了。  
   **英文**：As usual, heavy traffic caused me to be late for work.
   > **解析**：as usual 表示“像往常一样/照例”；traffic 意为“交通”。

7. **中文**：我询问了销售人员关于这台笔记本电脑的价格。  
   **英文**：I asked the salesperson about the price of the laptop.
   > **解析**：salesperson 表示“销售员/售货员”；asked 意为“询问了”。

8. **中文**：使用无线键盘和鼠标来操作屏幕。  
   **英文**：Use the wireless keyboard and mouse to operate the screen.
   > **解析**：keyboard 表示“键盘”；mouse 意为“鼠标”。

9. **中文**：点击绿色图标打开机密文件。  
   **英文**：Click the green icon to open the confidential file.
   > **解析**：click 表示“点击”；file 意为“文件”。

10. **中文**：复制这个重要页面并发送给团队。  
   **英文**：Copy this important page and send it to the team.
   > **解析**：copy 表示“复制”；page 意为“页面/页”。

11. **中文**：你在这家公司工作多久了？  
   **英文**：How long have you been working at this company?
   > **解析**：How long 用来询问时间长度，意为“多久/多长时间”。

12. **中文**：我想我们应该在星期五之前完成这个项目。  
   **英文**：I suppose we should finish this project before Friday.
   > **解析**：I suppose 表示“我想/我猜/我推测”（表达委婉的看法）。

13. **中文**：我的闹钟今天早上没有响。  
   **英文**：My alarm clock failed to ring this morning.
   > **解析**：alarm clock 表示“闹钟”。

14. **中文**：将复制的文本粘贴到文档窗口中。  
   **英文**：Paste the copied text into the document window.
   > **解析**：paste 表示“粘贴”。

15. **中文**：他在国际销售部门工作。  
   **英文**：He works in the international sales department.
   > **解析**：sales 表示“销售/销售额”。

16. **中文**：经理告诉我们要遵循明确的指示说明。  
   **英文**：The manager told us to follow the clear directions.
   > **解析**：directions 表示“指示/说明/方向”；told 是 tell 的过去式。 

17. **中文**：我更喜欢用于官方演示的单面复印件。  
   **英文**：I prefer single-sided copies for official presentations.
   > **解析**：single-sided 表示“单面的”。

18. **中文**：我们计划下个月搬到一个更大的办公室。  
   **英文**：We plan to move to a larger office next month.
   > **解析**：move 表示“搬迁/移动”。

19. **中文**：我们在会议开始时阅读了这份报告。  
   **英文**：We read the report at the beginning of the meeting.
   > **解析**：at the beginning of 表示“在……开始时”。

20. **中文**：我的电脑鼠标对点击没有反应。  
   **英文**：My computer mouse is not responding to clicks.
   > **解析**：mouse 表示“（电脑）鼠标”。
