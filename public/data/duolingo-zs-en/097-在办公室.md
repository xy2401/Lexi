## 单元讲解

本单元的主题是"与人谈论工作"。词表可以分成四组：电脑操作动词（click, right-click, copy, paste, save, download, move）、办公名词（file, folder, page, keyboard, mouse, software, directions）、职场与通勤（job, work, sales, salesperson, traffic, alarm clock, take）以及表达态度的短语（as usual, by the way, i suppose, how long, need, wanted, asked, told, ok, what, beginning, single-sided, double-sided）。拼在一起，就是办公室一天的写照：My alarm clock rings. I take the bus through heavy traffic. I click, copy, paste and save files all day.

语法主线有两条。一是祈使句——电脑操作的指令都用动词原形开头：Click the folder. Save the file. 二是转述与意愿动词的过去式：asked（问了）、told（告诉）、wanted（想要），它们常接人 + to do 结构：He told me to move the folder. 另一条线索是 how long 引导的时间提问：How long have you worked here?

学完这些词，你能用英语描述办公室日常、听懂并执行电脑操作指令，还能和同事聊聊工作与通勤。

## Tips

- **click / right-click** — 电脑操作的两个基本动作。click 左键单击：Click the file. right-click 右键单击：Right-click and paste. 构词：right-（右）+ click（点击）。祈使句直接用动词原形开头。

- **copy / paste / save** — 办公三件套：复制、粘贴、保存。固定搭配 copy and paste。save 还有"挽救、节省"的意思：Save time by using shortcuts. 记忆技巧：Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+S 保存。

- **download / move** — download 下载，down（下）+ load（装载）；move 移动：Move the file into the folder. 注意方向介词 into 表示"移入"。

- **file / folder / page** — 电子与纸质文件词。file 文件，folder 文件夹（folder = fold 折叠 + -er，原指折叠起来的纸夹），page 页。搭配：a page of the file.

- **keyboard / mouse** — 键盘和鼠标。mouse 一词多义：老鼠 → 鼠标，因外形得名，复数可写 mice 或 mouses。keyboard = key（键）+ board（板）。

- **software** — 软件，soft（软）+ ware（器物），与 hardware（硬件）相对。注意 software 是不可数名词：✗ a software → ✓ a piece of software / some software.

- **asked / told / wanted** — 三个过去式动词，都是接人再加内容的结构。ask sb for sth（向某人要某物）；tell sb to do sth（叫某人做某事）；want to do sth（想做某事）。原形 ask/tell/want 的变化要记牢：tell → told 是不规则变化。

- **need / take** — need 表需求，后接名词或 to do：I need to download the software. take 在通勤场景常用：take the bus（乘公交）。

- **how long / what** — how long 问时长：How long have you worked here? what 问事物或职业：What is your job? 注意 how long 问"多久"，how far 问距离，别混用。

- **job / work / sales / salesperson** — 工作四词。job 是可数名词"一份工作"；work 不可数，泛指工作；sales 指销售业务或业绩；salesperson = sales + person 销售员。✗ I have a good work. → ✓ I have a good job.

- **traffic / alarm clock** — 通勤二词。traffic 交通，不可数：The traffic was heavy. alarm clock 闹钟，早起上班全靠它。习惯表达：be stuck in traffic（堵车）。

- **as usual / by the way / i suppose** — 三个话语短语。as usual 像往常一样；by the way 顺便说一句，用于转换话题；I suppose 我猜想，语气不太确定：I suppose the report is ready.

- **single-sided / double-sided / directions / beginning / ok** — 打印与杂项。single-sided 单面，double-sided 双面，-sided 表示"……面的"；directions 用复数表示"说明、指示"；beginning 开头，与 end 相对；ok 万能应答词。

<quiz-sentence-builder>

1. **中文**：点击文件夹打开它。
   **英文**：Click the folder to open it.
   > **解析**：祈使句以动词原形 Click 开头；to open 是不定式作目的状语。

2. **中文**：请把文件保存到电脑上。
   **英文**：Please save the file on the computer.
   > **解析**：Please 引导祈使句；on the computer 是地点状语。

3. **中文**：右键点击然后粘贴文本。
   **英文**：Right-click and then paste the text.
   > **解析**：and 连接两个祈使动词 Right-click 与 paste；then 表示先后顺序。

4. **中文**：我需要下载这个软件。
   **英文**：I need to download this software.
   > **解析**：need 后接不定式 to download；software 是不可数名词，前面不加 a。

5. **中文**：她问我要一份复印件。
   **英文**：She asked me for a copy.
   > **解析**：ask sb for sth 是固定结构，asked 是 ask 的过去式；a copy 是可数名词短语。

6. **中文**：他告诉我会议九点开始。
   **英文**：He told me that the meeting starts at nine.
   > **解析**：tell sb that… 是转述结构，told 是 tell 的过去式；that 引导宾语从句。

7. **中文**：我想把这份工作做得更好。
   **英文**：I wanted to do the job better.
   > **解析**：wanted 是 want 的过去式，后接不定式 to do；better 是比较级作状语。

8. **中文**：你在这里工作多久了？
   **英文**：How long have you worked here?
   > **解析**：How long 问时长，搭配现在完成时 have worked，表示从过去持续到现在。

9. **中文**：像往常一样，交通很堵。
   **英文**：As usual, the traffic was heavy.
   > **解析**：As usual 作插入语放在句首；traffic 是不可数名词，用 heavy 形容拥堵。

10. **中文**：顺便说一下，我的闹钟坏了。
    **英文**：By the way, my alarm clock is broken.
    > **解析**：By the way 用于转换话题；is broken 表示"坏了"的状态。

11. **中文**：请把这页双面打印。
    **英文**：Print this page double-sided, please.
    > **解析**：祈使句以 Print 开头；double-sided 作方式状语说明打印方式。

12. **中文**：我想这是正确的答案。
    **英文**：I suppose this is the right answer.
    > **解析**：I suppose 后接省略 that 的宾语从句；this 作从句主语。

13. **中文**：把文件移到文件夹里。
    **英文**：Move the file into the folder.
    > **解析**：祈使句以 Move 开头；into 表示移动方向"进入"。

14. **中文**：按照屏幕上的说明操作。
    **英文**：Follow the directions on the screen.
    > **解析**：Follow 是祈使动词；directions 用复数表示多条操作说明。

15. **中文**：销售员今天早上打电话来了。
    **英文**：The salesperson called this morning.
    > **解析**：called 是 call 的过去式；this morning 是过去时间状语。

16. **中文**：这个月的销售业绩很好。
    **英文**：Sales are good this month.
    > **解析**：Sales 作复数名词，谓语用 are；this month 作时间状语。

17. **中文**：好的，我现在就做。
    **英文**：Ok, I will do it now.
    > **解析**：Ok 是应答词；will do 表示即将执行的动作。

18. **中文**：会议从一开始就很长。
    **英文**：The meeting was long from the beginning.
    > **解析**：from the beginning 是"从一开始"的固定短语；was 搭配单数主语。

19. **中文**：你想要单面的还是双面的？
    **英文**：Do you want it single-sided or double-sided?
    > **解析**：一般疑问句用 Do 开头；or 连接两个选择项。

20. **中文**：在开始之前复制这一页。
    **英文**：Copy this page before you begin.
    > **解析**：祈使句 Copy 开头；before 引导时间状语从句，从句用一般现在时表将来。

### 1

Please ____ the file before you leave.

- [x] save
- [ ] click
- [ ] told

> **解析**：离开前要"保存"文件，用 save；click 只是点击，told 是过去式动词，语法与语义都不符。

### 2

Right-click and ____ the text.

- [x] paste
- [ ] asked
- [ ] traffic

> **解析**：右键之后的动作是粘贴 paste；asked 是过去式，traffic 是名词，都不成立。

### 3

I need to ____ this software.

- [x] download
- [ ] single-sided
- [ ] page

> **解析**：need to 后接动词原形 download；single-sided 是形容词，page 是名词，都不能接在 to 后作谓语。

### 4

She ____ me for a copy.

- [x] asked
- [ ] told
- [ ] saved

> **解析**：ask sb for sth 是固定结构；tell 搭配 to do，不接 for；saved 不能接 sb for sth。

### 5

He ____ everyone the news this morning.

- [x] told
- [ ] asked
- [ ] moved

> **解析**：tell sb sth 是双宾结构，told 正确；ask 不能接"人 + 消息"双宾，moved 语义不通。

### 6

How ____ have you worked here?

- [x] long
- [ ] usual
- [ ] way

> **解析**：How long 问时长是固定搭配；usual 和 way 不能与 how 构成问时长的短语。

### 7

- [x] traffic

> **解析**：形容拥堵用 traffic；keyboard 和 folder 不能用 heavy 形容通勤状况。

### 11

### 12

I ____ this is the right answer.

> **解析**：I suppose 表示"我想"，后接从句；save 和 copy 不能接 that 从句表猜测。

### 13

### 14
