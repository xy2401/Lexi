## 单元讲解

本单元围绕"描述你的工作安排"展开。核心句型包括：Is it all right if I work from home?（我在家办公可以吗？）、Make sure the printer works.（确保打印机能用。）、I shouldn't wear pajamas all the time.（我不应该一直穿睡衣。）、These days, I work online.（最近我在线工作。）。

词表里有办公设备（printer, screen, battery, document）和居家词汇（home office, pajama, tie）。你可以练习：My battery is dead. / I need to print a document. / She works in her home office. / Put on a tie for the meeting. / I can't receive the invitation.

these days 表示"最近/如今"。the rest 表示"剩余的"。

## Tips

- **is it all right if** — ……可以吗？（礼貌请求）。搭配：Is it all right if I leave? / Is it all right if I work from home? 例句：Is it all right if I take a break? 注意比 Can I...? 更礼貌、更委婉。

- **make sure** — 确保。搭配：make sure that, make sure to do, make sure it works。例句：Make sure the printer is on. / Make sure to save the document. 注意 make sure 后接 that 从句或 to do。

- **these days** — 最近、如今。搭配：these days, work online these days。例句：These days, everyone works online. / I've been busy these days. 注意 these days 通常用于描述当前趋势或近期状况。

- **home office** — 家庭办公室。搭配：work in a home office, set up a home office。例句：I work in my home office. / She has a nice home office. 注意 home office 也可以指公司总部（英式）。

- **battery / dead** — 电池 / 没电的。搭配：the battery is dead, charge the battery, battery life。例句：My laptop battery is dead. / I need to charge my battery. 注意 dead 在这里表示"没电了"。

- **printer / print / document** — 打印机 / 打印 / 文件。搭配：print a document, the printer is slow, send a document。例句：I need to print this document. / The printer won't work. 注意 document 是正式文件。

- **pajama / tie / put on** — 睡衣 / 领带 / 穿上。搭配：wear pajamas, put on a tie, put on clothes。例句：Don't wear pajamas to the meeting! / Put on a tie. 注意 pajamas 通常用复数。put on 强调"穿上"的动作。

- **receive / invitation** — 收到 / 邀请。搭配：receive an invitation, receive an email, receive a document。例句：I received a meeting invitation. / Did you receive my email? 注意 receive 强调"收到"，accept 强调"接受"。

- **screen / online** — 屏幕 / 在线。搭配：look at the screen, a big screen, work online, online meeting。例句：I stare at the screen all day. / We have online meetings. 注意 online 既是形容词也是副词。

- **shouldn't / won't / can't** — 不应该 / 不会 / 不能。搭配：shouldn't wear pajamas, won't work, can't print。例句：You shouldn't work all the time. / The printer won't start. / I can't receive files.

- **the rest / all the time** — 剩余的 / 一直。搭配：the rest of the day, the rest of the week, work all the time。例句：I'll do the rest tomorrow. / She's online all the time. 注意 the rest of + 名词。

- **weekday / quiet** — 工作日 / 安静的。搭配：on weekdays, a quiet room, keep quiet。例句：I work from home on weekdays. / I need a quiet place to work. 注意 weekday 和 weekend 对应。
