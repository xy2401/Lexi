## 单元讲解

本单元的主题是"描述你的工作安排"，场景是在家办公（work from home）。词表分成四组：办公场所与设备（home office 家庭办公室, printer 打印机, screen 屏幕, battery 电池, document 文件, print 打印, online 在线）、工作状态与安排（break 休息, early 提早, weekday 工作日, these days 这些天, all the time 一直, quiet 安静, slow 慢, the rest 剩余的, moment 片刻, all, well）、着装与请求（pajama 睡衣, tie 领带, put on 穿上, is it all right if 如果……可以吗, make sure 确保, invitation 邀请, receive 收到）、以及情绪与义务（can't 不能, shouldn't 不应该, won't 不会, bother 打扰, unhappy 不开心, herself 她自己, forty 四十）。拼在一起，就是一段在家办公的日常：I work from my home office these days. My battery is dead and the printer is slow. I shouldn't work in my pajamas all the time.

语法主线是情态动词表义务与禁止：shouldn't（不应该）：You shouldn't work in pajamas.（你不该穿睡衣工作。）can't（不能）表能力或许可的否定；won't（不会）表将来否定。另一条主线是请求许可的 is it all right if：Is it all right if I take a break?（我休息一下可以吗？），与上一单元的 is it ok if 同义。还有 make sure（确保）后接从句：Make sure the printer is on.（确保打印机开着。）

学完这单元，你能用英语描述在家办公的安排与困扰：设备出了什么问题、穿什么上班、何时休息，还能礼貌地提出请求、表达情绪。

## Tips

- **home office / online** — home office 家庭办公室（home + office）；online 在线的、网上的：an online meeting（线上会议）。在家办公常说 work from home。
- **printer / print / screen / battery** — printer 打印机（print + -er 表机器）；print 打印；screen 屏幕；battery 电池：My battery is dead.（电池没电了。）dead 此处表"没电、耗尽"。
- **document / receive / invitation** — document 文件、文档；receive 收到（比 get 正式）；invitation 邀请：I received an invitation.（我收到了邀请。）
- **break / early / weekday / these days / all the time** — break 休息：take a break（休息一下）；early 提早；weekday 工作日（周一到周五），与 weekend 相对；these days 这些天、近来；all the time 一直、总是。
- **quiet / slow / the rest / moment** — quiet 安静的：a quiet room（安静的房间）；slow 慢的：The printer is slow.（打印机很慢。）the rest 剩余的：the rest of the day（剩下的一天）；moment 片刻：Just a moment.（稍等片刻。）
- **pajama / tie / put on** — pajama 睡衣（常用复数 pajamas）；tie 领带；put on 穿上（动作），与 wear（状态）相对：Put on your tie.（戴上领带。）
- **is it all right if / make sure** — Is it all right if I leave early?（我早走可以吗？）请求许可。make sure 确保：Make sure you receive the document.（确保你收到文件。）
- **can't / shouldn't / won't** — can't 不能（能力/许可否定）；shouldn't 不应该（建议否定）；won't 不会（将来否定）。注意三者语气不同。
- **bother / unhappy / herself** — bother 打扰：Don't bother me.（别打扰我。）unhappy 不开心（un- 否定前缀）；herself 她自己（反身代词）。
- **forty / all / well** — forty 四十；all 全部；well 好（副词），也可作语气词"嗯"：Well, I can't work today.（嗯，我今天没法工作。）

<quiz-sentence-builder>

1. **中文**：这些天我在家庭办公室工作。
   **英文**：I work from my home office these days.
   > **解析**：work from 表"从……工作"；these days 表"近来"。

2. **中文**：我的电池没电了。
   **英文**：My battery is dead.
   > **解析**：My battery 是单数主语，用 is；dead 表"没电"，作表语。

3. **中文**：打印机很慢。
   **英文**：The printer is slow.
   > **解析**：The printer 是单数主语，用 is；slow 作表语。

4. **中文**：帮我打印这份文件。
   **英文**：Please print this document for me.
   > **解析**：print 是祈使句动词原形；this document 作宾语。

5. **中文**：屏幕太暗了。
   **英文**：The screen is too dim.
   > **解析**：The screen 是单数主语，用 is；too dim 表"太暗"。

6. **中文**：我休息一下可以吗？
   **英文**：Is it all right if I take a break?
   > **解析**：Is it all right if 表请求许可；if 引导从句。

7. **中文**：确保你收到了邀请。
   **英文**：Make sure you receive the invitation.
   > **解析**：Make sure 表"确保"，后接从句；receive 表"收到"。

8. **中文**：你不该一直穿睡衣工作。
   **英文**：You shouldn't work in your pajamas all the time.
   > **解析**：shouldn't 表"不应该"；in your pajamas 表"穿睡衣"。

9. **中文**：戴上你的领带。
   **英文**：Put on your tie.
   > **解析**：Put on 是"穿上"的短语动词，祈使句用原形；your tie 作宾语。

10. **中文**：我今天没法工作。
   **英文**：I can't work today.
   > **解析**：can't 表"不能"；work 用原形，today 是时间状语。

11. **中文**：她不会来开会。
   **英文**：She won't come to the meeting.
   > **解析**：won't 是 will not 的缩写，表将来否定；come 用原形。

12. **中文**：别打扰我。
   **英文**：Don't bother me.
   > **解析**：否定祈使句用 Don't + bother；me 作宾语。

13. **中文**：我需要一间安静的房间。
   **英文**：I need a quiet room.
   > **解析**：quiet 修饰 room 表"安静的"；a quiet room 作宾语。

14. **中文**：今天是工作日。
   **英文**：Today is a weekday.
   > **解析**：Today 是主语，用 is；a weekday 作表语。

15. **中文**：我想早点结束。
   **英文**：I want to finish early.
   > **解析**：want to 后接动词原形 finish；early 作副词修饰 finish。

16. **中文**：剩下的一天我要休息。
   **英文**：I'll rest for the rest of the day.
   > **解析**：I'll 是 I will 的缩写；the rest of the day 表"剩下的一天"。

17. **中文**：稍等片刻。
   **英文**：Just a moment, please.
   > **解析**：Just a moment 表"稍等片刻"；please 使语气礼貌。

18. **中文**：她为自己感到不开心。
   **英文**：She feels unhappy about herself.
   > **解析**：feels 是 feel 的第三人称单数；about herself 表"关于她自己"。

19. **中文**：他四十岁了，还在学新东西。
   **英文**：He is forty and still learning new things.
   > **解析**：forty 表年龄；is learning 是现在进行时。

20. **中文**：嗯，好吧，我参加线上会议。
   **英文**：Well, I'll join the online meeting.
   > **解析**：Well 是语气词，用逗号隔开；I'll join 表将来。
